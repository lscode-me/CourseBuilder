# Security & Privacy - Задания

---

## Задание 1: De-identification

Напишите функцию для де-идентификации медицинских данных.

**Требования:**
- Удалить все 18 HIPAA идентификаторов
- Сохранить полезные агрегированные данные
- Тестовый dataset

---

## Задание 2: Audit Logger

Создайте систему audit logging.

**Требования:**
- Логировать все доступы к PHI
- Поиск по логам
- Alerts для подозрительной активности

---

## Задание 3: RBAC System

Реализуйте Role-Based Access Control.

**Требования:**
- Роли: Doctor, Nurse, Admin, Billing
- Permissions для каждой роли
- Проверка доступа

---

## Задание 4: Encryption Service

Создайте сервис для шифрования PHI.

**Требования:**
- Encrypt/decrypt функции
- Key management
- Field-level encryption

---

## Задание 5: Breach Detection

Реализуйте систему обнаружения breach.

**Требования:**
- Анализ audit logs
- Обнаружение аномалий
- Alerts
