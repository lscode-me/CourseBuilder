## Answers

1. **B** - Health Level 7
2. **B** - REST API и JSON (также XML)
3. **C** - | (pipe) разделитель
4. **C** - Patient resource
5. **B** - Медицинские изображения
6. **B** - Международная классификация болезней
7. **C** - Лабораторные и клинические наблюдения
8. **B** - Визит/госпитализация
9. **B** - Обмен данными между системами
10. **B** - Систематизированная номенклатура медицины
11. **B** - OBX (Observation Result)
12. **C** - MedicationRequest (назначение)
13. **C** - Гемоглобин (это лабораторный анализ, не vital sign)
14. **B** - POST (для создания)
15. **B** - Endocrine diseases (эндокринные заболевания)
16. **C** - ~350,000 концепций
17. **B** - Hemoglobin (гемоглобин)
18. **B** - Medical Record Number (номер медицинской карты)
19. **B** - Для предотвращения назначения опасных препаратов
20. **B** - Обмен медицинской информацией между организациями
21. **B** - Поступление/госпитализация (Admit)
22. **C** - {"reference": "Patient/patient-123"}
23. **C** - Initial encounter (первичное обращение)
24. **B** - SNOMED — онтология с отношениями, ICD-10 — классификация
25. **B** - ^ (caret) для компонентов
26. **C** - R4 (Release 4)
27. **C** - ~70,000 кодов
28. **C** - 6 частей (Component, Property, Timing, System, Scale, Method)
29. **B** - Неправильный формат references
30. **B** - HL7 v2 (legacy системы обычно используют HL7 v2)
