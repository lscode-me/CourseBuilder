# Медицинская Терминология - Задания

---

## Задание 1: Парсинг HL7 v2

Распарсите HL7 v2 сообщение и извлеките данные пациента.

**Требования:**
- Извлечь Patient ID, Name, DOB, Gender
- Обработать компоненты имени
- Вывести в структурированном виде

---

## Задание 2: FHIR Patient Resource

Создайте FHIR Patient resource из структурированных данных.

**Требования:**
- Использовать fhir.resources библиотеку
- Включить: identifier, name, gender, birthDate, address
- Сериализовать в JSON

---

## Задание 3: FHIR API Client

Напишите клиент для работы с FHIR сервером.

**Требования:**
- Создать пациента (POST)
- Получить пациента (GET)
- Поиск пациентов по имени
- Обработка ошибок

---

## Задание 4: HL7 to FHIR Конвертер

Конвертируйте HL7 v2 ADT сообщение в FHIR Patient.

**Требования:**
- Парсить HL7 PID сегмент
- Создать FHIR Patient
- Маппинг всех полей

---

## Задание 5: ICD-10 Lookup

Создайте утилиту для поиска ICD-10 кодов.

**Требования:**
- Загрузить базу ICD-10 кодов
- Поиск по коду или описанию
- Вернуть детальную информацию

---

## Задание 6: FHIR Observation

Создайте FHIR Observation resource для vital signs.

**Требования:**
- Blood pressure (систолическое/диастолическое)
- Использовать LOINC коды
- Связать с пациентом

---

## Задание 7: HL7 Validator

Напишите валидатор HL7 v2 сообщений.

**Требования:**
- Проверить структуру
- Обязательные сегменты
- Формат полей
- Вывести ошибки валидации

---

## Задание 8: FHIR Bundle

Создайте FHIR Bundle с несколькими ресурсами.

**Требования:**
- Patient + Encounter + Observation
- Правильные ссылки между ресурсами
- Тип Bundle: transaction
