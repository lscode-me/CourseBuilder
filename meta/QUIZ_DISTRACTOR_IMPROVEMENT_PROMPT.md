# Промпт для улучшения дистракторов в квизах

## 🎯 Назначение

Этот документ содержит промпт для улучшения качества дистракторов (неправильных вариантов ответов) в квизах курсов Taxes и Finance. 

**Проблема:** Вопросы в квизах интересные и важные, но дистракторы слишком очевидные. Они часто выдают себя:
- **Абсурдностью** — содержат явно нелепые утверждения
- **Длиной** — правильный ответ часто самый длинный и детальный, а неправильные — короткие и простые
- **Слишком очевидной неправильностью** — содержат фразы типа "разницы нет", "только для богатых", "все одинаково"

**Цель промпта:** создать дистракторы, которые:
- Правдоподобны и реалистичны
- Имеют примерно одинаковую длину с правильным ответом
- Основаны на типичных ошибках и заблуждениях
- Требуют реального понимания материала для исключения

## Проблемы текущих дистракторов

### 1. Абсурдные дистракторы
**Плохо:**
```
A) Налоги платят только те, кто живет на первом этаже
B) Все налогоплательщики платят фиксированную сумму в рублях
C) Единая процентная ставка применяется ко всем доходам независимо от их размера ✓
D) Ставка налога растет пропорционально доходу
```

**Хорошо:**
```
A) Единая процентная ставка применяется только к доходам выше определенного порога
B) Ставка налога зависит от типа дохода (зарплата, дивиденды, аренда), но не от размера
C) Единая процентная ставка применяется ко всем доходам независимо от их размера ✓
D) Ставка налога растет пропорционально доходу
```

### 2. Дистракторы, которые выдают себя длиной
**Плохо:**
```
A) Минимизация расходов компании
B) Увеличение выручки любой ценой
C) Максимизация стоимости компании для владельцев при управлении рисками ✓
D) Соблюдение всех бухгалтерских стандартов
```

**Хорошо:**
```
A) Минимизация расходов компании при сохранении текущего уровня доходов
B) Увеличение выручки любой ценой, включая принятие высоких рисков
C) Максимизация стоимости компании для владельцев при управлении рисками ✓
D) Соблюдение всех бухгалтерских стандартов и налоговых требований
```

### 3. Слишком очевидные дистракторы
**Плохо:**
```
A) Разницы нет, это синонимы
B) Сбор всегда больше по размеру, чем налог
C) Сбор взимается за совершение юридически значимого действия, налог — при наличии объекта налогообложения ✓
D) Сбор платят только юридические лица, налог — физические
```

**Хорошо:**
```
A) Сбор и налог отличаются только названием, но имеют одинаковую правовую природу
B) Сбор всегда больше по размеру, чем налог, так как включает административные расходы
C) Сбор взимается за совершение юридически значимого действия, налог — при наличии объекта налогообложения ✓
D) Сбор платят только юридические лица, налог — только физические лица
```

## Правила создания качественных дистракторов

### ✅ Что делать

1. **Использовать типичные ошибки и заблуждения**
   - Ошибки в понимании концепций
   - Перепутывание похожих терминов
   - Неправильное применение правил
   - Частично правильные, но неполные утверждения

2. **Обеспечить одинаковую длину вариантов**
   - Правильный ответ не должен быть заметно длиннее остальных
   - Все варианты должны быть примерно одинаковой длины (разница не более 20-30%)
   - Если правильный ответ длинный, расширить дистракторы до похожей длины

3. **Делать дистракторы правдоподобными**
   - Использовать реальные термины и концепции из курса
   - Основать на реальных заблуждениях студентов
   - Избегать явно абсурдных утверждений

4. **Использовать частично правильные утверждения**
   - Дистрактор может быть правильным в одной части, но неправильным в другой
   - Дистрактор может быть правильным для другого контекста или ситуации
   - Дистрактор может быть правильным, но неполным ответом

5. **Базировать на типичных ошибках**
   - Перепутывание похожих концепций (например, прямые vs косвенные налоги)
   - Неправильное применение формул или правил
   - Непонимание причинно-следственных связей

### ❌ Чего избегать

1. **Абсурдных утверждений**
   - "Только если автомобиль красного цвета"
   - "Налоги платят только те, кто живет на первом этаже"
   - "Умение говорить на государственном языке"

2. **Слишком очевидных неправильных ответов**
   - "Разницы нет, это синонимы"
   - "Все одинаково справедливы"
   - "Только для богатых/бедных"
   - **Избегать слова "Только" в начале дистракторов** — это часто является подсказкой, что ответ неправильный, так как правильные ответы обычно более комплексные и не начинаются с "Только"

3. **Сильного различия в длине**
   - Правильный ответ не должен быть в 2-3 раза длиннее дистракторов
   - Все варианты должны быть примерно одинаковой длины

4. **Использования юмора или сарказма**
   - Дистракторы должны быть серьезными и профессиональными
   - Избегать шуток или иронии

5. **Слишком простых дистракторов**
   - Дистракторы должны требовать понимания материала
   - Не использовать варианты, которые можно исключить без знания темы

6. **Слова "Только" в начале дистракторов**
   - Избегать формулировок типа "Только X" в начале дистрактора
   - Это часто является подсказкой, что ответ неправильный
   - Вместо "Только X" использовать разнообразные подходы в зависимости от контекста:
     * **Перепутывание похожих концепций:** "X, который является характеристикой Y" (когда X относится к другой концепции)
       - Пример: "Только аналитическое мышление" → "Аналитическое мышление, которое используется для разложения проблем на части" (когда правильный ответ — несколько видов мышления)
     * **Частично правильный ответ для другого контекста:** "X, который применяется в ситуации Y" или "X, измеряемый через Z"
       - Пример: "Только творческие способности" → "Творческие способности, которые измеряются через специальные тесты креативности"
     * **Неправильное применение правила или метода:** "X, который используется для Z" (когда X используется для другого)
       - Пример: "Только интуиция" → "Интуиция, которая является основным способом принятия решений в сложных ситуациях"
     * **Более естественные формулировки:** "X, который..." или "X, основанный на..." или "X, измеряемый через..."
       - Пример: "Только IQ-тесты" → "IQ-тесты, которые являются единственным надёжным способом измерения интеллекта"
     * **Избегать шаблонных формулировок** типа "X, без учёта Y и Z" — это тоже может быть подсказкой
     * **Использовать разные подходы** для разных дистракторов в одном вопросе, чтобы они не выглядели одинаково

## Типы качественных дистракторов

### Тип 1: Частично правильный ответ
**Пример:**
```
Вопрос: Что такое валовая прибыль?

A) Выручка минус все расходы компании (включая операционные)
B) Выручка минус прямые расходы (зарплаты инженеров, налоги на ФОТ) ✓
C) Выручка минус операционные расходы (аренда, маркетинг)
D) Выручка минус налоги и дивиденды
```

**Анализ:**
- A) Частично правильно, но включает операционные расходы (это чистая прибыль)
- B) Правильный ответ
- C) Частично правильно, но это операционная прибыль, а не валовая
- D) Неправильно, но использует реальные термины

### Тип 2: Перепутывание похожих концепций
**Пример:**
```
Вопрос: Что такое косвенные налоги?

A) Налоги, которые взимаются раз в год (это про периодичность, не про тип)
B) Налоги, которые включаются в цену товара и фактически оплачиваются потребителем ✓
C) Налоги, которые взимаются с дохода плательщика (это прямые налоги)
D) Налоги, которые платят только компании (это про субъект, не про тип)
```

**Анализ:**
- A) Перепутывание типа налога с периодичностью уплаты
- B) Правильный ответ
- C) Перепутывание косвенных с прямыми налогами
- D) Перепутывание типа налога с субъектом налогообложения

### Тип 3: Неправильное применение правила
**Пример:**
```
Вопрос: Когда признаётся доход по принципу начисления?

A) В момент выставления счёта клиенту, независимо от выполнения работ
B) В момент оказания услуги или подписания акта выполненных работ ✓
C) В момент фактического поступления денег на банковский счёт
D) В конце финансового года при расчёте налогов
```

**Анализ:**
- A) Частично правильно (выставление счёта важно), но не учитывает выполнение работ
- B) Правильный ответ
- C) Это кассовый метод, а не метод начисления
- D) Это про налоговый учёт, а не про принцип начисления

### Тип 4: Правильный ответ для другого контекста
**Пример:**
```
Вопрос: Что такое налог на прибыль организаций?

A) Налог, который платят только крупные компании (это про размер, не про суть)
B) Налог, который рассчитывается как процент от выручки (это про оборотные налоги)
C) Налог, рассчитываемый как (Доходы - Обоснованные расходы) × Ставка налога ✓
D) Налог, который платят только при наличии прибыли выше определённого порога
```

**Анализ:**
- A) Правильно про некоторые особенности, но не про суть налога
- B) Перепутывание с оборотными налогами (НДС)
- C) Правильный ответ
- D) Частично правильно (есть пороги), но не про основной принцип расчёта

## Процесс улучшения дистракторов

### Шаг 1: Анализ текущих дистракторов
Для каждого вопроса:
1. Определить правильный ответ
2. Найти абсурдные дистракторы
3. Найти дистракторы, которые выдают себя длиной
4. Найти слишком очевидные дистракторы

### Шаг 2: Определение типичных ошибок
1. Какие концепции студенты часто путают?
2. Какие типичные заблуждения есть по этой теме?
3. Какие частично правильные, но неполные ответы возможны?

### Шаг 3: Создание новых дистракторов
Для каждого дистрактора:
1. Выбрать тип ошибки (перепутывание, частично правильный, неправильное применение)
2. Использовать реальные термины и концепции из курса
3. Обеспечить примерно одинаковую длину с правильным ответом
4. Проверить правдоподобность

### Шаг 4: Проверка качества
Для каждого вопроса проверить:
- ✅ Все дистракторы правдоподобны и реалистичны
- ✅ Все варианты примерно одинаковой длины
- ✅ Нет абсурдных утверждений
- ✅ Дистракторы требуют понимания материала для исключения
- ✅ Правильный ответ не выделяется длиной или детальностью

- Дистракторы требуют понимания материала для исключения

## Метрики качества

После улучшения дистракторы должны соответствовать:

- ✅ **Правдоподобность**: Все дистракторы реалистичны и основаны на реальных концепциях
- ✅ **Одинаковая длина**: Разница в длине вариантов не более 20-30%
- ✅ **Требуют понимания**: Невозможно исключить дистракторы без знания материала
- ✅ **Типичные ошибки**: Основаны на реальных заблуждениях студентов
- ✅ **Профессионализм**: Нет абсурдных утверждений, юмора или сарказма

4. **Проверьте метрики** из раздела "Метрики качества"
5. **Используйте чеклист** для финальной проверки

## 🎯 Цель

После применения этого промпта дистракторы должны стать:
- **Более правдоподобными** — основаны на реальных концепциях и типичных ошибках
- **Более сбалансированными** — примерно одинаковой длины с правильным ответом
- **Более требовательными** — требуют реального понимания материала для исключения
- **Более профессиональными** — без абсурдных утверждений и юмора

При этом вопросы остаются:
- **Интересными** — проверяют важные концепции
- **Понятными** — формулировки ясны и однозначны
- **Обучающими** — помогают закрепить материал
