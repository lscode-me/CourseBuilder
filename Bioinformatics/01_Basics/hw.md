## Бонусное Задание 2: Рассчитать температуру плавления (Tm)

**Формула (для последовательностей < 14 bp):**
```
Tm = 4 * (G + C) + 2 * (A + T)
```

**Формула (для последовательностей >= 14 bp):**
```
Tm = 64.9 + 41 * (G + C - 16.4) / (A + T + G + C)
```

**Требования:**
1. Реализовать обе формулы
2. Автоматически выбирать формулу в зависимости от длины
3. Вернуть температуру в градусах Цельсия

**Пример:**
```python

# 8 bp: Tm = 4*(4) + 2*(4) = 24°C
```

**Цель:**
- Практическая биоинформатика (Tm используется в ПЦР)
- Работа с формулами
- Условная логика

**Пример хорошего решения:**
```python
def gc_content(sequence: str) -> float:
    """
    Вычисляет GC-содержание последовательности ДНК.
    
    Args:
        sequence: Строка ДНК последовательности
        
    Returns:
        Процент G и C в последовательности (0-100)
        
    Example:
        >>> gc_content("ATCG")
        50.0
    """
    if not sequence:
        return 0.0
    
    sequence = sequence.upper()
    gc_count = sequence.count('G') + sequence.count('C')
    return (gc_count / len(sequence)) * 100
```
