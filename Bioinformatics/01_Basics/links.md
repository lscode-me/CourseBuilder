# Основы Биоинформатики - Ресурсы

Подборка лучших ресурсов для изучения основ биоинформатики и молекулярной биологии для инженеров.

---

## Интерактивные Обучающие Платформы

**Rosalind - Bioinformatics Problems**
https://rosalind.info/
Платформа с задачами по биоинформатике (аналог LeetCode или Project Euler для био). Отличный способ практиковаться.

**Genetic Science Learning Center**
https://learn.genetics.utah.edu/
Интерактивные анимации и визуализации биологических процессов. Очень наглядно для инженеров.

**DNA Learning Center**
https://www.dnalc.org/
Образовательные материалы с 3D анимациями, виртуальными лабораториями и интерактивными уроками.

---

## Книги и Туториалы

**Bioinformatics Data Skills by Vince Buffalo**
https://www.oreilly.com/library/view/bioinformatics-data-skills/9781449367480/
Лучшая книга для программистов, входящих в биоинформатику. Фокус на практических навыках работы с данными.

**An Introduction to Bioinformatics Algorithms**
https://mitpress.mit.edu/9780262101066/an-introduction-to-bioinformatics-algorithms/
Алгоритмический подход к биоинформатике. Для тех, кто любит computer science.

**Molecular Biology of the Cell**
https://www.ncbi.nlm.nih.gov/books/NBK21054/
Бесплатный онлайн учебник. Глубокое погружение в молекулярную биологию (если интересно больше деталей).

## Официальная Документация

**BioPython Tutorial**
https://biopython.org/DIST/docs/tutorial/Tutorial.html
Официальный туториал по BioPython — основная библиотека для работы с биологическими данными в Python.

**NCBI Handbook**
https://www.ncbi.nlm.nih.gov/books/NBK143764/
Справочник по ресурсам NCBI (National Center for Biotechnology Information). Основная база биологических данных.

**Ensembl Documentation**
https://www.ensembl.org/info/website/tutorials/index.html
Туториалы по работе с базой данных Ensembl — одна из основных баз геномных данных.

## Видео Курсы

**Introduction to Genomic Technologies (Coursera)**
https://www.coursera.org/learn/introduction-genomics
Вводный курс от Johns Hopkins. Объясняет базовые концепции геномики для не-биологов.

**Genomic Data Science Specialization (Coursera)**
https://www.coursera.org/specializations/genomic-data-science
Полная специализация из 8 курсов. Покрывает статистику, алгоритмы, Python, R для геномики.

**DNA, RNA, and Proteins (Khan Academy)**
https://www.khanacademy.org/science/biology/dna-as-the-genetic-material
Базовые видео о ДНК, РНК и белках. Хорошая визуализация для понимания основ.

## Инструменты и Библиотеки

**BioPython**
https://biopython.org/
Главная Python библиотека для биоинформатики. Работа с последовательностями, файлами, базами данных.

**pysam - Python SAM/BAM Interface**
https://pysam.readthedocs.io/
Python обёртка для samtools. Работа с alignment файлами.

**scikit-bio**
https://scikit.bio/
Библиотека для биоинформатики, интегрированная с научным стеком Python (NumPy, SciPy, pandas).

**PyVCF - VCF Parser**
https://pyvcf.readthedocs.io/
Чтение и запись VCF файлов (variant calling format).

## Браузеры Генома

**UCSC Genome Browser**
https://genome.ucsc.edu/
Мощный браузер генома с визуализацией генов, вариантов, conservation scores и многого другого.

**Ensembl Genome Browser**
https://www.ensembl.org/
Альтернативный браузер генома. Хорошая документация и API для программного доступа.

**IGV - Integrative Genomics Viewer**
https://software.broadinstitute.org/software/igv/
Desktop приложение для визуализации геномных данных. Must-have инструмент.

## Базы Данных

**NCBI GenBank**
https://www.ncbi.nlm.nih.gov/genbank/
Крупнейшая общедоступная база последовательностей ДНК. Содержит практически все известные геномы.

**UniProt - Protein Database**
https://www.uniprot.org/
База данных белков с функциональной аннотацией.

**dbSNP - SNP Database**
https://www.ncbi.nlm.nih.gov/snp/
База данных однонуклеотидных полиморфизмов (SNPs).

## Советы по Использованию Ресурсов

1. **Начните с Rosalind** — практические задачи дадут понимание через код
2. **Смотрите визуализации** — DNA Learning Center и Khan Academy помогут "увидеть" процессы
3. **Читайте Bioinformatics Data Skills** — это книга специально для программистов
4. **Присоединяйтесь к Biostars** — задавайте вопросы, когда застряли
5. **Практикуйтесь с реальными данными** — используйте NCBI для скачивания примеров

**Порядок изучения:**
1. Genetic Science Learning Center (визуализации) → понять биологию
2. BioPython Tutorial → научиться работать с данными
3. Rosalind → практиковаться через задачи
4. Bioinformatics Data Skills → системное изучение
