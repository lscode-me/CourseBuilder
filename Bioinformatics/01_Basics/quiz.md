## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | ДНК состоит из 4 нуклеотидов: Аденин (A), Цитозин (C), Гуанин (G) и Тимин (T). |
| 2 | C | Геном человека содержит ~3.2 миллиарда пар оснований ≈ 3.2 ГБ текста. |
| 3 | C | G (гуанин) комплементарен C (цитозину), A комплементарен T. |
| 4 | A | Только ~2% генома кодирует белки. Остальное — интроны, регуляторы, повторы. |
| 5 | B | Транскрипция — создание РНК копии с ДНК матрицы. |
| 6 | B | Illumina секвенаторы читают риды длиной 100-150 пар оснований. |
| 7 | C | SNP — замена одного нуклеотида на другой, самый частый тип вариантов. |
| 8 | B | 23 пары = 46 хромосом в диплоидной клетке. |
| 9 | B | Референс-геном — эталонная последовательность для сравнения. |
| 10 | A | 30x coverage = каждая позиция прочитана в среднем 30 раз. |
| 11 | C | Кодон = 3 нуклеотида, кодирующие одну аминокислоту. |
| 12 | C | Центральная догма: ДНК → РНК → Белок. |
| 13 | B | Интроны вырезаются при сплайсинге, в белок попадают только экзоны. |
| 14 | B | "ATCGATCG": 4 буквы G/C из 8 = 50%. |
| 15 | C | Патогенная мутация может вызывать или предрасполагать к заболеванию. |
| 16 | A | РНК использует урацил (U) вместо тимина (T). |
| 17 | C | 4³ = 64 кодона (61 для аминокислот + 3 стоп-кодона). |
| 18 | B | AUG — старт-кодон, также кодирует метионин. |
| 19 | B | Сплайсинг происходит после транскрипции, до трансляции. |
| 20 | B | Pre-mRNA содержит интроны, которые ещё не вырезаны. |
| 21 | B | 3 стоп-кодона: UAA, UAG, UGA. |
| 22 | D | "GGGGCCCC": все 8 нуклеотидов — G или C = 100%. |
| 23 | C | VUS = вариант с неопределённым клиническим значением. |
| 24 | A | РНК одноцепочечная, ДНК двухцепочечная. |
| 25 | C | Экзоны — это кодирующие участки, входящие в ~2%. |
| 26 | B | 20 стандартных аминокислот кодируются 61 кодоном. |
| 27 | B | После сплайсинга в mRNA остаются только экзоны. |
| 28 | C | Из миллионов вариантов только единицы (0-10) патогенные. |
| 29 | B | При транскрипции A (ДНК) спаривается с U (РНК). |
| 30 | C | ДНК хранит информацию, но химические реакции выполняют белки. |
| 31 | B | Разные ткани экспрессируют разные наборы генов (тканеспецифичность). |
| 32 | B | Экспрессия — использование информации гена для создания продукта. |

## Scoring Guide

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **29-32 правильных (90-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
| **23-28 правильных (72-88%)** | ✅ Хорошо | Хороший результат! Повторите темы, в которых ошиблись. |
| **16-22 правильных (50-69%)** | ⚠️ Удовлетворительно | Рекомендуется перечитать соответствующие разделы лекции. |
| **Менее 16 правильных (<50%)** | 📚 Нужно повторить | Внимательно перечитайте лекцию и попробуйте ещё раз. |
