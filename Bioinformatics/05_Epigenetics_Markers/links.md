# Полезные ссылки: Эпигенетика и Генетические Маркеры

## Базы данных

### Эпигеномные данные
- [ENCODE](https://www.encodeproject.org/) — Энциклопедия элементов ДНК, включая эпигенетические данные
- [Roadmap Epigenomics](http://www.roadmapepigenomics.org/) — Эпигеномные карты тканей человека
- [GEO (Gene Expression Omnibus)](https://www.ncbi.nlm.nih.gov/geo/) — Репозиторий геномных данных
- [IHEC (International Human Epigenome Consortium)](https://ihec-epigenomes.org/) — Международный консорциум эпигеномики

### Генетические маркеры
- [dbSNP](https://www.ncbi.nlm.nih.gov/snp/) — База данных SNP
- [GWAS Catalog](https://www.ebi.ac.uk/gwas/) — Каталог результатов GWAS исследований
- [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/) — Клиническая значимость вариантов
- [gnomAD](https://gnomad.broadinstitute.org/) — Частоты вариантов в популяциях

### Фармакогенетика
- [PharmGKB](https://www.pharmgkb.org/) — База фармакогенетических данных
- [CPIC](https://cpicpgx.org/) — Клинические рекомендации по фармакогенетике
- [PharmVar](https://www.pharmvar.org/) — Номенклатура фармакогенов

## Инструменты

### Анализ метилирования
- [Bismark](https://www.bioinformatics.babraham.ac.uk/projects/bismark/) — Выравнивание и анализ бисульфитного секвенирования
- [methylKit](https://bioconductor.org/packages/methylKit/) — R-пакет для анализа метилирования
- [MethylSeekR](https://bioconductor.org/packages/MethylSeekR/) — Идентификация регуляторных регионов

### Анализ гистонов (ChIP-seq)
- [MACS2](https://github.com/macs3-project/MACS) — Поиск пиков в ChIP-seq
- [HOMER](http://homer.ucsd.edu/) — Анализ ChIP-seq и мотивов
- [deepTools](https://deeptools.readthedocs.io/) — Визуализация и анализ

### GWAS анализ
- [PLINK](https://www.cog-genomics.org/plink/) — Стандартный инструмент для GWAS
- [GCTA](https://yanglab.westlake.edu.cn/software/gcta/) — Анализ сложных признаков
- [LDSC](https://github.com/bulik/ldsc) — LD Score Regression
- [LocusZoom](http://locuszoom.org/) — Визуализация GWAS результатов

### Криминалистика
- [STRmix](https://strmix.com/) — Анализ смешанных ДНК-профилей
- [GEDmatch](https://www.gedmatch.com/) — Сравнение геномных данных
