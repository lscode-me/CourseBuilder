# Форматы Файлов - Ресурсы

---

## Официальные Спецификации

**SAM/BAM Format Specification**
https://samtools.github.io/hts-specs/SAMv1.pdf
Полная спецификация SAM/BAM формата

**VCF Format Specification**
https://samtools.github.io/hts-specs/VCFv4.3.pdf
Детальное описание VCF формата версии 4.3

**BED Format Description**
https://genome.ucsc.edu/FAQ/FAQformat.html#format1
Описание BED формата от UCSC

**FASTQ Format**
https://en.wikipedia.org/wiki/FASTQ_format
Подробное описание FASTQ формата

## Инструменты Командной Строки

**SAMtools**
http://www.htslib.org/
Основной инструмент для работы с SAM/BAM/CRAM файлами

**BCFtools**
http://www.htslib.org/
Инструмент для работы с VCF/BCF файлами вариантов

**BEDTools**
https://bedtools.readthedocs.io/
Инструментарий для операций с BED файлами и геномными интервалами

**seqtk**
https://github.com/lh3/seqtk
Быстрый инструмент для обработки FASTA/FASTQ файлов

**Tabix**
http://www.htslib.org/doc/tabix.html
Индексация и запрос tab-delimited файлов (VCF, BED, GFF)

---

## Python Библиотеки

**BioPython - SeqIO**
https://biopython.org/wiki/SeqIO
Работа с FASTA/FASTQ и другими форматами последовательностей

**pysam**
https://pysam.readthedocs.io/
Python интерфейс для работы с SAM/BAM/VCF файлами

**PyVCF**
https://pyvcf.readthedocs.io/
Парсер VCF файлов для Python

**pybedtools**
https://daler.github.io/pybedtools/
Python обёртка для bedtools
