# Форматы Файлов - Домашние Задания

Практические задания на работу с основными биоинформатическими форматами.

---

## Задание 1: Парсинг FASTA

Напишите функцию для чтения FASTA файла и подсчёта статистик.

**Требования:**
1. Прочитать FASTA файл
2. Вернуть словарь: {sequence_id: {length, gc_content}}
3. Обработать multi-line последовательности

**Цель:** Работа с FASTA форматом, базовая статистика

---

## Задание 2: Фильтрация FASTQ по качеству

Отфильтруйте FASTQ файл, оставив только риды с хорошим качеством.

**Требования:**
1. Читать FASTQ файл
2. Вычислять среднее качество рида
3. Сохранять риды с avg_quality >= 30
4. Записать результат в новый FASTQ

**Цель:** Понимание quality scores, QC

---

## Задание 3: Анализ SAM FLAGS

Напишите функцию для декодирования SAM FLAG в читаемый формат.

**Требования:**
1. Принимать FLAG (число)
2. Возвращать список установленных флагов
3. Использовать битовые операции

**Пример:**
```python
decode_flag(99)  # → ['paired', 'mapped_in_proper_pair', 'first_in_pair']
```

**Цель:** Понимание битовых флагов в SAM

## Задание 4: Парсинг CIGAR строки

Разберите CIGAR строку на операции.

**Требования:**
1. Принимать CIGAR строку ("100M", "90M2D8M")
2. Вернуть список операций: [(90, 'M'), (2, 'D'), (8, 'M')]
3. Подсчитать общую длину на референсе

**Цель:** Понимание CIGAR, как риды выравниваются

## Задание 5: Подсчёт покрытия из BAM

Подсчитайте покрытие для региона из BAM файла.

**Требования:**
1. Использовать pysam
2. Для каждой позиции подсчитать количество ридов
3. Вернуть массив покрытия

**Цель:** Работа с BAM, понимание coverage

## Задание 6: Чтение VCF и фильтрация

Прочитайте VCF и отфильтруйте варианты.

**Требования:**
1. Читать VCF файл
2. Оставить только PASS варианты
3. Оставить только SNPs (REF и ALT по 1 символу)
4. Качество >= 30

**Цель:** Работа с VCF, фильтрация вариантов

## Задание 7: Анализ генотипов
