## Вопрос 10: Read Group

Зачем нужен Read Group (@RG) в SAM/BAM?

A) Для сортировки ридов  
B) Для группировки ридов из одного сэмпла/библиотеки  
C) Для удаления дубликатов  
D) Для индексации файла  

---

## Ключ к Ответам

1. **B** - QC → Alignment → Variant Calling → Filtering
2. **B** - BWA выравнивает риды на референс-геном
3. **B** - Дубликаты это PCR artifacts с одинаковыми координатами
4. **C** - BQSR корректирует качество на основе known sites
5. **B** - HaplotypeCaller вызывает варианты
6. **C** - 30x — стандартное покрытие для клиники
7. **B** - QD = QUAL / DP (качество на глубину)
8. **B** - SnpEff аннотирует эффекты вариантов
9. **B** - PASS означает успешное прохождение фильтров
10. **B** - @RG группирует риды из одного источника
