# CLI Tools - Домашние Задания

---

## Задание 1: Базовая статистика BAM

Используйте samtools для получения статистики выравнивания.

**Требования:**
- Общее количество ридов
- Mapped vs unmapped
- Properly paired %
- Average insert size

---

## Задание 2: Фильтрация BAM

Создайте отфильтрованный BAM файл с высококачественными ридами.

**Требования:**
- MAPQ ≥ 30
- Properly paired
- Не дубликаты
- Сохранить и индексировать

---

## Задание 3: Региональная экстракция

Извлеките риды из конкретных регионов генома.

**Требования:**
- Использовать BED файл с регионами
- Создать отдельный BAM для каждого региона
- Подсчитать покрытие

---

## Задание 4: VCF статистика

Проанализируйте VCF файл с помощью bcftools.

**Требования:**
- Подсчитать SNPs и Indels
- Transition/Transversion ratio
- Распределение по качеству

---

## Задание 5: Фильтрация VCF

Создайте высококачественный subset VCF.

**Требования:**
- QUAL ≥ 30
- DP ≥ 20
- PASS only
- Сохранить в bgzipped VCF с индексом

---

## Задание 6: BEDtools пересечения

Найдите варианты в экзонах.

**Требования:**
- Использовать BED файл экзонов
- Найти пересечение с VCF
- Подсчитать % вариантов в экзонах

---

## Задание 7: Покрытие по генам

Подсчитайте среднее покрытие для каждого гена.

**Требования:**
- BED файл генов
- BAM файл
- Вывести: gene_name, avg_coverage

---

## Задание 8: FASTQ subsampling

Создайте subset FASTQ файла для быстрого тестирования.

**Требования:**
- Взять 100,000 случайных ридов
- Сохранить paired-end структуру
- Проверить качество FastQC

---

## Задание 9: Комплексный пайплайн

Напишите bash скрипт, который:
- Фильтрует BAM (quality)
- Вызывает варианты в регионах (BED)
- Фильтрует VCF
- Генерирует summary

---

## Задание 10: Сравнение сэмплов

Сравните два VCF файла.

**Требования:**
- Найти уникальные для каждого
- Найти общие варианты
- Визуализировать Venn диаграммой

---
