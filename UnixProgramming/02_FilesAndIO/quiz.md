## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | stdout соответствует fd=1, stdin=0, stderr=2 |
| 2 | B | O_CREAT создаёт файл, если он не существует |
| 3 | B | os.read() возвращает bytes, не строку |
| 4 | C | os.fsync(fd) гарантирует запись на диск |
| 5 | C | SEEK_SET перемещает от начала файла |
| 6 | B | os.dup() создаёт копию файлового дескриптора |
| 7 | B | os.dup2(old, new) заменяет new копией old |
| 8 | B | LOCK_SH (shared) разрешает нескольким читать |
| 9 | A | LOCK_NB — неблокирующий режим, возвращает ошибку вместо ожидания |
| 10 | B | mkstemp() возвращает кортеж (fd, path) |
| 11 | B | O_EXCL + O_CREAT — ошибка если файл существует |
| 12 | B | O_APPEND — все записи добавляются в конец |
| 13 | B | Sparse файл — файл с незаполненными участками (дырками) |
| 14 | B | Атомарное обновление: записать во временный файл, затем rename |
| 15 | B | fileno() возвращает целочисленный файловый дескриптор |
