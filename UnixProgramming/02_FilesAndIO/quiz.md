## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | stdout соответствует fd=1, stdin=0, stderr=2 |
| 2 | B | O_CREAT создаёт файл, если он не существует |
| 3 | D | os.read() возвращает bytes, не строку |
| 4 | B | os.fsync(fd) гарантирует запись на диск |
| 5 | D | SEEK_SET перемещает от начала файла |
| 6 | D | os.dup() создаёт копию файлового дескриптора |
| 7 | D | os.dup2(old, new) заменяет new копией old |
| 8 | D | LOCK_SH (shared) разрешает нескольким читать |
| 9 | B | LOCK_NB — неблокирующий режим, возвращает ошибку вместо ожидания |
| 10 | B | mkstemp() возвращает кортеж (fd, path) |
| 11 | D | O_EXCL + O_CREAT — ошибка если файл существует |
| 12 | C | O_APPEND — все записи добавляются в конец |
| 13 | C | Sparse файл — файл с незаполненными участками (дырками) |
| 14 | D | Атомарное обновление: записать во временный файл, затем rename |
| 15 | D | fileno() возвращает целочисленный файловый дескриптор |
