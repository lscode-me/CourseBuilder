## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | os.stat() возвращает stat_result с метаданными: size, mode, uid, gid, times |
| 2 | B | stat.S_ISDIR(mode) проверяет, является ли mode директорией |
| 3 | B | lstat не следует за symlinks, возвращает stat самой ссылки |
| 4 | B | S_IRUSR — read permission for user (owner) |
| 5 | B | rw-r--r-- = 110 100 100 = 644 в восьмеричной |
| 6 | C | Жёсткие ссылки указывают на один inode |
| 7 | A | os.readlink() возвращает путь, на который указывает ссылка |
| 8 | B | os.F_OK проверяет существование файла |
| 9 | B | os.walk() — генератор, выдающий (root, dirs, files) |
| 10 | B | Path.name возвращает имя файла (последний компонент) |
| 11 | B | 0666 & ~022 = 0644 (umask убирает биты) |
| 12 | B | os.replace() атомарно заменяет существующий файл |
| 13 | B | st_nlink — количество жёстких ссылок на inode |
| 14 | B | inode — структура данных файловой системы с метаданными |
| 15 | B | scandir возвращает DirEntry с кэшированными stat данными |
