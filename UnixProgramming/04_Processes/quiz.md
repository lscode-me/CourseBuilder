## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | fork() возвращает 0 в дочернем процессе |
| 2 | B | exec() заменяет текущий процесс, код после exec не выполняется |
| 3 | B | Зомби — завершённый процесс, ожидающий wait() от родителя |
| 4 | A | os.wait() возвращает (pid, status) |
| 5 | C | WEXITSTATUS извлекает код возврата из status |
| 6 | C | WNOHANG делает waitpid неблокирующим |
| 7 | B | execvp ищет программу в PATH |
| 8 | D | os._exit() используется в дочернем процессе, обходит cleanup |
| 9 | A | check=True бросает CalledProcessError при ненулевом коде |
| 10 | D | COW копирует страницы памяти только при записи |
| 11 | A | PIPE позволяет захватить stdout/stderr |
| 12 | A | Pool создаёт пул рабочих процессов для параллельной обработки |
| 13 | A | Двойной fork создаёт процесс, усыновляемый init, без зомби |
| 14 | B | WIFSIGNALED проверяет, был ли процесс убит сигналом |
| 15 | A | shell=True позволяет shell injection при небезопасном вводе |
