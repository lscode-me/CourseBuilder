## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | fork() возвращает 0 в дочернем процессе |
| 2 | B | exec() заменяет текущий процесс, код после exec не выполняется |
| 3 | B | Зомби — завершённый процесс, ожидающий wait() от родителя |
| 4 | C | os.wait() возвращает (pid, status) |
| 5 | B | WEXITSTATUS извлекает код возврата из status |
| 6 | B | WNOHANG делает waitpid неблокирующим |
| 7 | A | execvp ищет программу в PATH |
| 8 | B | os._exit() используется в дочернем процессе, обходит cleanup |
| 9 | B | check=True бросает CalledProcessError при ненулевом коде |
| 10 | B | COW копирует страницы памяти только при записи |
| 11 | A | PIPE позволяет захватить stdout/stderr |
| 12 | B | Pool создаёт пул рабочих процессов для параллельной обработки |
| 13 | B | Двойной fork создаёт процесс, усыновляемый init, без зомби |
| 14 | B | WIFSIGNALED проверяет, был ли процесс убит сигналом |
| 15 | B | shell=True позволяет shell injection при небезопасном вводе |
