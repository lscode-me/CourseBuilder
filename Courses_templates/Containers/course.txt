Containers
Курс по контейнеризации в Linux — от низкоуровневых механизмов ядра до оркестрации в production.
01_Intro история изоляции: от chroot к контейнерам, процессы.
02_Namespaces Linux Namespaces: PID, NET, MNT, UTS, IPC, USER, CGROUP.
03_Cgroups Control Groups: управление ресурсами CPU, Memory, I/O.
04_FileSystem OverlayFS, AUFS, слои образов, union filesystems.
05_OCI OCI Standards: Runtime Spec, Image Spec, runC, unshare, nsenter.
06_Runtimes containerd, Podman, CRI-O, Buildah — container runtimes.
07_Networking контейнерные сети: bridge, overlay, CNI, veth, DNS.
08_Docker CLI, Dockerfile, images, volumes, security.
09_Compose Docker Compose, multi-container apps, Docker Swarm.
10_Kubernetes Pods, Deployments, Services, kubectl, архитектура.
11_Systemd systemd-nspawn, machinectl, системные контейнеры.

Требования: Linux (Ubuntu 22.04+), Docker/Podman, 8GB RAM, root доступ.
