JavaScript
Курс по языку JavaScript и TypeScript. Для разработчиков, которые хотят освоить язык веба и современную экосистему.
01_Intro история JS, ECMAScript, где выполняется, браузер vs Node.js.
02_Basics переменные, типы данных, let/const/var, операторы.
03_Functions функции, стрелочные функции, замыкания, контекст this.
04_Objects объекты, массивы, деструктуризация, spread/rest.
05_Prototypes прототипы, классы, наследование, new.
06_Async колбэки, промисы, async/await, Event Loop.
07_Modules ES modules, import/export, CommonJS, бандлеры.
08_DOM работа с DOM, события, манипуляции страницей.
09_TypeScriptBasics типизация, интерфейсы, типы, дженерики.
10_TypeScriptAdvanced utility types, type guards, декораторы.
11_NodeJS серверный JavaScript, npm, работа с файлами, http.
12_Ecosystem фреймворки (React, Vue, Express), инструменты (ESLint, Prettier).

Требования: браузер, Node.js, редактор кода.
