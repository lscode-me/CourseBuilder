Python
Курс для начинающих программистов. Основы языка Python от синтаксиса до стандартной библиотеки.
01_Intro что такое Python, установка, первые шаги.
02_DataStructures числа, строки, списки, словари, множества.
03_FlowControl условия, циклы, управление потоком.
04_Functions функции, параметры, декораторы, генераторы.
05_Classes классы, ООП, наследование.
06_Modules модули, пакеты, организация кода.
07_Exceptions обработка ошибок, исключения.
08_Files работа с файлами и файловой системой.
09_StandardModules важные модули стандартной библиотеки.
10_AdditionalModules популярные pip-пакеты.

Требования: Linux/macOS, Python 3.10+, терминал, текстовый редактор.
