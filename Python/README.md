# Python Course

Курс для тех, кто умеет пользоваться компьютером, устанавливать и запускать программы, понимает основы алгоритмов и устройство вычислительных систем. Для тех кто только начинает программирование и интересуется языком Python.

---

## 📋 Требования

- **ОС**: Linux или macOS
- **Python**: CPython 3.10+
- **Инструменты**: терминал, текстовый редактор или IDE

## 🚀 Как использовать курс

### 1. Подготовка окружения

```bash
# Установите Python (рекомендуется pyenv)
pyenv install 3.11.5
pyenv global 3.11.5

# Создайте виртуальное окружение для практики
python -m venv course_env
source course_env/bin/activate
```

### 2. Изучение материала

1. Читайте лекции последовательно
2. Выполняйте все примеры кода
3. Экспериментируйте в REPL
4. Выполняйте практические задания в конце каждого модуля

### 3. Практика

После каждого модуля выполняйте предложенные задания:
- **Practice Ideas** — небольшие задачи для закрепления
- **Going Deeper** — продвинутые темы для самостоятельного изучения
