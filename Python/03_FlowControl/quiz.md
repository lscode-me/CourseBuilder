## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Первое истинное условие (x > 3) выполняется, остальные пропускаются. |
| 2 | D | Python проверяет условия сверху вниз и выполняет первый истинный блок. |
| 3 | C | В Python: `value_if_true if condition else value_if_false`. |
| 4 | B | Непустая строка "0" — truthy. Пустая строка, 0, [] — falsy. |
| 5 | D | `is None` проверяет идентичность. `== None` работает, но менее идиоматично. |
| 6 | B | `range(2, 10, 3)` — от 2 до 9 с шагом 3: 2, 5, 8. |
| 7 | B | `range(3)` генерирует 0, 1, 2. |
| 8 | C | `enumerate("AB", start=1)` даёт (1, 'A'), (2, 'B'). |
| 9 | C | `zip()` объединяет итерируемые объекты: zip([1,2], ['a','b']) → [(1,'a'), (2,'b')]. |
| 10 | C | `break` прерывает цикл при i=3, до этого печатаются 0, 1, 2. |
| 11 | D | `continue` пропускает итерацию с i=2, печатаются 0, 1, 3, 4. |
| 12 | C | `else` выполняется если цикл не был прерван через `break`. |
| 13 | B | Цикл выполняется 3 раза (count = 1, 2, 3), затем break. |
| 14 | D | Comprehension с фильтром: только чётные числа 0, 2, 4, 6, 8. |
| 15 | A | matrix[1] — второй ряд: [0*1, 1*1, 2*1] = [0, 1, 2]. |
| 16 | D | Dict comprehension для x=1,2,3: {1:1, 2:4, 3:9}. |
| 17 | B | Generator не создаёт весь список в памяти, вычисляет по запросу. |
| 18 | A | Изменение размера списка во время итерации может вызвать пропуск элементов. |
| 19 | C | По умолчанию итерация по словарю — по ключам. |
| 20 | D | `match/case` появился в Python 3.10 (PEP 634). |
