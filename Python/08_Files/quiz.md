## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | `open()` — встроенная функция для открытия файлов. |
| 2 | B | `'r'` — режим чтения (read), используется по умолчанию. |
| 3 | C | Режим `'w'` создаёт новый файл или перезаписывает существующий. |
| 4 | B | `'a'` (append) добавляет в конец, не удаляя существующее содержимое. |
| 5 | B | `with` гарантирует закрытие файла даже при исключении. |
| 6 | B | Незакрытые файлы могут привести к утечке ресурсов и потере данных. |
| 7 | B | `read()` возвращает весь контент как одну строку. |
| 8 | C | `readlines()` возвращает список строк (с `\n`). |
| 9 | B | В конце файла `readline()` возвращает пустую строку. |
| 10 | C | `for line in f:` читает по одной строке, не загружая весь файл в память. |
| 11 | B | `write()` записывает строку как есть, без переноса. Добавьте `\n` сами. |
| 12 | B | `writelines()` записывает итерируемый объект строк без добавления `\n`. |
| 13 | C | Python 3 по умолчанию использует UTF-8 для текстовых файлов. |
| 14 | B | `'rb'`, `'wb'` — бинарные режимы чтения/записи. |
| 15 | B | `tell()` возвращает текущую позицию (смещение в байтах). |
| 16 | B | `seek(0)` перемещает курсор в начало файла. |
| 17 | B | `Path('/path')` создаёт объект пути. |
| 18 | B | Оператор `/` в pathlib соединяет пути. |
| 19 | D | Все варианты проверяют существование (exists — общая, is_file — только файлы). |
| 20 | B | `read_text()` читает как строку, `read_bytes()` — как bytes. |
| 21 | A | `/` создаёт новый путь: `/home/user/docs`. |
| 22 | B | `makedirs()` или `mkdir(parents=True)` создаёт промежуточные директории. |
| 23 | B | `tempfile` — модуль для работы с временными файлами и директориями. |
| 24 | B | `shutil` (shell utilities) — копирование, перемещение, удаление файлов/директорий. |
| 25 | A | `json.load(file)` — из файла, `json.loads(string)` — из строки. |
