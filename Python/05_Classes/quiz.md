## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | `class` — ключевое слово для определения класса. |
| 2 | B | `self` — ссылка на текущий экземпляр, позволяет обращаться к его атрибутам и методам. |
| 3 | C | `__init__` — инициализатор, вызывается после создания экземпляра. `__new__` создаёт сам объект. |
| 4 | B | Каждый экземпляр имеет свой атрибут name. dog1.name = "Rex". |
| 5 | B | Атрибуты класса общие для всех экземпляров; атрибуты экземпляра уникальны. |
| 6 | C | Синтаксис наследования: `class Child(Parent):`. |
| 7 | B | `super()` даёт доступ к методам родительского класса. |
| 8 | B | Метод переопределён в дочернем классе, вызывается его версия. |
| 9 | B | `isinstance(obj, Class)` проверяет, является ли obj экземпляром Class или его подкласса. |
| 10 | B | `_name` — конвенция для "protected", `__name` — name mangling для "private". |
| 11 | B | Name mangling: `__private` становится `_MyClass__private`. |
| 12 | A | `@property` позволяет определять getter для атрибута как метод. |
| 13 | B | Статический метод не получает self или cls, это обычная функция внутри класса. |
| 14 | B | `@classmethod` получает класс (cls) вместо экземпляра (self). |
| 15 | B | Python поддерживает множественное наследование. |
| 16 | B | MRO определяет порядок поиска методов в иерархии наследования (алгоритм C3). |
| 17 | A | `__str__` — читаемое представление, `__repr__` — однозначное (для отладки). |
| 18 | C | `__len__` вызывается при `len(obj)`. |
| 19 | B | `__add__` реализует `+`. `__radd__` для правого операнда. |
| 20 | C | Без `__eq__` сравнивается идентичность объектов (как `is`). |
| 21 | A | `from abc import ABC, abstractmethod`, затем `class MyABC(ABC):` с `@abstractmethod`. |
| 22 | B | `@dataclass` автоматически генерирует стандартные методы класса. |
| 23 | B | `__slots__` заменяет `__dict__`, экономя память для большого количества объектов. |
| 24 | B | Композиция ("has-a") предпочтительнее наследования ("is-a") для гибкости. |
| 25 | B | Duck typing: важно поведение объекта, а не его тип. |
