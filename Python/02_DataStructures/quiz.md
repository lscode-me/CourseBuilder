## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | `decimal` — это модуль, а не встроенный тип. Встроенные числовые: int, float, complex. |
| 2 | C | В Python 3 int не ограничен размером (только памятью). |
| 3 | B | Из-за особенностей float: `0.1 + 0.2 = 0.30000000000000004`. Используйте Decimal для точности. |
| 4 | C | `0xFF` — шестнадцатеричный (hex), `0b` — двоичный, `0o` — восьмеричный. |
| 5 | B | `**` — оператор возведения в степень: 2³ = 8. |
| 6 | D | `[0]` — непустой список, это truthy. Пустой список `[]` — falsy. |
| 7 | B | Строки неизменяемы. Попытка изменить символ вызывает TypeError. |
| 8 | B | `[::-1]` — срез с шагом -1, переворачивает строку. |
| 9 | B | `split()` разделяет строку. По умолчанию по пробелам. |
| 10 | B | `:.2f` форматирует float с 2 знаками после точки: 3.14. |
| 11 | B | Главное отличие: list изменяемый (mutable), tuple — нет (immutable). |
| 12 | C | `append()` добавляет в конец. `insert(i, x)` вставляет на позицию i. |
| 13 | B | `range(4)` даёт 0,1,2,3. Квадраты: 0,1,4,9. |
| 14 | B | `list.sort()` изменяет на месте (возвращает None), `sorted()` возвращает новый список. |
| 15 | B | `(42,)` — кортеж из одного элемента. `(42)` — просто число в скобках. |
| 16 | B | Множество автоматически удаляет дубликаты. Останется {1, 2, 3} — 3 элемента. |
| 17 | B | `&` — пересечение, `\|` — объединение, `-` — разность, `^` — симм. разность. |
| 18 | C | При отсутствии ключа `d["key"]` вызывает KeyError. |
| 19 | B | `get()` возвращает None (или указанное значение по умолчанию) вместо ошибки. |
| 20 | A | Dict comprehension создаёт словарь. range(3) = 0,1,2. |
| 21 | C | `items()` возвращает view с парами (key, value). |
| 22 | B | Mutable default argument создаётся один раз. Используйте `lst=None` и `if lst is None: lst = []`. |
| 23 | B | Shallow copy создаёт новый контейнер, но вложенные объекты остаются общими. |
| 24 | B | `Counter` подсчитывает количество каждого элемента в итерируемом объекте. |
| 25 | C | set использует хэш-таблицу, поиск за O(1). В list/tuple — O(n). |
