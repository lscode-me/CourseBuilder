## 1. Rethinking Conditionals

### 1.1 The Problem with "Types"

Many learners memorize conditionals as formulas:
```
Type 1: If + Present → will + infinitive
Type 2: If + Past → would + infinitive
Type 3: If + Past Perfect → would have + past participle
```

This leads to mechanical usage without understanding.

**Better approach:** Think about **REAL vs UNREAL**

```
REAL CONDITIONS: Possible, likely, factual
"If it rains, we'll stay home." (could happen)

UNREAL CONDITIONS: Hypothetical, imaginary, contrary to fact
"If it rained, we would stay home." (hypothetical)
"If it had rained, we would have stayed home." (didn't happen)
```

### 1.2 The Core Concept

English uses **tense backshift** to signal unreality:

```
Present reality → Past form for unreal
"If I have money..." (real — maybe I do)
"If I had money..." (unreal — I don't have money)

Past reality → Past Perfect for unreal
"If I saw him..." (at some point)
"If I had seen him..." (unreal — I didn't see him)
```

## 2. Zero Conditional: General Truths

### 2.1 Form and Meaning

```
If/When + Present Simple → Present Simple

For: Facts, general truths, scientific laws, instructions
```

**Examples:**
```
"If you heat water to 100°C, it boils."
"If you mix blue and yellow, you get green."
"If I drink coffee late, I can't sleep."
"When you press this button, the machine starts."
```

### 2.2 If vs When

```
IF = possibility (may or may not happen)
"If it rains, the match is cancelled."

WHEN = expectation (will definitely happen)
"When the sun rises, the birds start singing."
```

In Zero conditional, they're often interchangeable for habits:
```
"If/When I eat too much, I feel sick."
```

## 3. First Conditional: Real Future Possibilities

### 3.1 Form and Meaning

```
If + Present Simple → will/can/may/might + infinitive

For: Real future possibilities, likely situations
```

**Examples:**
```
"If you study hard, you will pass the exam."
"If it's nice tomorrow, we can go to the beach."
"If she calls, I might change my plans."
"If the train is late, we won't make the connection."
```

### 3.2 Modal Variations

The result clause doesn't have to use "will":

```
"If you need help, call me." (imperative)
"If you're hungry, there's food in the fridge." (present)
"If you've finished, you can leave." (permission)
"If it rains, we might cancel." (possibility)
"If you want to succeed, you must work hard." (obligation)
```

### 3.3 The "No Will After If" Rule

**Major Russian speaker error:** Using "will" in the if-clause.

```
❌ If it will rain tomorrow...
✅ If it rains tomorrow...

❌ If you will help me...
✅ If you help me...

❌ I'll call you if I will have time.
✅ I'll call you if I have time.
```

**Exception:** "Will" in if-clause for willingness/request:
```
"If you will just sign here, we can proceed."
(= If you are willing to sign...)
```

## 4. Second Conditional: Unreal Present/Future

### 4.1 Form and Meaning

```
If + Past Simple → would/could/might + infinitive

For: Hypothetical, imaginary, unlikely situations
```

**Examples:**
```
"If I had more time, I would travel more."
(Reality: I don't have much time)

"If I won the lottery, I would buy a house."
(Unlikely to happen)

"If I were you, I would accept the offer."
(Impossible — I'm not you)
```

### 4.2 Were vs Was

In formal English, use "were" for all persons in unreal conditions:

```
FORMAL: "If I were rich..."
        "If she were here..."
        "If it were possible..."

INFORMAL: "If I was rich..."
          "If she was here..."
```

For IELTS and formal writing: prefer "were"

**Fixed expression:** "If I were you..." (always "were", even informal)

### 4.3 Real vs Unreal: The Difference in Meaning

Compare:
```
REAL (1st conditional):
"If I have time tomorrow, I'll call you."
(Maybe I'll have time, maybe I won't — open possibility)

UNREAL (2nd conditional):
"If I had time, I would call you."
(I don't have time — that's why I can't call)
```

The second conditional **implies the opposite** of the condition.

## 5. Third Conditional: Unreal Past

### 5.1 Form and Meaning

```
If + Past Perfect → would/could/might + have + past participle

For: Hypothetical past situations (contrary to what happened)
```

**Examples:**
```
"If I had studied harder, I would have passed."
(Reality: I didn't study hard, I didn't pass)

"If we had left earlier, we wouldn't have missed the train."
(Reality: We left late, we missed the train)

"If you had told me, I could have helped."
(Reality: You didn't tell me, I couldn't help)
```

### 5.2 Expressing Regret

Third conditional often expresses **regret** about the past:

```
"If only I had listened to my parents!"
"I wish I had taken that job."
"If I had known, I would never have said that."
```

### 5.3 Common Errors

```
❌ If I would have known...
✅ If I had known...

❌ If I had knew...
✅ If I had known...

❌ ...I would had helped.
✅ ...I would have helped.
```

## 6. Mixed Conditionals

Real situations don't always fit neat categories. Mixed conditionals combine different time references.

### 6.1 Past Condition → Present Result

**Form:** If + Past Perfect → would + infinitive

```
"If I had studied medicine, I would be a doctor now."
(Past decision → present state)

"If she hadn't moved to London, she wouldn't know so many people."
(Past action → present situation)

"If I hadn't broken my leg, I would be playing football today."
(Past event → present activity)
```

### 6.2 Present Condition → Past Result

**Form:** If + Past Simple → would have + past participle

```
"If I were braver, I would have asked her out."
(Present characteristic → past action)

"If she weren't so shy, she would have spoken up at the meeting."
(Present trait → past opportunity)

"If I knew French, I would have understood the film."
(Present knowledge → past understanding)
```

### 6.3 How to Choose

Ask yourself:
```
1. WHEN is the condition? (Present trait or past event?)
2. WHEN is the result? (Present state or past outcome?)
3. Match each clause to its TIME.
```

## 7. Wish & If Only: Expressing Regret

### 7.1 Wish + Past: Present Regret

For things you want to be different **NOW**:

```
"I wish I had more money." (I don't have much)
"I wish I could speak Chinese." (I can't)
"I wish it weren't raining." (It is raining)
"I wish I knew the answer." (I don't know)
```

**Structure:** wish + Past Simple (like 2nd conditional)

### 7.2 Wish + Past Perfect: Past Regret

For things you wanted to be different in the **PAST**:

```
"I wish I had studied harder." (I didn't)
"I wish I hadn't said that." (I did say it)
"I wish I had taken that opportunity." (I didn't take it)
```

**Structure:** wish + Past Perfect (like 3rd conditional)

### 7.3 Wish + Would: Complaints/Requests

For things you want **someone else to do/stop doing**:

```
"I wish you would stop making that noise."
"I wish it would stop raining."
"I wish they would hurry up."
"I wish he wouldn't smoke in the house."
```

**Note:** You can't say "I wish I would..." — use "I wish I could..."

### 7.4 If Only: Emphatic Wish

"If only" = stronger, more emotional version of "wish":

```
"If only I had more time!"
"If only she were here!"
"If only I had known!"
"If only you would listen to me!"
```

## 8. Subjunctive Mood

### 8.1 What Is Subjunctive?

The subjunctive is a verb form used for hypothetical, wished-for, or demanded situations. In modern English, it's mostly visible in formal contexts.

### 8.2 Present Subjunctive

**Form:** Base verb (no -s, no "to")

Used after verbs of demand, suggestion, recommendation:

```
"I suggest that he attend the meeting."
(not "attends")

"It's essential that she be present."
(not "is")

"They demanded that the company pay compensation."
(not "pays")

"I recommend that he take some time off."
(not "takes")
```

**Verbs that trigger subjunctive:**
```
suggest, recommend, propose, demand, insist
request, require, ask, advise, urge
```

**Adjectives that trigger subjunctive:**
```
essential, important, vital, necessary
desirable, advisable, crucial, imperative
```

### 8.3 Subjunctive with "Be"

"Be" is most visible because it doesn't change to "is/are/am":

```
"It's vital that everyone be informed."
"I insist that she be given another chance."
"The rules require that he be present."
```

### 8.4 British Alternative

British English often uses "should" instead:

```
American: "I suggest that he attend."
British: "I suggest that he should attend."

American: "It's important that she be there."
British: "It's important that she should be there."
```

Both are correct. For IELTS: use American subjunctive for variety.

### 8.5 Fixed Expressions with Subjunctive

```
"God bless you!" (not "blesses")
"Long live the Queen!"
"So be it."
"Be that as it may..."
"Come what may..."
"If need be..."
```

## 9. Other Conditional Forms

### 9.1 Unless = If... not

```
"Unless you hurry, you'll miss the train."
= "If you don't hurry, you'll miss the train."

"I won't go unless she invites me."
= "I won't go if she doesn't invite me."
```

**Common error:**
```
❌ Unless you don't hurry... (double negative)
✅ Unless you hurry...
```

### 9.2 Provided/Providing (that)

More formal alternative to "if":

```
"You can go provided (that) you finish your work."
"I'll help you providing you pay me."
```

### 9.3 As long as / So long as

Emphasizes the condition:

```
"You can borrow my car as long as you're careful."
"I don't mind so long as you tell me first."
```

### 9.4 Suppose / Supposing / What if

For imagining scenarios:

```
"Suppose you won the lottery, what would you do?"
"Supposing it rains, shall we cancel?"
"What if we got caught?"
```

### 9.5 But for / If it weren't for

"Without" in conditional meaning:

```
"But for your help, I would have failed."
= "If it weren't for your help..."
= "Without your help..."

"If it hadn't been for the rain, we would have gone out."
```

### 9.6 Otherwise / Or else

Implies a condition:

```
"Hurry up, otherwise you'll be late."
(= If you don't hurry up...)

"Study hard, or else you'll fail."
```

## 10. Common Errors by Russian Speakers

### 10.1 Will in If-Clause

```
❌ "If I will have money, I will buy a car."
✅ "If I have money, I will buy a car."

❌ "If he will come, tell him to wait."
✅ "If he comes, tell him to wait."
```

**Why:** Russian uses future in both clauses: "Если я буду иметь..." English doesn't.

### 10.2 Would in If-Clause

```
❌ "If I would know, I would tell you."
✅ "If I knew, I would tell you."

❌ "If I would have time, I would help."
✅ "If I had time, I would help."
```

### 10.3 Confusing Real and Unreal

```
"If I had more time tomorrow, I would help you."
→ Is this possible or hypothetical?

REAL (might happen): "If I have time tomorrow, I'll help you."
UNREAL (probably not): "If I had time, I would help you."
```

### 10.4 Double Would

```
❌ "If I would have known, I would have helped."
✅ "If I had known, I would have helped."
```

This error is common even among native speakers (informal AmE), but avoid it in formal contexts.

### 10.5 Was vs Were

```
FORMAL:
✅ "If I were you..."
✅ "If she were here..."

Less formal but acceptable:
"If I was rich..."

NEVER:
❌ "If I would be you..."
```

## 💡 Key Takeaways

- **Real vs Unreal**: The core distinction — is the situation possible or hypothetical?
- **Tense backshift signals unreality**: Past for unreal present, Past Perfect for unreal past
- **No "will/would" in if-clause**: The condition gets present/past, not future/conditional
- **Mixed conditionals**: Match each clause to its actual time reference
- **Subjunctive**: Use base verb after suggest/recommend/demand in formal English
