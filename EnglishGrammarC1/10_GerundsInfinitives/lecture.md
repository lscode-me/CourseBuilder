## 1. Gerund vs Infinitive: The Basics

### 1.1 What's the Difference?

Both can function as **nouns** (subjects, objects), but they're not interchangeable:

```
GERUND (-ing form used as noun):
"Swimming is good exercise."
"I enjoy reading."

INFINITIVE (to + base verb):
"To err is human."
"I want to learn."
```

### 1.2 Why It's Hard

**No logical rule** — you must learn which verbs take which form:

```
"I enjoy swimming." ✓ (gerund)
❌ "I enjoy to swim."

"I want to swim." ✓ (infinitive)
❌ "I want swimming."
```

## 2. Verbs Followed by Gerund

### 2.1 Common Verbs + Gerund

**MEGA list (memorize!):**

```
enjoy, finish, avoid, mind, suggest, recommend,
consider, imagine, practice, keep, deny, admit,
delay, postpone, risk, miss, discuss, quit, 
give up, put off, can't help, can't stand,
feel like, be worth, it's no use, it's no good
```

### 2.2 Examples

```
"I enjoy reading."
"She finished writing the report."
"He avoided answering the question."
"Would you mind closing the door?"
"I suggest taking a break."
"They considered moving abroad."
"I can't help laughing."
"It's worth visiting."
"It's no use crying."
```

### 2.3 Preposition + Gerund

After **all prepositions**, use gerund:

```
"I'm interested in learning."
"She's good at swimming."
"Thank you for helping."
"I look forward to hearing from you."
"He apologized for being late."
"Instead of complaining, do something!"
"Before leaving, check everything."
"After finishing, she left."
```

**Common error:**
```
❌ "I look forward to see you."
✅ "I look forward to seeing you."
(NOTE: "to" here is a preposition, not part of infinitive!)
```

## 3. Verbs Followed by Infinitive

### 3.1 Common Verbs + Infinitive

```
want, need, hope, expect, decide, plan, promise,
refuse, agree, offer, seem, appear, pretend,
learn, manage, fail, afford, arrange, demand,
deserve, tend, choose, wish, would like
```

### 3.2 Examples

```
"I want to leave."
"She hopes to get the job."
"They decided to move."
"He promised to call."
"I can't afford to buy a house."
"She agreed to help."
"He pretended to be asleep."
```

### 3.3 Verb + Object + Infinitive

Some verbs take **object + infinitive**:

```
ask, tell, order, advise, warn, encourage, allow,
permit, persuade, remind, invite, expect, want

"She asked me to help."
"I told him to wait."
"They encouraged us to apply."
"He reminded me to call."
"I want you to come."
```

## 4. Verbs That Take Both (Different Meanings!)

### 4.1 Stop

```
STOP + GERUND: Quit the activity
"I stopped smoking." (I quit smoking)

STOP + INFINITIVE: Stop in order to do something
"I stopped to smoke." (I paused to have a cigarette)
```

### 4.2 Remember / Forget

```
REMEMBER + GERUND: Memory of past action
"I remember meeting him." (I met him, I remember it)

REMEMBER + INFINITIVE: Remember to do future action
"Remember to call me." (Don't forget to call)

FORGET + GERUND: Forget a past experience
"I'll never forget visiting Paris."

FORGET + INFINITIVE: Forget to do something
"I forgot to lock the door." (I should have locked it)
```

### 4.3 Try

```
TRY + GERUND: Experiment with something
"Try adding more salt." (experiment — maybe it helps)

TRY + INFINITIVE: Attempt, make an effort
"I tried to open the door." (I attempted but maybe failed)
```

### 4.4 Regret

```
REGRET + GERUND: Regret a past action
"I regret telling her." (I told her, I wish I hadn't)

REGRET + INFINITIVE: Formal announcement
"I regret to inform you..." (I'm sorry to say...)
```

### 4.5 Go On

```
GO ON + GERUND: Continue the same activity
"She went on talking for hours."

GO ON + INFINITIVE: Move to the next activity
"After the introduction, he went on to discuss the main points."
```

### 4.6 Mean

```
MEAN + GERUND: Involve, result in
"This means working overtime."

MEAN + INFINITIVE: Intend
"I didn't mean to hurt you."
```

### 4.7 Like / Love / Hate / Prefer

```
Generally interchangeable, but:

GERUND: General preference, enjoyment
"I like swimming." (I enjoy it in general)

INFINITIVE: Specific occasion, choice
"I'd like to swim now." (I want to swim now)

"I like to arrive early." (specific habit/choice)
"I like arriving early." (generally enjoy it)
```

## 5. Verbs That Take Both (Same Meaning)

Some verbs accept **both forms** with little/no difference:

```
begin, start, continue, intend, bother, love, hate, like, prefer

"It began raining." = "It began to rain."
"She continued working." = "She continued to work."
"I love cooking." ≈ "I love to cook."
```

**Note:** With stative/mental verbs, avoid double -ing:
```
❌ "I was beginning understanding."
✅ "I was beginning to understand."
```

## 6. Perfect and Passive Forms

### 6.1 Perfect Infinitive

**To have + past participle** (completed before main verb):

```
"She seems to have forgotten."
(It seems that she forgot)

"He claims to have met the President."
(He claims he met...)

"I'm happy to have helped."
(I helped, I'm happy about it)
```

### 6.2 Perfect Gerund

**Having + past participle**:

```
"He admitted having stolen the money."
"I remember having seen her somewhere."
"She denied having been there."
```

### 6.3 Passive Infinitive

**To be + past participle**:

```
"She wants to be promoted."
"The building needs to be repaired."
"I expect to be contacted soon."
```

### 6.4 Passive Gerund

**Being + past participle**:

```
"I hate being ignored."
"She remembered being told about it."
"He resents being criticized."
```

## 7. After Adjectives and Nouns

### 7.1 Adjective + Infinitive

```
"It's difficult to understand."
"I'm happy to help."

```

### 7.2 Adjective + Preposition + Gerund

```
"I'm tired of waiting."

```

### 7.3 Noun + Infinitive

```
"I have a lot of work to do."

"She was the first to arrive."
"It's time to go."
```

## 8. Common Errors

### 8.1 Look Forward To

```
❌ "I look forward to see you."
✅ "I look forward to seeing you."

("to" is a preposition here!)
```

### 8.2 Be Used To / Get Used To

```
❌ "I'm used to wake up early."
✅ "I'm used to waking up early."

❌ "I can't get used to live here."
✅ "I can't get used to living here."

(Compare: "I used to wake up early" = past habit, infinitive)
```

### 8.3 Worth

```
❌ "It's worth to visit."
✅ "It's worth visiting."
```

### 8.4 Suggest / Recommend

```
❌ "I suggest to take a break."
✅ "I suggest taking a break."
✅ "I suggest (that) we take a break."
```

### 8.5 Allow / Permit

Two patterns:
```
"They don't allow smoking." (no object → gerund)
"They don't allow us to smoke." (object → infinitive)
```

## 💡 Key Takeaways

- **No logical rule**: Memorize verb patterns
- **After prepositions**: Always gerund (including "look forward to")
- **Both with different meaning**: Stop doing ≠ stop to do
- **Be used to / Get used to**: Always gerund (not infinitive)
- **Perfect/passive forms**: Exist for both (having done, to have done)
