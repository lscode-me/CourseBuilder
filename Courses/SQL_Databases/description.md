# Курс: SQL_Databases

## Описание курса

Курс по реляционным базам данных и языку SQL. Для разработчиков, которые хотят научиться проектировать БД и писать эффективные запросы.

## Цели курса

После прохождения курса слушатель будет:
- понимать основные принципы и концепции SQL_Databases
- уметь применять полученные знания на практике
- ориентироваться в терминологии и инструментарии

## Целевая аудитория

- Разработчики и IT-специалисты
- Студенты технических специальностей
- Все, кто хочет изучить SQL_Databases

## Предварительные требования

12_Advanced оконные функции, CTE, представления, хранимые процедуры.

## План курса

01. **Intro** - что такое базы данных, реляционная модель, СУБД (PostgreSQL, MySQL, SQLite).
02. **BasicQueries** - SELECT, FROM, WHERE, ORDER BY, LIMIT — чтение данных.
03. **Filtering** - операторы сравнения, LIKE, IN, BETWEEN, NULL, логические операторы.
04. **Joins** - INNER JOIN, LEFT/RIGHT JOIN, FULL JOIN, CROSS JOIN, self-join.
05. **Aggregation** - GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX.
06. **Subqueries** - вложенные запросы, коррелированные подзапросы, EXISTS.
07. **DataModification** - INSERT, UPDATE, DELETE, UPSERT, транзакции.
08. **SchemaDesign** - CREATE TABLE, типы данных, PRIMARY KEY, FOREIGN KEY, constraints.
09. **Normalization** - 1NF, 2NF, 3NF, BCNF, денормализация, когда нарушать правила.
10. **Indexes** - индексы, B-tree, hash, как ускорить запросы, EXPLAIN.
11. **Transactions** - ACID, уровни изоляции, блокировки, deadlocks.
12. **Advanced** - оконные функции, CTE, представления, хранимые процедуры.

Примерная длительность: 12-15 часов
