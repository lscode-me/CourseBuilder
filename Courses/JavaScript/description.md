# Курс: JavaScript

## Описание курса

Курс по языку JavaScript и TypeScript. Для разработчиков, которые хотят освоить язык веба и современную экосистему.

## Цели курса

После прохождения курса слушатель будет:
- понимать основные принципы и концепции JavaScript
- уметь применять полученные знания на практике
- ориентироваться в терминологии и инструментарии

## Целевая аудитория

- Разработчики и IT-специалисты
- Студенты технических специальностей
- Все, кто хочет изучить JavaScript

## Предварительные требования

- Современный браузер (Chrome, Firefox, Safari)
- Node.js установленный на компьютере
- Редактор кода (VS Code, WebStorm или аналогичный)
- Базовые знания HTML и CSS

## План курса

1. **Введение в JavaScript** - история JS, ECMAScript, где выполняется, браузер vs Node.js
2. **Основы языка** - переменные, типы данных, let/const/var, операторы
3. **Функции** - функции, стрелочные функции, замыкания, контекст this
4. **Объекты и массивы** - объекты, массивы, деструктуризация, spread/rest
5. **Прототипы и классы** - прототипы, классы, наследование, new
6. **Асинхронность** - колбэки, промисы, async/await, Event Loop
7. **Модули** - ES modules, import/export, CommonJS, бандлеры
8. **Работа с DOM** - работа с DOM, события, манипуляции страницей
9. **Основы TypeScript** - типизация, интерфейсы, типы, дженерики
10. **Продвинутый TypeScript** - utility types, type guards, декораторы
11. **Node.js** - серверный JavaScript, npm, работа с файлами, http
12. **Экосистема** - фреймворки (React, Vue, Express), инструменты (ESLint, Prettier)
12. **Ecosystem** - фреймворки (React, Vue, Express), инструменты (ESLint, Prettier).

Примерная длительность: 12-15 часов
