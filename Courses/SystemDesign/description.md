# Курс: System Design

## Описание курса

Курс по системному дизайну и архитектуре. Для разработчиков и архитекторов, которые хотят освоить проектирование крупных распределенных систем.

## Цели курса

После прохождения курса слушатель будет:
- понимать принципы проектирования распределенных систем
- уметь выбирать архитектурные решения и технологии
- знать как масштабировать системы и обеспечивать надежность

## Целевая аудитория

- Senior разработчики
- Системные архитекторы
- Team Lead и Tech Lead
- Кандидаты на позиции системных архитекторов

## Предварительные требования

- Опыт разработки не менее 3-5 лет
- Знание основ баз данных и сетей
- Понимание принципов веб-разработки

## План курса

1. **Введение в системный дизайн** - масштабируемость, надежность, доступность
2. **Горизонтальное масштабирование** - load balancing, sharding, partitioning
3. **Кэширование** - стратегии, Redis, CDN, browser caching
4. **Базы данных** - SQL vs NoSQL, ACID, CAP theorem
5. **Микросервисы** - монолит vs микросервисы, communication patterns
6. **Очереди сообщений** - async processing, message brokers
7. **Поиск** - full-text search, Elasticsearch, indexing
8. **Мониторинг** - logging, metrics, distributed tracing
9. **API дизайн** - REST, GraphQL, версионирование
10. **Безопасность** - аутентификация, авторизация, HTTPS
11. **Развертывание** - containerization, CI/CD, blue-green
12. **Кейс-стади** - разбор реальных архитектур крупных систем

Примерная длительность: 20-25 часов
