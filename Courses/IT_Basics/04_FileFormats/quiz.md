## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Текстовые файлы содержат символы в кодировке (UTF-8, ASCII и т.д.) и читаемы человеком. |
| 2 | B | PNG — бинарный формат изображений. JSON, Python, HTML — текстовые. |
| 3 | D | Magic numbers — фиксированные байты в начале файла для идентификации формата. |
| 4 | D | PNG начинается с `89 50 4E 47 0D 0A 1A 0A` (.PNG....). |
| 5 | B | JPEG начинается с `FF D8 FF`. |
| 6 | A | DOCX, XLSX, PPTX — это ZIP архивы с XML внутри, начинаются с `50 4B` (PK). |
| 7 | A | `file -i` показывает MIME тип и кодировку. |
| 8 | D | Правильный MIME для JSON: `application/json`. |
| 9 | A | PNG имеет MIME тип `image/png`. |
| 10 | A | Расширение — часть имени файла, его можно изменить без изменения содержимого. |
| 11 | D | Для бинарных файлов нужен режим `'rb'` (read binary). |
| 12 | A | PNG состоит из сигнатуры и chunks (IHDR, IDAT, IEND и др.) с length, type, data, CRC. |
| 13 | C | PDF начинается с `%PDF-` (байты: 25 50 44 46 2D). |
| 14 | C | ELF (Executable and Linkable Format) — формат исполняемых файлов Linux. |
| 15 | C | tar только объединяет файлы. Для сжатия используется gzip/bzip2 (tar.gz, tar.bz2). |
| 16 | B | bzip2 даёт лучшее сжатие, но работает медленнее чем gzip. |
| 17 | A | `Content-Type` — HTTP заголовок для указания MIME типа. |
| 18 | D | `python-magic` (импортируется как `magic`) определяет тип по содержимому. |
| 19 | A | `xxd -l 8` показывает первые 8 байт в hex формате. |
| 20 | A | PNG использует Big-Endian (network byte order) для всех числовых значений. |

| **Менее 10 правильных (<50%)** | 📚 Нужно повторить | Рекомендуется перечитать лекцию и попрактиковаться с командой file. |
