# IT Basics
## Фундаментальные концепции: данные, форматы, кодировки

---

## 📚 О курсе

Этот курс охватывает фундаментальные концепции, которые должен знать каждый IT-специалист. Мы разберём вечные темы, которые являются источником множества проблем и недопонимания: кодировки символов, форматы файлов, структурированные данные и многое другое.

### Целевая аудитория

- Начинающие разработчики
- Системные администраторы
- DevOps инженеры
- Data инженеры
- Все, кто работает с данными и файлами

### Предварительные требования

- Базовое умение работать с компьютером
- Опыт работы в командной строке (желательно)
- Понимание основ программирования (желательно)

## 🛠️ Практические требования

### Рекомендуемое окружение

- Linux, macOS или WSL на Windows
- Терминал с bash или zsh
- Текстовый редактор (VS Code, Vim, etc.)

### Справочник команд

В этом курсе используются команды Linux/Unix. Ниже — краткое описание каждой:

#### Просмотр файлов

| Команда | Описание |
|---------|----------|
| `cat` | Выводит содержимое файла целиком |
| `head` | Показывает первые N строк файла (по умолчанию 10) |
| `tail` | Показывает последние N строк файла |
| `less` | Постраничный просмотр с возможностью скроллинга (выход: `q`) |
| `file` | Определяет тип файла по его содержимому (magic numbers) |

#### Hex-просмотр и редактирование

| Команда | Описание |
|---------|----------|
| `xxd` | Создаёт hex-дамп файла (показывает байты в шестнадцатеричном виде) |
| `hexdump` | Альтернатива xxd для просмотра hex-представления |
| `od` | Octal dump — просмотр файла в восьмеричной, hex или других системах |
| `hexedit` | Интерактивный редактор бинарных файлов в hex-режиме |

#### Кодировки и текст

| Команда | Описание |
|---------|----------|
| `iconv` | Конвертирует файл из одной кодировки в другую |
| `locale` | Показывает текущие настройки локали системы |
| `dos2unix` | Конвертирует переносы строк Windows (CRLF) в Unix (LF) |

#### Обработка данных

| Команда | Описание |
|---------|----------|
| `jq` | Парсер и процессор JSON — фильтрация, извлечение, трансформация |
| `yq` | Аналог jq для YAML файлов |
| `sed` | Потоковый редактор — поиск и замена текста в файлах |

#### Сжатие и архивирование

| Команда | Описание |
|---------|----------|
| `gzip` / `gunzip` | Сжатие/распаковка файлов алгоритмом gzip (.gz) |
| `bzip2` / `bunzip2` | Сжатие/распаковка алгоритмом bzip2 (.bz2) — лучше сжимает, медленнее |
| `xz` / `unxz` | Сжатие/распаковка алгоритмом LZMA (.xz) — лучшее сжатие |
| `zcat` | Просмотр содержимого .gz файла без распаковки |
| `tar` | Объединяет файлы в архив (без сжатия), часто вместе с gzip/bzip2/xz |
| `zip` / `unzip` | Создание/распаковка ZIP-архивов |
| `zipinfo` | Показывает информацию о содержимом ZIP-архива |

#### Хэши и контрольные суммы

| Команда | Описание |
|---------|----------|
| `md5sum` | Вычисляет MD5 хэш файла (128 бит, устаревший) |
| `sha1sum` | Вычисляет SHA-1 хэш (160 бит, устаревший) |
| `sha256sum` | Вычисляет SHA-256 хэш — рекомендуемый стандарт |
| `sha512sum` | Вычисляет SHA-512 хэш (512 бит) |
| `shasum` | Универсальная команда для SHA (macOS), флаг `-a` для выбора алгоритма |

#### Работа с файлами

| Команда | Описание |
|---------|----------|
| `chmod` | Изменяет права доступа к файлу (rwx для owner/group/others) |
| `cp` | Копирует файлы и директории |
| `mv` | Перемещает или переименовывает файлы |
| `find` | Ищет файлы по имени, типу, размеру и другим критериям |
| `strings` | Извлекает текстовые строки из бинарных файлов |

#### Анализ бинарных файлов

| Команда | Описание |
|---------|----------|
| `binwalk` | Анализирует бинарные файлы, находит встроенные файлы и сигнатуры |
| `exiftool` | Читает и редактирует метаданные изображений и медиафайлов |
| `readelf` | Показывает информацию о ELF-файлах (исполняемые в Linux) |
| `objdump` | Дизассемблер и анализатор объектных файлов |
| `nm` | Показывает символы (функции, переменные) в объектных файлах |

#### Вывод и форматирование

| Команда | Описание |
|---------|----------|
| `echo` | Выводит текст в терминал |
| `printf` | Форматированный вывод текста (как в C) |
| `man` | Показывает справку по команде (выход: `q`) |

#### Сеть и загрузка

| Команда | Описание |
|---------|----------|
| `curl` | HTTP-клиент для загрузки файлов и работы с API |
| `wget` | Загружает файлы из интернета |

#### Кодирование данных

| Команда | Описание |
|---------|----------|
| `base64` | Кодирует/декодирует данные в Base64 |

> **💡 Совет:** Используйте `man <команда>` для получения подробной справки по любой команде, например `man tar`.

### Установка инструментов

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y jq file xxd coreutils vim-common  # vim-common содержит xxd
sudo apt install -y dos2unix exiftool binwalk         # дополнительные утилиты

# macOS
brew install jq coreutils exiftool binwalk

# yq (YAML процессор) — установка отдельно
# https://github.com/mikefarah/yq/releases

# Python библиотеки (опционально, для практики)

pip install chardet pyyaml
```

> **Примечание:** Большинство базовых команд (`cat`, `head`, `tail`, `tar`, `gzip`, `file`, `chmod`, `find`, `md5sum`, `sha256sum`) уже предустановлены в Linux и macOS.
