## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Язык разметки аннотирует текст тегами для структурирования и форматирования. |
| 2 | A | HTML (HyperText Markup Language) — стандарт для веб-страниц. |
| 3 | A | DOCTYPE указывает браузеру использовать стандартный (standards) режим рендеринга. |
| 4 | C | `<nav>` — семантический тег HTML5 для навигации. |
| 5 | D | XML позволяет создавать произвольные теги, HTML имеет фиксированный набор. |
| 6 | A | XML требует точного совпадения регистра открывающего и закрывающего тегов. |
| 7 | C | `&lt;` — entity для символа `<` в XML и HTML. |
| 8 | C | `##` создаёт `<h2>` (заголовок второго уровня). |
| 9 | B | `**текст**` или `__текст__` создают жирный текст. |
| 10 | C | `[текст](url)` — синтаксис ссылки в Markdown. |
| 11 | B | Три обратных кавычки с указанием языка для подсветки синтаксиса. |
| 12 | C | `|` (вертикальная черта) разделяет ячейки таблицы в Markdown. |
| 13 | D | `id` должен быть уникальным на странице, `class` может повторяться. |
| 14 | B | XML документ должен иметь ровно один корневой элемент. |
| 15 | C | `*`, `-` или `+` начинают маркированный список. |
| 16 | D | `method="GET"` или `method="POST"` указывает HTTP метод. |
| 17 | A | SVG (Scalable Vector Graphics) — XML-based формат векторной графики. |
| 18 | B | `> текст` создаёт blockquote (цитату). |
| 19 | D | Namespaces предотвращают конфликты имён при использовании тегов из разных схем. |
| 20 | A | pandoc — универсальный конвертер документов. |
