# Введение в программирование на языке Rust

Rust — современный системный язык программирования, ориентированный на безопасность памяти, высокую производительность и надёжность без использования сборщика мусора.

Rust сочетает идеи системного программирования, функционального программирования, строгой типизации и современных инструментов разработки.

Язык широко используется для системных и инфраструктурных компонентов, backend‑сервисов, embedded‑разработки и высоконагруженных безопасных систем.

## 🎯 Для кого этот курс

- Разработчики с опытом в других языках (Python, Java, C/C++, JavaScript)
- Системные программисты, желающие изучить современную альтернативу C/C++
- Backend-разработчики, интересующиеся высокопроизводительными решениями
- Все, кто хочет понять философию Rust и его применение

Вы будете:

- Понимать философию и цели Rust

## 📖 Как проходить курс

1. **Последовательно** — модули построены от простого к сложному
2. **С практикой** — пробуйте все примеры кода
3. **С квизами** — проверяйте понимание после каждой лекции
4. **С размышлением** — формируйте понимание, когда Rust уместен
