## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | main() — это точка входа в программу, обязательная для всех исполняемых программ на Rust |
| 2 | D | Правильный синтаксис: `fn main() { }`, где `fn` — ключевое слово для определения функции |
| 3 | C | println! — это макрос (обозначается восклицательным знаком), а не обычная функция |
| 4 | C | Восклицательный знак указывает, что это макрос, который обрабатывается на этапе компиляции |
| 5 | D | Код выведет "Hello, Alice!", так как {} заменяется значением переменной name |
| 6 | A | В строке три плейсхолдера {}, которые будут заменены на 5, 3 и 8 соответственно |
| 7 | A | cargo run компилирует код (если нужно) и запускает программу |
| 8 | B | После cargo build исполняемый файл находится в target/debug/ (для debug сборки) |
| 9 | C | Оптимизированная сборка создаётся командой cargo build --release |
| 10 | B | println! выводит с переводом строки (\n), print! выводит без перевода строки |
| 11 | D | {:b} форматирует число в двоичном виде, поэтому 10 в десятичной = 1010 в двоичной |
| 12 | B | Позиционные аргументы {0} и {1} позволяют использовать аргументы в любом порядке |
| 13 | C | Однострочные комментарии в Rust начинаются с // |
| 14 | D | cargo check проверяет код на ошибки без создания исполняемого файла (быстрее чем build) |
| 15 | B | cargo fmt автоматически форматирует код согласно стандартам Rust |
| 16 | B | Ошибка компиляции: отсутствует точка с запятой после println!("Hello") |
| 17 | A | {:>10} выравнивает текст вправо на 10 символов, поэтому "right" будет справа |
| 18 | C | Именованные аргументы позволяют использовать {name} с указанием name = "Alice" |
| 19 | A | Каждый println! выводит новую строку, поэтому будет выведено 3 строки |
| 20 | B | Файл main.rs находится в директории src/ проекта, созданного через cargo new |
| 21 | C | Плейсхолдеры {} заменяются значениями переменных x и y |
| 22 | D | {:x} форматирует число в шестнадцатеричном виде в нижнем регистре, 255 = ff |
| 23 | A | {:*^10} центрирует текст "hi" и заполняет пробелы звёздочками, получается ****hi**** |
| 24 | D | Документационные комментарии начинаются с /// и используются для генерации документации |
| 25 | D | Скомпилированный файл можно запустить напрямую: ./target/debug/hello_world |
