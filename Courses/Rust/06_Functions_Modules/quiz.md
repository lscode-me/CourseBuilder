## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Правильный синтаксис: `fn имя(параметры) -> тип_возврата { }` |
| 2 | A | Выражение `x + y` без точки с запятой возвращается автоматически |
| 3 | C | Точка с запятой превращает выражение в оператор, который возвращает () |
| 4 | B | pub делает элемент публичным (доступным извне модуля) |
| 5 | B | Модули создаются с помощью `mod имя { }` |
| 6 | B | use импортирует элементы модуля для более короткого синтаксиса |
| 7 | C | Функция без pub приватна и недоступна извне модуля |
| 8 | B | `x + y` — выражение, вычисляющее значение; остальное — операторы |
| 9 | C | Функция возвращает кортеж из двух значений |
| 10 | B | Вложенные модули обращаются через `::` |
| 11 | C | super обращается к родительскому модулю: `super::function()` |
| 12 | D | self в use импортирует текущий модуль: `use self::module` |
| 13 | B | pub use реэкспортирует элемент, делая его доступным через текущий модуль |
| 14 | C | Модули можно создавать в отдельных файлах через mod.rs или файл с именем модуля |
| 15 | C | Несколько значений возвращаются через кортеж: `(value1, value2)` |
| 16 | D | Замыкание — анонимная функция, которая может захватывать переменные из области видимости |
| 17 | C | Рекурсивные функции поддерживаются в Rust |
| 18 | A | Функция высшего порядка — функция, принимающая или возвращающая другие функции |
| 19 | C | Тесты размещаются в том же модуле через `#[cfg(test)] mod tests { }` |
| 20 | B | `use ... as` импортирует с переименованием для избежания конфликтов имён |
