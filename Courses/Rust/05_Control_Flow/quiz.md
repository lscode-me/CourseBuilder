## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | if возвращает значение, в данном случае 5, так как условие true |
| 2 | B | Ошибка компиляции: все ветки if должны возвращать значения одного типа |
| 3 | C | loop возвращает значение через break, counter * 2 = 3 * 2 = 6 |
| 4 | D | while выполняется пока x != 0, выводит 3, 2, 1, затем x становится 0 и цикл завершается |
| 5 | A | Диапазон 1..5 не включает 5, поэтому выводит 1 2 3 4 |
| 6 | B | Диапазон 1..=3 включает 3, поэтому выводит 1 2 3 |
| 7 | D | match должен покрывать все возможные случаи, нужен catch-all паттерн _ |
| 8 | D | x = 10 не попадает в диапазоны 1..5 и 6..9, поэтому срабатывает catch-all _ |
| 9 | C | continue пропускает итерацию когда i == 3, поэтому выводит 1 2 4 5 |
| 10 | D | break 'outer прерывает внешний цикл когда i==2 и j==2, поэтому последний вывод 21 |
| 11 | A | while let — цикл, который выполняется пока паттерн совпадает |
| 12 | C | match guards проверяет условие, x=5 > 3, поэтому выводит "больше 3" |
| 13 | B | Match guards — дополнительные условия в match: `Some(x) if условие => ...` |
| 14 | C | if let проверяет паттерн, opt = None не совпадает, выполняется else |
| 15 | C | return можно использовать в loop для выхода из функции |
| 16 | C | Вложенные if проверяют условия последовательно, x=5 между 0 и 10 |
| 17 | D | age=25 попадает в диапазон 18..64, поэтому выводит "взрослый" |
| 18 | A | for итерируется по ссылкам, v остаётся доступным, выводит элементы и вектор |
| 19 | A | match деструктурирует кортеж, (0, 5) совпадает с (0, y), выводит y=5 |
| 20 | A | continue пропускает итерацию когда x==3, поэтому выводит 1 2 4 5 |
