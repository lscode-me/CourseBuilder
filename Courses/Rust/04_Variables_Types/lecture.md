## 1. Объявление переменных

### 1.1 let — неизменяемые переменные

В Rust переменные по умолчанию **неизменяемые** (immutable). Это ключевая особенность языка для обеспечения безопасности.

**Example: Базовое объявление**

```rust

fn main() {
    let x = 5;
    println!("x = {}", x);
}
```

**Output:**
```

x = 5
```

**Попытка изменить неизменяемую переменную:**

```rust

fn main() {
    let x = 5;
    x = 6;  // Ошибка компиляции!
    println!("x = {}", x);
}
```

**Ошибка компиляции:**
```

error[E0384]: cannot assign twice to immutable variable `x`
 --> src/main.rs:3:5
  |
2 |     let x = 5;
  |         - first assignment to `x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
```

### 1.2 let mut — изменяемые переменные

Для создания изменяемой переменной используется ключевое слово **mut** (mutable).

**Example: Изменяемая переменная**

```rust

fn main() {
    let mut x = 5;
    println!("x = {}", x);
    x = 6;
    println!("x = {}", x);
}
```

**Output:**
```

x = 5
x = 6
```

**Почему неизменяемость по умолчанию?**

- **Безопасность:** Предотвращает случайные изменения

- **Параллелизм:** Неизменяемые данные безопасны для многопоточности

- **Читаемость:** Явно показывает намерение изменить значение

> **💡 Pro Tip:**  
> Используйте `mut` только когда действительно нужно изменять значение. Это делает код более безопасным и понятным.

## 2. Примитивные типы

### 2.1 Целочисленные типы

Rust имеет несколько целочисленных типов разного размера:

| Тип | Размер | Диапазон |
|-----|--------|----------|
| i8 | 8 бит | -128 до 127 |
| i16 | 16 бит | -32,768 до 32,767 |
| i32 | 32 бит | -2,147,483,648 до 2,147,483,647 |
| i64 | 64 бит | -9,223,372,036,854,775,808 до 9,223,372,036,854,775,807 |
| i128 | 128 бит | Очень большой диапазон |
| isize | Зависит от архитектуры | Размер указателя |
| u8 | 8 бит | 0 до 255 |
| u16 | 16 бит | 0 до 65,535 |
| u32 | 32 бит | 0 до 4,294,967,295 |
| u64 | 64 бит | 0 до 18,446,744,073,709,551,615 |
| u128 | 128 бит | Очень большой диапазон |
| usize | Зависит от архитектуры | Размер указателя |

**i** — знаковые (signed) типы (могут быть отрицательными)  
**u** — беззнаковые (unsigned) типы (только положительные)

**Example: Целочисленные типы**

```rust

fn main() {
    let a: i32 = 42;
    let b: u32 = 42;
    let c: i8 = -128;
    let d: u8 = 255;
    
    println!("a (i32) = {}", a);
    println!("b (u32) = {}", b);
    println!("c (i8) = {}", c);
    println!("d (u8) = {}", d);
}
```

**Output:**
```

a (i32) = 42
b (u32) = 42
c (i8) = -128
d (u8) = 255
```

**Тип по умолчанию:** `i32` для целых чисел.

### 2.2 Числа с плавающей точкой

Rust имеет два типа для чисел с плавающей точкой:

- **f32** — 32-битное число (одинарная точность)

- **f64** — 64-битное число (двойная точность)

**Тип по умолчанию:** `f64`.

**Example: Числа с плавающей точкой**

```rust

fn main() {
    let x: f32 = 3.14;
    let y: f64 = 2.71828;
    let z = 1.5;  // f64 по умолчанию
    
    println!("x (f32) = {}", x);
    println!("y (f64) = {}", y);
    println!("z (f64) = {}", z);
}
```

**Output:**
```

x (f32) = 3.14
y (f64) = 2.71828
z (f64) = 1.5
```

### 2.3 Булев тип

**bool** — логический тип с двумя значениями: `true` и `false`.

**Example: Булев тип**

```rust

fn main() {
    let is_rust_fun: bool = true;
    let is_learning: bool = false;
    
    println!("Rust интересен? {}", is_rust_fun);
    println!("Изучаем? {}", is_learning);
}
```

**Output:**
```

Rust интересен? true
Изучаем? false
```

### 2.4 Символьный тип

**char** — 32-битный Unicode символ (не байт!).

**Example: Символьный тип**

```rust

fn main() {
    let letter: char = 'A';
    let emoji: char = '🦀';
    let chinese: char = '中';
    
    println!("Буква: {}", letter);
    println!("Эмодзи: {}", emoji);
    println!("Китайский: {}", chinese);
}
```

**Output:**
```

Буква: A
Эмодзи: 🦀
Китайский: 中
```

**Важно:** `char` — это один Unicode символ, а не байт. Строки рассматриваются отдельно.

## 3. Вывод типов (Type Inference)

### 3.1 Автоматический вывод типов

Rust может автоматически определять тип переменной на основе значения.

**Example: Вывод типов**

```rust

fn main() {
    let x = 5;        // i32
    let y = 3.14;     // f64
    let z = true;     // bool
    let c = 'A';      // char
    
    println!("x: {}, тип: i32", x);
    println!("y: {}, тип: f64", y);
    println!("z: {}, тип: bool", z);
    println!("c: {}, тип: char", c);
}
```

**Output:**
```

x: 5, тип: i32
y: 3.14, тип: f64
z: true, тип: bool
c: A, тип: char
```

### 3.2 Когда нужна аннотация типа

**Примеры, когда компилятор не может вывести тип:**

**Example: Неоднозначность типа**

```rust

fn main() {
    // Ошибка: неоднозначный тип
    // let x = vec![];
    
    // Правильно: явная аннотация типа
    let x: Vec<i32> = vec![];
    println!("x = {:?}", x);
}
```

**Example: Функции с параметрами**

```rust

fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let result = add(5, 3);
    println!("Результат: {}", result);
}
```

**Output:**
```

Результат: 8
```

В функциях типы параметров и возвращаемого значения должны быть указаны явно.

## 4. Аннотации типов

### 4.1 Явное указание типа

Хотя Rust выводит типы автоматически, иногда полезно указывать их явно для ясности.

**Example: Явные аннотации**

```rust

fn main() {
    let x: i32 = 5;
    let y: f64 = 3.14;
    let is_active: bool = true;
    let name: &str = "Rust";
    
    println!("x = {}", x);
    println!("y = {}", y);
    println!("is_active = {}", is_active);
    println!("name = {}", name);
}
```

**Output:**
```

x = 5
y = 3.14
is_active = true
name = Rust
```

### 4.2 Когда использовать аннотации

**Рекомендуется использовать аннотации:**

- В сигнатурах функций
- Когда тип неочевиден из контекста
- Для документации кода
- Когда нужно явно указать размер типа

**Example: Функция с аннотациями**

```rust

fn calculate_area(width: f64, height: f64) -> f64 {
    width * height
}

fn main() {
    let area = calculate_area(10.0, 5.0);
    println!("Площадь: {}", area);
}
```

**Output:**
```

Площадь: 50
```

## 5. Числовые литералы

### 5.1 Различные форматы записи

**Example: Различные форматы чисел**

```rust

fn main() {
    let decimal = 98_222;        // 98222
    let hex = 0xff;              // 255 в десятичной
    let octal = 0o77;            // 63 в десятичной
    let binary = 0b1111_0000;    // 240 в десятичной
    let byte = b'A';             // 65 (u8)
    
    println!("Десятичное: {}", decimal);
    println!("Шестнадцатеричное: {}", hex);
    println!("Восьмеричное: {}", octal);
    println!("Двоичное: {}", binary);
    println!("Байт: {}", byte);
}
```

**Output:**
```

Десятичное: 98222
Шестнадцатеричное: 255
Восьмеричное: 63
Двоичное: 240
Байт: 65
```

**Подчёркивания (`_`)** можно использовать для читаемости больших чисел.

### 5.2 Типы числовых литералов

**Example: Указание типа литерала**

```rust

fn main() {
    let x = 5u32;        // u32
    let y = 3.14f32;     // f32
    let z = 1000i64;     // i64
    
    println!("x: {} (u32)", x);
    println!("y: {} (f32)", y);
    println!("z: {} (i64)", z);
}
```

**Output:**
```

x: 5 (u32)
y: 3.14 (f32)
z: 1000 (i64)
```

## 6. Преобразование типов

### 6.1 Явное преобразование (as)

**Example: Преобразование типов**

```rust

fn main() {
    let x: i32 = 42;
    let y: f64 = x as f64;
    let z: u8 = 255;
    let w: i16 = z as i16;
    
    println!("x (i32) = {}", x);
    println!("y (f64) = {}", y);
    println!("z (u8) = {}", z);
    println!("w (i16) = {}", w);
}
```

**Output:**
```

x (i32) = 42
y (f64) = 42
z (u8) = 255
w (i16) = 255
```

**⚠️ Warning:**  
Преобразование может привести к потере данных или переполнению. Будьте осторожны!

**Example: Потенциальная потеря данных**

```rust

fn main() {
    let x: f64 = 3.14;
    let y: i32 = x as i32;  // Теряется дробная часть
    
    println!("x (f64) = {}", x);
    println!("y (i32) = {}", y);
}
```

**Output:**
```

x (f64) = 3.14
y (i32) = 3
```

## 7. Константы

### 7.1 Объявление констант

**const** — константы, которые должны быть известны на этапе компиляции.

**Example: Константы**

```rust

const MAX_POINTS: u32 = 100_000;
const PI: f64 = 3.14159;

fn main() {
    println!("Максимум очков: {}", MAX_POINTS);
    println!("Пи: {}", PI);
}
```

**Output:**
```

Максимум очков: 100000
Пи: 3.14159
```

**Отличия const от let:**

- Константы всегда неизменяемы (не нужен mut)
- Должны иметь аннотацию типа
- Должны быть известны на этапе компиляции
- Могут быть объявлены в глобальной области видимости

### 7.2 Статические переменные

**static** — глобальные переменные с временем жизни всей программы.

**Example: Статические переменные**

```rust

static LANGUAGE: &str = "Rust";
static mut COUNTER: u32 = 0;

fn main() {
    println!("Язык: {}", LANGUAGE);
    
    unsafe {
        COUNTER += 1;
        println!("Счётчик: {}", COUNTER);
    }
}
```

**Output:**
```

Язык: Rust
Счётчик: 1
```

**⚠️ Warning:**  
Изменяемые статические переменные требуют блока `unsafe` из-за проблем с безопасностью многопоточности.

## 8. Тенирование (Shadowing)

### 8.1 Что такое shadowing

**Shadowing** — возможность объявить новую переменную с тем же именем, что скрывает предыдущую.

**Example: Shadowing**

```rust

fn main() {
    let x = 5;
    let x = x + 1;
    let x = x * 2;
    
    println!("x = {}", x);
}
```

**Output:**
```

x = 12
```

**Что происходит:**

1. `x = 5`
2. `x = 5 + 1 = 6` (новая переменная x)
3. `x = 6 * 2 = 12` (ещё одна новая переменная x)

### 8.2 Shadowing vs mut

**Example: Shadowing позволяет менять тип**

```rust

fn main() {
    let spaces = "   ";           // &str
    let spaces = spaces.len();    // usize (можно изменить тип!)
    
    println!("Количество пробелов: {}", spaces);
}
```

**Output:**
```

Количество пробелов: 3
```

**С mut это невозможно:**

```rust

fn main() {
    let mut spaces = "   ";
    spaces = spaces.len();  // Ошибка: несовместимые типы!
}
```

**Ошибка компиляции:**
```

error[E0308]: mismatched types

 --> src/main.rs:3:13
  |
3 |     spaces = spaces.len();
  |             ^^^^^^^^^^^^ expected `&str`, found `usize`
```

> **💡 Pro Tip:**  
> Shadowing полезен, когда нужно преобразовать значение в другой тип, сохраняя то же имя переменной.

## 9. Кортежи (Tuples)

### 9.1 Базовое использование

**Кортеж** — коллекция значений разных типов фиксированного размера.

**Example: Кортежи**

```rust

fn main() {
    let tup: (i32, f64, bool) = (500, 6.4, true);
    
    println!("Кортеж: {:?}", tup);
    println!("Первый элемент: {}", tup.0);
    println!("Второй элемент: {}", tup.1);
    println!("Третий элемент: {}", tup.2);
}
```

**Output:**
```

Кортеж: (500, 6.4, true)
Первый элемент: 500
Второй элемент: 6.4
Третий элемент: true
```

### 9.2 Деструктуризация кортежей

**Example: Деструктуризация**

```rust

fn main() {
    let tup = (500, 6.4, true);
    let (x, y, z) = tup;
    
    println!("x = {}", x);
    println!("y = {}", y);
    println!("z = {}", z);
}
```

**Output:**
```

x = 500
y = 6.4
z = true
```

## 10. Массивы

### 10.1 Базовое использование

**Массив** — коллекция элементов одного типа фиксированного размера.

**Example: Массивы**

```rust

fn main() {
    let arr: [i32; 5] = [1, 2, 3, 4, 5];
    
    println!("Массив: {:?}", arr);
    println!("Первый элемент: {}", arr[0]);
    println!("Второй элемент: {}", arr[1]);
}
```

**Output:**
```

Массив: [1, 2, 3, 4, 5]
Первый элемент: 1
Второй элемент: 2
```

### 10.2 Инициализация массива

**Example: Инициализация одинаковыми значениями**

```rust

fn main() {
    let arr = [3; 5];  // Массив из 5 элементов, каждый равен 3
    
    println!("Массив: {:?}", arr);
}
```

**Output:**
```

Массив: [3, 3, 3, 3, 3]
```

**⚠️ Warning:**  
Выход за границы массива вызывает панику во время выполнения!

```rust

fn main() {
    let arr = [1, 2, 3];
    println!("{}", arr[10]);  // Паника!
}
```

- **let создаёт неизменяемые переменные:** По умолчанию переменные неизменяемы для безопасности

- **Rust имеет богатую систему типов:** Целые числа, числа с плавающей точкой, bool, char

- **Вывод типов автоматический:** Компилятор определяет типы, но можно указать явно

- **Shadowing позволяет переиспользовать имена:** Полезно для преобразования типов
