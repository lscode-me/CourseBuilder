# Курс: Введение в программирование на языке Rust

## Описание курса

Rust — современный системный язык программирования,
ориентированный на безопасность памяти, высокую производительность
и надёжность без использования сборщика мусора.

Rust сочетает идеи:
- системного программирования;
- функционального программирования;
- строгой типизации;
- современных инструментов разработки.

Язык широко используется для:
- системных и инфраструктурных компонентов;
- backend‑сервисов;
- embedded‑разработки;
- высоконагруженных и безопасных систем.

Курс даёт практическое и концептуальное введение в Rust
для разработчиков с опытом в других языках.

---

## Цели курса

После прохождения курса слушатель:
- понимает философию и цели Rust;
- умеет писать базовые программы на Rust;
- понимает ownership и borrowing;
- работает с типами и ошибками;
- понимает, где Rust применять не стоит.
