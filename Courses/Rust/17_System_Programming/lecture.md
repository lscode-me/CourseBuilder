## 1. Понятие системного программирования

### 1.1 Что такое системное программирование

**Системное программирование** — разработка программ, которые:
- Работают близко к аппаратному обеспечению
- Управляют системными ресурсами
- Обеспечивают работу других программ
- Требуют полного контроля над системой

**Примеры:**

- Операционные системы
- Драйверы устройств
- Системные библиотеки
- Сетевые стеки
- Виртуальные машины

### 1.2 Характеристики системного программирования

**Ключевые требования:**

- **Производительность** — минимальный overhead

- **Контроль** — полный контроль над ресурсами

- **Надёжность** — критически важные компоненты

- **Предсказуемость** — детерминированное поведение

## 2. User Space vs Kernel Space

### 2.1 User Space

**User Space** — пространство, где выполняются пользовательские приложения.

**Характеристики:**

- Изолированное выполнение
- Ограниченный доступ к ресурсам
- Защита от других процессов
- Системные вызовы для доступа к ядру

**Example: User space программа**

```rust

use std::fs::File;

fn main() {
    // Системный вызов через стандартную библиотеку
    let file = File::open("data.txt");
    // ...
}
```

### 2.2 Kernel Space

**Kernel Space** — пространство, где выполняется ядро ОС.

**Характеристики:**

- Полный доступ к ресурсам
- Управление памятью
- Управление процессами
- Прямой доступ к железу

**Примеры:**

- Драйверы устройств
- Управление памятью
- Планировщик процессов

### 2.3 Граница между пространствами

**Системные вызовы** — интерфейс между user space и kernel space.

**Примеры системных вызовов:**

- `open()` — открытие файла
- `read()` — чтение данных
- `write()` — запись данных
- `fork()` — создание процесса
- `exec()` — выполнение программы
- `mmap()` — отображение памяти
- `socket()` — создание сокета

**Example: Системный вызов в Rust**

```rust

use std::fs::File;
use std::io::Read;

fn main() -> std::io::Result<()> {
    // File::open вызывает системный вызов open()
    let mut file = File::open("data.txt")?;
    let mut contents = String::new();
    // read_to_string вызывает системный вызов read()
    file.read_to_string(&mut contents)?;
    println!("{}", contents);
    Ok(())
}
```

### 2.4 Переключение контекста

**При системном вызове происходит:**

1. Переключение из user space в kernel space
2. Выполнение кода ядра
3. Возврат в user space

**Это дорогая операция**, поэтому важно минимизировать количество системных вызовов.

## 3. Контроль памяти и ресурсов

### 3.1 Управление памятью

**В системном программировании:**

- Прямой контроль над памятью
- Управление heap и stack
- Работа с указателями
- Отсутствие сборщика мусора

**Rust преимущества:**

- Безопасность памяти без GC
- Предсказуемое управление памятью
- Нет runtime overhead

### 3.2 Управление ресурсами

**Системные ресурсы:**

- Память
- Файловые дескрипторы
- Сетевые соединения
- Процессы и потоки
- Семафоры и мьютексы
- Разделяемая память

**RAII в Rust:**

- Автоматическое управление ресурсами
- Гарантированное освобождение
- Без утечек ресурсов

**Example: RAII для файлов**

```rust

use std::fs::File;
use std::io::Write;

fn write_data() -> std::io::Result<()> {
    // Файл автоматически закроется при выходе из области видимости
    let mut file = File::create("output.txt")?;
    file.write_all(b"Hello, world!")?;
    // Файл закрывается здесь автоматически
    Ok(())
}

fn main() {
    write_data().unwrap();
}
```

### 3.3 Управление процессами

**В системном программировании:**

- Создание процессов
- Управление жизненным циклом
- Коммуникация между процессами
- Синхронизация

**Example: Создание процесса**

```rust

use std::process::Command;

fn main() {
    let output = Command::new("echo")
        .arg("Hello from process")
        .output()
        .expect("Не удалось выполнить команду");
    
    println!("{}", String::from_utf8_lossy(&output.stdout));
}
```

### 3.4 Управление потоками

**Потоки в системном программировании:**

- Создание и управление потоками
- Синхронизация
- Разделяемая память
- Приоритеты

**Example: Системные потоки**

```rust

use std::thread;
use std::time::Duration;

fn main() {
    let handle = thread::spawn(|| {
        for i in 1..5 {
            println!("Поток: {}", i);
            thread::sleep(Duration::from_millis(100));
        }
    });
    
    handle.join().unwrap();
}
```

## 4. Почему Rust подходит для системного уровня

### 4.1 Безопасность без потери производительности

**Rust обеспечивает:**

- Безопасность памяти на этапе компиляции
- Производительность уровня C/C++
- Отсутствие runtime overhead
- Предсказуемое поведение

**Сравнение подходов:**

| Подход | Безопасность | Производительность | Runtime |
|--------|--------------|-------------------|---------|
| C/C++ | Ручное управление | ⭐⭐⭐⭐⭐ | Нет |
| Rust | Компилятор гарантирует | ⭐⭐⭐⭐⭐ | Нет |
| Java/Go | GC проверяет | ⭐⭐⭐ | Да |
| Python | GC проверяет | ⭐⭐ | Да |

### 4.2 Сравнение с C/C++

| Аспект | C/C++ | Rust |
|--------|-------|------|
| Безопасность памяти | Ручное управление | Гарантируется компилятором |
| Производительность | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| Время компиляции | Быстрое | Медленное (проверки) |
| Отладка | Сложная | Проще (меньше ошибок) |
| Экосистема | Огромная | Растущая |
| Кривая обучения | Средняя | Крутая |

### 4.3 Реальные применения

**Примеры системного Rust:**

- **Linux Kernel** — поддержка Rust в ядре (6.1+)

- **Redox OS** — ОС на Rust

- **Firecracker** — микро-VM для serverless

- **TiKV** — распределённая база данных

- **Servo** — движок браузера

**Примеры компонентов:**

- Драйверы устройств
- Файловые системы
- Сетевые стеки
- Виртуальные машины

### 4.4 Преимущества для системного программирования

**Ключевые преимущества:**

1. **Безопасность памяти** — предотвращение целого класса ошибок
2. **Производительность** — без overhead от GC
3. **Предсказуемость** — детерминированное поведение
4. **Современные инструменты** — cargo, rust-analyzer
5. **Растущая экосистема** — библиотеки для системного программирования

## 6. Практические примеры

### 6.1 Пример: Системный монитор

```rust

use std::process::Command;

fn get_system_info() -> String {
    // Получение системной информации
    let output = Command::new("uname")
        .arg("-a")
        .output()
        .expect("Не удалось выполнить команду");
    
    String::from_utf8_lossy(&output.stdout).to_string()
}

fn main() {
    println!("Системная информация: {}", get_system_info());
}
```

### 6.2 Пример: Управление процессами

```rust

use std::process::{Command, Stdio};

fn main() {
    let mut child = Command::new("sleep")
        .arg("5")
        .stdout(Stdio::piped())
        .spawn()
        .expect("Не удалось запустить процесс");
    
    let output = child.wait_with_output()
        .expect("Ошибка ожидания процесса");
    
    println!("Процесс завершён с кодом: {:?}", output.status.code());
}
```

### 6.3 Пример: Работа с файловой системой

```rust

use std::fs;
use std::path::Path;

fn list_directory(path: &Path) -> std::io::Result<()> {
    for entry in fs::read_dir(path)? {
        let entry = entry?;
        let path = entry.path();
        println!("{}", path.display());
    }
    Ok(())
}

fn main() {
    list_directory(Path::new(".")).unwrap();
}
```
