## 1. Гравитация

### 1.1 Закон всемирного тяготения

**Гравитация** — основная сила, управляющая Вселенной.

**Закон Ньютона:**

```python
# Закон всемирного тяготения
gravity = {
    "формула": "F = G × (m₁ × m₂) / r²",
    "где": {
        "F": "Сила притяжения",
        "G": "Гравитационная постоянная (6.67 × 10⁻¹¹ Н·м²/кг²)",
        "m₁, m₂": "Массы объектов",
        "r": "Расстояние между центрами"
    },
    "свойства": {
        "всегда_притяжение": "Только притяжение, нет отталкивания",
        "дальнодействие": "Действует на любых расстояниях",
        "слабая": "Самая слабая из фундаментальных сил"
    }
}

print("Закон всемирного тяготения:")
for key, value in gravity.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Закон всемирного тяготения:
  Формула: F = G × (m₁ × m₂) / r²

Где:
  F: Сила притяжения
  G: Гравитационная постоянная (6.67 × 10⁻¹¹ Н·м²/кг²)
  M₁, M₂: Массы объектов
  R: Расстояние между центрами

Свойства:
  Всегда Притяжение: Tолько притяжение, нет отталкивания
  Дальнодействие: Действует на любых расстояниях
  Слабая: Самая слабая из фундаментальных сил
```

### 1.2 Роль гравитации в космосе

**Гравитация управляет:**

```python
# Роль гравитации
gravity_role = {
    "формирование": {
        "звёзды": "Коллапс облаков",
        "планеты": "Аккреция в протопланетном диске",
        "галактики": "Коллапс тёмной материи"
    },
    "удержание": {
        "орбиты": "Планеты вокруг звёзд",
        "звёзды": "В галактиках",
        "галактики": "В скоплениях"
    },
    "эволюция": {
        "звёзды": "Гравитационный коллапс → синтез",
        "чёрные_дыры": "Коллапс под действием гравитации"
    }
}

print("Роль гравитации в космосе:")
for category, details in gravity_role.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Роль гравитации в космосе:
  Формирование:
    Звёзды: Коллапс облаков
    Планеты: Аккреция в протопланетном диске
    Галактики: Коллапс тёмной материи

Удержание:
    Орбиты: Планеты вокруг звёзд
    Звёзды: В галактиках
    Галактики: В скоплениях

Эволюция:
    Звёзды: Гравитационный коллапс → синтез
    Чёрные Дыры: Коллапс под действием гравитации
```

## 2. Плазма

### 2.1 Что такое плазма

**Плазма** — четвёртое состояние вещества (после твёрдого, жидкого, газообразного).

**Характеристики:**

```python
# Плазма
plasma = {
    "определение": "Ионизированный газ (электроны отделены от ядер)",
    "состояние": ">99% видимой материи во Вселенной",
    "свойства": {
        "проводимость": "Проводит электричество",
        "магнитное_поле": "Взаимодействует с магнитными полями",
        "коллективное_поведение": "Частицы движутся согласованно"
    },
    "где": {
        "звёзды": "Вся звезда — плазма",
        "межзвёздная_среда": "Ионизированный газ",
        "аккреционные_диски": "Горячая плазма",
        "джеты": "Релятивистская плазма"
    }
}

print("Плазма:")
for key, value in plasma.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Плазма:
  Определение: Ионизированный газ (электроны отделены от ядер)
  Состояние: >99% видимой материи во Вселенной

Свойства:
  Проводимость: Проводит электричество
  Магнитное Поле: Взаимодействует с магнитными полями
  Коллективное Поведение: Частицы движутся согласованно

Где:
  Звёзды: Вся звезда — плазма
  Межзвёздная Среда: Ионизированный газ
  Аккреционные Диски: Горячая плазма
  Джеты: Релятивистская плазма
```

```python
        "магнитное_пересоединение": "Перестройка магнитных полей, выделение энергии",
        "альфвеновские_волны": "Волны в плазме",
        "ускорение_частиц": "Магнитные поля ускоряют частицы"
    },
    "примеры": {
        "солнечные_вспышки": "Магнитное пересоединение",
        "джеты": "Магнитные поля ускоряют плазму",
        "аккреционные_диски": "Магнитная вязкость"
    }
}

print("Магнитогидродинамика:")
for key, value in mhd.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Магнитогидродинамика:
  Принцип: Плазма + магнитное поле = сложная динамика

Процессы:
  Магнитное Пересоединение: Перестройка магнитных полей, выделение энергии
  Альфвеновские Волны: Волны в плазме
  Ускорение Частиц: Магнитные поля ускоряют частицы

Примеры:
  Солнечные Вспышки: Магнитное пересоединение
```

## 3. Излучение

### 3.1 Типы излучения

**Излучение** — перенос энергии через пространство.

**Механизмы:**

```python
# Типы излучения
radiation_types = {
    "тепловое": {
        "механизм": "Тепловое движение частиц",
        "спектр": "Чёрное тело",
        "пример": "Звёзды, аккреционные диски"
    },
    "синхротронное": {
        "механизм": "Электроны в магнитном поле",
        "спектр": "Степенной закон",
        "пример": "Джеты, пульсары"
    },
    "обратный_комптон": {
        "механизм": "Рассеяние фотонов на быстрых электронах",
        "спектр": "Высокоэнергетический",
        "пример": "Гамма-лучи от блазаров"
    },
    "тормозное": {
        "механизм": "Торможение заряженных частиц",
        "спектр": "Широкий",
        "пример": "Рентген от горячего газа"
    }
}

print("Типы излучения:")
for rad_type, details in radiation_types.items():
    print(f"\n{rad_type.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Типы излучения:
  Тепловое:
    Механизм: Tепловое движение частиц
    Спектр: Чёрное тело
    Пример: Звёзды, аккреционные диски

Синхротронное:
    Механизм: Электроны в магнитном поле
    Спектр: Степенной закон
    Пример: Джеты, пульсары

Обратный Комптон:
    Механизм: Рассеяние фотонов на быстрых электронах
    Спектр: Высокоэнергетический
    Пример: Гамма-лучи от блазаров

Тормозное:
    Механизм: Tорможение заряженных частиц

    Пример: Рентген от горячего газа
```

### 3.2 Закон Стефана-Больцмана

**Связь температуры и излучения:**

```python
# Закон Стефана-Больцмана
stefan_boltzmann = {

        "L": "Светимость",

        "σ": "Постоянная Стефана-Больцмана",
        "T": "Температура"
    },
    "следствие": "Светимость растёт как T⁴",
    "пример": {
        "звезда_в_2_раза_горячее": "В 16 раз ярче",
        "применение": "Определение размеров звёзд"
    }
}

print("Закон Стефана-Больцмана:")
for key, value in stefan_boltzmann.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Закон Стефана-Больцмана:
  Формула: L = 4πR²σT⁴

Где:
  L: Светимость
  R: Радиус
  σ: Постоянная Стефана-Больцмана
  T: Температура

Следствие: Светимость растёт как T⁴

Пример:
  Звезда В 2 Раза Горячее: В 16 раз ярче

```

## 4. Ударные волны

### 4.1 Что такое ударная волна

**Ударная волна** — резкий скачок давления, температуры и плотности.

**Образование:**

```python
# Ударные волны
shock_waves = {
    "определение": "Резкий скачок параметров среды",
    "образование": {
        "сверхзвуковое_движение": "Объект движется быстрее звука",
        "взрыв": "Сверхновая, гамма-всплеск",
        "встреча_потоков": "Ветер от звезды встречает межзвёздную среду"
    },
    "эффекты": {
        "сжатие": "Газ сжимается",
        "нагрев": "Температура резко растёт",
        "ускорение_частиц": "Космические лучи"
    }
}

print("Ударные волны:")
for key, value in shock_waves.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Ударные волны:
  Определение: Резкий скачок параметров среды

Образование:
  Сверхзвуковое Движение: Объект движется быстрее звука
  Взрыв: Сверхновая, гамма-всплеск
  Встреча Потоков: Ветер от звезды встречает межзвёздную среду

Эффекты:
  Сжатие: Газ сжимается
  Нагрев: Температура резко растёт
  Ускорение Частиц: Космические лучи
```
