## 1. Тёмная материя

### 1.1 Проблема

**Проблема:** Галактики вращаются быстрее, чем должны.

**Наблюдение:**

```python
# Проблема вращения галактик
rotation_problem = {
    "ожидание": {
        "закон": "v ∝ 1/√r (дальше от центра — медленнее)",
        "причина": "Большая часть массы в центре"
    },
    "наблюдение": {
        "скорость": "Остаётся постоянной на больших расстояниях",
        "проблема": "Не соответствует видимой массе"
    },
    "вывод": "Есть невидимая масса — тёмная материя"
}

print("Проблема вращения галактик:")
for category, details in rotation_problem.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Проблема вращения галактик:
  Ожидание:
    Закон: v ∝ 1/√r (дальше от центра — медленнее)
    Причина: Большая часть массы в центре

Наблюдение:
    Скорость: Остаётся постоянной на больших расстояниях
    Проблема: Не соответствует видимой массе

Вывод: Есть невидимая масса — тёмная материя
```

## 2. Роль тёмной материи

### 2.1 Формирование структуры

**Тёмная материя и галактики:**

```python
# Роль тёмной материи
dark_matter_role = {
    "формирование_галактик": {
        "процесс": "Тёмная материя коллапсирует первой",
        "результат": "Создаёт гравитационные ямы",
        "следствие": "Обычная материя падает в ямы"
    },
    "гало_галактик": {
        "структура": "Тёмная материя в гало",
        "размер": "В 10 раз больше видимой галактики",
        "масса": "~80-90% массы галактики"
    },
    "скопления": {
        "роль": "Удерживает скопления галактик",
```

## 3. Тёмная энергия

### 3.1 Открытие

**Ускорение расширения:**

```python
# Открытие тёмной энергии
dark_energy_discovery = {
    "1998": {
        "наблюдение": "Сверхновые типа Ia",
        "результат": "Вселенная расширяется быстрее, чем ожидалось",
        "вывод": "Расширение ускоряется"
    },
    "проблема": {
        "ожидание": "Гравитация должна замедлять расширение",
        "наблюдение": "Расширение ускоряется",
        "требуется": "Отталкивающая сила — тёмная энергия"
    },
    "нобелевская": "2011 (Перлмуттер, Шмидт, Рисс)"
}

print("Открытие тёмной энергии:")
for category, details in dark_energy_discovery.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Открытие тёмной энергии:
  1998:
    Наблюдение: Сверхновые типа Ia
    Результат: Вселенная расширяется быстрее, чем ожидалось
    Вывод: Расширение ускоряется

Проблема:
    Ожидание: Гравитация должна замедлять расширение
    Наблюдение: Расширение ускоряется
    Требуется: Отталкивающая сила — тёмная энергия

Нобелевская: 2011 (Перлмуттер, Шмидт, Рисс)
```

## 4. Состав Вселенной

### 4.1 Распределение

**Что составляет Вселенную:**

```python
# Состав Вселенной
universe_composition = {
    "обычная_материя": {
        "процент": "~5%",
        "состав": "Звёзды, планеты, газ, пыль",
        "видимость": "Видима (излучает свет)"
    },
    "тёмная_материя": {
        "процент": "~27%",
        "состав": "Неизвестно",
        "видимость": "Невидима (только гравитация)"
    },
    "тёмная_энергия": {
        "процент": "~68%",
        "состав": "Энергия вакуума",
        "видимость": "Невидима (ускоряет расширение)"
```

```
    Состав: Звёзды, планеты, газ, пыль

Тёмная Материя:

Тёмная Энергия:
    Процент: ~68%
```

## 💡 Key Takeaways

- **Тёмная материя** — невидимая материя, составляющая ~27% Вселенной; взаимодействует только гравитационно

- **Доказательства** — кривые вращения галактик, скопления, гравитационное линзирование, реликтовое излучение

- **Роль** — формирует структуру Вселенной, удерживает галактики и скопления

- **Тёмная энергия** — ~68% Вселенной; вызывает ускорение расширения

- **Состав Вселенной** — только ~5% обычной материи, 95% — тёмная материя и тёмная энергия
