## 1. Обзор Солнечной системы

### 1.1 Что такое Солнечная система

**Солнечная система** — это гравитационно связанная система, состоящая из Солнца и всех объектов, вращающихся вокруг него.

**Основные компоненты:**

```python
# Структура Солнечной системы
solar_system_components = {
    "центральная_звезда": {
        "название": "Солнце",
        "тип": "жёлтый карлик (G-тип)",
        "масса": "99.86% массы системы"
    },
    "планеты": {
        "земная_группа": ["Меркурий", "Венера", "Земля", "Марс"],
        "газовые_гиганты": ["Юпитер", "Сатурн"],
        "ледяные_гиганты": ["Уран", "Нептун"]
    },
    "малые_тела": {
        "карликовые_планеты": ["Плутон", "Церера", "Эрида"],
        "астероиды": "Пояс астероидов",
        "кометы": "Облако Оорта, пояс Койпера"
    },
    "спутники": "Более 200 известных спутников",
    "космическая_пыль": "Межпланетная среда"
}

print("Компоненты Солнечной системы:")
for category, content in solar_system_components.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    if isinstance(content, dict):
        for key, value in content.items():
            print(f"  {key.replace('_', ' ').title()}: {value}")
    elif isinstance(content, list):
        for item in content:
            print(f"  • {item}")
    else:
        print(f"  {content}")
```

**Output:**
```

Компоненты Солнечной системы:

Центральная Звезда:
  Название: Солнце
  Тип: жёлтый карлик (G-тип)
  Масса: 99.86% массы системы

Планеты:
  • Меркурий
  • Венера
  • Земля
  • Марс
  • Юпитер
  • Сатурн
  • Уран
  • Нептун

Малые Тела:
  Карликовые Планеты: Плутон, Церера, Эрида
  Астероиды: Пояс астероидов
  Кометы: Облако Оорта, пояс Койпера

Спутники:
  Более 200 известных спутников

  Межпланетная среда
```

### 1.2 Масштабы Солнечной системы

**Размеры:**

- Диаметр орбиты Нептуна: ~60 АЕ
- Внешний край пояса Койпера: ~50 АЕ
- Облако Оорта: ~2000-100 000 АЕ

**Временные масштабы:**

- Возраст: ~4.6 миллиарда лет
- Период обращения планет: от 88 дней (Меркурий) до 165 лет (Нептун)

## 2. Солнце

### 2.1 Характеристики Солнца

**Солнце** — это звезда главной последовательности спектрального класса G2V.

**Основные параметры:**

```python
# Характеристики Солнца
sun_properties = {
    "масса": "1.989 × 10³⁰ кг",
    "радиус": "696 000 км (109 радиусов Земли)",
    "температура_поверхности": "5778 K",
    "температура_ядра": "~15 миллионов K",
    "светимость": "3.828 × 10²⁶ Вт",
    "возраст": "~4.6 миллиарда лет",
    "состав": {
        "водород": "73%",
        "гелий": "25%",
        "другие_элементы": "2%"
    }
}

print("Характеристики Солнца:")
for property_name, value in sun_properties.items():
    if isinstance(value, dict):
        print(f"\n{property_name.replace('_', ' ').title()}:")
        for key, val in value.items():
            print(f"  {key.replace('_', ' ').title()}: {val}")
    else:
        print(f"  {property_name.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Характеристики Солнца:
  Масса: 1.989 × 10³⁰ кг
  Радиус: 696 000 км (109 радиусов Земли)
  Температура Поверхности: 5778 K
  Температура Ядра: ~15 миллионов K
  Светимость: 3.828 × 10²⁶ Вт
  Возраст: ~4.6 миллиарда лет

Состав:
  Водород: 73%
  Гелий: 25%
  Другие Элементы: 2%
```

### 2.2 Источник энергии Солнца

**Термоядерный синтез:**

- В ядре Солнца происходит превращение водорода в гелий
- Процесс: 4H → He + энергия
- Выделяется огромное количество энергии

**Влияние на Солнечную систему:**

- Солнце обеспечивает свет и тепло
- Солнечный ветер формирует гелиосферу
- Гравитация удерживает все объекты на орбитах

### 3.2 Особенности каждой планеты

**Меркурий:**

- Ближайшая к Солнцу планета
- Экстремальные перепады температур
- Нет атмосферы

**Венера:**

- Густая атмосфера из CO₂
- Парниковый эффект (температура ~470°C)
- Вращается в обратном направлении

**Земля:**

- Единственная планета с жидкой водой
- Атмосфера с кислородом
- Активная тектоника плит

**Марс:**

- Тонкая атмосфера
- Признаки древней воды
- Два спутника: Фобос и Деймос

## 6. Происхождение Солнечной системы

### 6.1 Небулярная гипотеза

**Небулярная гипотеза** — современная теория образования Солнечной системы.

**Основные этапы:**

```python
# Формирование Солнечной системы
formation_stages = {
    "1_коллапс_туманности": {
        "время": "~4.6 млрд лет назад",
        "процесс": "Гравитационный коллапс межзвёздного облака",
        "результат": "Образование протозвёзды и протопланетного диска"
    },
    "2_аккреция_планет": {
        "время": "~10 млн лет",
        "процесс": "Столкновение и слипание частиц пыли",
        "результат": "Образование планетезималей, затем планет"
    },
    "3_миграция_планет": {
        "время": "~100 млн лет",
        "процесс": "Взаимодействие планет с диском",
        "результат": "Миграция планет к их текущим орбитам"
    },
    "4_поздняя_тяжёлая_бомбардировка": {
        "время": "~3.9 млрд лет назад",
        "процесс": "Массовое падение астероидов и комет",
        "результат": "Формирование кратеров, возможно доставка воды на Землю"
    }
}

print("Этапы формирования Солнечной системы:")
for stage, details in formation_stages.items():
    stage_name = stage.split('_', 1)[1].replace('_', ' ').title()
    print(f"\n{stage_name}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Этапы формирования Солнечной системы:

Коллапс Туманности:
  Время: ~4.6 млрд лет назад
  Процесс: Гравитационный коллапс межзвёздного облака
  Результат: Образование протозвёзды и протопланетного диска

Аккреция Планет:
  Время: ~10 млн лет
  Процесс: Столкновение и слипание частиц пыли
  Результат: Образование планетезималей, затем планет

Миграция Планет:
  Время: ~100 млн лет
  Процесс: Взаимодействие планет с диском
  Результат: Миграция планет к их текущим орбитам

Поздняя Тяжёлая Бомбардировка:
  Время: ~3.9 млрд лет назад
  Процесс: Массовое падение астероидов и комет
  Результат: Формирование кратеров, возможно доставка воды на Землю
```

### 6.2 Доказательства теории

**Наблюдательные доказательства:**

- Все планеты вращаются в одном направлении
- Орбиты планет лежат примерно в одной плоскости
- Наблюдения протопланетных дисков вокруг других звёзд
- Состав метеоритов соответствует предсказаниям

## 💡 Key Takeaways

- **Солнечная система** состоит из Солнца, 8 планет, множества спутников и малых тел

- **Планеты земной группы** (Меркурий, Венера, Земля, Марс) имеют твёрдую поверхность

- **Газовые гиганты** (Юпитер, Сатурн) состоят в основном из водорода и гелия

- **Спутники** разнообразны по размерам и свойствам, некоторые могут иметь условия для жизни

- **Небулярная гипотеза** объясняет формирование Солнечной системы из коллапсирующего облака
