## 1. Что такое малые тела

### 1.1 Определение

**Малые тела Солнечной системы** — это объекты, которые не являются планетами или карликовыми планетами, но вращаются вокруг Солнца.

**Основные категории:**

```python
# Классификация малых тел
minor_bodies = {
    "астероиды": {
        "расположение": "Пояс астероидов (2-4 АЕ), околоземные",
        "состав": "Скалистые и металлические",
        "размер": "От метров до сотен километров",
        "пример": "Церера (карликовая планета), Веста, Паллада"
    },
    "кометы": {
        "расположение": "Пояс Койпера, облако Оорта",
        "состав": "Лёд, пыль, органические соединения",
        "размер": "Ядра от 1 до 50 км",
        "пример": "Комета Галлея, комета Хейла-Боппа"
    },
    "метеороиды": {
        "расположение": "Различные орбиты",
        "состав": "Камни, металлы",
        "размер": "От миллиметров до метров",
        "пример": "Метеорные потоки, болиды"
    },
    "космическая_пыль": {
        "расположение": "Весь объём Солнечной системы",
        "состав": "Микроскопические частицы",
        "размер": "Микрометры",
        "пример": "Зодиакальный свет"
    }
}

print("Малые тела Солнечной системы:")
for body_type, info in minor_bodies.items():
    print(f"\n{body_type.replace('_', ' ').title()}:")
    for key, value in info.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Малые тела Солнечной системы:

Астероиды:
  Расположение: Пояс астероидов (2-4 АЕ), околоземные
  Состав: Скалистые и металлические
  Размер: От метров до сотен километров
  Пример: Церера (карликовая планета), Веста, Паллада

Кометы:
  Расположение: Пояс Койпера, облако Оорта
  Состав: Лёд, пыль, органические соединения
  Размер: Ядра от 1 до 50 км
  Пример: Комета Галлея, комета Хейла-Боппа

Метеороиды:
  Расположение: Различные орбиты
  Состав: Камни, металлы
  Размер: От миллиметров до метров
  Пример: Метеорные потоки, болиды

Космическая Пыль:
  Расположение: Весь объём Солнечной системы
  Состав: Микроскопические частицы
  Размер: Микрометры
  Пример: Зодиакальный свет
```

## 2. Астероиды

### 2.1 Пояс астероидов

**Пояс астероидов** — это область между орбитами Марса и Юпитера (2-4 АЕ от Солнца), где находится большинство астероидов.

**Характеристики:**

```python
# Пояс астероидов
asteroid_belt = {
    "расположение": "2.2 - 3.2 АЕ от Солнца",
    "общее_количество": "Более 1 миллиона известных",
    "размеры": {
        "большие": ">100 км (около 200)",
        "средние": "1-100 км (тысячи)",
        "малые": "<1 км (миллионы)"
    },
    "общая_масса": "~4% массы Луны",
    "крупнейшие": {
        "Церера": "946 км (карликовая планета)",
        "Веста": "525 км",
        "Паллада": "512 км",
        "Гигея": "434 км"
    }
}

print("Пояс астероидов:")
for key, value in asteroid_belt.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Пояс астероидов:
  Расположение: 2.2 - 3.2 АЕ от Солнца
  Общее Количество: Более 1 миллиона известных

Размеры:
  Большие: >100 км (около 200)
  Средние: 1-100 км (тысячи)
  Малые: <1 км (миллионы)

Общая Масса: ~4% массы Луны

Крупнейшие:
  Церера: 946 км (карликовая планета)
  Веста: 525 км
  Паллада: 512 км
  Гигея: 434 км
```

### 2.2 Типы астероидов

**По составу:**

- **C-тип (углеродистые)**: 75% астероидов, тёмные, богаты углеродом

- **S-тип (силикатные)**: 17% астероидов, светлые, каменистые

- **M-тип (металлические)**: 8% астероидов, металлические, возможно ядра разрушенных планет

**По орбитам:**

- **Главный пояс**: между Марсом и Юпитером

- **Троянцы**: в точках Лагранжа Юпитера

- **Околоземные**: пересекают орбиту Земли

## 3. Кометы

### 3.1 Структура комет

**Комета** состоит из:
- **Ядро**: твёрдое тело из льда, пыли и органических соединений

- **Кома**: атмосфера из газа и пыли вокруг ядра

- **Хвост**: вытянутый поток газа и пыли

**Когда комета приближается к Солнцу:**

```python
# Изменения кометы при приближении к Солнцу
comet_evolution = {
    "далеко_от_солнца": {
        "состояние": "Только ядро",
        "температура": "<100 K",
        "активность": "Неактивна"
    },
    "3-4_АЕ": {
        "состояние": "Начинает образовываться кома",
        "температура": "~150 K",
        "активность": "Слабая сублимация льда"
    },
    "1-2_АЕ": {
        "состояние": "Активная кома и хвост",
        "температура": "~200-300 K",
        "активность": "Интенсивная сублимация"
    },
    "близко_к_солнцу": {
        "состояние": "Максимальная активность",
        "температура": ">300 K",
        "активность": "Яркий хвост, возможен распад"
    }
}

print("Эволюция кометы при приближении к Солнцу:")
for position, changes in comet_evolution.items():
    print(f"\n{position.replace('_', ' ').title()}:")
    for key, value in changes.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Эволюция кометы при приближении к Солнцу:

Далеко От Солнца:
  Состояние: Только ядро
  Температура: <100 K
  Активность: Неактивна

3-4 Ае:
  Состояние: Начинает образовываться кома
  Температура: ~150 K
  Активность: Слабая сублимация льда

1-2 Ае:
  Состояние: Активная кома и хвост
  Температура: ~200-300 K
  Активность: Интенсивная сублимация

Близко К Солнцу:
  Состояние: Максимальная активность
  Температура: >300 K
  Активность: Яркий хвост, возможен распад
```

### 3.2 Орбиты комет

**Короткопериодические** (< 200 лет):
- Происходят из пояса Койпера
- Орбиты в плоскости эклиптики
- Пример: комета Галлея (76 лет)

**Долгопериодические** (> 200 лет):
- Происходят из облака Оорта
- Орбиты под любыми углами
- Пример: комета Хейла-Боппа (2500 лет)

## 4. Метеороиды, метеоры и метеориты

### 4.1 Различия

**Метеороид** — небольшое тело в космосе (до 1 метра)

**Метеор** — метеороид, входящий в атмосферу Земли и сгорающий ("падающая звезда")

**Метеорит** — часть метеороида, достигшая поверхности Земли

**Болид** — очень яркий метеор (ярче Венеры)

### 4.2 Метеорные потоки

**Метеорные потоки** происходят, когда Земля пересекает орбиту кометы, оставляющую пылевой след.

**Известные потоки:**

```python
# Метеорные потоки
meteor_showers = {
    "Персеиды": {
        "период": "12-13 августа",
        "источник": "Комета Свифта-Туттля",
        "частота": "~100 метеоров/час"
    },
    "Леониды": {
        "период": "17-18 ноября",
        "источник": "Комета Темпеля-Туттля",
        "частота": "~15 метеоров/час (периодически всплески)"
    },
    "Геминиды": {
        "период": "13-14 декабря",
        "источник": "Астероид 3200 Фаэтон",
        "частота": "~120 метеоров/час"
    }
}

print("Основные метеорные потоки:")
for shower, info in meteor_showers.items():
    print(f"\n{shower}:")
    for key, value in info.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Основные метеорные потоки:

Персеиды:
  Период: 12-13 августа
  Источник: Комета Свифта-Туттля
  Частота: ~100 метеоров/час

Леониды:
  Период: 17-18 ноября
  Источник: Комета Темпеля-Туттля
  Частота: ~15 метеоров/час (периодически всплески)

Геминиды:
  Период: 13-14 декабря
  Источник: Астероид 3200 Фаэтон
  Частота: ~120 метеоров/час
```

## 5. Пояс Койпера

### 5.1 Описание

**Пояс Койпера** — область за орбитой Нептуна (30-50 АЕ), содержащая ледяные объекты.

**Характеристики:**

```python
# Пояс Койпера
kuiper_belt = {
    "расположение": "30-50 АЕ от Солнца",
    "объекты": {
        "карликовые_планеты": ["Плутон", "Хаумеа", "Макемаке", "Эрида"],
        "кьюбивано": "Классические объекты пояса Койпера",
        "плутино": "Резонансные объекты (как Плутон)"
    },
    "состав": "Лёд (вода, метан, аммиак), скальные породы",
    "происхождение": "Остатки формирования Солнечной системы"
}

print("Пояс Койпера:")
for key, value in kuiper_belt.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, list):
                print(f"  {k.replace('_', ' ').title()}: {', '.join(v)}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Пояс Койпера:
  Расположение: 30-50 АЕ от Солнца

Объекты:
  Карликовые Планеты: Плутон, Хаумеа, Макемаке, Эрида
  Кьюбивано: Классические объекты пояса Койпера
  Плутино: Резонансные объекты (как Плутон)

Состав: Лёд (вода, метан, аммиак), скальные породы
Происхождение: Остатки формирования Солнечной системы
```

### 5.2 Плутон и другие карликовые планеты

**Плутон:**

- Была 9-й планетой, теперь карликовая планета
- Орбита пересекает орбиту Нептуна
- Имеет 5 спутников, крупнейший — Харон

## 6. Облако Оорта

### 6.1 Описание

**Облако Оорта** — гипотетическая сферическая область на расстоянии 2000-100 000 АЕ, источник долгопериодических комет.

**Характеристики:**

```python
# Облако Оорта
oort_cloud = {
    "расположение": "2000-100 000 АЕ от Солнца",
    "форма": "Сферическая оболочка",
    "количество_объектов": "Триллионы",
    "состав": "Ледяные объекты (кометы)",
    "происхождение": "Объекты, выброшенные из внутренней Солнечной системы",
    "роль": "Источник долгопериодических комет"
}

print("Облако Оорта:")
for key, value in oort_cloud.items():
    print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Облако Оорта:
  Расположение: 2000-100 000 АЕ от Солнца
  Форма: Сферическая оболочка
  Количество Объектов: Триллионы
  Состав: Ледяные объекты (кометы)
  Происхождение: Объекты, выброшенные из внутренней Солнечной системы
  Роль: Источник долгопериодических комет
```

### 6.2 Наблюдательные доказательства

Облако Оорта не наблюдалось напрямую, но его существование предполагается на основе:

- Орбит долгопериодических комет
- Их изотропного распределения
- Моделей формирования Солнечной системы

## 💡 Key Takeaways

- **Астероиды** — каменистые объекты пояса астероидов между Марсом и Юпитером

- **Кометы** — ледяные объекты с орбитами из пояса Койпера или облака Оорта

- **Метеороиды/метеоры/метеориты** — различаются по местоположению (космос/атмосфера/поверхность)

- **Пояс Койпера** — область за Нептуном с ледяными объектами, включая карликовые планеты

- **Облако Оорта** — гипотетическая сферическая область, источник долгопериодических комет
