## 1. Определение звезды

### 1.1 Что такое звезда

**Звезда** — это самосветящийся газовый шар, в недрах которого происходит термоядерный синтез.

**Ключевые характеристики:**

```python
# Характеристики звезды
star_characteristics = {
    "состав": {
        "водород": "~73%",
        "гелий": "~25%",
        "другие_элементы": "~2%"
    },
    "источник_энергии": "Термоядерный синтез",
    "состояние": "Гидростатическое равновесие",
    "излучение": "Свет и тепло",
    "температура_ядра": "10-15 миллионов K",
    "температура_поверхности": "От 3000 K до 50000 K"
}

print("Ключевые характеристики звезды:")
for category, value in star_characteristics.items():
    if isinstance(value, dict):
        print(f"\n{category.replace('_', ' ').title()}:")
        for key, val in value.items():
            print(f"  {key.replace('_', ' ').title()}: {val}")
    else:
        print(f"  {category.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Ключевые характеристики звезды:
  Состав:
    Водород: ~73%
    Гелий: ~25%
    Другие Элементы: ~2%
  Источник Энергии: Термоядерный синтез
  Состояние: Гидростатическое равновесие
  Излучение: Свет и тепло
  Температура Ядра: 10-15 миллионов K
  Температура Поверхности: От 3000 K до 50000 K
```

**Отличие от планет:**

```python
# Сравнение звезды и планеты
comparison = {
    "звезда": {
        "источник_света": "Собственный (термоядерный синтез)",
        "энергия": "Генерирует",
        "масса": ">0.08 масс Солнца (минимум для синтеза)",
        "температура_ядра": "Миллионы K"
    },
    "планета": {
        "источник_света": "Отражает свет звезды",
        "энергия": "Не генерирует (только остаточное тепло)",
        "масса": "<0.08 масс Солнца",
        "температура_ядра": "Тысячи K (остаточное тепло)"
    }
}

print("Сравнение звезды и планеты:")
for obj_type, properties in comparison.items():
    print(f"\n{obj_type.title()}:")
    for prop, value in properties.items():
        print(f"  {prop.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Звезда:
  Источник Света: Собственный (термоядерный синтез)
  Энергия: Генерирует
  Масса: >0.08 масс Солнца (минимум для синтеза)
  Температура Ядра: Миллионы K

Планета:
  Источник Света: Отражает свет звезды
  Энергия: Не генерирует (только остаточное тепло)
  Масса: <0.08 масс Солнца
  Температура Ядра: Tысячи K (остаточное тепло)
```

## 2. Гравитация и давление

### 2.1 Гидростатическое равновесие

Звезда находится в **гидростатическом равновесии** — баланс между двумя силами:

**Гравитация (сжатие):**

- Притягивает всё вещество к центру
- Пытается сжать звезду

**Давление (расширение):**

- Создаётся горячим газом и излучением
- Противодействует гравитации
- Расширяет звезду

**Баланс:** Гравитация = Давление

Если баланс нарушается:

- Больше гравитация → звезда сжимается
- Больше давление → звезда расширяется

## 3. Термоядерный синтез

### 3.1 Что такое термоядерный синтез

**Термоядерный синтез** — процесс слияния лёгких атомных ядер в более тяжёлые с выделением энергии.

**В звёздах главным образом:**
4 ядра водорода (протоны) → 1 ядро гелия + энергия

**Условия для синтеза:**

- Температура: ~10-15 миллионов К
- Высокое давление
- Высокая плотность

**Почему нужна высокая температура:**

- Ядра имеют положительный заряд
- Они отталкиваются (кулоновское отталкивание)
- Нужна высокая скорость (температура) для преодоления барьера

---

## 4. Энергия звёзд

### 4.1 Откуда берётся энергия

**Источник энергии:** E = mc²

При синтезе гелия из водорода небольшая часть массы превращается в энергию.

**Цикл:**

1. В ядре происходит синтез
2. Выделяется энергия (фотоны, нейтрино)
3. Энергия медленно переносится к поверхности
4. Излучается в космос

**Время переноса энергии:**

- От ядра до поверхности Солнца: ~100 000 лет
- Фотон "блуждает" из-за постоянного поглощения и переизлучения

## 5. Строение звезды

**Слои звезды (на примере Солнца):**

- **Ядро**: синтез, T ~15 млн К

- **Зона лучистого переноса**: перенос энергии фотонами

- **Зона конвекции**: перенос энергии конвекцией

- **Фотосфера**: видимая поверхность

- **Хромосфера**: внешняя атмосфера

- **Корона**: очень горячая внешняя оболочка
