## 1. Что такое AGN

### 1.1 Определение

**Активное ядро галактики (AGN)** — это компактная область в центре галактики, излучающая огромное количество энергии.

**Характеристики:**

```python
# Характеристики AGN
agn_properties = {
    "размер": "Несколько световых дней",
    "яркость": "Может превышать яркость всей галактики",
    "источник_энергии": "Аккреция на сверхмассивную чёрную дыру",
    "излучение": {
        "радио": "Джеты",
        "оптическое": "Аккреционный диск",
        "рентген": "Корона, горячий газ",
        "гамма": "Высокоэнергетические процессы"
    },
    "распространённость": "~10% галактик имеют активные ядра"
}

print("Характеристики AGN:")
for key, value in agn_properties.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Характеристики AGN:
  Размер: Несколько световых дней
  Яркость: Может превышать яркость всей галактики
  Источник Энергии: Аккреция на сверхмассивную чёрную дыру

Излучение:
  Радио: Джеты
  Оптическое: Аккреционный диск
  Рентген: Корона, горячий газ
  Гамма: Высокоэнергетические процессы
  Распространённость: ~10% галактик имеют активные ядра
```

**Единая модель AGN:**
Все типы AGN объясняются одной моделью, но выглядят по-разному в зависимости от угла обзора.

## 2. Сверхмассивные чёрные дыры

### 2.1 Роль в AGN

**Сверхмассивные чёрные дыры** — центральный двигатель AGN:

```python
# Сверхмассивные чёрные дыры в AGN
smbh_in_agn = {
    "масса": "10⁶ - 10¹⁰ M☉",
    "расположение": "Центр галактики",
    "роль": {
        "гравитация": "Притягивает вещество",
        "аккреция": "Вещество падает, выделяется энергия",
        "эффективность": "~10% массы → энергия (E=mc²)"
    },
    "активность": {
        "активная": "Много вещества падает → яркий AGN",
        "неактивная": "Мало вещества → тихое ядро (как в Млечном Пути)"
    }
}

print("Сверхмассивные чёрные дыры в AGN:")
for key, value in smbh_in_agn.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Сверхмассивные чёрные дыры в AGN:
  Масса: 10⁶ - 10¹⁰ M☉
  Расположение: Центр галактики

Роль:
  Гравитация: Притягивает вещество
  Аккреция: Вещество падает, выделяется энергия
  Эффективность: ~10% массы → энергия (E=mc²)

Активность:
  Активная: Много вещества падает → яркий AGN
  Неактивная: Мало вещества → тихое ядро (как в Млечном Пути)
```

### 2.2 Почему не все галактики активны

**Факторы:**

```python
# Почему не все галактики активны
agn_activity_factors = {

        "проблема": "Газ должен попасть в центр",
        "механизмы": "Столкновения, приливные силы, потеря углового момента"

        "активность": "Эпизодическая",
        "время": "AGN активны миллионы-миллиарды лет"
    }
}

print("Факторы активности AGN:")
for factor, details in agn_activity_factors.items():
    print(f"\n{factor.replace('_', ' ').title()}:")
    for key, value in details.items():
```

**Output:**

```
Факторы активности AGN:
  Наличие Газа:

    Источник: Межзвёздный газ, слияния галактик

  Направление Газа:
    Проблема: Газ должен попасть в центр
    Механизмы: Столкновения, приливные силы, потеря углового момента

  Временной Фактор:
    Активность: Эпизодическая
    Время: AGN активны миллионы-миллиарды лет
```

## 3. Аккреционные диски

### 3.1 Структура аккреционного диска

**Аккреционный диск** — вращающийся диск вещества вокруг чёрной дыры.

**Характеристики:**

```python
# Аккреционный диск
accretion_disk = {
    "структура": {
        "внутренняя_часть": {
            "температура": "Миллионы K",
            "излучение": "Рентген, ультрафиолет"
        },
        "средняя_часть": {
            "температура": "Десятки тысяч K",
            "излучение": "Ультрафиолет, оптическое"
        },
        "внешняя_часть": {
            "температура": "Тысячи K",
            "излучение": "Инфракрасное"
        }
    },
    "процессы": {
        "трение": "Внутренние слои вращаются быстрее",
        "нагрев": "Трение выделяет энергию",
        "охлаждение": "Излучение уносит энергию"
    },
    "размер": "От нескольких до тысяч радиусов Шварцшильда"
}

print("Аккреционный диск:")
for category, value in accretion_disk.items():
    if isinstance(value, dict):
        print(f"\n{category.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {category.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Аккреционный диск:
  Структура:
    Внутренняя Часть:
      Температура: Миллионы K
      Излучение: Рентген, ультрафиолет
    Средняя Часть:
      Температура: Десятки тысяч K
      Излучение: Ультрафиолет, оптическое
    Внешняя Часть:
      Температура: Tысячи K
      Излучение: Инфракрасное

Процессы:
  Tрение: Внутренние слои вращаются быстрее
  Нагрев: Tрение выделяет энергию
  Охлаждение: Излучение уносит энергию
  Размер: От нескольких до тысяч радиусов Шварцшильда
```

### 3.2 Эффективность аккреции

**Эффективность:**

```python
# Эффективность аккреции
accretion_efficiency = {
    "термоядерный_синтез": {
        "эффективность": "~0.7% (E=mc²)",
        "пример": "Звёзды"
    },
    "аккреция_на_чёрную_дыру": {
        "эффективность": "~10-40% (E=mc²)",
        "пример": "AGN, квазары",
        "сравнение": "В 10-50 раз эффективнее синтеза"
    }
}

print("Эффективность аккреции:")
for process, details in accretion_efficiency.items():
    print(f"\n{process.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Эффективность аккреции:
  Термоядерный Синтез:
    Эффективность: ~0.7% (E=mc²)
    Пример: Звёзды

  Аккреция На Чёрную Дыру:
    Эффективность: ~10-40% (E=mc²)
    Пример: AGN, квазары
    Сравнение: В 10-50 раз эффективнее синтеза
```

**Почему так эффективно:**

- Гравитационная энергия очень велика
- Вещество падает с огромной скоростью
- Выделяется огромное количество энергии

## 4. Джеты

### 4.1 Релятивистские джеты

**Джеты** — струи вещества, вылетающие из полюсов аккреционного диска.

**Характеристики:**

```python
# Релятивистские джеты
jets = {
    "направление": "Перпендикулярно аккреционному диску",
    "скорость": "0.99c - близка к скорости света",
    "длина": "Тысячи - миллионы св. лет",
    "механизм": {
        "магнитные_поля": "Ускоряют заряженные частицы",
        "процесс": "Магнитное поле закручивается диском",
        "результат": "Частицы выталкиваются вдоль оси"
    },
    "излучение": {
        "синхротронное": "Радио, рентген",
        "обратный_комптон": "Гамма-лучи"
    }
}

print("Релятивистские джеты:")
for key, value in jets.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Релятивистские джеты:
  Направление: Перпендикулярно аккреционному диску
  Скорость: 0.99c - близка к скорости света
  Длина: Tысячи - миллионы св. лет

Механизм:
  Магнитные Поля: Ускоряют заряженные частицы
  Процесс: Магнитное поле закручивается диском
  Результат: Частицы выталкиваются вдоль оси

Излучение:
  Синхротронное: Радио, рентген
  Обратный Комптон: Гамма-лучи
```

## 5. Типы AGN

### 5.1 Классификация

**Типы AGN (в зависимости от угла обзора и свойств):**

```python
# Типы AGN
agn_types = {

    },
    "сейфертовские": {
        "тип": "Близкие квазары",
        "галактика": "Видна галактика вокруг",
        "подтипы": {
            "тип_1": "Широкие линии излучения",
            "тип_2": "Узкие линии (тор закрывает ядро)"

    "радиогалактики": {

        "яркость": "Очень переменная",
```

## 💡 Key Takeaways

- **AGN** — активные ядра галактик, излучающие огромную энергию из-за аккреции на сверхмассивную чёрную дыру

- **Сверхмассивные чёрные дыры** (10⁶-10¹⁰ M☉) — центральный двигатель AGN

- **Аккреционные диски** — вращающиеся диски вещества, выделяющие энергию при падении на чёрную дыру

- **Релятивистские джеты** — струи вещества, вылетающие вдоль оси вращения со скоростью близкой к скорости света

- **Единая модель AGN** — все типы AGN объясняются одной моделью, но выглядят по-разному в зависимости от угла обзора
