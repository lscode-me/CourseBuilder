## 1. Блазары

### 1.1 Что такое блазар

**Блазар** — это AGN, у которого джет направлен прямо на нас.

**Характеристики:**

```python
# Блазары
blazars = {
    "определение": "AGN с джетом, направленным на нас",
    "типы": {
        "BL_Lacertae": "Слабое излучение линий",
        "квазары_OVV": "Сильное излучение линий"
    },
    "особенности": {
        "яркость": "Очень переменная (часы-дни)",
        "излучение": "Все длины волн (радио до гамма)",
        "поляризация": "Высокая (синхротронное излучение)"
    },
    "релятивистские_эффекты": {
        "допплеровское_усиление": "Джет к нам → кажется ярче",
        "сжатие_времени": "Быстрые вариации"
    }
}

print("Блазары:")
for key, value in blazars.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```
Блазары:
  Определение: AGN с джетом, направленным на нас

Типы:
  BL Lacertae: Слабое излучение линий
  Квазары OVV: Сильное излучение линий

Особенности:
  Яркость: Очень переменная (часы-дни)
  Излучение: Все длины волн (радио до гамма)
  Поляризация: Высокая (синхротронное излучение)

Релятивистские Эффекты:
  Допплеровское Усиление: Джет к нам → кажется ярче
  Сжатие Времени: Быстрые вариации
```

## 3. Сейфертовские галактики

### 3.1 Типы сейфертовских галактик

**Сейфертовские галактики** — близкие AGN с видимой галактикой.

**Классификация:**

```python
# Сейфертовские галактики
seyfert_galaxies = {
    "тип_1": {
        "линии_излучения": "Широкие (газ движется быстро)",
        "видимость": "Ядро видно",
        "тор": "Не закрывает ядро"
    },
    "тип_2": {
        "линии_излучения": "Узкие (тор закрывает ядро)",
        "видимость": "Ядро скрыто",
        "тор": "Закрывает широкие линии"
    },
    "общее": {
        "расстояние": "Близкие (z < 0.1)",
        "галактика": "Видна спиральная галактика",
        "яркость": "Ярче обычных галактик, но слабее квазаров"
    }
}

print("Сейфертовские галактики:")
for category, details in seyfert_galaxies.items():
    if isinstance(details, dict):
        print(f"\n{category.replace('_', ' ').title()}:")
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {category.replace('_', ' ').title()}: {details}")
```

**Output:**
```
Сейфертовские галактики:
  Тип 1:
    Линии Излучения: Широкие (газ движется быстро)
    Видимость: Ядро видно
    Тор: Не закрывает ядро

  Тип 2:
    Линии Излучения: Узкие (тор закрывает ядро)
    Видимость: Ядро скрыто
    Тор: Закрывает широкие линии

  Общее:
    Расстояние: Близкие (z < 0.1)
    Галактика: Видна спиральная галактика
    Яркость: Ярче обычных галактик, но слабее квазаров
```

```python
    "расстояние": "Миллиарды св. лет",
    "направленность": "Узкий пучок (джет)"

print("Гамма-всплески:")
for key, value in gamma_ray_bursts.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**

### 4.2 Типы гамма-всплесков

**Два основных типа:**

```python
# Типы гамма-всплесков
grb_types = {
    "длинные_GRB": {
        "длительность": ">2 секунды",
        "происхождение": "Коллапс массивной звезды (гиперновая)",
        "механизм": "Образование чёрной дыры + джет",
        "расположение": "В областях звездообразования"
    },
    "короткие_GRB": {
        "длительность": "<2 секунды",
        "происхождение": "Слияние нейтронных звёзд",
        "механизм": "Слияние → чёрная дыра + джет",

    print(f"\n{grb_type.replace('_', ' ').title()}:")

```

**Output:**
```
Типы гамма-всплесков:
  Длинные GRB:
    Длительность: >2 секунды
    Происхождение: Коллапс массивной звезды (гиперновая)
    Механизм: Образование чёрной дыры + джет
    Расположение: В областях звездообразования

Короткие GRB:
    Длительность: <2 секунды
    Происхождение: Слияние нейтронных звёзд
    Механизм: Слияние → чёрная дыра + джет
```

## 💡 Key Takeaways

- **Блазары** — AGN с джетом, направленным на нас; очень переменные, все длины волн
- **Радиогалактики** — галактики с яркими джетами и лепестками в радио
- **Сейфертовские галактики** — близкие AGN (тип 1: ядро видно, тип 2: тор закрывает)
- **Гамма-всплески (GRB)** — самые мощные взрывы во Вселенной (длинные: гиперновые, короткие: слияния нейтронных звёзд)
- **Единая модель** — все активные объекты объясняются одной моделью, различия — в угле обзора и расстоянии
