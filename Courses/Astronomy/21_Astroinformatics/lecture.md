## 1. Введение в астроинформатику

### 1.1 Общая идея

**Современная астрономия — это data-intensive наука.**

**Проблема:**

```python
# Масштабы данных в астрономии
astronomy_data_scale = {
    "проблема": "Объёмы данных превысили возможности ручного анализа",
    "примеры": {
        "SDSS": {
            "название": "Sloan Digital Sky Survey",
            "объём": "Десятки ТБ данных",
            "объекты": "Миллионы галактик, звёзд, квазаров"
        },
        "LSST": {
            "название": "Vera Rubin Observatory (LSST)",
            "объём": "~20 ТБ данных в день",
            "объекты": "Миллиарды объектов"
        }
    },
    "решение": "Astroinformatics — применение информатики к астрономии"
}

print("Масштабы данных в астрономии:")
for key, value in astronomy_data_scale.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Масштабы данных в астрономии:
  Проблема: Объёмы данных превысили возможности ручного анализа

Примеры:
  SDSS:
    Название: Sloan Digital Sky Survey
    Объём: Десятки ТБ данных
    Объекты: Миллионы галактик, звёзд, квазаров
  LSST:
    Название: Vera Rubin Observatory (LSST)
    Объём: ~20 ТБ данных в день
    Объекты: Миллиарды объектов

Решение: Astroinformatics — применение информатики к астрономии
```

**Astroinformatics** — это применение:
- Информатики
- Data science
- High-performance computing
к задачам астрономии и астрофизики.

**Современная астроинформатика:**

```python
# Ключевые концепты
key_concepts = {
    "data_pipelines": {
        "описание": "Автоматизированная обработка данных",
        "пример": "От сырых данных до каталогов"
    },
    "reproducibility": {
        "описание": "Воспроизводимость результатов",
        "важность": "Критично для науки"
    },
    "open_data": {
        "описание": "Открытый доступ к данным",
        "примеры": "SDSS, Gaia, LSST"
    },
    "virtual_observatories": {
        "описание": "Единый доступ к данным",
        "цель": "Объединить данные разных обсерваторий"
    },
    "FAIR": {
        "расшифровка": "Findable, Accessible, Interoperable, Reusable",
        "принцип": "Данные должны быть доступны и переиспользуемы"
    }
}

print("Ключевые концепты:")
for concept, details in key_concepts.items():
    print(f"\n{concept.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

```

    Пример: От сырых данных до каталогов

Reproducibility:
    Описание: Воспроизводимость результатов
    Важность: Критично для науки

Open Data:
    Описание: Открытый доступ к данным
    Примеры: SDSS, Gaia, LSST

Virtual Observatories:
    Описание: Единый доступ к данным
    Цель: Объединить данные разных обсерваторий

FAIR:
    Расшифровка: Findable, Accessible, Interoperable, Reusable
    Принцип: Данные должны быть доступны и переиспользуемы
```
