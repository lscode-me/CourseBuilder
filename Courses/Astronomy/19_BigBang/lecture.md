## 1. Теория Большого взрыва

### 1.1 Основная идея

**Большой взрыв** — теория о происхождении и эволюции Вселенной.

**Ключевые идеи:**

```python
# Теория Большого взрыва
big_bang_theory = {
    "начало": {
        "время": "~13.8 миллиардов лет назад",
        "состояние": "Вся Вселенная в одной точке",
        "температура": "Бесконечная (сингулярность)"
    },
    "расширение": {
        "процесс": "Вселенная начала расширяться",
        "результат": "Охлаждение и формирование структуры"
    },
    "важно": "Не взрыв в пространстве, а расширение самого пространства"
}

print("Теория Большого взрыва:")
for concept, details in big_bang_theory.items():
    print(f"\n{concept.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Теория Большого взрыва:
  Начало:
    Время: ~13.8 миллиардов лет назад
    Состояние: Вся Вселенная в одной точке
    Температура: Бесконечная (сингулярность)

Расширение:
    Процесс: Вселенная начала расширяться
    Результат: Охлаждение и формирование структуры

Важно: Не взрыв в пространстве, а расширение самого пространства
```

## 3. Доказательства Большого взрыва

### 3.1 Реликтовое излучение

**Космический микроволновой фон (CMB):**

```python
# Реликтовое излучение
cmb = {
    "определение": "Излучение от эпохи рекомбинации",
    "температура": "2.725 K",
    "длина_волны": "Микроволны (~1 мм)",
    "однородность": {
        "изотропность": "Одинаково во всех направлениях",
        "флуктуации": "Небольшие вариации (1 часть на 100 000)",
        "значение": "Зародыши галактик"
    },
    "открытие": {
        "год": "1965",
        "авторы": "Пензиас и Вильсон",
        "нобелевская": "1978"
    }
}

print("Реликтовое излучение:")
for key, value in cmb.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Реликтовое излучение:
  Определение: Излучение от эпохи рекомбинации
  Температура: 2.725 K
  Длина Волны: Микроволны (~1 мм)

Однородность:
    Изотропность: Одинаково во всех направлениях
    Флуктуации: Небольшие вариации (1 часть на 100 000)
    Значение: Зародыши галактик

Открытие:
    Год: 1965
    Авторы: Пензиас и Вильсон
    Нобелевская: 1978
```

        "вероятность": "Низкая"
    },
    "большое_сжатие": {
        "условие": "Гравитация побеждает",
        "результат": "Вселенная сжимается обратно",
        "вероятность": "Низкая (расширение ускоряется)"
    },
    "тепловая_смерть": {
        "условие": "Расширение продолжается",
        "результат": "Всё остывает, структура распадается",

print("Будущее Вселенной:")
