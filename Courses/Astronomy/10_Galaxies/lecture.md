## 1. Что такое галактика

### 1.1 Определение

**Галактика** — это гравитационно связанная система, состоящая из звёзд, газа, пыли и тёмной материи.

**Масштабы:**

```python
# Характеристики галактик
galaxy_properties = {
    "количество_звёзд": "10⁶ - 10¹²",
    "размер": "От тысяч до сотен тысяч световых лет",
    "масса": "10⁹ - 10¹² M☉",
    "компоненты": {
        "звёзды": "Основной видимый компонент",
        "газ": "Межзвёздный газ (водород, гелий)",
        "пыль": "Межзвёздная пыль",
        "тёмная_материя": "~80-90% массы (невидима)"
    }
}

print("Характеристики галактик:")
for key, value in galaxy_properties.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Характеристики галактик:
  Количество Звёзд: 10⁶ - 10¹²
  Размер: От тысяч до сотен тысяч световых лет
  Масса: 10⁹ - 10¹² M☉

Компоненты:
  Звёзды: Основной видимый компонент
  Газ: Межзвёздный газ (водород, гелий)
  Пыль: Межзвёздная пыль
  Тёмная Материя: ~80-90% массы (невидима)
```

**История:**

- До 1920-х годов — думали, что Млечный Путь — это вся Вселенная
- 1924 год — Эдвин Хаббл доказал, что "туманности" — это другие галактики
- Сейчас — известно о триллионах галактик в наблюдаемой Вселенной

## 2. Типы галактик

### 2.1 Классификация Хаббла

**Последовательность Хаббла** — классификация галактик по форме:

```python
# Классификация Хаббла
hubble_sequence = {
    "эллиптические": {
        "обозначение": "E0 - E7",
        "форма": "Эллипсоид (от круглой до вытянутой)",
        "характеристики": {
            "звёзды": "Старые, красные",
            "газ": "Мало или нет",
            "звездообразование": "Нет",
            "пример": "M87, M49"
        }
    },
    "спиральные": {
        "обозначение": "Sa, Sb, Sc",
        "форма": "Диск со спиральными рукавами",
        "характеристики": {
            "звёзды": "Смесь старых и молодых",
            "газ": "Много",
            "звездообразование": "Активное в рукавах",
            "пример": "Млечный Путь, Андромеда"
        }
    },
    "неправильные": {
        "обозначение": "Irr",
        "форма": "Нет чёткой структуры",
        "характеристики": {
            "звёзды": "Молодые, голубые",
            "газ": "Много",
            "звездообразование": "Очень активное",
            "пример": "Большое и Малое Магеллановы Облака"
        }
    }
}

print("Классификация Хаббла:")
for galaxy_type, details in hubble_sequence.items():
    print(f"\n{galaxy_type.title()} галактики:")
    for key, value in details.items():
        if isinstance(value, dict):
            print(f"  {key.replace('_', ' ').title()}:")
            for k, v in value.items():
                print(f"    {k.replace('_', ' ').title()}: {v}")
        else:
            print(f"  {key.replace('_', ' ').title()}: {value}")
```

```
Неправильные галактики:
  Обозначение: Irr

    Звёзды: Молодые, голубые
```

### 3.2 Структура Млечного Пути

**Компоненты:**

```python
# Структура Млечного Пути
milky_way_structure = {
    "балдж": {
        "расположение": "Центральная выпуклость",
        "размер": "~10 000 св. лет",
        "звёзды": "Старые, красные"
    },
    "диск": {
        "спиральные_рукава": ["Рукав Ориона", "Рукав Персея", "Рукав Стрельца"],
        "звездообразование": "Активное в рукавах",
        "Солнце": "В рукаве Ориона"
    },
    "гало": {
        "шаровые_скопления": "~150 известных",
        "звёзды": "Старые, металл-бедные",
        "тёмная_материя": "Большая часть массы"
    }
}

print("Структура Млечного Пути:")
for component, details in milky_way_structure.items():
    print(f"\n{component.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for key, value in details.items():
            if isinstance(value, list):
                print(f"  {key.replace('_', ' ').title()}: {', '.join(value)}")
            else:
                print(f"  {key.replace('_', ' ').title()}: {value}")
    else:
        print(f"  {details}")
```

## 4. Скопления и сверхскопления

### 4.1 Скопления галактик

**Скопление галактик** — группа галактик, связанных гравитацией.

**Характеристики:**

```python
# Скопления галактик
galaxy_clusters = {
    "размер": "Несколько миллионов св. лет",
    "количество_галактик": "Десятки - тысячи",
    "масса": "10¹⁴ - 10¹⁵ M☉",
    "компоненты": {
        "галактики": "~5% массы",
        "газ": "~15% массы (межгалактический, очень горячий)",
        "тёмная_материя": "~80% массы"
    },
    "примеры": {
        "скопление_Девы": {
            "расстояние": "~54 млн св. лет",
            "количество": "~2000 галактик",
            "размер": "~15 млн св. лет"
        },
        "скопление_Кома": {
            "расстояние": "~320 млн св. лет",
            "количество": "~1000 галактик"
        }
    }
}

print("Скопления галактик:")
for key, value in galaxy_clusters.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Скопления галактик:
  Размер: Несколько миллионов св. лет
  Количество Галактик: Десятки - тысячи
  Масса: 10¹⁴ - 10¹⁵ M☉

  Газ: ~15% массы (межгалактический, очень горячий)

  Скопление Девы:
    Расстояние: ~54 млн св. лет
```

## 5. Эволюция галактик

```python
galaxy_formation = {

        "процесс": "Слияния небольших галактик",
        "результат": "Формирование крупных галактик"
    },
    "4_эволюция": {
        "спиральные": "Сохраняют газ, продолжают звездообразование",
```

## 💡 Key Takeaways

- **Галактики** — гравитационно связанные системы из звёзд, газа, пыли и тёмной материи

- **Классификация Хаббла**: эллиптические (E), спиральные (S), неправильные (Irr)

- **Млечный Путь** — спиральная галактика с ~100-400 млрд звёзд, диаметр ~100 000 св. лет

- **Скопления галактик** — группы из десятков-тысяч галактик

- **Сверхскопления** — нитевидные структуры из скоплений, размером сотни миллионов св. лет

- **Эволюция галактик** происходит через слияния и аккрецию газа
