## 1. Спектральные линии

### 1.1 Что такое спектральные линии

**Спектральные линии** — это тёмные или яркие линии в спектре, соответствующие определённым длинам волн.

**Типы:**

```python
# Спектральные линии
spectral_lines = {
    "линии_поглощения": {
        "природа": "Тёмные линии",
        "причина": "Атомы поглощают свет на определённых длинах волн",
        "пример": "Спектр звезды (непрерывный спектр + линии поглощения)"
    },
    "линии_излучения": {
        "природа": "Яркие линии",
        "причина": "Атомы излучают свет на определённых длинах волн",
        "пример": "Туманности, аккреционные диски"
    },
    "непрерывный_спектр": {
        "природа": "Сплошной спектр",
        "причина": "Горячее плотное вещество",
        "пример": "Звёзды, аккреционные диски"
    }
}

print("Спектральные линии:")
for line_type, details in spectral_lines.items():
    print(f"\n{line_type.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Спектральные линии:
  Линии Поглощения:
    Природа: Tёмные линии
    Причина: Атомы поглощают свет на определённых длинах волн
    Пример: Спектр звезды (непрерывный спектр + линии поглощения)

Линии Излучения:
    Природа: Яркие линии
    Причина: Атомы излучают свет на определённых длинах волн
    Пример: Туманности, аккреционные диски

Непрерывный Спектр:
    Природа: Сплошной спектр
    Причина: Горячее плотное вещество
    Пример: Звёзды, аккреционные диски
```

## 2. Эффект Доплера

### 2.1 Что такое эффект Доплера

**Эффект Доплера** — изменение частоты волны при движении источника или наблюдателя.

**В астрономии:**

```python
# Эффект Доплера в астрономии
doppler_effect = {
    "приближение": {
        "смещение": "Синее (к коротким длинам волн)",
        "причина": "Волны сжимаются",
        "пример": "Галактика приближается"
    },
    "удаление": {
        "смещение": "Красное (к длинным длинам волн)",
        "причина": "Волны растягиваются",
        "пример": "Галактика удаляется"
    },
    "формула": {
        "нерелятивистская": "Δλ/λ = v/c",
        "релятивистская": "z = √((1+v/c)/(1-v/c)) - 1",
        "где": "z — красное смещение, v — скорость, c — скорость света"
    }
}

print("Эффект Доплера в астрономии:")
for category, details in doppler_effect.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Эффект Доплера в астрономии:
  Приближение:
    Смещение: Синее (к коротким длинам волн)
    Причина: Волны сжимаются
    Пример: Галактика приближается

Удаление:
    Смещение: Красное (к длинным длинам волн)
    Причина: Волны растягиваются
    Пример: Галактика удаляется

Формула:
    Нерелятивистская: Δλ/λ = v/c
    Релятивистская: z = √((1+v/c)/(1-v/c)) - 1
    Где: z — красное смещение, v — скорость, c — скорость света
```

## 3. Красное смещение

### 3.1 Что такое красное смещение

**Красное смещение (z)** — увеличение длины волны света от удаляющегося объекта.

**Определение:**

```python
# Красное смещение
redshift = {
    "определение": "z = (λнаблюдаемая - λлабораторная) / λлабораторная",
    "интерпретация": {
        "z_0": "Объект не движется относительно нас",
        "z_>0": "Объект удаляется (красное смещение)",
        "z_<0": "Объект приближается (синее смещение)"
    },
    "примеры": {
        "близкие_галактики": "z = 0.001 - 0.1",
        "далёкие_галактики": "z = 0.1 - 2",
        "квазары": "z = 2 - 7+",
        "реликтовое_излучение": "z = 1100"
    }
}

print("Красное смещение:")
for key, value in redshift.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Красное смещение:
  Определение: z = (λнаблюдаемая - λлабораторная) / λлабораторная

Интерпретация:
  Z 0: Объект не движется относительно нас
  Z >0: Объект удаляется (красное смещение)
  Z <0: Объект приближается (синее смещение)

Примеры:
  Близкие Галактики: z = 0.001 - 0.1
  Далёкие Галактики: z = 0.1 - 2
  Квазары: z = 2 - 7+
  Реликтовое Излучение: z = 1100
```

## 4. Расширение Вселенной

### 4.1 Закон Хаббла

**Закон Хаббла** — связь между расстоянием и скоростью удаления галактик.

**Формула:**

```python
# Закон Хаббла
hubble_law = {
    "формула": "v = H₀ × d",
    "где": {
        "v": "Скорость удаления",
        "H₀": "Постоянная Хаббла (~70 км/с/Мпк)",
        "d": "Расстояние до галактики"
    },
    "открытие": {
        "год": "1929",
        "автор": "Эдвин Хаббл",
        "значение": "Доказательство расширения Вселенной"
    },
    "интерпретация": {
        "не_галактики_движутся": "Пространство расширяется",
        "аналогия": "Точки на надуваемом шарике"
    }
}

print("Закон Хаббла:")
for key, value in hubble_law.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Закон Хаббла:
  Формула: v = H₀ × d

Где:
  V: Скорость удаления
  H₀: Постоянная Хаббла (~70 км/с/Мпк)
  D: Расстояние до галактики

Открытие:
  Год: 1929
  Автор: Эдвин Хаббл
  Значение: Доказательство расширения Вселенной

Интерпретация:
  Не Галактики Движутся: Пространство расширяется
  Аналогия: Tочки на надуваемом шарике
```

## 5. Использование красного смещения

### 5.1 Измерение расстояний

**Красное смещение как индикатор расстояния:**

```python
# Красное смещение и расстояние
redshift_distance = {
    "принцип": "Чем больше z, тем дальше объект",
    "для_близких": {
        "z_<0.1": "v = cz (нерелятивистская формула)",
        "расстояние": "d = v/H₀"
    },
    "для_далёких": {
        "z_>0.1": "Нужна космологическая формула",
        "расстояние": "Зависит от модели Вселенной"
    },
    "важность": "Основной метод измерения расстояний до далёких объектов"
}

print("Красное смещение и расстояние:")
for key, value in redshift_distance.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Красное смещение и расстояние:
  Принцип: Чем больше z, тем дальше объект

Для Близких:
  Z <0.1: v = cz (нерелятивистская формула)
  Расстояние: d = v/H₀

Для Далёких:
  Z >0.1: Нужна космологическая формула
  Расстояние: Зависит от модели Вселенной

Важность: Основной метод измерения расстояний до далёких объектов
```

### 5.2 Изучение ранней Вселенной

**Красное смещение = машина времени:**

```python
# Красное смещение и время
redshift_time = {
    "принцип": "Большое z = далёкое прошлое",
    "примеры": {
        "z_1": "~6 млрд лет назад",
        "z_3": "~2 млрд лет назад",
        "z_6": "~1 млрд лет назад",
        "z_1100": "~380 000 лет после Большого взрыва (реликтовое излучение)"
    },
    "применение": "Изучение эволюции Вселенной"
}

print("Красное смещение и время:")
for key, value in redshift_time.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Примеры:
  Z 1: ~6 млрд лет назад
  Z 3: ~2 млрд лет назад
  Z 6: ~1 млрд лет назад
  Z 1100: ~380 000 лет после Большого взрыва (реликтовое излучение)

Применение: Изучение эволюции Вселенной
```

## 💡 Key Takeaways

- **Спектральные линии** — тёмные (поглощение) или яркие (излучение) линии на определённых длинах волн

- **Эффект Доплера** — изменение частоты при движении (синее смещение при приближении, красное при удалении)

- **Красное смещение (z)** — увеличение длины волны; три типа: доплеровское, космологическое, гравитационное

- **Закон Хаббла** (v = H₀d) — связь между расстоянием и скоростью удаления; доказательство расширения Вселенной

- **Красное смещение** используется для измерения расстояний и изучения ранней Вселенной
