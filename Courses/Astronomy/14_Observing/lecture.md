## 1. Электромагнитный спектр

### 1.1 Что такое электромагнитное излучение

**Электромагнитное излучение** — это волны электрического и магнитного полей, распространяющиеся в пространстве.

**Спектр:**

```python
# Электромагнитный спектр
em_spectrum = {
    "гамма_лучи": {
        "длина_волны": "<0.01 нм",
        "энергия": "Самая высокая",
        "источники": "Гамма-всплески, чёрные дыры, пульсары"
    },
    "рентген": {
        "длина_волны": "0.01 - 10 нм",
        "энергия": "Очень высокая",
        "источники": "Аккреционные диски, горячий газ"
    },
    "ультрафиолет": {
        "длина_волны": "10 - 400 нм",
        "энергия": "Высокая",
        "источники": "Горячие звёзды, квазары"
    },
    "видимый_свет": {
        "длина_волны": "400 - 700 нм",
        "энергия": "Средняя",
        "источники": "Звёзды, галактики"
    },
    "инфракрасное": {
        "длина_волны": "700 нм - 1 мм",
        "энергия": "Низкая",
        "источники": "Холодные объекты, пыль"
    },
    "радио": {
        "длина_волны": ">1 мм",
        "энергия": "Самая низкая",
        "источники": "Холодный газ, джеты, реликтовое излучение"
    }
}

print("Электромагнитный спектр:")
for radiation_type, properties in em_spectrum.items():
    print(f"\n{radiation_type.replace('_', ' ').title()}:")
    for key, value in properties.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**

## 2. Атмосфера Земли

### 2.1 Проблема атмосферы

**Атмосфера блокирует большую часть излучения:**

```python
# Влияние атмосферы
atmosphere_effects = {
    "пропускает": {
        "видимый_свет": "✓",
        "радио": "✓ (некоторые диапазоны)",
        "инфракрасное": "✓ (окна прозрачности)"
    },
    "блокирует": {
        "ультрафиолет": "Озоновый слой",
        "рентген": "Атмосфера",
        "гамма": "Атмосфера",
        "большая_часть_ИК": "Водяной пар, CO₂"
    },
    "искажает": {
        "видимый_свет": "Турбулентность (мерцание звёзд)",
        "решение": "Адаптивная оптика, космические телескопы"
    }
}

print("Влияние атмосферы на наблюдения:")
for category, details in atmosphere_effects.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Влияние атмосферы на наблюдения:
  Пропускает:
    Видимый Свет: ✓
    Радио: ✓ (некоторые диапазоны)
    Инфракрасное: ✓ (окна прозрачности)

  Блокирует:
    Ультрафиолет: Озоновый слой
    Рентген: Атмосфера
    Гамма: Атмосфера
    Большая Часть ИК: Водяной пар, CO₂

Искажает:
  Видимый Свет: Турбулентность (мерцание звёзд)
  Решение: Адаптивная оптика, космические телескопы
```

### 2.2 Решения

**Как преодолеть ограничения атмосферы:**

```python
# Решения проблемы атмосферы
atmosphere_solutions = {
    "наземные_телескопы": {
        "адаптивная_оптика": "Коррекция искажений в реальном времени",
        "высокие_горы": "Меньше атмосферы, сухой воздух",
        "примеры": "Мауна-Кеа, Паранал, Чили"
    },
    "космические_телескопы": {
        "преимущество": "Нет атмосферы",
        "примеры": {
            "Hubble": "Видимый, УФ, ближний ИК",
            "Spitzer": "Инфракрасное",
            "Chandra": "Рентген",
            "Fermi": "Гамма",
            "JWST": "Инфракрасное (2021)"
        }
    }
}

print("Решения проблемы атмосферы:")
for solution, details in atmosphere_solutions.items():
    print(f"\n{solution.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Решения проблемы атмосферы:
  Наземные Телескопы:
    Адаптивная Оптика: Коррекция искажений в реальном времени
    Высокие Горы: Меньше атмосферы, сухой воздух
    Примеры: Мауна-Кеа, Паранал, Чили

Космические Телескопы:
    Преимущество: Нет атмосферы
    Примеры:
      Hubble: Видимый, УФ, ближний ИК
      Spitzer: Инфракрасное
      Chandra: Рентген
      Fermi: Гамма
      JWST: Инфракрасное (2021)
```

## 5. Многоволновая астрономия

### 5.1 Принцип

**Многоволновая астрономия** — изучение объектов на всех длинах волн.

**Почему это важно:**

```python
# Многоволновая астрономия
multi_wavelength = {
    "принцип": "Один объект изучается на всех длинах волн",
    "пример": {
        "объект": "Активная галактика",
        "радио": "Джеты",
        "оптическое": "Звёзды галактики",
        "рентген": "Аккреционный диск",
        "гамма": "Высокоэнергетические процессы"
    },
    "результат": "Полная картина объекта"
}

print("Многоволновая астрономия:")
for key, value in multi_wavelength.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        if "объект" in value:
            print(f"  Объект: {value['объект']}")
            for k, v in value.items():
                if k != "объект":
                    print(f"  {k.replace('_', ' ').title()}: {v}")
        else:
            for k, v in value.items():
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Многоволновая астрономия:
  Принцип: Один объект изучается на всех длинах волн

Пример:
  Объект: Активная галактика
  Радио: Джеты
  Оптическое: Звёзды галактики
  Рентген: Аккреционный диск
  Гамма: Высокоэнергетические процессы

Результат: Полная картина объекта
```

## 💡 Key Takeaways

- **Электромагнитный спектр** — от гамма-лучей до радио; разные объекты видны на разных длинах волн

- **Атмосфера Земли** блокирует большую часть излучения; нужны космические телескопы

- **Наземные телескопы** — оптические и радио; адаптивная оптика улучшает качество

- **Космические телескопы** — доступ ко всему спектру, нет атмосферных искажений

- **Многоволновая астрономия** — изучение объектов на всех длинах волн даёт полную картину
