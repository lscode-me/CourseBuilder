## 1. Пространство-время

### 1.1 Концепция Эйнштейна

**Пространство-время** — единая четырёхмерная структура, объединяющая пространство и время.

**Идея:**

```python
# Пространство-время
spacetime = {
    "измерения": {
        "пространство": "3 измерения (x, y, z)",
        "время": "1 измерение (t)",
        "вместе": "4-мерное пространство-время"
    },
    "аналогия": {
        "2d_лист": "Пространство-время как лист",
        "искривление": "Масса искривляет лист",
        "гравитация": "Искривление = гравитация"
    },
    "важность": "Фундамент общей теории относительности"
}

print("Пространство-время:")
for key, value in spacetime.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Пространство-время:
  Измерения:
    Пространство: 3 измерения (x, y, z)
    Время: 1 измерение (t)
    Вместе: 4-мерное пространство-время

Аналогия:
  2D Лист: Пространство-время как лист
  Искривление: Масса искривляет лист
  Гравитация: Искривление = гравитация

Важность: Фундамент общей теории относительности
```

### 1.2 Отличие от ньютоновской физики

**Ньютоновская физика:**

- Пространство и время отдельны
- Пространство абсолютно и неизменно
- Время течёт одинаково для всех

**Эйнштейновская физика:**

- Пространство и время едины
- Пространство-время может искривляться
- Время течёт по-разному в разных местах

## 2. Общая теория относительности (интуитивно)

### 2.1 Основная идея

**Общая теория относительности (ОТО)** — теория гравитации Эйнштейна.

**Ключевая идея:**

```python
# Основная идея ОТО
general_relativity = {
    "принцип_эквивалентности": {
        "формулировка": "Гравитация = ускорение",
        "пример": "В лифте нельзя отличить гравитацию от ускорения",
        "следствие": "Гравитация — это не сила, а искривление пространства-времени"
    },
    "уравнение_Эйнштейна": {
        "смысл": "Масса-энергия → искривление пространства-времени",
        "обратно": "Искривление → движение (гравитация)"
    },
    "аналогия": {
        "мяч_на_листе": "Мяч катится по искривлённому листу",
        "планета": "Планета движется по искривлённому пространству-времени"
    }
}

print("Основная идея ОТО:")
for concept, details in general_relativity.items():
    print(f"\n{concept.replace('_', ' ').title()}:")
    if isinstance(details, dict):
        for k, v in details.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {details}")
```

**Output:**
```

Основная идея ОТО:
  Принцип Эквивалентности:
    Формулировка: Гравитация = ускорение
    Пример: В лифте нельзя отличить гравитацию от ускорения
    Следствие: Гравитация — это не сила, а искривление пространства-времени

Уравнение Эйнштейна:
    Смысл: Масса-энергия → искривление пространства-времени
    Обратно: Искривление → движение (гравитация)

Аналогия:
    Мяч На Листе: Мяч катится по искривлённому листу
    Планета: Планета движется по искривлённому пространству-времени
```

### 2.2 Искривление пространства-времени

**Как масса искривляет пространство-время:**

```python
# Искривление пространства-времени
spacetime_curvature = {
    "масса": {
        "эффект": "Искривляет пространство-время вокруг себя",
        "аналогия": "Шар на резиновом листе создаёт вмятину"
    },
    "движение": {
        "прямолинейное": "В искривлённом пространстве выглядит как орбита",
        "пример": "Планета "падает" по искривлённому пространству"
    },
    "сила": {
        "ньютоновская": "Гравитация — это сила",
        "эйнштейновская": "Гравитация — это геометрия"
    }
}

print("Искривление пространства-времени:")
for concept, details in spacetime_curvature.items():
    print(f"\n{concept.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Искривление пространства-времени:
  Масса:
    Эффект: Искривляет пространство-время вокруг себя
    Аналогия: Шар на резиновом листе создаёт вмятину

Движение:
    Прямолинейное: В искривлённом пространстве выглядит как орбита
    Пример: Планета "падает" по искривлённому пространству

Сила:
    Ньютоновская: Гравитация — это сила
    Эйнштейновская: Гравитация — это геометрия
```

## 4. Время в ОТО

### 4.1 Замедление времени

**Время течёт по-разному:**

```python
# Замедление времени
time_dilation = {
    "гравитационное": {
        "эффект": "Время течёт медленнее в сильном гравитационном поле",
        "пример": "Часы на Земле идут медленнее, чем в космосе",
        "применение": "GPS требует поправки на ОТО"
    },
    "релятивистское": {
        "эффект": "Время замедляется при движении",
        "пример": "Космонавты стареют медленнее",

print("Замедление времени:")
for type_dilation, details in time_dilation.items():

```

**Output:**
```

Замедление времени:
  Гравитационное:

Релятивистское:
```
