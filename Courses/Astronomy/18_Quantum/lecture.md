## 1. Квантование энергии

### 1.1 Основная идея

**Квантование** — энергия может принимать только определённые дискретные значения.

**Принцип:**

```python
# Квантование энергии
energy_quantization = {
    "классическая_физика": {
        "энергия": "Любое значение",
        "пример": "Электрон на любой орбите"
    },
    "квантовая_физика": {
        "энергия": "Только определённые уровни",
        "пример": "Электрон только на разрешённых орбитах",
        "формула": "E = n × hν (n = 1, 2, 3, ...)"
    },
    "следствие": "Атомы могут излучать/поглощать только определённые энергии"
}

print("Квантование энергии:")
for physics_type, details in energy_quantization.items():
    print(f"\n{physics_type.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Квантование энергии:
  Классическая Физика:
    Энергия: Любое значение
    Пример: Электрон на любой орбите

Квантовая Физика:
    Энергия: Tолько определённые уровни
    Пример: Электрон только на разрешённых орбитах
    Формула: E = n × hν (n = 1, 2, 3, ...)

Следствие: Атомы могут излучать/поглощать только определённые энергии
```

### 1.2 Принцип запрета Паули

**Принцип запрета Паули** — два электрона не могут находиться в одном квантовом состоянии.

**Следствия:**

```python
# Принцип запрета Паули
pauli_exclusion = {
    "формулировка": "Два фермиона не могут быть в одном состоянии",
    "фермионы": "Электроны, нейтроны, протоны",
    "следствие": {
        "атомы": "Электроны занимают разные уровни",
        "белые_карлики": "Электроны не могут все быть внизу",
        "нейтронные_звёзды": "Нейтроны не могут все быть внизу"
    },
    "результат": "Создаётся давление вырождения"
}

print("Принцип запрета Паули:")
for key, value in pauli_exclusion.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Принцип запрета Паули:
  Формулировка: Два фермиона не могут быть в одном состоянии
  Фермионы: Электроны, нейтроны, протоны

Следствие:
    Атомы: Электроны занимают разные уровни
    Белые Карлики: Электроны не могут все быть внизу
    Нейтронные Звёзды: Нейтроны не могут все быть внизу

Результат: Создаётся давление вырождения
```

## 2. Давление вырождения

### 2.1 Что такое давление вырождения

**Давление вырождения** — давление, создаваемое квантовыми эффектами, не зависящее от температуры.

**Сравнение:**

```python
# Давление вырождения
degeneracy_pressure = {
    "обычный_газ": {
        "давление": "Зависит от температуры",
        "механизм": "Столкновения частиц",
        "при_охлаждении": "Давление падает"
    },
    "вырожденный_газ": {
        "давление": "Не зависит от температуры",
        "механизм": "Принцип запрета Паули",
        "при_охлаждении": "Давление остаётся"
    },
    "важность": "Удерживает белые карлики и нейтронные звёзды"
}

print("Давление вырождения:")
for gas_type, details in degeneracy_pressure.items():
    print(f"\n{gas_type.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Давление вырождения:
  Обычный Газ:
    Давление: Зависит от температуры
    Механизм: Столкновения частиц
    При Охлаждении: Давление падает

Вырожденный Газ:
    Давление: Не зависит от температуры
    Механизм: Принцип запрета Паули
    При Охлаждении: Давление остаётся

Важность: Удерживает белые карлики и нейтронные звёзды
```

## 3. Квантовые эффекты в звёздах

### 3.1 Термоядерный синтез

**Квантовое туннелирование:**

```python
# Квантовое туннелирование в синтезе
quantum_tunneling = {
    "проблема": {
        "кулоновский_барьер": "Протоны отталкиваются",
        "энергия": "Нужна очень высокая энергия для преодоления"
    },
    "решение": {
        "квантовое_туннелирование": "Протоны могут "просачиваться" через барьер",
        "вероятность": "Мала, но достаточна при высокой температуре",
        "результат": "Синтез происходит быстрее, чем классически"
    }
}

print("Квантовое туннелирование в синтезе:")
for category, details in quantum_tunneling.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    for key, value in details.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Квантовое туннелирование в синтезе:
  Проблема:
    Кулоновский Барьер: Протоны отталкиваются
    Энергия: Нужна очень высокая энергия для преодоления

Решение:
    Квантовое Туннелирование: Протоны могут "просачиваться" через барьер
    Вероятность: Мала, но достаточна при высокой температуре
    Результат: Синтез происходит быстрее, чем классически
```

### 3.2 Излучение Хокинга

**Испарение чёрных дыр:**

```python
# Излучение Хокинга
hawking_radiation = {
    "механизм": {
        "виртуальные_пары": "Частица-античастица рождаются из вакуума",
        "у_горизонта": "Одна падает в чёрную дыру, другая улетает",
        "результат": "Чёрная дыра теряет массу"
    },
    "температура": {
        "формула": "T = ħc³/(8πGMk)",
        "для_солнечной_массы": "~10⁻⁶ K (практически незаметно)",
        "для_маленькой": "Выше (быстрее испаряется)"
    },
    "время_испарения": {
        "солнечная_масса": "10⁶⁷ лет (дольше возраста Вселенной)",
        "маленькая": "Может испариться"
    }
}

print("Излучение Хокинга:")
for category, details in hawking_radiation.items():
    if isinstance(details, dict):
        print(f"\n{category.replace('_', ' ').title()}:")
        for k, v in details.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {category.replace('_', ' ').title()}: {details}")
```

**Output:**
```

Излучение Хокинга:
  Механизм:
    Виртуальные Пары: Частица-античастица рождаются из вакуума
    У Горизонта: Одна падает в чёрную дыру, другая улетает
    Результат: Чёрная дыра теряет массу

Температура:
    Формула: T = ħc³/(8πGMk)
    Для Солнечной Массы: ~10⁻⁶ K (практически незаметно)
    Для Маленькой: Выше (быстрее испаряется)

Время Испарения:
    Солнечная Масса: 10⁶⁷ лет (дольше возраста Вселенной)
    Маленькая: Может испариться
```

## 💡 Key Takeaways

- **Квантование энергии** — энергия может принимать только дискретные значения
