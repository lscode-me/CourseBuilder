## 1. Что такое экзопланеты

### 1.1 Определение

**Экзопланета** (или внесолнечная планета) — это планета, вращающаяся вокруг звезды, отличной от Солнца.

**История открытий:**

```python
# История открытий экзопланет
exoplanet_history = {
    "1992": {
        "событие": "Первые экзопланеты",
        "объект": "Пульсары PSR B1257+12",
        "количество": "3 планеты"
    },
    "1995": {
        "событие": "Первая экзопланета у обычной звезды",
        "объект": "51 Пегаса b",
        "метод": "Радиальная скорость"
    },
    "2009": {
        "событие": "Запуск Кеплера",
        "результат": "Тысячи кандидатов",
        "метод": "Транзитный метод"
    },
    "2024": {
        "событие": "Текущее состояние",
        "подтверждено": ">5000 экзопланет",
        "кандидатов": "Десятки тысяч"
    }
}

print("История открытий экзопланет:")
for year, info in exoplanet_history.items():
    print(f"\n{year}:")
    for key, value in info.items():
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

История открытий экзопланет:

1992:
  Событие: Первые экзопланеты
  Объект: Пульсары PSR B1257+12
  Количество: 3 планеты

1995:
  Событие: Первая экзопланета у обычной звезды
  Объект: 51 Пегаса b
  Метод: Радиальная скорость

2009:
  Событие: Запуск Кеплера
  Результат: Tысячи кандидатов
  Метод: Транзитный метод

2024:
  Событие: Текущее состояние
  Подтверждено: >5000 экзопланет
  Кандидатов: Десятки тысяч
```

## 2. Методы обнаружения экзопланет

### 2.1 Транзитный метод

**Транзитный метод** — обнаружение планет по затемнению звезды, когда планета проходит перед ней.

**Как это работает:**

```python
# Транзитный метод
transit_method = {
    "принцип": "Измерение уменьшения яркости звезды",
    "что_измеряется": {
        "глубина_затмения": "Зависит от размера планеты",
        "период": "Время между транзитами = период орбиты",
        "длительность": "Зависит от размера орбиты"
    },
    "информация": {
        "радиус_планеты": "Из глубины затмения",
        "период_орбиты": "Из интервала между транзитами",
        "большая_полуось": "Из третьего закона Кеплера"
    },
    "преимущества": [
        "Можно обнаружить множество планет",
        "Даёт размер планеты",
        "Возможна спектроскопия атмосферы"
    ],
    "недостатки": [
        "Требуется точное выравнивание",
        "Много ложных срабатываний",
        "Нужны повторные наблюдения"
    ]
}

print("Транзитный метод обнаружения экзопланет:")
print(f"\nПринцип: {transit_method['принцип']}")
print("\nЧто измеряется:")
for key, value in transit_method['что_измеряется'].items():
    print(f"  {key.replace('_', ' ').title()}: {value}")
print("\nПреимущества:")
for item in transit_method['преимущества']:
    print(f"  • {item}")
```

**Output:**
```

Транзитный метод обнаружения экзопланет:

Принцип: Измерение уменьшения яркости звезды

Что измеряется:
  Глубина Затмения: Зависит от размера планеты
  Период: Время между транзитами = период орбиты
  Длительность: Зависит от размера орбиты

Преимущества:
  • Можно обнаружить множество планет
  • Даёт размер планеты
  • Возможна спектроскопия атмосферы
```

### 2.2 Метод радиальной скорости

**Метод радиальной скорости** — обнаружение планет по колебаниям звезды из-за гравитационного влияния планеты.

**Принцип:**

- Планета и звезда вращаются вокруг общего центра масс
- Звезда "колеблется" относительно нас
- Измеряется доплеровское смещение спектральных линий

**Что можно определить:**

- Минимальная масса планеты
- Период орбиты
- Эксцентриситет орбиты

### 2.3 Другие методы

**Методы прямого наблюдения:**

- Коронография (блокировка света звезды)
- Использование адаптивной оптики
- Поляриметрия

**Гравитационное микролинзирование:**

- Искривление света дальним объектом
- Временное увеличение яркости

**Астрометрия:**

- Измерение точного положения звезды
- Обнаружение колебаний

## 3. Типы экзопланет

### 3.1 Классификация по размеру

**Типы экзопланет:**

```python
# Типы экзопланет по размеру
exoplanet_types = {
    "суперземли": {
        "размер": "1.5-2 радиуса Земли",
        "масса": "До 10 масс Земли",
        "состав": "Скалистые или океанические",
        "пример": "Кеплер-452b, Проксима Центавра b"
    },
    "нептуны": {
        "размер": "~4 радиуса Земли",
        "масса": "10-50 масс Земли",
        "состав": "Газовые оболочки, возможные океаны",
        "пример": "Множество в данных Кеплера"
    },
    "горячие_юпитеры": {
        "размер": "Сравнимы с Юпитером",
        "масса": "Массивные",
        "особенность": "Очень близко к звезде",
        "пример": "51 Пегаса b, HD 209458 b"
    },
    "земного_типа": {
        "размер": "~1 радиус Земли",
        "масса": "~1 масса Земли",
        "состав": "Скалистые",
        "пример": "Кеплер-186f, TRAPPIST-1 планеты"

print("Типы экзопланет:")
for planet_type, info in exoplanet_types.items():
```

```
  Размер: ~1 радиус Земли
  Масса: ~1 масса Земли

  Пример: Кеплер-186f, TRAPPIST-1 планеты
```

### 3.2 Классификация по орбитам

**Типы орбит:**

- **Близкие орбиты**: периоды от часов до дней

- **Средние орбиты**: периоды от недель до месяцев

- **Далёкие орбиты**: периоды от лет до десятилетий

**Особые случаи:**

- **Горячие юпитеры**: газовые гиганты очень близко к звезде

- **Раскалённые планеты**: температуры поверхности > 2000 K

- **Планеты в обитаемой зоне**: условия для жидкой воды

## 4. Обитаемая зона

### 4.1 Определение

**Обитаемая зона** (зона Златовласки) — это область вокруг звезды, где условия позволяют существовать жидкой воде на поверхности планеты.

**Факторы:**

```python
# Обитаемая зона
habitable_zone = {
    "определение": "Расстояние от звезды, где возможна жидкая вода",
    "факторы": {
        "яркость_звезды": "Определяет внешние границы",
        "размер_звезды": "Влияет на стабильность зоны",
        "атмосфера_планеты": "Может расширять зону (парниковый эффект)",
        "состав_планеты": "Влияет на способность удерживать воду"
    },
    "для_солнца": {
        "внутренняя_граница": "~0.95 АЕ",
        "внешняя_граница": "~1.7 АЕ",
        "земля": "1.0 АЕ (внутри зоны)"
    },
    "другие_звёзды": {
        "красные_карлики": "Очень близко к звезде",
        "гиганты": "Дальше от звезды"
    }
}

print("Обитаемая зона:")
for key, value in habitable_zone.items():
    if isinstance(value, dict):
        print(f"\n{key.replace('_', ' ').title()}:")
        for k, v in value.items():
            if isinstance(v, dict):
                print(f"  {k.replace('_', ' ').title()}:")
                for k2, v2 in v.items():
                    print(f"    {k2.replace('_', ' ').title()}: {v2}")
            else:
                print(f"  {k.replace('_', ' ').title()}: {v}")
    else:
        print(f"  {key.replace('_', ' ').title()}: {value}")
```

**Output:**
```

Обитаемая зона:
  Определение: Расстояние от звезды, где возможна жидкая вода

Факторы:
  Яркость Звезды: Определяет внешние границы
  Размер Звезды: Влияет на стабильность зоны
  Атмосфера Планеты: Может расширять зону (парниковый эффект)
  Состав Планеты: Влияет на способность удерживать воду

Для Солнца:
  Внутренняя Граница: ~0.95 АЕ
  Внешняя Граница: ~1.7 АЕ
  Земля: 1.0 АЕ (внутри зоны)

Другие Звёзды:
  Красные Карлики: Очень близко к звезде
  Гиганты: Дальше от звезды
```

### 4.2 Ограничения концепции

**Проблемы:**

- Обитаемая зона — упрощение
- Жизнь может существовать и вне зоны (подлёдные океаны)
- Атмосфера может кардинально изменить условия

**Расширенные концепции:**

- Подповерхностная жизнь
- Жизнь в атмосферах газовых гигантов
- Экстремофилы расширяют возможные условия

## 5. Поиск жизни

### 5.1 Биомаркеры

**Биомаркеры** — признаки, указывающие на возможное присутствие жизни.

**Типы биомаркеров:**

```python
# Биомаркеры
biosignatures = {
    "атмосферные": {
        "кислород": "O₂ (может быть абиогенным)",
        "озон": "O₃ (связан с кислородом)",
        "метан": "CH₄ (может быть биогенным)",
        "комбинации": "O₂ + CH₄ (сильный признак жизни)"
    },
    "поверхностные": {
        "растительность": "Красный край (red edge)",
        "биоплёнки": "Специфические спектральные признаки"
    },
    "технологические": {
        "радиосигналы": "SETI поиск",
        "загрязнение": "Искусственные химические соединения",
        "мегаструктуры": "Гипотетические артефакты"
    }
}

print("Биомаркеры для поиска жизни:")
for category, signatures in biosignatures.items():
    print(f"\n{category.replace('_', ' ').title()}:")
    for name, description in signatures.items():
        print(f"  {name.replace('_', ' ').title()}: {description}")
```

**Output:**
```

Биомаркеры для поиска жизни:

Атмосферные:
  Кислород: O₂ (может быть абиогенным)
  Озон: O₃ (связан с кислородом)
  Метан: CH₄ (может быть биогенным)
  Комбинации: O₂ + CH₄ (сильный признак жизни)

Поверхностные:
  Растительность: Красный край (red edge)
  Биоплёнки: Специфические спектральные признаки

Технологические:
  Радиосигналы: SETI поиск
  Загрязнение: Искусственные химические соединения
  Мегаструктуры: Гипотетические артефакты
```
