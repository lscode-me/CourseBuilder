# 📘 Курс: Введение в Астрономию и Астрофизику

Комплексный курс по астрономии и астрофизике на русском языке.

---

## 📖 Описание курса

Астрономия изучает небесные объекты и Вселенную в целом.
Астрофизика применяет законы физики для объяснения их природы,
происхождения и эволюции.

Курс охватывает:
- Основные астрономические объекты
- Физические процессы в космосе
- Элементы теоретической физики (интуитивно)
- Современные представления о Вселенной

Математика сведена к минимуму. Упор сделан на понимание и физический смысл.

---

## 🎯 Цели курса

После курса слушатель:
- Понимает, какие объекты существуют во Вселенной
- Знает, чем они отличаются и как связаны
- Понимает, какие физические процессы ими управляют
- Ориентируется в современной картине космоса

## 📋 Формат модуля

Каждый модуль содержит:

```
XX_ModuleName/
├── lecture.md    # Основной материал лекции (600-1000 строк)
└── quiz.md       # Вопросы для самопроверки (20-30 вопросов)
```

### Структура лекции

- **Prerequisites** — что нужно знать перед началом
- **Learning Objectives** — цели обучения (3-5 пунктов)
- **Основной материал** — теория с примерами и кодом
- **Key Takeaways** — главные выводы (3-5 пунктов)
- **Next Steps** — что изучить дальше
- **Additional Resources** — дополнительные материалы

### Quiz

- 20-30 вопросов с множественным выбором
- Покрывают Learning Objectives из лекции
- Ответы с пояснениями
- Scoring Guide для самооценки

## 🚀 Как использовать курс

### Последовательное изучение

1. **Читайте лекции** по порядку (30-45 минут)
2. **Проходите квизы** после каждой лекции
3. **Выполняйте Practice Ideas** из Next Steps
4. **Переходите к следующей лекции**

### Выборочное изучение

Можно изучать модули выборочно, но рекомендуется:
- Начать с Модуля 1 (Основы)
- Модуль 2 (Солнечная система) независим
- Модули 3-4 (Звёзды и компактные объекты) связаны
- Модуль 5 (Галактики) требует Модуля 3
- Модули 7-8 (Астрофизика и космология) требуют предыдущих
