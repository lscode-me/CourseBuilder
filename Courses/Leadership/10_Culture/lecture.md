## 1. Что такое культура

### 1.1 Определение

> **💡 Key Insight:**  
> Культура — это "как мы делаем вещи здесь". Неписаные правила поведения, которые определяют daily interactions.

**Формула культуры:**
```

Culture = Values × Behaviors × Habits × Stories

```

- **Values** — что мы считаем важным

- **Behaviors** — как мы действуем

- **Habits** — повторяющиеся паттерны

- **Stories** — что мы рассказываем новичкам

### 1.2 Культура vs декларации

**На стене написано:**
```

"Мы ценим инновации и risk-taking"

```

**В реальности:**
```

- Любая ошибка публично критикуется
- Новые идеи отвергаются
- Promotions получают "безопасные" люди

```

> **⚠️ Warning:**  
> Культура — это то, что происходит, не то, что написано в документах.

### 1.3 Уровни культуры

**Edgar Schein's Model:**

```

┌─────────────────────────────────────────┐
│           ARTIFACTS                     │  Видимое:
│   Офис, dress code, ceremonies          │  легко наблюдать
├─────────────────────────────────────────┤
│        ESPOUSED VALUES                  │  Декларируемое:
│   Mission statements, policies          │  что говорим
├─────────────────────────────────────────┤
│    UNDERLYING ASSUMPTIONS               │  Глубинное:
│   Неосознанные убеждения                │  настоящие драйверы
└─────────────────────────────────────────┘

```

## 2. Почему культура важна

### 2.1 Влияние на performance

**Google's Project Aristotle** (исследование эффективных команд):

```

Что НЕ влияет на эффективность:

- Состав команды (интроверты vs экстраверты)
- Опыт и образование
- Размер команды

Что ВЛИЯЕТ:

1. Psychological Safety (главный фактор!)
2. Dependability
3. Structure & Clarity
4. Meaning
5. Impact

```

### 2.2 Психологическая безопасность

**Определение (Amy Edmondson):**
Убеждённость, что команда безопасна для межличностных рисков.

**Что это значит:**

- Можно задать "глупый" вопрос
- Можно признать ошибку
- Можно не согласиться с начальником
- Можно предложить новую идею

### 2.3 Симптомы плохой культуры

```

Red flags:

- Высокая текучесть
- Blame culture ("это не я")
- Информация скрывается
- Люди боятся говорить правду
- Решения принимаются политически
- Нет diversity of thought

```

## 3. Создание психологической безопасности

### 3.1 Модель Amy Edmondson

**Три шага:**

1. **Set the stage**
   - Frame работу как learning problem
   - Acknowledge uncertainty
   - "Мы делаем сложное, ошибки неизбежны"

2. **Invite participation**
   - Ask questions
   - Show humility ("Я могу быть неправ")
   - Request input actively

3. **Respond productively**
   - Thank for speaking up
   - No punishment for errors
   - Forward-looking discussions

### 3.2 Конкретные практики

**Как лидер:**

```markdown

✅ DO:

- Признавайте свои ошибки публично
- Задавайте вопросы команде
- Благодарите за несогласие
- Celebrate learning, не только успехи
- "Я не знаю" — OK ответ

❌ DON'T:

- Наказывать за ошибки
- Игнорировать concerns
- Быть "всегда правым"
- Критиковать перед другими
- Создавать фаворитов

```

### 3.3 Измерение психологической безопасности

**Survey questions (по Edmondson):**
```

1. Если я ошибусь, это будет held against me?
2. Члены команды могут поднять проблемы?
3. Люди иногда отвергают других за их различия?
4. Безопасно ли рисковать в этой команде?
5. Сложно ли просить помощь у коллег?
6. Кто-то намеренно подрывает мои усилия?
7. Мои уникальные навыки ценятся?

```

## 4. Формирование командных ценностей

### 4.1 Процесс создания

**Workshop для команды (2-3 часа):**

```

1. Individual Reflection (15 min)
   "Когда команда работала лучше всего, что было важно?"

2. Small Group Discussion (30 min)
   Группы по 3-4 человека делятся insights

3. Identify Themes (20 min)
   Какие темы повторяются?

4. Define Values (45 min)
   Сформулировать 3-5 ключевых ценностей

5. Behaviors (30 min)
   Какие behaviors демонстрируют каждую ценность?

6. Anti-patterns (20 min)
   Какие behaviors противоречат ценностям?

```

### 4.2 Пример ценностей команды

```markdown
## Team Values

### 1. Ownership
**Behaviors:**
- Берём ответственность за результат
- Если видим проблему — решаем
- Не говорим "это не моя работа"

**Anti-patterns:**
- Перекладывание blame
- Ожидание инструкций

### 2. Radical Candor
**Behaviors:**
- Даём честный feedback
- Спрашиваем feedback о себе
- Disagree openly, commit together

**Anti-patterns:**
- Говорить за спиной
- Избегать сложных разговоров

### 3. Continuous Learning
**Behaviors:**
- Делимся знаниями
- Признаём, что не знаем
- Post-mortems без blame

**Anti-patterns:**

- "Мы всегда так делали"
- Скрывать ошибки

```

### 4.3 Поддержание ценностей

**Reinforcement:**

- Hiring: спрашивать о ценностях
- Recognition: награждать за behaviors
- Performance: включать в review
- Stories: рассказывать примеры
- Onboarding: объяснять новичкам

## 5. Culture Add vs Culture Fit

### 5.1 Проблема "Culture Fit"

**Традиционный подход:**
```

"Нам нужен человек, который впишется в культуру"
→ Часто = "похож на нас"
→ Risk: homogeneous team, bias

```

### 5.2 Culture Add

**Лучший подход:**
```

"Нам нужен человек, который разделяет ценности И добавляет diversity"

Вопросы:

- Разделяет ли core values?
- Какую perspective/experience добавит?
- Как расширит наше thinking?

```

### 5.3 Interview для культуры

**Вопросы:**
```

Values alignment:

- "Расскажи о ситуации, когда ты не согласился с решением команды"
- "Как ты давал feedback, который был неприятным?"
- "Расскажи об ошибке и что ты сделал"

Diversity of thought:

- "Какой опыт у тебя отличается от большинства?"
- "Когда ты менял своё мнение?"

```

## 6. Изменение культуры

### 6.1 Почему это сложно

```

Culture change is SLOW because:

- Habits глубоко укоренены
- Incentives часто противоречат
- Resistance от тех, кому выгоден status quo
- Требует consistent behavior от лидеров

```

### 6.2 Framework для изменений

**Kotter's 8 Steps (adapted):**

```

1. Create Urgency
   Почему нужно меняться сейчас?
   
2. Build Coalition
   Найти allies, кто поддержит
   
3. Form Vision
   Куда идём? Как выглядит успех?
   
4. Communicate Vision
   Повторять, повторять, повторять
   
5. Remove Obstacles
   Изменить процессы, policies
   
6. Generate Short-term Wins
   Показать, что новый подход работает
   
7. Build on Change
   Не останавливаться после первых успехов
   
8. Anchor in Culture
   Сделать новое нормой

```

### 6.3 Практические советы

**Start small:**

- Одна практика/behavior за раз
- Pilot в вашей команде
- Expand при успехе

**Lead by example:**

- Вы должны демонстрировать первым
- Inconsistency kills change
- "Делай как я делаю, не как говорю" не работает

**Make it easy:**

- Новое поведение должно быть проще старого
- Remove friction
- Add nudges

## 7. Типы культур

### 7.1 Westrum Organizational Typology

| Aspect | Pathological | Bureaucratic | Generative |
|--------|-------------|--------------|------------|
| Information | Hidden | Ignored | Actively sought |
| Messengers | Killed | Neglected | Trained |
| Responsibilities | Shirked | Narrow | Shared |
| Bridging | Discouraged | Allowed | Encouraged |
| Failure | Punished | Just | Inquiry |
| Novelty | Crushed | Problems | Implemented |

**Generative culture коррелирует с:**

- Higher software delivery performance
- Lower burnout
- Better security outcomes

### 7.2 Netflix Culture

**Ключевые элементы:**

- Freedom and Responsibility
- Context, not Control
- High Performance = High Talent Density
- Candor
- "Keeper Test": "Would I fight to keep this person?"

### 7.3 Spotify Model

**Squads, Tribes, Chapters, Guilds:**

- Autonomy команд
- Alignment через tribes
- Cross-cutting expertise через chapters
- Communities through guilds

## 8. Культура в распределённых командах

### 8.1 Challenges

```

Remote/distributed teams:

- Меньше casual interactions
- Culture spreads slower
- Сложнее читать signals
- Onboarding harder
- Subcultures в locations

```

### 8.2 Решения

**Intentional culture building:**
```

- Document values explicitly
- Regular video calls (cameras on!)
- Virtual social events
- Team offsites (если возможно)
- Consistent async communication norms

```

**Over-communication:**
```

- Больше context в messages
- Explicit expectations
- Written documentation
- Regular sync meetings

```

## 9. Toxic Culture

### 9.1 Признаки

```

🚨 Warning signs:

- Blame culture
- Information hoarding
- Political decisions
- Bullying / harassment
- Unrealistic expectations
- Burnout normalized
- High turnover

```

### 9.2 Как лидер

**Что можете сделать:**

- Create safe space в вашей команде
- Не participate в toxic behaviors
- Escalate serious issues
- Document и report

**Когда уходить:**

- Если не можете защитить команду
- Если values конфликтуют фундаментально
- Если burnout неизбежен

## 💡 Key Takeaways

- **Культура = behaviors:** Не слова на стене, а повседневные действия

- **Psychological Safety #1:** Главный фактор эффективности команды

- **Lead by example:** Лидер моделирует культуру каждый день

- **Culture Add > Fit:** Diversity strengthens, homogeneity weakens

- **Change is slow:** Consistent effort over time
