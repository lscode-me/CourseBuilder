## 1. Что такое культура

### 1.1 Определение

> **💡 Key Insight:**  
> Культура — это "как мы делаем вещи здесь". Неписаные правила поведения, которые определяют daily interactions.

**Простой тест культуры:**

Новый человек пришёл в команду. Что он узнает за первую неделю **не из документов**, а из наблюдения?

- Как люди общаются на митингах?
- Что происходит, когда кто-то ошибается?
- Кто принимает решения и как?
- Можно ли не согласиться с руководителем?
- Как относятся к новым идеям?

**Ответы на эти вопросы — это и есть культура.**

**Формула культуры:**

```
Culture = Values × Behaviors × Habits × Stories × Incentives

Values:     Что мы считаем важным (на словах и на деле)
Behaviors:  Как мы действуем ежедневно
Habits:     Повторяющиеся паттерны (митинги, reviews, celebrations)
Stories:    Что мы рассказываем новичкам ("У нас однажды...")
Incentives: Что награждается и что наказывается
```

### 1.2 Культура vs Декларации

**Три уровня культуры:**

| Уровень | Что это | Пример |
|---------|---------|--------|
| **Декларируемая** | Что написано | "Мы ценим инновации" |
| **Воспринимаемая** | Что люди думают | "Здесь поощряют эксперименты" |
| **Реальная** | Что происходит | Ошибки наказываются, новые идеи отвергаются |

**Пример разрыва:**

```
Декларируемое:                         Реальное:
───────────────────────────────────────────────────────────────
"Мы ценим work-life balance"     →     Руководители пишут в 11 PM,
                                       overtime нормализован

"Мы приветствуем обратную связь" →     Несогласие воспринимается
                                       как нелояльность

"Мы растим людей"                →     Нет времени на 1-on-1,
                                       развитие — "твоя проблема"

"Прозрачность — наша ценность"   →     Решения принимаются кулуарно,
                                       информация скрывается
```

> **⚠️ Warning:**  
> Культура — это то, что **происходит**, не то, что **написано**. Разрыв между декларациями и реальностью создаёт цинизм.

### 1.3 Edgar Schein's Model: Три уровня культуры

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  LEVEL 1: ARTIFACTS (Visible)                                   │
│  ─────────────────────────────────────────                      │
│  • Офис: open space или кабинеты?                               │
│  • Dress code: casual или formal?                               │
│  • Ceremonies: all-hands, team events, celebrations             │
│  • Communication: email, Slack, формальные митинги              │
│  • Stories: какие истории рассказывают?                         │
│                                                                 │
│  → Легко наблюдать, сложно интерпретировать                     │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  LEVEL 2: ESPOUSED VALUES (Declared)                            │
│  ─────────────────────────────────────────                      │
│  • Mission statements                                           │
│  • Company values на стенах                                     │
│  • Policies и guidelines                                        │
│  • Публичные заявления руководства                              │
│                                                                 │
│  → Что говорим; может отличаться от реальности                  │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  LEVEL 3: UNDERLYING ASSUMPTIONS (Deep)                         │
│  ─────────────────────────────────────────                      │
│  • Неосознанные убеждения                                       │
│  • "Так тут принято"                                            │
│  • Считается настолько очевидным, что не обсуждается            │
│                                                                 │
│  Examples:                                                      │
│  - "Менеджер всегда прав"                                       │
│  - "Ошибаться опасно для карьеры"                               │
│  - "Помогать другим = отвлекаться от своей работы"              │
│  - "Быстрее = лучше"                                            │
│                                                                 │
│  → Настоящие драйверы поведения                                 │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**Как использовать модель:**

1. Начните с artifacts — что видите?
2. Сравните с espoused values — совпадают?
3. Выявите underlying assumptions — что драйвит поведение?
4. Изменения нужны на уровне 3, но начинать придётся с уровня 2

## 2. Почему культура важна

### 2.1 Влияние на performance: Google's Project Aristotle

**Исследование:**
- Google изучил 180+ команд
- Цель: найти, что отличает эффективные команды от неэффективных
- Результаты удивили

**Что НЕ влияет на эффективность:**

| Фактор | Ожидание | Реальность |
|--------|----------|------------|
| Состав команды | "Нужны правильные люди" | Не влияет |
| Интроверты vs экстраверты | "Нужен баланс" | Не влияет |
| Опыт и образование | "Чем больше, тем лучше" | Не влияет |
| Размер команды | "Оптимальный размер" | Не влияет |
| Colocation | "Нужно сидеть вместе" | Не влияет |

**Что ВЛИЯЕТ (в порядке важности):**

| # | Фактор | Описание | Impact |
|---|--------|----------|--------|
| 1 | **Psychological Safety** | Безопасно рисковать | Highest |
| 2 | **Dependability** | Коллеги выполняют обещания | High |
| 3 | **Structure & Clarity** | Понятные цели и роли | High |
| 4 | **Meaning** | Работа важна лично | Medium |
| 5 | **Impact** | Работа важна для мира | Medium |

> **💡 Key Insight:**  
> Psychological Safety — **главный фактор** эффективности команды. Важнее опыта, навыков и состава.

### 2.2 Что такое психологическая безопасность

**Определение (Amy Edmondson):**

> "A shared belief that the team is safe for interpersonal risk-taking."

**Перевод на практику:**

| Ситуация | Психологически безопасно | Психологически опасно |
|----------|-------------------------|----------------------|
| Задать вопрос | "Можно глупый вопрос?" — "Конечно!" | "Это должен знать каждый джун" |
| Признать ошибку | "Я накосячил" — "Давай разберём, что произошло" | "Кто это сделал?! Какой идиот..." |
| Не согласиться | "Я думаю иначе..." — "Интересно, расскажи" | "Ты что, умнее всех?" |
| Предложить идею | "А что если..." — "Давай попробуем" | "У нас нет на это времени" |
| Попросить помощь | "Не понимаю, поможешь?" — "Конечно" | "Это твоя работа, разбирайся" |

**Что Psychological Safety НЕ означает:**

| Это НЕ | Это ДА |
|--------|--------|
| "Все со всем согласны" | Открытое несогласие и дискуссия |
| "Нет стандартов качества" | Высокие стандарты + поддержка |
| "Нельзя давать критику" | Честный feedback с заботой |
| "Все друзья" | Профессиональное уважение |
| "Нет accountability" | Ответственность за результат |

### 2.3 Симптомы плохой культуры

**Red Flags — что наблюдать:**

| Симптом | Как проявляется | Underlying Issue |
|---------|-----------------|------------------|
| **Blame culture** | "Это не я", "Это другой отдел" | Fear of punishment |
| **Information hiding** | Узнаёте новости последним | Lack of trust |
| **Political decisions** | Решения по connections, не merit | Power over competence |
| **Fear of speaking** | Молчат на митингах | Psychological unsafety |
| **High turnover** | Лучшие уходят первыми | Toxic environment |
| **No disagreement** | Все всегда согласны | Fear of conflict |
| **Burnout normalized** | "Так у всех" | Exploitation culture |

**Тест "что происходит когда...":**

```
Что происходит когда...                 Здоровая культура        Токсичная культура
───────────────────────────────────────────────────────────────────────────────────
...кто-то ошибается?                    Разбор, learning         Наказание, shame
...кто-то не согласен с боссом?         Дискуссия                Игнор или репрессии
...проект провалился?                   Post-mortem без blame    Поиск виноватых
...новичок задаёт вопрос?               Рады помочь              "Должен знать сам"
...кто-то просит отпуск?                "Конечно"                Guilt-tripping
...поднята неудобная тема?              Обсуждение               Замалчивание
```

## 3. Создание психологической безопасности

### 3.1 Модель Amy Edmondson: Leader's Toolkit

**Три шага для лидера:**

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  STEP 1: SET THE STAGE                                          │
│  ────────────────────────────────────────                       │
│  Frame работу как learning problem                              │
│                                                                 │
│  Phrases to use:                                                │
│  • "Мы делаем сложное, ошибки неизбежны"                       │
│  • "Я ожидаю, что мы будем учиться по пути"                    │
│  • "Никто не знает всего, включая меня"                        │
│  • "Эксперименты могут не получиться — и это OK"               │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  STEP 2: INVITE PARTICIPATION                                   │
│  ────────────────────────────────────────                       │
│  Активно просите input                                          │
│                                                                 │
│  Phrases to use:                                                │
│  • "Что я могу упускать?"                                      │
│  • "Какие concerns у вас есть?"                                │
│  • "Кто думает иначе?"                                         │
│  • "Помогите мне понять..."                                    │
│  • "Я могу быть неправ..."                                     │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  STEP 3: RESPOND PRODUCTIVELY                                   │
│  ────────────────────────────────────────                       │
│  Reward candor, not silence                                     │
│                                                                 │
│  Phrases to use:                                                │
│  • "Спасибо, что сказал. Это важно."                           │
│  • "Рад, что ты это поднял."                                   │
│  • "Давай разберём, что произошло и что узнали"                │
│  • "Что мы можем сделать по-другому в следующий раз?"          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 Конкретные сценарии и реакции

**Сценарий 1: Кто-то ошибся**

| Плохая реакция | Хорошая реакция |
|----------------|-----------------|
| "Как ты мог это пропустить?" | "Давай разберёмся, что произошло" |
| "Кто за это ответит?" | "Что мы можем сделать сейчас?" |
| *Публичная критика* | *Приватный разговор* |
| "В следующий раз думай лучше" | "Что бы помогло избежать этого?" |

**Сценарий 2: Кто-то не согласен с вами**

| Плохая реакция | Хорошая реакция |
|----------------|-----------------|
| "Я уже решил" | "Расскажи подробнее, что ты имеешь в виду?" |
| *Defensive body language* | "Это интересная точка зрения" |
| "У нас нет времени обсуждать" | "Давай обсудим после митинга" |
| Игнорирование | "Спасибо, что поделился. Я подумаю над этим" |

**Сценарий 3: Кто-то молчит на митингах**

| Плохая реакция | Хорошая реакция |
|----------------|-----------------|
| *Игнорировать* | "Мария, что ты думаешь?" |
| "Почему ты молчишь?" | Приватно: "Я заметил, что ты редко говоришь. Всё ОК?" |
| *Предполагать, что всё хорошо* | Создать async канал для input |

**Сценарий 4: Кто-то признаётся в незнании**

| Плохая реакция | Хорошая реакция |
|----------------|-----------------|
| "Это базовая вещь" | "Хороший вопрос, давай разберём" |
| *Удивлённый взгляд* | "Я тоже это не сразу понял" |
| "Тебе нужно подтянуться" | "Хочешь, расскажу или покажу ресурсы?" |

### 3.3 DO и DON'T для лидера

**✅ DO (Делайте):**

| Практика | Почему работает |
|----------|-----------------|
| Признавайте свои ошибки публично | Моделирует, что ошибаться — OK |
| Задавайте вопросы команде | Показывает, что их мнение важно |
| Благодарите за несогласие | Reinforces speaking up |
| Celebrate learning, не только успехи | Shift focus с результата на рост |
| Говорите "Я не знаю" | Снижает pressure быть perfect |
| Делитесь своими сомнениями | Humanizes лидера |

**❌ DON'T (Не делайте):**

| Практика | Почему разрушает safety |
|----------|------------------------|
| Наказывать за ошибки | Люди будут скрывать проблемы |
| Игнорировать concerns | Люди перестанут поднимать темы |
| Быть "всегда правым" | Люди не будут оспаривать |
| Критиковать перед другими | Публичный shame = страх |
| Создавать фаворитов | "Не в круге" = небезопасно |
| Прерывать или dismissing | "Моё мнение не ценят" |

### 3.4 Измерение психологической безопасности

**7-item Survey (Amy Edmondson):**

| # | Вопрос | Scoring |
|---|--------|---------|
| 1 | Если я ошибусь в этой команде, это будет использовано против меня | Reverse (disagree = good) |
| 2 | Члены этой команды могут поднимать проблемы и сложные вопросы | Agree = good |
| 3 | Люди в этой команде иногда отвергают других за их отличия | Reverse |
| 4 | Безопасно рисковать в этой команде | Agree = good |
| 5 | Сложно просить помощь у членов этой команды | Reverse |
| 6 | Никто в этой команде не действует намеренно, чтобы подорвать мои усилия | Agree = good |
| 7 | Работая с членами этой команды, мои уникальные навыки и таланты ценятся | Agree = good |

**Scoring:**
- 5-point scale (1 = Strongly Disagree, 5 = Strongly Agree)
- Reverse score questions 1, 3, 5
- Average = Psychological Safety Score
- Benchmark: < 3.5 = concern, 3.5-4.0 = OK, > 4.0 = good

### 3.5 Когда Psychological Safety разрушается

**Триггеры разрушения:**

| Событие | Почему разрушает | Как восстановить |
|---------|-----------------|------------------|
| Увольнение после ошибки | "Ошибаться = уволят" | Public narrative о причинах |
| Игнорирование raised concern | "Зачем говорить, если игнорируют" | Follow-up на каждый concern |
| Публичная критика | Страх публичного shame | Приватный feedback, публичный praise |
| Promotion политических игроков | "Важны связи, не merit" | Transparent promotion criteria |
| Смена руководителя | "Новый может быть другим" | Explicitly re-establish norms |

> **⚠️ Warning:**  
> Psychological Safety строится медленно (месяцы) и разрушается быстро (один инцидент). Один публичный разнос может уничтожить годы работы.

## 4. Формирование командных ценностей

### 4.1 Процесс создания

**Workshop для команды (2-3 часа):**

```

1. Individual Reflection (15 min)
   "Когда команда работала лучше всего, что было важно?"

2. Small Group Discussion (30 min)
   Группы по 3-4 человека делятся insights

3. Identify Themes (20 min)
   Какие темы повторяются?

4. Define Values (45 min)
   Сформулировать 3-5 ключевых ценностей

5. Behaviors (30 min)
   Какие behaviors демонстрируют каждую ценность?

6. Anti-patterns (20 min)
   Какие behaviors противоречат ценностям?

```

### 4.2 Пример ценностей команды

```markdown
## Team Values

### 1. Ownership
**Behaviors:**
- Берём ответственность за результат
- Если видим проблему — решаем
- Не говорим "это не моя работа"

**Anti-patterns:**
- Перекладывание blame
- Ожидание инструкций

### 2. Radical Candor
**Behaviors:**
- Даём честный feedback
- Спрашиваем feedback о себе
- Disagree openly, commit together

**Anti-patterns:**
- Говорить за спиной
- Избегать сложных разговоров

### 3. Continuous Learning
**Behaviors:**
- Делимся знаниями
- Признаём, что не знаем
- Post-mortems без blame

**Anti-patterns:**

- "Мы всегда так делали"
- Скрывать ошибки

```

### 4.3 Поддержание ценностей

**Reinforcement:**

- Hiring: спрашивать о ценностях
- Recognition: награждать за behaviors
- Performance: включать в review
- Stories: рассказывать примеры
- Onboarding: объяснять новичкам

## 5. Culture Add vs Culture Fit

### 5.1 Проблема "Culture Fit"

**Традиционный подход и его ловушки:**

```
"Нам нужен человек, который впишется в культуру"
                    ↓
Часто на практике означает:
                    ↓
"Похож на нас" → Bias → Homogeneous team → Groupthink
```

**Риски "Culture Fit":**

| Риск | Как проявляется | Последствия |
|------|-----------------|-------------|
| **Confirmation bias** | "Он нам понравился" | Нанимаем похожих |
| **Affinity bias** | "У нас много общего" | Нет diversity |
| **Homogeneity** | Все думают одинаково | Blind spots, groupthink |
| **Discrimination** | "Не впишется" | Legal и ethical issues |
| **Echo chamber** | Нет новых идей | Stagnation |

### 5.2 Culture Add: Лучший подход

**Формула Culture Add:**

```
Culture Add = 
  Shares Core Values (necessary)
  + Brings New Perspective (differentiator)
  + Expands Our Thinking (value-add)
```

**Матрица оценки кандидата:**

```
                    SHARES VALUES
                    │
           YES      │      NO
     ┌──────────────┼──────────────┐
  H  │              │              │
  I  │   HIRE       │   NO HIRE    │
  G  │  (Culture    │  (Values     │
  H  │   Add)       │   conflict)  │
  ─┼─────────────────────────────────┼─ ADDS PERSPECTIVE
  L  │              │              │
  O  │   CONSIDER   │   NO HIRE    │
  W  │  (May become │  (Double     │
     │   homogeneous│   problem)   │
     └──────────────┴──────────────┘
```

**Вопросы для Culture Add оценки:**

| Область | Вопрос | Что ищем |
|---------|--------|----------|
| Values | Разделяет ли core values? | Non-negotiable alignment |
| Perspective | Какой уникальный опыт/background? | Different viewpoints |
| Challenge | Будет ли challenge status quo? | Healthy pushback |
| Growth | Чему мы научимся у них? | New skills/knowledge |

### 5.3 Culture Interview: Framework

**Structured Culture Interview (45-60 min):**

```
[5 min]  Intro и context
[15 min] Values alignment questions
[15 min] Culture add questions  
[10 min] Red flag detection
[10 min] Candidate questions
[5 min]  Wrap-up
```

**Values Alignment Questions (with scoring):**

| Value | Question | Green Flag | Red Flag |
|-------|----------|------------|----------|
| **Ownership** | "Расскажи о ситуации, когда что-то пошло не так в твоей зоне ответственности" | Owns it, talks about lessons | Blames others, excuses |
| **Candor** | "Когда ты давал feedback, который был неприятным?" | Specific example, care + directness | Avoids conflict, vague |
| **Learning** | "Расскажи о своей самой большой профессиональной ошибке" | Honest, reflective | Defensiveness, denial |
| **Collaboration** | "Как ты разрешал disagreement с коллегой?" | Seeks understanding, compromises | Wins at all costs, avoids |

**Culture Add Questions:**

| Question | Purpose |
|----------|---------|
| "Какой опыт у тебя отличается от большинства в нашей сфере?" | Unique perspective |
| "Когда ты в последний раз фундаментально менял своё мнение?" | Open-mindedness |
| "Что бы ты хотел изменить в типичной engineering culture?" | Fresh thinking |
| "Какой подход из предыдущего опыта мы могли бы использовать?" | Bringing new practices |

**Red Flag Detection:**

| Question | Red Flag Indicators |
|----------|---------------------|
| "Почему ты уходишь с текущего места?" | Blame, negativity about people |
| "Расскажи о конфликте с коллегой" | "Я был прав, они были неправы" |
| "Что тебе не нравится в командах, где ты работал?" | Long list of complaints |
| "Как ты справлялся с feedback, с которым не согласен?" | Dismissiveness, arguing |

## 6. Изменение культуры

### 6.1 Почему это сложно

```

Culture change is SLOW because:

- Habits глубоко укоренены
- Incentives часто противоречат
- Resistance от тех, кому выгоден status quo
- Требует consistent behavior от лидеров

```

### 6.2 Framework для изменений

**Kotter's 8 Steps (adapted):**

```

1. Create Urgency
   Почему нужно меняться сейчас?
   
2. Build Coalition
   Найти allies, кто поддержит
   
3. Form Vision
   Куда идём? Как выглядит успех?
   
4. Communicate Vision
   Повторять, повторять, повторять
   
5. Remove Obstacles
   Изменить процессы, policies
   
6. Generate Short-term Wins
   Показать, что новый подход работает
   
7. Build on Change
   Не останавливаться после первых успехов
   
8. Anchor in Culture
   Сделать новое нормой

```

### 6.3 Практические советы

**Start small:**

- Одна практика/behavior за раз
- Pilot в вашей команде
- Expand при успехе

**Lead by example:**

- Вы должны демонстрировать первым
- Inconsistency kills change
- "Делай как я делаю, не как говорю" не работает

**Make it easy:**

- Новое поведение должно быть проще старого
- Remove friction
- Add nudges

## 7. Типы культур

### 7.1 Westrum Organizational Typology

Westrum классифицировал организации по тому, как они обрабатывают информацию:

```
┌────────────────────────────────────────────────────────────────┐
│                                                                │
│   PATHOLOGICAL        BUREAUCRATIC        GENERATIVE           │
│   (Power-oriented)    (Rule-oriented)     (Performance-oriented)
│                                                                │
│   "Who is to blame?"  "What's the rule?"  "How can we improve?"│
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

**Детальное сравнение:**

| Aspect | Pathological | Bureaucratic | Generative |
|--------|-------------|--------------|------------|
| **Information** | Hidden, used as power | Ignored if not in process | Actively sought |
| **Messengers** | Shot (punished) | Neglected | Trained & thanked |
| **Responsibilities** | Shirked, blamed on others | Narrow, "not my job" | Shared, collective ownership |
| **Bridging teams** | Discouraged, turf wars | Allowed but not helped | Encouraged & rewarded |
| **Failure** | Punished, scapegoating | Leads to more rules | Leads to inquiry & learning |
| **Novelty** | Crushed | Creates problems | Implemented as opportunity |
| **Cooperation** | Low | Modest | High |

**Почему это важно:**

Исследования DORA (Accelerate) показали:

| Культура | Software Delivery | Burnout | Security |
|----------|-------------------|---------|----------|
| Pathological | Low performance | High | Poor |
| Bureaucratic | Medium | Medium | Medium |
| **Generative** | **High performance** | **Low** | **Good** |

**Диагностика вашей культуры:**

| Вопрос | Pathological | Bureaucratic | Generative |
|--------|--------------|--------------|------------|
| Что происходит с messenger'ом плохих новостей? | Наказывают | Игнорируют | Благодарят |
| Как относятся к failures? | Ищут виноватых | Пишут новые правила | Учатся |
| Как принимаются решения? | Политика | Процедуры | Data + discussion |
| Как относятся к новым идеям? | Подавляют | "Не в процессе" | Пробуют |

### 7.2 Netflix Culture Deep Dive

**Ключевые принципы Netflix Culture:**

| Principle | What It Means | Practice |
|-----------|---------------|----------|
| **Freedom & Responsibility** | Доверяем людям делать правильное | Нет approval процессов, minimal policies |
| **Context, not Control** | Лидеры дают context, не приказы | Объяснить "why", не "how" |
| **High Talent Density** | Только exceptional people | "Adequate performance = generous severance" |
| **Candor** | Радикальная честность | 360 feedback, прямой feedback |
| **Keeper Test** | "Would I fight to keep this person?" | Если нет → manage out |

**Netflix Practices:**

```
Unlimited PTO:           Нет лимита отпуска (но есть expectations)
No Expense Policy:       "Act in Netflix's best interest"
Information Sharing:     Вся информация открыта (почти)
Freedom in Comp:         Менеджеры определяют зарплаты
No Performance Reviews:  360 feedback вместо formal reviews
```

> **⚠️ Warning:**  
> Netflix culture работает для Netflix. Copy-paste не работает. Адаптируйте под свой context.

### 7.3 Spotify Model Deep Dive

**Структура Spotify:**

```
┌─────────────────────────────────────────────────────────────────┐
│                         TRIBE                                   │
│                    (100+ people, business area)                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                                                         │   │
│  │   SQUAD         SQUAD         SQUAD         SQUAD       │   │
│  │  (5-9 people)  (5-9 people)  (5-9 people)  (5-9 people) │   │
│  │                                                         │   │
│  └─────────────────────────────────────────────────────────┘   │
│                              │                                  │
│                              │                                  │
│            ┌─────────────────┼─────────────────┐               │
│            │                 │                 │               │
│        CHAPTER           CHAPTER           CHAPTER             │
│     (competency:       (competency:      (competency:          │
│      Backend)          Frontend)          QA)                  │
│                                                                │
│  ───────────────────────────────────────────────────────────── │
│                                                                │
│                         GUILDS                                  │
│              (Cross-tribe communities of interest)              │
│                                                                │
└─────────────────────────────────────────────────────────────────┘
```

**Элементы Spotify Model:**

| Element | Purpose | Size | Lead |
|---------|---------|------|------|
| **Squad** | Product team, autonomous | 5-9 | Product Owner |
| **Tribe** | Collection of related squads | 40-150 | Tribe Lead |
| **Chapter** | Functional expertise (Backend, QA) | Varies | Chapter Lead |
| **Guild** | Interest community (Security, UX) | Varies | Coordinator |

**Принципы Spotify:**

| Principle | Description |
|-----------|-------------|
| Autonomous Squads | Squads decide HOW to work |
| Alignment through Tribes | Shared mission coordinates |
| Expertise through Chapters | Functional growth path |
| Community through Guilds | Knowledge sharing across org |

> **⚠️ Warning:**  
> "Spotify Model" — это snapshot of 2012. Spotify сами давно эволюционировали. Используйте как inspiration, не blueprint.

### 7.4 Choosing Your Culture Model

**Факторы выбора:**

| Factor | Implications |
|--------|--------------|
| Company size | Small → informal, Large → need structure |
| Industry | Regulated → more process, Tech → more freedom |
| Company stage | Startup → speed, Scale-up → sustainability |
| Talent strategy | Elite → Netflix-like, Volume → more process |
| Risk tolerance | High → more freedom, Low → more controls |

**Не copy-paste:**

```
❌ "Netflix не делает performance reviews, мы тоже не будем"
   Problem: Нет high talent density, feedback не работает

✅ "Netflix верит в candor. Как мы можем усилить культуру feedback?"
   Approach: Adapt principle, not practice
```

## 8. Культура в распределённых командах

### 8.1 Challenges

```

Remote/distributed teams:

- Меньше casual interactions
- Culture spreads slower
- Сложнее читать signals
- Onboarding harder
- Subcultures в locations

```

### 8.2 Решения

**Intentional culture building:**
```

- Document values explicitly
- Regular video calls (cameras on!)
- Virtual social events
- Team offsites (если возможно)
- Consistent async communication norms

```

**Over-communication:**
```

- Больше context в messages
- Explicit expectations
- Written documentation
- Regular sync meetings

```

## 9. Toxic Culture

### 9.1 Признаки

```

🚨 Warning signs:

- Blame culture
- Information hoarding
- Political decisions
- Bullying / harassment
- Unrealistic expectations
- Burnout normalized
- High turnover

```

### 9.2 Как лидер

**Что можете сделать:**

- Create safe space в вашей команде
- Не participate в toxic behaviors
- Escalate serious issues
- Document и report

**Когда уходить:**

- Если не можете защитить команду
- Если values конфликтуют фундаментально
- Если burnout неизбежен

## 💡 Key Takeaways

- **Культура = behaviors:** Не слова на стене, а повседневные действия. Смотрите что происходит, не что написано

- **Schein's Model:** Три уровня — artifacts, espoused values, underlying assumptions. Изменения нужны на глубинном уровне

- **Psychological Safety #1:** Google Project Aristotle: главный фактор эффективности команды — важнее опыта и навыков

- **Создание Safety:** Set the stage → Invite participation → Respond productively. Строится месяцами, разрушается мгновенно

- **Lead by example:** Лидер моделирует культуру каждый день. "Делай как я делаю" должно работать

- **Culture Add > Fit:** Values alignment + diversity of perspective. Избегайте homogeneous teams

- **Westrum Typology:** Generative cultures (performance-oriented) коррелируют с высокой delivery performance

- **Не copy-paste:** Netflix/Spotify — inspiration, не blueprint. Адаптируйте под свой context

- **Change is slow:** Consistent effort over time. Kotter's 8 Steps для systematic change
