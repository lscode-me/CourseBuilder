## 1. Hiring как инвестиция

### 1.1 Стоимость найма

**Прямые costs:**

- Recruiter fees
- Job posting платформы
- Interview time команды
- Onboarding training

**Indirect costs плохого найма:**
```
Bad hire за $100K/год:

- 6 месяцев низкой productivity: $50K
- Team productivity loss: $30K
- Management time: $20K
- Potential cultural damage: ???
- Rehiring costs: $20K+

Total: $120K+ и месяцы потерянного времени
```

> **💡 Key Insight:**  
> Лучше оставить позицию открытой, чем нанять неподходящего человека.

### 1.2 Hiring Bar

**Принцип:**
```
Hire people who raise the average of your team,
not just fill a seat.
```

**Questions:**

- Этот человек сделает команду лучше?
- Я был бы рад работать с ним/ней?
- Он/она может научить нас чему-то?

## 2. Job Description

### 2.1 Структура JD

```markdown
## [Title] at [Company]

### About Us

[2-3 sentences about company and mission]

### About the Role

[What you'll do, why it matters]

### What You'll Work On

- [Responsibility 1]
- [Responsibility 2]
- [Responsibility 3]

### We're Looking For

- [Must-have skill 1]
- [Must-have skill 2]
- [Must-have skill 3]

### Nice to Have

- [Optional skill 1]
- [Optional skill 2]

### What We Offer

- [Benefit 1]
- [Benefit 2]
- [Benefit 3]

### Interview Process

[Describe steps]
```

### 2.2 Избегайте в JD

```
❌ Unrealistic requirements:
"10 years experience in technology that exists 5 years"

❌ Kitchen sink:
"Must know: Java, Python, Go, Rust, C++, JavaScript, 
TypeScript, Ruby, PHP, Scala..."

❌ Gendered language:
"Rockstar ninja developer"

❌ Vague descriptions:
"Work on exciting projects"

✅ Instead:
Realistic, specific, inclusive, honest
```

## 3. Sourcing кандидатов

### 3.1 Каналы

**Referrals:**

- Лучший источник (quality + cultural fit)
- Быстрее и дешевле
- Referral bonus program

**Job boards:**

- LinkedIn, Indeed, Glassdoor
- Specialized: AngelList, StackOverflow Jobs
- Local: HeadHunter, etc.

**Outbound:**

- LinkedIn recruiting
- GitHub / Open source
- Conferences / Meetups
- University programs

**Recruiter:**

- External agencies
- Internal recruiters
- Executive search (senior roles)

### 3.2 Diversity в sourcing

```
Problem:

- Referrals → similar people
- Same sources → same profiles

Solutions:

- Diverse sourcing channels
- Blind resume review
- Diverse interview panels
- Partner with diversity organizations
```

## 4. Interview Process

### 4.1 Типичные этапы

```
1. Recruiter Screen (30 min)
   - Basics: experience, motivation, logistics
   - Sell the role
   
2. Hiring Manager Screen (45-60 min)
   - Technical overview
   - Cultural fit initial assessment
   - Role expectations
   
3. Technical Interview(s) (1-3 rounds)
   - Coding
   - System design
   - Domain expertise
   
4. Team Fit / Culture (1 round)
   - Values alignment
   - Collaboration style
   - Cultural add
   
5. Final / Executive (если нужно)
   - Senior alignment
   - Offer discussion
```

### 4.2 Structured Interviews

**Почему structured:**

- Consistent across candidates
- Reduces bias
- Easier to compare
- Better predictions

**Как сделать structured:**
```
1. Define competencies to assess
2. Prepare questions for each
3. Use rubric for scoring
4. Same questions for all candidates
5. Multiple interviewers rate independently
```

### 4.3 Scorecard

**Example:**

| Competency | Questions | Score (1-4) | Notes |
|------------|-----------|-------------|-------|
| Technical skills | Q1, Q2 | _ | _ |
| Problem solving | Q3, Q4 | _ | _ |
| Communication | Throughout | _ | _ |
| Culture fit | Q5, Q6 | _ | _ |

**Scoring:**
```
1 - Does not meet expectations
2 - Partially meets
3 - Meets expectations
4 - Exceeds expectations
```

## 5. Technical Interviews

### 5.1 Coding Interview

**Формат:**

- Live coding (pair programming style)
- Take-home assignment + review
- Code review exercise

**Best practices:**
```
✅ Real-world problems (не algorithmic tricks)
✅ Allow internet/docs usage
✅ Focus on process, not just result
✅ Give hints when stuck
✅ Assess how they think, not just code

❌ Gotcha questions
❌ Obscure algorithms
❌ Whiteboard without computer
❌ Time pressure that creates anxiety
```

### 5.2 System Design

**Для senior+ позиций:**
```
- Open-ended problem
- Discuss trade-offs
- Scaling considerations
- Draw architecture
- Walk through flow
```

**Оценка:**

- Clarifying questions (requirements gathering)
- Breaking down problem
- Trade-off awareness
- Communication
- Depth in areas of expertise

### 5.3 Take-Home vs Live

**Take-Home:**
```
Плюсы:

- Меньше stress
- Realistic environment
- Can show best work

Минусы:

- Time investment (для кандидата)
- Can be "helped" by others
- Longer process
```

**Live Coding:**
```
Плюсы:

- See thought process
- Verify skills directly
- Faster decision

Минусы:

- Stress affects performance
- Not realistic environment
- Favors extroverts
```

## 6. Cultural / Behavioral Interviews

### 6.1 STAR Method

**Структура вопроса:**
```
"Tell me about a time when [situation]"

Кандидат отвечает по STAR:

- Situation: контекст
- Task: задача
- Action: что сделал
- Result: результат
```

### 6.2 Примеры вопросов

**Collaboration:**
```
"Tell me about a time you had a conflict with a teammate.
How did you handle it?"
```

**Initiative:**
```
"Tell me about a time you improved something 
without being asked."
```

**Failure:**
```
"Tell me about a time you failed. 
What did you learn?"
```

**Leadership:**
```
"Tell me about a time you influenced a decision 
without formal authority."
```

### 6.3 Bias в интервью

**Common biases:**
```
- Affinity bias: "Like me"
- Halo effect: One good thing → everything good
- Horn effect: One bad thing → everything bad
- Confirmation bias: Looking for evidence of first impression
- Recency bias: Remember last candidate better
```

**Mitigation:**
```
1. Structured interviews
2. Diverse panel
3. Independent scoring
4. Calibration sessions
5. Awareness training
```

## 7. Making the Decision

### 7.1 Debrief Process

```
1. All interviewers submit written feedback BEFORE meeting
2. Debrief meeting:
   - Each shares assessment
   - Discuss disagreements
   - No "I don't feel it" without specifics
3. Decision: Hire / No Hire / Need more data
```

### 7.2 Red Flags

```
🚨 Strong "No Hire" signals:

- Misrepresentation of experience
- Disrespectful to anyone
- Can't explain their own work
- Blame without ownership
- Strong resistance to feedback
```

### 7.3 Hire Decision

**Questions:**
```
1. Does this person meet the bar?
2. Will they be successful in THIS role?
3. Would I want to work with them?
4. Are there concerns I'm ignoring?
```

**When in doubt:**
```
Lean towards "no" for:

- Culture concerns
- Integrity concerns
- "Not sure" feeling from multiple interviewers

Consider "yes" for:

- Skills gap that's trainable
- Nervousness that affected performance
- Non-traditional background with potential
```

## 8. Onboarding

### 8.1 Goals of Onboarding

```
By end of Week 1:

- Has all access and tools
- Met immediate team
- Understands first tasks

By end of Month 1:

- Delivered first small contribution
- Understands team processes
- Building relationships

By end of Month 3:

- Fully productive
- Contributing independently
- Integrated into culture
```

### 8.2 Onboarding Checklist

```markdown
## Before Day 1

- [ ] Equipment ordered
- [ ] Accounts created
- [ ] Buddy assigned
- [ ] First week calendar set
- [ ] Team informed

## Day 1

- [ ] Welcome meeting with manager
- [ ] Tool setup
- [ ] Intro to buddy
- [ ] Org overview
- [ ] First task assigned

## Week 1

- [ ] Meet all teammates
- [ ] Read key documentation
- [ ] Attend team ceremonies
- [ ] Complete first small task
- [ ] Daily check-ins with buddy

## Month 1

- [ ] Complete onboarding docs
- [ ] First code shipped
- [ ] 1-on-1 with manager (weekly)
- [ ] Meet cross-functional partners
- [ ] 30-day feedback

## Month 3

- [ ] 90-day review
- [ ] Goals set for next quarter
- [ ] Fully integrated
```

### 8.3 Buddy Program

**Buddy responsibilities:**
```
- Daily check-ins (Week 1)
- Answer "dumb" questions
- Navigate culture and politics
- Social connection
- NOT performance evaluation
```

**Buddy selection:**

- Not the manager
- Similar level or slightly senior
- Good communicator
- Positive attitude

## 9. Retention Starts at Hiring

### 9.1 Setting Expectations

**During hiring:**
```
Be honest about:

- Real challenges
- Growth opportunities
- Team dynamics
- Company stage
```

**Why:**

- Right expectations = less disappointment
- Self-selection of fit
- Trust from day 1

### 9.2 First 90 Days

**Critical period:**

- 20% of turnover happens in first 45 days
- Experience shapes long-term engagement
- Early wins build confidence

**Manager's role:**

- Regular 1-on-1s (weekly)
- Clear feedback
- Celebrate small wins
- Address concerns quickly

---

## 💡 Key Takeaways

- **Hire to raise the bar:** Not just fill a seat

- **Structure reduces bias:** Consistent process, same questions

- **Technical + Cultural:** Both matter equally

- **Onboarding is investment:** First 90 days shape retention

- **When in doubt, don't:** Better to wait than hire wrong
