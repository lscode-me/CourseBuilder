## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | В bash используется синтаксис `if condition; then ... fi` |
| 2 | A | В [ ] используется `=` для сравнения строк, `==` работает в [[ ]] |
| 3 | B | Для числового сравнения используется `-eq` (equal) |
| 4 | B | `-f` проверяет, что файл существует и это обычный файл |
| 5 | C | [[ ]] не требует кавычек и поддерживает pattern matching |
| 6 | C | В [ ] нужно разделять условия: `[ cond1 ] && [ cond2 ]` |
| 7 | A | `elif` означает "else if" — альтернативное условие |
| 8 | B | `-d` проверяет, что путь существует и это директория |
| 9 | A | `=~` для regex, `==` для pattern matching в [[ ]] |
| 10 | B | Все три способа проверяют пустую строку |
