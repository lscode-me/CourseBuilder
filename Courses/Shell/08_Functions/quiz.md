# Функции - Quiz

## Question 1: Объявление функции

Как правильно объявить функцию?

A) `function my_func { ... }`
B) `my_func() { ... }`
C) `def my_func() { ... }`
D) A и B верны

## Answer Key

1. D - Оба способа объявления функций работают в bash

## Scoring Guide

9-10 правильных: Отлично
