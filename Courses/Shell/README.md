# Программирование в командной оболочке (Shell Scripting)

Курс по программированию в командной оболочке — от основ навигации до продвинутого shell scripting.

---

## 📖 Описание курса

Командная оболочка (shell) — один из ключевых интерфейсов взаимодействия с операционными системами Unix/Linux и macOS.

Shell‑программирование используется для:

- автоматизации задач
- администрирования систем
- обработки файлов и потоков данных
- сборки и деплоя
- glue‑кода между инструментами

Основной фокус курса — **bash** как наиболее распространённая оболочка. Также рассматриваются sh (POSIX), zsh, fish, dash.

Курс формирует инженерное понимание shell, а не просто набор команд.

---

## 🎯 Цели курса

После прохождения курса слушатель:

- уверенно работает в командной строке
- понимает философию Unix
- пишет надёжные bash‑скрипты
- понимает различия между shell‑оболочками
- умеет читать и поддерживать shell‑код
- понимает ограничения shell
