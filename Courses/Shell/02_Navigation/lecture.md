## 1. Текущая директория и команда pwd

Прежде чем начать навигацию, важно понимать, где вы находитесь в файловой системе.

### 1.1 Что такое текущая рабочая директория

**Текущая рабочая директория** (current working directory) — это директория, в которой вы сейчас находитесь. Все команды, которые вы выполняете, работают относительно этой директории, если не указан полный путь.

**Example: Проверка текущей директории**

```bash
$ pwd
```

**Output:**
```
/home/user
```

Команда `pwd` (print working directory) показывает полный путь к текущей директории. Это абсолютный путь, начинающийся с корня файловой системы (`/`).

### 1.2 Зачем нужно знать текущую директорию

Понимание текущей директории важно, потому что:

- Многие команды работают с файлами относительно текущей директории
- Относительные пути зависят от текущей позиции
- Ошибки в путях часто возникают из-за непонимания текущей директории

**Example: Работа с относительными путями**

```bash
# Текущая директория
$ pwd
/home/user

# Создать файл в текущей директории
$ touch myfile.txt

# Файл создан в /home/user/myfile.txt
```

Если бы вы не знали текущую директорию, вы могли бы подумать, что файл создан где-то ещё.

## 2. Команда cd — изменение директории

Команда `cd` (change directory) позволяет перемещаться по файловой системе.

### 2.1 Базовое использование cd

**Example: Переход в другую директорию**

```bash
# Перейти в директорию /etc
$ cd /etc

# Проверить текущую директорию
$ pwd
```

**Output:**
```
/etc
```

После выполнения `cd /etc` текущая директория изменилась на `/etc`.

**Example: Переход в поддиректорию**

```bash
# Если вы в /home/user
$ cd Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

Здесь использован относительный путь. Shell интерпретирует `Documents` как поддиректорию текущей директории.

### 2.2 Домашний каталог

**Домашний каталог** — это личная директория пользователя, обычно расположенная в `/home/username` (Linux) или `/Users/username` (macOS).

**Example: Переход в домашний каталог**

```bash
# Три способа перейти в домашний каталог
$ cd ~
$ cd
$ cd $HOME

# Все три команды делают одно и то же
$ pwd
```

**Output:**
```
/home/user
```

Символ `~` (тильда) — это сокращение для домашнего каталога. Команда `cd` без аргументов также переводит в домашний каталог.

### 2.3 Специальные символы для навигации

Shell предоставляет несколько специальных символов для удобной навигации:

- `~` — домашний каталог пользователя
- `.` — текущая директория
- `..` — родительская директория (на уровень выше)
- `-` — предыдущая директория

**Example: Использование специальных символов**

```bash
# Текущая директория
$ pwd
/home/user/Documents

# Перейти на уровень выше
$ cd ..
$ pwd
```

**Output:**
```
/home/user
```

```bash
# Вернуться в предыдущую директорию
$ cd /etc
$ cd -
$ pwd
```

**Output:**
```
/home/user
```

Команда `cd -` возвращает вас в директорию, где вы были до последнего перехода.

**Example: Комбинации с ..**

```bash
# Подняться на два уровня выше
$ cd ../..

# Перейти в соседнюю директорию
$ cd ../Downloads

# Вернуться в текущую директорию (ничего не делает, но показывает концепцию)
$ cd .
```

### 2.4 Абсолютные и относительные пути

**Абсолютный путь** начинается с `/` и указывает полный путь от корня файловой системы.

**Относительный путь** указывает путь относительно текущей директории.

**Example: Абсолютные пути**

```bash
# Абсолютный путь — всегда начинается с /
$ cd /home/user/Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

Абсолютный путь работает одинаково из любой директории.

**Example: Относительные пути**

```bash
# Если вы в /home/user
$ cd Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

```bash
# Если вы в /home
$ cd user/Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

Относительный путь зависит от того, где вы находитесь.

> **💡 Pro Tip:**  
> Используйте абсолютные пути в скриптах для надёжности. Относительные пути удобны для интерактивной работы.

## 3. Команда ls — просмотр содержимого директории

Команда `ls` (list) показывает содержимое директории.

### 3.1 Базовое использование ls

**Example: Простой список файлов**

```bash
$ ls
```

**Output:**
```
Documents  Downloads  Pictures  Videos
```

По умолчанию `ls` показывает только видимые файлы и директории в простом формате.

**Example: Подробный формат**

```bash
$ ls -l
```

**Output:**
```
total 16
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Documents
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Downloads
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Pictures
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Videos
```

Опция `-l` (long format) показывает подробную информацию:

- Права доступа (первая колонка)
- Количество ссылок
- Владелец
- Группа
- Размер
- Дата и время модификации
- Имя файла/директории

### 3.2 Просмотр скрытых файлов

**Скрытые файлы** в Unix-подобных системах — это файлы, имена которых начинаются с точки (`.`). Они не отображаются по умолчанию.

**Example: Показать скрытые файлы**

```bash
$ ls -a
```

**Output:**
```
.  ..  .bashrc  .bash_history  .profile  Documents  Downloads
```

Опция `-a` (all) показывает все файлы, включая скрытые. Обратите внимание на файлы, начинающиеся с точки: `.bashrc`, `.bash_history`, `.profile`.

**Example: Комбинация опций**

```bash
$ ls -la
```

**Output:**
```
total 48
drwxr-xr-x 5 user user 4096 Jan 15 10:00 .
drwxr-xr-x 3 root root 4096 Jan  1 00:00 ..
-rw-r--r-- 1 user user 220 Jan 15 09:00 .bashrc
-rw------- 1 user user 1000 Jan 15 09:30 .bash_history
-rw-r--r-- 1 user user 807 Jan 15 09:00 .profile
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Documents
...
```

Комбинация `-la` показывает все файлы в подробном формате.

### 3.3 Полезные опции ls

**Example: Человекочитаемые размеры**

```bash
$ ls -lh
```

**Output:**
```
total 16K
drwxr-xr-x 2 user user 4.0K Jan 15 10:00 Documents
drwxr-xr-x 2 user user 4.0K Jan 15 10:00 Downloads
-rw-r--r-- 1 user user 1.2M Jan 15 10:00 largefile.txt
```

Опция `-h` (human-readable) показывает размеры в удобном формате (K, M, G вместо байтов).

**Example: Сортировка по времени**

```bash
$ ls -lt
```

**Output:**
```
total 16
drwxr-xr-x 2 user user 4096 Jan 15 11:00 Newest
drwxr-xr-x 2 user user 4096 Jan 15 10:30 Middle
drwxr-xr-x 2 user user 4096 Jan 15 10:00 Oldest
```

Опция `-t` сортирует файлы по времени модификации (новые первыми).

**Example: Рекурсивный просмотр**

```bash
$ ls -R
```

**Output:**
```
.:
Documents  Downloads

./Documents:
file1.txt  file2.txt

./Downloads:
archive.zip
```

Опция `-R` (recursive) показывает содержимое всех поддиректорий рекурсивно.

**Example: Цветной вывод**

```bash
$ ls --color=auto
```

Многие системы по умолчанию используют цветной вывод, где директории, исполняемые файлы и другие типы файлов отображаются разными цветами.

### 3.4 Фильтрация вывода ls

**Example: Показать только директории**

```bash
$ ls -d */
```

**Output:**
```
Documents/  Downloads/  Pictures/  Videos/
```

**Example: Показать только файлы определённого типа**

```bash
$ ls *.txt
```

**Output:**
```
file1.txt  file2.txt  report.txt
```

Здесь используется glob-шаблон `*.txt`, который будет подробно рассмотрен в следующем модуле.

## 4. Пути в файловой системе

Понимание путей критично для эффективной работы в shell.

### 4.1 Структура абсолютного пути

Абсолютный путь в Unix-подобных системах начинается с `/` (корень файловой системы) и описывает полный путь к файлу или директории.

**Example: Структура пути**

```bash
/home/user/Documents/file.txt
```

Этот путь можно разбить на части:

- `/` — корень файловой системы
- `home` — директория в корне
- `user` — поддиректория в `home`
- `Documents` — поддиректория в `user`
- `file.txt` — файл в `Documents`

**Example: Навигация по абсолютному пути**

```bash
$ cd /usr/local/bin
$ pwd
```

**Output:**
```
/usr/local/bin
```

Абсолютный путь работает из любой директории.

### 4.2 Относительные пути

Относительный путь указывает местоположение относительно текущей директории.

**Example: Различные относительные пути**

```bash
# Текущая директория: /home/user
$ pwd
/home/user

# Перейти в поддиректорию
$ cd Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

```bash
# Вернуться в /home/user
$ cd /home/user

# Перейти в соседнюю директорию
$ cd ../Downloads
$ pwd
```

**Output:**
```
/home/user/Downloads
```

Здесь `../Downloads` означает "подняться на уровень выше (в `/home`), затем перейти в `Downloads`".

### 4.3 Специальные директории в пути

**Example: Использование . и ..**

```bash
# Текущая директория: /home/user/Documents
$ pwd
/home/user/Documents

# Перейти в текущую директорию (ничего не изменится)
$ cd .
$ pwd
```

**Output:**
```
/home/user/Documents
```

```bash
# Перейти в родительскую директорию
$ cd ..
$ pwd
```

**Output:**
```
/home/user
```

```bash
# Комбинированные пути
$ cd ../Downloads/../Documents
$ pwd
```

**Output:**
```
/home/user/Documents
```

### 4.4 Работа с пробелами в путях

Если в имени файла или директории есть пробелы, нужно использовать кавычки или экранирование.

**Example: Пути с пробелами**

```bash
# Создать директорию с пробелом в имени
$ mkdir "My Documents"

# Перейти в неё (с кавычками)
$ cd "My Documents"
$ pwd
```

**Output:**
```
/home/user/My Documents
```

```bash
# Альтернатива: экранирование пробела
$ cd My\ Documents
$ pwd
```

**Output:**
```
/home/user/My Documents
```

Обратный слэш `\` экранирует следующий символ, делая пробел частью имени, а не разделителем.

> **⚠️ Warning:**  
> Всегда используйте кавычки или экранирование для путей с пробелами. Без этого shell интерпретирует пробел как разделитель аргументов.

## 5. Домашний каталог

Домашний каталог — это личная директория пользователя, где хранятся личные файлы и настройки.

### 5.1 Расположение домашнего каталога

**Example: Путь к домашнему каталогу**

```bash
# В Linux обычно

$ echo $HOME
```

**Output:**
```
/home/username
```

```bash
# В macOS обычно

$ echo $HOME
```

**Output:**
```
/Users/username
```

Переменная окружения `$HOME` содержит путь к домашнему каталогу.

### 5.2 Символ тильды (~)

Символ `~` является сокращением для домашнего каталога.

**Example: Использование тильды**

```bash
# Перейти в домашний каталог
$ cd ~
$ pwd
```

**Output:**
```
/home/user
```

```bash
# Использовать тильду в путях

$ ls ~/Documents
```

**Output:**
```
file1.txt  file2.txt
```

```bash
# Комбинировать тильду с другими путями
$ cd ~/Documents/Projects
$ pwd
```

**Output:**
```
/home/user/Documents/Projects
```

### 5.3 Домашний каталог другого пользователя

**Example: Домашний каталог другого пользователя**

```bash
# Домашний каталог текущего пользователя
$ echo ~
/home/user

# Домашний каталог другого пользователя
$ echo ~otheruser
/home/otheruser
```

Синтаксис `~username` позволяет обращаться к домашнему каталогу указанного пользователя.

## 6. Скрытые файлы

Скрытые файлы — важная часть Unix-подобных систем, используемая для хранения конфигурационных файлов.

### 6.1 Что такое скрытые файлы

Файлы и директории, имена которых начинаются с точки (`.`), считаются скрытыми и не отображаются командами `ls` по умолчанию.

**Example: Просмотр скрытых файлов**

```bash
# Обычный список (скрытые файлы не видны)
$ ls
Documents  Downloads  Pictures
```

```bash
# Со скрытыми файлами
$ ls -a
.  ..  .bashrc  .bash_history  .profile  Documents  Downloads
```

Обратите внимание на файлы, начинающиеся с точки: `.bashrc`, `.bash_history`, `.profile`.

### 6.2 Зачем нужны скрытые файлы

Скрытые файлы обычно используются для:

- **Конфигурационных файлов**: Настройки приложений и оболочки

- **Истории команд**: Сохранение истории команд shell

- **Временных файлов**: Файлы, создаваемые программами

- **Личных настроек**: Персональные настройки пользователя

**Example: Типичные скрытые файлы**

```bash
$ ls -la ~ | grep "^\."
```

**Output:**
```
drwxr-xr-x 5 user user 4096 Jan 15 10:00 .
drwxr-xr-x 3 root root 4096 Jan  1 00:00 ..
-rw-r--r-- 1 user user 220 Jan 15 09:00 .bashrc
-rw------- 1 user user 1000 Jan 15 09:30 .bash_history
-rw-r--r-- 1 user user 807 Jan 15 09:00 .profile
-rw-r--r-- 1 user user  25 Jan 15 09:00 .gitconfig
```

- `.bashrc` — конфигурация bash для интерактивных сессий
- `.bash_history` — история выполненных команд
- `.profile` — настройки окружения
- `.gitconfig` — настройки Git

### 6.3 Специальные записи . и ..

В каждой директории есть две специальные записи:

- `.` — ссылка на саму директорию
- `..` — ссылка на родительскую директорию

**Example: Использование . и ..**

```bash
# . означает текущую директорию
$ ls .
Documents  Downloads

# .. означает родительскую директорию

$ ls ..
user  otheruser
```

Эти записи существуют в каждой директории и используются для навигации.

## 7. Эффективная навигация

Несколько техник для более эффективной работы с файловой системой.

### 7.1 Автодополнение (Tab completion)

Автодополнение — одна из самых полезных функций shell. Нажмите `Tab` для автодополнения путей.

**Example: Использование Tab**

```bash
# Начните вводить путь и нажмите Tab
$ cd /usr/l<Tab>
# Shell дополнит до /usr/local/

$ cd Doc<Tab>
# Если есть только одна директория, начинающаяся с Doc, она дополнится
```

Если есть несколько вариантов, нажмите `Tab` дважды, чтобы увидеть все варианты.

### 7.2 История команд и навигация

**Example: Использование истории для повторения команд**

```bash
# Выполнить последнюю команду cd
$ !cd

# Или использовать стрелки для поиска в истории
# Стрелка вверх — предыдущая команда
# Стрелка вниз — следующая команда
```

### 7.3 Pushd и Popd (альтернатива cd)

Некоторые системы поддерживают `pushd` и `popd` для работы со стеком директорий.

**Example: Pushd и Popd**

```bash
# Перейти в директорию и запомнить предыдущую
$ pushd /etc
/etc ~

# Перейти в другую директорию
$ pushd /var
/var /etc ~

# Вернуться к предыдущей (popd убирает из стека)

$ popd
/etc ~
```

Эти команды будут подробнее рассмотрены в модуле о встроенных командах.

### 7.4 Быстрая навигация с алиасами

**Example: Создание алиасов для частых переходов**

```bash
# Создать алиас для перехода в часто используемую директорию
$ alias proj='cd ~/Documents/Projects'

# Теперь можно просто написать

$ proj
$ pwd
```

**Output:**
```
/home/user/Documents/Projects
```

## 8. Практические примеры навигации

Рассмотрим несколько реальных сценариев использования.

### 8.1 Example: Поиск и переход к файлу

```bash
# Найти файл в системе
$ find /home -name "important.txt" 2>/dev/null
/home/user/Documents/important.txt

# Перейти в директорию с файлом

$ cd /home/user/Documents
$ ls important.txt
```

### 8.2 Example: Навигация по проекту

```bash
# Структура проекта
$ cd ~/Projects/myproject
$ ls -R
.:
src  tests  docs  README.md

./src:
main.py  utils.py

./tests:
test_main.py

# Переход между директориями проекта
$ cd src
$ pwd
/home/user/Projects/myproject/src

$ cd ../tests
$ pwd
/home/user/Projects/myproject/tests
```

### 8.3 Example: Работа с несколькими директориями

```bash
# Запомнить текущую директорию
$ CURRENT_DIR=$(pwd)
$ echo $CURRENT_DIR
/home/user/Documents

# Перейти в другую директорию, выполнить действия
$ cd /tmp
$ ls

# Вернуться обратно

$ cd "$CURRENT_DIR"
$ pwd
```

**Output:**
```
/home/user/Documents
```

## 💡 Key Takeaways

- **pwd** показывает текущую рабочую директорию, что важно для понимания контекста выполнения команд

- **cd** позволяет перемещаться по файловой системе, поддерживает абсолютные и относительные пути, а также специальные символы (`~`, `.`, `..`, `-`)

- **ls** отображает содержимое директорий с различными опциями для форматирования и фильтрации вывода

- **Абсолютные пути** начинаются с `/` и работают из любой директории, **относительные пути** зависят от текущей позиции

- **Скрытые файлы** (начинающиеся с `.`) используются для конфигурации и не отображаются по умолчанию, но доступны с опцией `-a`
