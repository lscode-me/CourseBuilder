## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | `pwd` (print working directory) показывает полный путь к текущей рабочей директории |
| 2 | B | `~` (тильда) является сокращением для домашнего каталога, также работает просто `cd` |
| 3 | B | `..` означает родительскую директорию, из `/home/user/Documents` это будет `/home/user` |
| 4 | A | Опция `-a` (all) показывает все файлы, включая скрытые (начинающиеся с точки) |
| 5 | B | Абсолютный путь начинается с `/` и указывает полный путь от корня файловой системы |
| 6 | A | Символ `~` означает домашний каталог текущего пользователя |
| 7 | A | `cd -` возвращает в предыдущую директорию (ту, где вы были до последнего `cd`) |
| 8 | B | Буква 'd' в начале строки `ls -l` означает, что это директория (directory) |
| 9 | B | Для путей с пробелами нужно использовать кавычки `"My Documents"` или экранирование `My\ Documents` |
| 10 | C | Опция `-h` (human-readable) показывает размеры в удобном формате (K, M, G) |
| 11 | B | `..` означает родительскую директорию (на уровень выше) |
| 12 | B | Опция `-t` сортирует файлы по времени модификации, новые первыми |
| 13 | C | Опция `-R` (recursive) показывает содержимое всех поддиректорий рекурсивно |
| 14 | A | Относительный путь `Documents/Projects` из `/home/user` ведёт в `/home/user/Documents/Projects` |
| 15 | B | Путь `../Downloads/../Documents` эквивалентен просто `Documents` (поднялись, спустились, поднялись, спустились) |
| 16 | B | `ls -la` показывает все файлы (включая скрытые) в подробном формате |
| 17 | A | Можно использовать `~john` или абсолютный путь `/home/john` |
| 18 | C | Двойное нажатие Tab показывает все возможные варианты автодополнения |
| 19 | B | `.` — ссылка на текущую директорию, `..` — ссылка на родительскую директорию |
| 20 | C | Glob-шаблон `*.txt` показывает все файлы с расширением `.txt` |
| 21 | C | `/` — это корень файловой системы, абсолютный путь всегда начинается с `/` |
| 22 | B | Опция `--color` включает цветной вывод (или `--color=auto` для автоматического) |
| 23 | B | Из `/home/user/Documents/Projects` нужно 3 раза выполнить `cd ..`: Projects→Documents→user→home |
| 24 | C | `ls -lah` комбинирует `-l` (подробный), `-a` (все файлы), `-h` (человекочитаемые размеры) |
| 25 | C | Пробел экранируется обратным слэшем: `My\ Documents` (или используйте кавычки) |
