# Работа с текстом - Quiz

## Question 1: grep

Что делает `grep -i "error" log.txt`?

A) Ищет "error" с учётом регистра
B) Ищет "error" без учёта регистра
C) Исключает строки с "error"
D) Заменяет "error"

## Answer Key

1. B - Опция -i игнорирует регистр при поиске
