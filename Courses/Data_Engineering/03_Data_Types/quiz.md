## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Structured данные имеют строгую, заранее определённую схему, в отличие от semi-structured (гибкая) и unstructured (нет схемы). |
| 4 | A | Operational данные используются для поддержки текущих операций и обновляются в real-time или near real-time. |
| 5 | A | OLTP системы оптимизированы для быстрых транзакций и операций записи/чтения отдельных записей. |
| 6 | D | OLAP системы используют columnar storage и денормализованную структуру для оптимизации аналитических запросов. |
| 7 | C | ~70% данных в мире являются unstructured (текст, медиа, логи), что делает их обработку важной задачей. |
| 8 | A | SQL запросы используются для structured данных в реляционных базах данных. |
| 9 | C | Semi-structured данные имеют гибкую схему, встроенную в сами данные, что обеспечивает легкость расширения. |
| 10 | A | NLP (Natural Language Processing) используется для обработки unstructured текстовых данных, извлечения информации и анализа. |

## Scoring Guide

Подсчитайте количество правильных ответов:

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **9-10 правильных (90-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
| **7-8 правильных (70-89%)** | ✅ Хорошо | Хороший результат! Повторите темы, в которых ошиблись. |
| **5-6 правильных (50-69%)** | ⚠️ Удовлетворительно | Рекомендуется перечитать соответствующие разделы лекции. |
| **Менее 5 правильных (<50%)** | 📚 Нужно повторить | Внимательно перечитайте лекцию и попробуйте ещё раз. |
