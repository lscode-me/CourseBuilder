## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Все перечисленные этапы (Ingestion, Storage, Processing, Serving, Consumption) входят в жизненный цикл данных. |

| 3 | B | Batch ingestion используется, когда можно обрабатывать данные порциями по расписанию, а не в реальном времени. |
| 4 | C | Streaming ingestion обеспечивает низкую задержку обработки, обрабатывая данные по мере поступления. |
| 5 | B | OLAP хранилища оптимизированы для аналитических запросов и агрегаций, в отличие от OLTP для транзакций. |
| 6 | A | Bronze Layer содержит сырые данные без обработки, как они поступили из источников. |
| 7 | A | Silver Layer содержит очищенные и валидированные данные, готовые для анализа. |
| 8 | D | Создание источников данных не является частью processing. Processing включает трансформацию, очистку, обогащение. |
| 9 | A | Обогащение данных означает добавление дополнительной информации к существующим данным (например, вычисляемые поля, справочники). |
| 10 | C | Все перечисленные методы (REST API, прямой доступ к БД, экспорт в файлы) используются для serving данных. |
| 11 | B | Кеширование используется для ускорения доступа к часто запрашиваемым данным, уменьшая нагрузку на основное хранилище. |
| 12 | D | Потребителями данных могут быть аналитики, data scientists, приложения и другие системы, которым нужны данные. |
| 13 | A | Правильный порядок: Ingestion → Storage → Processing → Serving → Consumption. |
| 14 | D | Gold Layer содержит агрегированные данные и бизнес-метрики, оптимизированные для потребления. |
| 15 | A | Airflow используется для оркестрации batch ingestion jobs, позволяя планировать и мониторить выполнение. |

| 18 | A | Агрегация данных означает группировку данных и вычисление метрик (суммы, средние, количества). |
| 19 | C | Все методы (кеширование, индексы, партиционирование) используются для оптимизации serving данных. |
| 20 | D | Data Lake — это хранилище сырых данных в различных форматах, в отличие от структурированных хранилищ. |
| 21 | C | Трансформация данных включает изменение структуры, нормализацию форматов и объединение данных из разных источников. |
| 22 | C | Все операции (удаление дубликатов, обработка NULL, валидация) входят в очистку данных. |
| 23 | A | REST API является распространённым источником данных, особенно для интеграции с внешними сервисами. |
| 24 | A | Все перечисленные (Kafka, WebSockets, Event streams) являются потоковыми источниками данных. |

## Scoring Guide

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **27-30 правильных (90-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
