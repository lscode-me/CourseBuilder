## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 3 | A | CSV — это текстовый формат без схемы, простой и читаемый, но без сжатия. |
| 4 | B | JSON используется для API responses и semi-structured данных благодаря гибкой схеме. |
| 5 | C | Avro использует schema-on-write и обеспечивает хорошее сжатие благодаря бинарному формату. |
| 6 | A | Parquet оптимизирован для аналитических запросов и агрегаций благодаря columnar storage. |
| 7 | A | ORC обычно используется в Hadoop экосистеме и для Hive таблиц. |
| 8 | B | Row-based форматы обеспечивают быстрое чтение полных записей, но медленные агрегации. |
| 9 | A | Column-based форматы обеспечивают быстрые агрегации (читаем только нужные колонки) и отличное сжатие. |
| 10 | C | Parquet, Avro и ORC используют schema-on-write, где схема применяется при записи. |
| 11 | C | CSV и Data Lakes используют schema-on-read, где схема применяется при чтении. |
| 13 | A | Parquet — лучший выбор для аналитики благодаря columnar storage и отличному сжатию. |
| 14 | B | Avro — лучший выбор для streaming данных благодаря schema-on-write и поддержке schema evolution. |
| 15 | A | Parquet обычно даёт наименьший размер благодаря columnar storage и эффективному сжатию. |

## Scoring Guide

Подсчитайте количество правильных ответов:

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **14-15 правильных (93-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
