## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Data Engineering создаёт инфраструктуру данных (pipelines, хранилища), а Data Science использует эти данные для извлечения инсайтов и создания моделей. |
| 2 | D | Создание ML моделей — это задача Data Scientist, а не Data Engineer. Data Engineer создаёт инфраструктуру для данных, которые использует Data Scientist. |
| 3 | C | Streaming Processing System обрабатывает данные в реальном времени по мере их поступления, в отличие от Batch Processing, который обрабатывает данные порциями. |
| 4 | A | OLAP системы оптимизированы для аналитических запросов и агрегаций, в то время как OLTP оптимизированы для транзакций. |
| 5 | C | Концепция "данные как продукт" означает, что данные должны иметь документацию, SLA, пользователей и рассматриваться как полноценный продукт. |
| 6 | A | Data Engineer может работать с различными источниками данных: базами данных, API, файлами, очередями сообщений и другими. |
| 7 | A | Batch processing jobs обычно запускаются по расписанию (например, раз в день, час) для обработки накопленных данных. |
| 8 | B | Data Engineer предоставляет подготовленные и очищенные данные для Data Scientist, который использует их для создания моделей. |
| 9 | D | Upsert (update + insert) обновляет существующие записи и вставляет новые, в отличие от full load (полная загрузка) или incremental load (только новые). |
| 10 | C | Distributed systems позволяют горизонтальное масштабирование (добавление узлов), что важно для обработки больших объёмов данных. |
| 11 | D | Все перечисленные операции (удаление дубликатов, нормализация, обогащение) являются типичными трансформациями данных. |
| 12 | C | Spark используется для обработки больших объёмов данных в batch режиме, в то время как Pandas подходит для меньших объёмов. |
| 13 | A | Data Warehouse — это хранилище данных, оптимизированное для аналитических запросов и отчётов, в отличие от OLTP баз данных. |
| 14 | A | Junior Data Engineer должен знать Python, SQL и базовые инструменты (Pandas, PostgreSQL), а не системный дизайн или управление командой. |
| 15 | B | Data Engineer должен исправить проблему и перезапустить job, чтобы обеспечить актуальность данных. |
| 16 | B | ETL (Extract-Transform-Load) трансформирует данные перед загрузкой, а ELT (Extract-Load-Transform) загружает сырые данные и трансформирует их в хранилище. |
| 17 | D | Data Lake — это хранилище сырых данных в их нативном формате, в отличие от Data Warehouse, где данные структурированы. |
| 18 | D | Все аспекты (точность, полнота, свежесть) важны для обеспечения качества данных. |
| 19 | D | Streaming processing используется, когда нужна обработка в реальном времени с низкой задержкой, например, для fraud detection или real-time dashboards. |
| 20 | C | Data Engineer является мостом между источниками данных и их потребителями (аналитиками, data scientists, бизнес-пользователями). |
| 21 | C | Нормализация данных означает приведение данных к единому формату, структуре и стандартам для обеспечения консистентности. |
| 22 | B | Incremental load загружает только новые или изменённые данные, что более эффективно, чем полная загрузка всех данных каждый раз. |
| 23 | C | Data Catalog — это реестр метаданных о данных, включающий схемы, источники, lineage и другую информацию для discovery данных. |
| 24 | D | Horizontal scaling (горизонтальное масштабирование) позволяет добавлять больше серверов, в отличие от vertical scaling (увеличение мощности одного сервера). |
| 25 | B | SLA (Service Level Agreement) — это соглашение об уровне обслуживания, которое определяет доступность, свежесть и другие характеристики данных как продукта. |
| 26 | A | Обогащение данных означает добавление дополнительной информации к существующим данным, например, вычисляемых полей или данных из других источников. |
| 27 | B | Партиционирование используется для улучшения производительности запросов (запросы обрабатывают только нужные партиции) и управления данными. |
| 28 | B | Data pipeline — это последовательность шагов (сбор, трансформация, загрузка) для обработки данных от источников до потребителей. |
| 29 | C | Идемпотентность означает, что повторное выполнение pipeline даёт тот же результат, что важно для надёжности и возможности перезапуска. |
| 30 | B | Modern Data Stack включает современные инструменты для всех этапов работы с данными: сбор (Fivetran), хранение (Snowflake), обработка (dbt), анализ (Looker). |

| Результат | Оценка | Рекомендации |
