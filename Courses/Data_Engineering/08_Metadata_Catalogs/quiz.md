## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Метаданные — это данные о данных: структура (schema), происхождение (lineage), качество, использование. |
| 2 | A | Schema определяет структуру данных: какие поля есть, их типы, ограничения и правила. |
| 3 | C | Explicit schema используется в SQL таблицах, Avro, Parquet, где схема определена заранее и валидируется при записи. |
| 4 | A | Backward compatible изменение означает, что старый код может читать новые данные (например, добавление optional поля). |
| 5 | C | Data Catalog — это централизованный реестр метаданных о данных в организации, включающий схемы, описания, lineage. |
| 6 | A | Все компоненты (метаданные, lineage, quality метрики) входят в Data Catalog для полного понимания данных. |
| 7 | C | Lineage отслеживает происхождение данных: откуда пришли, какие трансформации прошли, куда используются. |
| 8 | D | Upstream lineage показывает откуда пришли данные и предыдущие трансформации (источники данных). |
| 9 | B | Downstream lineage показывает куда используются данные и зависимые таблицы (потребители данных). |
| 10 | C | Data Discovery — это процесс поиска и понимания доступных данных через метаданные, теги, описания. |
| 11 | C | Lineage используется для impact analysis (что сломается), debugging (отслеживание проблем) и документации. |
| 12 | B | Best practices включают документацию, автоматическое отслеживание lineage, тегирование данных и governance. |
| 13 | D | Data Catalog обеспечивает discovery данных, governance и контроль доступа, collaboration и общие знания. |
| 14 | C | Все типы изменений (backward compatible, forward compatible, breaking changes) существуют в schema evolution. |
| 15 | D | Автоматизация обеспечивает актуальность и полноту метаданных, что критично для больших систем с множеством таблиц. |

## Scoring Guide

Подсчитайте количество правильных ответов:

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **14-15 правильных (93-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
| **11-13 правильных (73-87%)** | ✅ Хорошо | Хороший результат! Повторите темы, в которых ошиблись. |
| **8-10 правильных (53-67%)** | ⚠️ Удовлетворительно | Рекомендуется перечитать соответствующие разделы лекции. |
| **Менее 8 правильных (<53%)** | 📚 Нужно повторить | Внимательно перечитайте лекцию и попробуйте ещё раз. |
