## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | SOCK_STREAM использует TCP |
| 2 | A | bind() привязывает сокет к локальному адресу |
| 3 | B | Параметр listen() — размер backlog очереди |
| 4 | B | accept() возвращает (socket, address) |
| 5 | B | sendall() повторяет send() до отправки всех данных |
| 6 | D | SO_REUSEADDR позволяет bind() сразу после закрытия |
| 7 | C | UDP не требует connect(), но можно использовать |
| 8 | D | recvfrom() возвращает (data, address) |
| 9 | D | getaddrinfo() — универсальное разрешение (IPv4/6, DNS) |
| 10 | C | timeout возникает при истечении времени ожидания |
| 11 | D | SHUT_WR прекращает отправку (half-close) |
| 12 | B | TCP_NODELAY отключает Nagle для низкой задержки |
| 13 | A | AF_INET для IPv4, AF_INET6 для IPv6 |
| 14 | A | Порты 0-1023 (privileged ports) требуют root |
| 15 | B | BrokenPipeError — запись в закрытое соединение |
