## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | os.stat() возвращает stat_result с метаданными: size, mode, uid, gid, times |
| 2 | B | stat.S_ISDIR(mode) проверяет, является ли mode директорией |
| 3 | C | lstat не следует за symlinks, возвращает stat самой ссылки |
| 4 | D | S_IRUSR — read permission for user (owner) |
| 5 | D | rw-r--r-- = 110 100 100 = 644 в восьмеричной |
| 6 | C | Жёсткие ссылки указывают на один inode |
| 7 | C | os.readlink() возвращает путь, на который указывает ссылка |
| 8 | C | os.F_OK проверяет существование файла |
| 9 | C | os.walk() — генератор, выдающий (root, dirs, files) |
| 10 | D | Path.name возвращает имя файла (последний компонент) |
| 11 | B | 0666 & ~022 = 0644 (umask убирает биты) |
| 12 | D | os.replace() атомарно заменяет существующий файл |
| 13 | B | st_nlink — количество жёстких ссылок на inode |
| 14 | B | inode — структура данных файловой системы с метаданными |
| 15 | D | scandir возвращает DirEntry с кэшированными stat данными |
| 16 | C | st_nlink — количество жёстких ссылок на inode |
| 17 | B | rename() атомарно перемещает/переименовывает файл |
| 18 | A | remove() и unlink() — это одна функция (алиасы) |
| 19 | D | makedirs() создаёт все промежуточные директории рекурсивно |
| 20 | D | st_mtime — время последней модификации содержимого файла |
