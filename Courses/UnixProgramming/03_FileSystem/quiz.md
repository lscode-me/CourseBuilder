## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | os.stat() возвращает stat_result с метаданными: size, mode, uid, gid, times |
| 2 | D | stat.S_ISDIR(mode) проверяет, является ли mode директорией |
| 3 | B | lstat не следует за symlinks, возвращает stat самой ссылки |
| 4 | D | S_IRUSR — read permission for user (owner) |
| 5 | B | rw-r--r-- = 110 100 100 = 644 в восьмеричной |
| 6 | A | Жёсткие ссылки указывают на один inode |
| 7 | C | os.readlink() возвращает путь, на который указывает ссылка |
| 8 | C | os.F_OK проверяет существование файла |
| 9 | C | os.walk() — генератор, выдающий (root, dirs, files) |
| 10 | D | Path.name возвращает имя файла (последний компонент) |
| 11 | D | 0666 & ~022 = 0644 (umask убирает биты) |
| 12 | C | os.replace() атомарно заменяет существующий файл |
| 13 | C | st_nlink — количество жёстких ссылок на inode |
| 14 | B | inode — структура данных файловой системы с метаданными |
| 15 | A | scandir возвращает DirEntry с кэшированными stat данными |
