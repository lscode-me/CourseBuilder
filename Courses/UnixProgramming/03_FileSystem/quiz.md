| # | Answer | Explanation |

| 1 | B | os.stat() возвращает stat_result с метаданными: size, mode, uid, gid, times |

| 11 | B | 0666 & ~022 = 0644 (umask убирает биты) |
| 12 | D | os.replace() атомарно заменяет существующий файл |
| 13 | A | st_nlink — количество жёстких ссылок на inode |
| 14 | A | inode — структура данных файловой системы с метаданными |
| 15 | C | scandir возвращает DirEntry с кэшированными stat данными |
| 16 | C | st_nlink — количество жёстких ссылок на inode |
| 17 | B | rename() атомарно перемещает/переименовывает файл |
