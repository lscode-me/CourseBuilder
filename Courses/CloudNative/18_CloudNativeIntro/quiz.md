---

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | CNCF (Cloud Native Computing Foundation) — организация, управляющая cloud native проектами. |
| 2 | C | "Cattle" — серверы заменяемы и эфемерны. Сломался — уничтожь и создай новый. |
| 3 | B | MySQL — не CNCF проект. Kubernetes, Prometheus, Helm — graduated CNCF проекты. |
| 4 | C | "Design for failure" — предполагайте, что всё может сломаться, и проектируйте устойчиво. |
| 5 | C | Для простого CRUD с маленькой командой монолит проще и эффективнее. |
