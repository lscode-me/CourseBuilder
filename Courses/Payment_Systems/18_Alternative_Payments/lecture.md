## 1. Обзор альтернатив

### 1.1 Почему важны

- Ниже комиссии (для торговцев)
- Удобство (для клиентов)
- Охват (для тех, кто без карт)
- Инновации

### 1.2 Типы

| Тип | Примеры |
|-----|---------|
| A2A (банк-банк) | Open Banking, СБП |
| E-wallets | PayPal, Qiwi |
| QR-платежи | СБП, Alipay |
| P2P | Переводы между людьми |
| BNPL | Рассрочка |

## 2. Open Banking

### 2.1 Что это

**Open Banking** — доступ к банковским данным и инициация платежей через API.

### 2.2 PSD2 в Европе

- **AISP** — доступ к данным счёта
- **PISP** — инициация платежей
- Требует согласия клиента

### 2.3 A2A платежи

```
Клиент → Merchant → API банка клиента → Перевод → Счёт merchant
```

**Преимущества:**
- Ниже комиссии (0.1-0.5%)
- Мгновенно
- Без карты

## 3. Электронные кошельки

### 3.1 Типы

| Тип | Примеры | Особенности |
|-----|---------|-------------|
| Closed | Подарочные карты | Только у одного продавца |
| Semi-open | Starbucks | Несколько продавцов |
| Open | PayPal, Qiwi | Везде |

### 3.2 PayPal

- Глобальный лидер
- Привязка карт или счетов
- Защита покупателя
- Комиссии 2-3%

### 3.3 Региональные кошельки

| Регион | Кошелёк |
|--------|---------|
| Китай | Alipay, WeChat Pay |
| Россия | Qiwi, ЮMoney |
| Индия | Paytm |
| Африка | M-Pesa |

---

## 4. QR-платежи

### 4.1 Как работают

1. Торговец показывает QR-код
2. Клиент сканирует приложением банка
3. Подтверждает платёж
4. Деньги переводятся

### 4.2 Типы

| Тип | Описание |
|-----|----------|
| Static QR | Один код для всех платежей |
| Dynamic QR | Уникальный код для каждого платежа |

### 4.3 СБП в России

- 0.4-0.7% для торговцев
- Мгновенные переводы
- QR-платежи
- Интеграция с банками

---

## 5. P2P переводы

### 5.1 Что это

**P2P (Peer-to-Peer)** — переводы между физическими лицами.

### 5.2 Примеры

| Страна | Сервис |
|--------|--------|
| Россия | СБП, переводы по номеру телефона |
| США | Venmo, Zelle, Cash App |
| ЕС | SEPA Instant |

### 5.3 Особенности

- Обычно бесплатно
- Мгновенно
- Привязка к телефону

---

## 6. BNPL (Buy Now Pay Later)

### 6.1 Что это

**BNPL** — оплата покупки частями без процентов.

### 6.2 Как работает

1. Покупатель выбирает BNPL
2. BNPL-провайдер платит торговцу
3. Покупатель платит частями

### 6.3 Игроки

| Провайдер | Регион |
|-----------|--------|
| Klarna | Европа, США |
| Afterpay | Австралия, США |
| Affirm | США |
| Тинькофф Рассрочка | Россия |

### 6.4 Для торговца

- Комиссия: 3-6%
- Выше конверсия
- Выше средний чек

---

## 7. Банковские переводы

### 7.1 SEPA

**SEPA (Single Euro Payments Area):**
- Стандартные переводы в евро
- 34 страны
- SEPA Instant — мгновенные

### 7.2 SWIFT

- Международные переводы
- Несколько дней
- Высокие комиссии

---

## 8. Сравнение с картами

| Метод | Комиссия торговца | Скорость | Охват |
|-------|-------------------|----------|-------|
| Карты | 1.5-3% | T+1 | Глобальный |
| СБП | 0.4-0.7% | Мгновенно | Россия |
| Open Banking | 0.1-0.5% | Мгновенно | ЕС, UK |
| PayPal | 2-3% | Мгновенно | Глобальный |

---

## 💡 Key Takeaways

- **Open Banking** снижает комиссии и ускоряет платежи
- **E-wallets** популярны в разных регионах
- **QR-платежи** просты и дёшевы
- **BNPL** повышает конверсию
- **Карты всё ещё доминируют** но альтернативы растут
