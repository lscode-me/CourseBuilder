### 1.2 Основные регуляторные области

| Область | Основные требования | Регуляторы (примеры) |
|---------|---------------------|---------------------|
| **Идентификация (KYC)** | Верификация личности клиентов | ЦБ, FinCEN, FCA |

| **Безопасность карт** | Защита карточных данных | PCI SSC (PCI DSS) |
| **Лицензирование** | Право на платёжную деятельность | ЦБ, FCA, BaFin |
| **Защита потребителей** | Прозрачность, права клиентов | PSD2 (EU), CFPB (US) |

## 2. KYC (Know Your Customer)

### 2.1 Что такое KYC

**KYC (Know Your Customer)** — процесс идентификации и верификации личности клиентов, их деятельности и источников средств.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ЦЕЛИ KYC                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   • Убедиться, что клиент — тот, за кого себя выдаёт                       │
│   • Оценить риски работы с клиентом                                         │
│   • Понять цели и характер деятельности                                     │
│   • Определить источники средств                                            │
│   • Идентифицировать бенефициаров (для юрлиц)                              │
│   • Выполнить требования регуляторов                                        │
│                                                                             │
│   КОГДА ТРЕБУЕТСЯ:                                                          │
│   • При открытии счёта / регистрации                                        │
│   • При достижении лимитов                                                  │
│   • При изменении риск-профиля                                              │
│   • Периодически (refresh) — обычно ежегодно для высокого риска            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 Уровни KYC (Risk-Based Approach)

| Уровень | Данные | Лимиты (пример) | Применение |
|---------|--------|-----------------|------------|
| **Упрощённый (SDD)** | Телефон, email | <15,000 ₽/мес | Электронные кошельки |
| **Стандартный (CDD)** | Паспорт, адрес | <600,000 ₽/мес | Обычные счета |
| **Расширенный (EDD)** | Источник дохода, beneficial owners | Без лимитов | VIP, высокий риск, PEP |

```
│   ┌─────────────────────────────────────────────────────────────────────┐  │

│   │ • PEP (Politically Exposed Persons)                                  │  │
│   │ • Негативные новости (adverse media)                                 │  │
│   │ • Внутренние чёрные списки                                          │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │

│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Факторы:                                                             │  │
│   │ • Страна резидентства / гражданства                                  │  │

│   │ • Approve with conditions — ограниченные лимиты, EDD                │  │
│   │ • Decline — отказать                                                 │  │
│   │ • Escalate — передать на ручной разбор комплаенсу                   │  │

│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.4 Методы верификации документов

| Метод | Описание | Надёжность | Автоматизация |
|-------|----------|------------|---------------|
| **OCR + ML** | Распознавание документа, проверка MRZ | Средняя | Высокая |
| **Liveness check** | Видео-селфи, движения головой | Высокая | Высокая |
| **Database check** | Сверка с госреестрами (ФМС, ЕГРЮЛ) | Высокая | Высокая |
| **Ручная проверка** | Аналитик проверяет вручную | Высокая | Низкая |
| **Video KYC** | Видеозвонок с оператором | Очень высокая | Низкая |
| **Биометрия** | Face match, отпечатки | Очень высокая | Высокая |

## 3. AML (Anti-Money Laundering)

### 3.1 Что такое отмывание денег

**Отмывание денег (Money Laundering)** — процесс сокрытия незаконного происхождения средств и придания им видимости легальных.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ЭТАПЫ ОТМЫВАНИЯ ДЕНЕГ                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. PLACEMENT (Размещение)                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Введение наличных в финансовую систему                              │  │
│   │                                                                      │  │
│   │ • Дробление на мелкие суммы (structuring / smurfing)                │  │
│   │ • Покупка денежных инструментов                                     │  │
│   │ • Внесение в казино                                                  │  │
│   │ • Смешивание с легальной выручкой                                   │  │
│   │                                                                      │  │
│   │ ← Наиболее уязвимый этап для обнаружения                            │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   2. LAYERING (Расслоение)                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Создание сложной цепочки транзакций для сокрытия следа              │  │
│   │                                                                      │  │
│   │ • Множественные переводы между счетами                              │  │
│   │ • Использование shell companies                                     │  │
│   │ • Переводы через офшоры                                             │  │
│   │ • Конвертация в криптовалюту                                        │  │
│   │ • Торговые схемы (over/under invoicing)                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   3. INTEGRATION (Интеграция)                                               │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Возврат "очищенных" средств в легальную экономику                   │  │
│   │                                                                      │  │
│   │ • Покупка недвижимости, бизнеса                                     │  │
│   │ • Инвестиции                                                         │  │
│   │ • Займы от подставных компаний                                      │  │
│   │ • Luxury goods                                                       │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 Красные флаги (Red Flags)

| Категория | Примеры подозрительных признаков |
|-----------|----------------------------------|
| **Транзакции** | Необычно крупные суммы; Дробление (structuring); Round amounts; Быстрые переводы туда-обратно |
| **Поведение** | Нежелание предоставлять информацию; Несоответствие профилю; Сложные схемы без экономического смысла |
| **Контрагенты** | Переводы в/из высокорисковых стран; Связь с shell companies; Неизвестные отправители |
| **Паттерны** | Внезапный рост активности; Необъяснимые источники; Использование третьих лиц |

## 4. Санкционный комплаенс

### 4.1 Типы санкций

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        ТИПЫ САНКЦИЙ                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   СТРАНОВЫЕ (Comprehensive)                                                 │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Полный запрет на операции с резидентами страны                      │  │
│   │ Примеры: КНДР, Иран, Куба, Сирия (для США)                          │  │
│   │ ⚠️ Любая транзакция = нарушение                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   СЕКТОРАЛЬНЫЕ (Sectoral)                                                   │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Ограничения для определённых секторов экономики                     │  │
│   │ Примеры: нефтегаз, финансы, оборонка                                │  │
│   │ • SSI (Sectoral Sanctions Identifications) — OFAC                   │  │
│   │ • Запреты на определённые типы операций                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   СПИСОЧНЫЕ (List-based)                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Запрет операций с конкретными лицами/организациями                  │  │
│   │ • SDN List (OFAC) — ~12,000+ записей                                │  │
│   │ • EU Consolidated List — ~2,000+ записей                            │  │
│   │ • UN Consolidated List                                               │  │
│   │ • Перечни Совета Безопасности ООН                                   │  │
│   │ • Национальные списки                                                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ВТОРИЧНЫЕ САНКЦИИ                                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Санкции против тех, кто ведёт бизнес с первичными целями            │  │
│   │ Экстерриториальное применение (США)                                 │  │
│   │ ⚠️ Даже если ваша компания не в США, но использует USD              │  │
```

### 4.2 Ключевые санкционные списки

```

│   │                                                                      │  │
```

## 6. GDPR и защита персональных данных

### 6.1 Основные принципы GDPR

| Принцип | Описание |
|---------|----------|
| **Законность** | Должно быть правовое основание для обработки |
| **Прозрачность** | Субъект должен знать, как используются данные |
| **Минимизация** | Собирать только необходимые данные |
| **Ограничение цели** | Использовать только для заявленных целей |
| **Точность** | Данные должны быть актуальными |
| **Ограничение хранения** | Не хранить дольше необходимого |
| **Целостность и конфиденциальность** | Защита от несанкционированного доступа |

### 6.2 Правовые основания для обработки

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                ПРАВОВЫЕ ОСНОВАНИЯ ДЛЯ ОБРАБОТКИ (GDPR)                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. СОГЛАСИЕ (Consent)                                                     │
│      • Свободное, конкретное, информированное                              │
│      • Можно отозвать в любой момент                                       │
│      → Для маркетинга, рассылок                                            │
│                                                                             │
│   2. ДОГОВОР (Contract)                                                     │
│      • Необходимо для исполнения договора                                  │
│      → Обработка платежа для выполнения заказа                             │
│                                                                             │
│   3. ЮРИДИЧЕСКОЕ ОБЯЗАТЕЛЬСТВО (Legal obligation)                          │
│      • Требуется законом                                                    │
│      → AML-хранение данных 5 лет, налоговая отчётность                     │
│                                                                             │
│   4. ЖИЗНЕННЫЕ ИНТЕРЕСЫ (Vital interests)                                  │
│      • Защита жизни и здоровья                                              │
│      → Редко применимо к платежам                                          │
│                                                                             │
│   5. ПУБЛИЧНЫЙ ИНТЕРЕС (Public task)                                       │
│      • Государственные функции                                              │
│      → Для госорганов                                                       │
│                                                                             │
│   6. ЗАКОННЫЕ ИНТЕРЕСЫ (Legitimate interests)                              │
│      • Баланс между интересами компании и правами субъекта                 │
│      → Fraud prevention, analytics                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.3 Права субъектов данных

| Право | Описание | Срок ответа |
|-------|----------|-------------|
| **Доступ (Access)** | Получить копию своих данных | 30 дней |
| **Исправление (Rectification)** | Исправить неточные данные | 30 дней |
| **Удаление (Erasure)** | "Право быть забытым" | 30 дней |
| **Ограничение (Restriction)** | Ограничить обработку | 30 дней |
| **Переносимость (Portability)** | Получить данные в машиночитаемом формате | 30 дней |
| **Возражение (Objection)** | Возразить против обработки | Без задержек |

### 6.4 Штрафы GDPR

- **До €20 млн** или **4% глобального оборота** (что больше) — за серьёзные нарушения
- **До €10 млн** или **2% оборота** — за менее серьёзные нарушения
- **Примеры**: Amazon — €746 млн (2021), Meta — €1.2 млрд (2023)

### 7.3 MSB в США

**MSB (Money Services Business)** — категория регулируемых компаний в США.

- Регистрация в FinCEN на федеральном уровне
- Лицензии на уровне штатов (50 разных требований!)
- BitLicense для криптовалют (New York)
- Compliance: AML Program, BSA reporting

## 9. Трансграничные сложности

### 9.1 Проблемы международных платежей

| Проблема | Описание | Решение |
|----------|----------|---------|
| **Разные юрисдикции** | Каждая страна — свои правила | Локальные лицензии или партнёры |
| **Разные KYC** | Разные уровни и требования | Унифицировать до максимума |
| **Санкции** | Разные списки (US vs EU vs UN) | Проверять все релевантные списки |
| **Налоги** | Withholding tax, VAT | Налоговое планирование |
| **Data localization** | Требования хранить данные локально | Локальные ЦОД |

### 9.2 Passporting в ЕС

- Лицензия в одной стране ЕС даёт право работать во всём ЕС/EEA
- Требуется уведомление регулятора принимающей страны (notification)
- Popular jurisdictions: Литва, Ирландия, Нидерланды, Люксембург
- Post-Brexit: Великобритания требует отдельной лицензии

## 💡 Key Takeaways

- **KYC/AML** — обязательны для всех платёжных организаций; подход risk-based
- **Санкции** — нулевая толерантность; штрафы в миллиарды долларов
- **PCI DSS** — обязателен для работы с картами; токенизируйте PAN
- **GDPR** — права субъектов данных; штрафы до 4% оборота
- **Лицензирование** — требуется везде; в ЕС passporting экономит усилия
- **Compliance — инвестиция**, а не расход: регуляторные штрафы и репутация дороже
- **Три линии защиты** — стандартный подход к организации контроля
- **Международная экспансия** — каждая страна = новые требования
