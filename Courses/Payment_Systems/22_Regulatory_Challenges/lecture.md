## 2. KYC (Know Your Customer)

### 2.1 Что это

**KYC** — процесс идентификации и верификации клиентов.

### 2.2 Уровни

| Уровень | Данные | Лимиты |
|---------|--------|--------|
| Минимальный | Телефон, email | Низкие |
| Стандартный | Паспорт, адрес | Средние |
| Расширенный | Источник дохода | Высокие |

### 2.3 Процесс

```
Регистрация → Сбор данных → Верификация → Screening → Решение
```

### 2.4 Методы верификации

- Документы (паспорт, права)
- Liveness check (видео)
- Адрес (выписки, счета)
- Биометрия

---

## 3. AML (Anti-Money Laundering)

### 3.1 Что это

**AML** — противодействие отмыванию денег.

### 3.2 Этапы отмывания

```
Размещение → Расслоение → Интеграция
(Placement)  (Layering)   (Integration)
```

### 3.3 Красные флаги

- Необычно крупные транзакции
- Структурирование (дробление)
- Несоответствие профилю
- Высокорисковые страны
- Подозрительные паттерны

### 3.4 Меры

| Мера | Описание |
|------|----------|
| Transaction monitoring | Автоматический анализ |
| Screening | Проверка по спискам |
| SAR/STR | Отчёты о подозрительных операциях |
| Risk scoring | Оценка риска клиента |

---

## 4. Санкции

### 4.1 Типы

| Тип | Описание |
|-----|----------|
| Страновые | Ограничения по странам |
| Секторальные | Ограничения по отраслям |
| Списочные | Конкретные лица/организации |

### 4.2 Основные списки

| Список | Регулятор |
|--------|-----------|
| SDN | OFAC (США) |
| EU Sanctions | ЕС |
| UN Sanctions | ООН |
| UK Sanctions | Великобритания |

### 4.3 Процесс screening

```
Клиент/Транзакция → Screening против списков → Match → Анализ → Решение
```

### 4.4 Последствия нарушения

- Огромные штрафы ($миллионы-миллиарды)
- Уголовное преследование
- Отзыв лицензий
- Репутационный ущерб

---

## 5. PCI DSS

### 5.1 Что это

**PCI DSS** — стандарт безопасности данных карт.

### 5.2 Требования

| Категория | Примеры |
|-----------|---------|
| Сеть | Firewall, сегментация |
| Данные | Шифрование, маскирование |
| Доступ | Минимальные права, MFA |
| Мониторинг | Логирование, тестирование |

### 5.3 Уровни соответствия

| Уровень | Транзакции/год | Требования |
|---------|----------------|------------|
| 1 | >6 млн | Аудит QSA |
| 2 | 1-6 млн | SAQ |
| 3 | 20K-1 млн | SAQ |
| 4 | <20K | SAQ |

### 5.4 Важные данные

- PAN — не хранить без причины
- CVV — никогда не хранить
- PIN — никогда не хранить

## 6. GDPR и защита данных

### 6.1 Основные принципы

- Законность обработки
- Минимизация данных
- Ограничение хранения
- Права субъекта данных

### 6.2 Права пользователей

| Право | Описание |
|-------|----------|
| Доступ | Получить свои данные |
| Исправление | Исправить неточности |
| Удаление | Быть забытым |
| Портируемость | Перенести данные |

### 6.3 Штрафы

- До 4% от глобального оборота
- До €20 млн

## 7. Лицензирование

### 7.1 Типы лицензий

| Тип | Описание |
|-----|----------|
| EMI | Electronic Money Institution |
| PI | Payment Institution |
| Banking | Банковская лицензия |
| MSB | Money Service Business (США) |

### 7.2 Требования

- Капитал
- Governance
- Комплаенс
- Отчётность

### 7.3 Пример: EMI в ЕС

- Минимальный капитал: €350K
- Safeguarding клиентских средств
- Регулярная отчётность
- AML программа

## 💡 Key Takeaways

- **KYC/AML обязательны** — идентификация и мониторинг
- **Санкции критичны** — огромные штрафы за нарушение
- **PCI DSS для карт** — защита данных карт
- **GDPR в ЕС** — права пользователей
- **Лицензии требуются** — для платёжной деятельности
