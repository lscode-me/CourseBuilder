## 1. Введение

Когда вы платите 1 000 ₽ в магазине, торговец получает не 1 000 ₽. Часть суммы уходит на комиссии. Но кто их получает и сколько?

Понимание финансовых потоков критично для:
- Торговцев (оптимизация расходов)
- Банков (понимание доходов)
- Fintech (построение бизнес-моделей)
- Регуляторов (контроль рынка)

```
│                   FOUR-PARTY MODEL                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────────┐                    ┌─────────────┐        │
│   │  ДЕРЖАТЕЛЬ  │ ═══════════════════│   ТОРГОВЕЦ  │        │
│   │             │      Товар/Услуга   │             │        │
│   │   Платит    │ ◄═══════════════════│   Получает  │        │
│   │   1 000 ₽   │      Оплата 1 000 ₽ │   975 ₽     │        │

│          │                                  │               │
│          │                                  │               │
│   ┌──────▼──────┐                    ┌──────▼──────┐        │
│   │   ЭМИТЕНТ   │ ◄──────────────────│   ЭКВАЙЕР   │        │
│   │             │    Interchange      │             │        │
│   │  Получает   │    15 ₽            │   Получает  │        │
│   │  15 ₽       │                    │   10 ₽      │        │

│              ┌─────────────────────────┐                    │
│              │    ПЛАТЁЖНАЯ СИСТЕМА    │                    │
│              │    Получает ≈ 2-3 ₽     │                    │
│              └─────────────────────────┘                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Кто кому платит

| От кого | Кому | Что | Размер |
|---------|------|-----|--------|
| Держатель | Эмитент | Обслуживание карты | 0-5 000 ₽/год |
| Торговец | Эквайер | MDR (комиссия за транзакцию) | 1-3% |
| Эквайер | Эмитент | Interchange fee | 1-2% |
| Эквайер | ПС | Scheme fee | 0.1-0.3% |
| Эмитент | ПС | Scheme fee | 0.1-0.3% |

## 3. MDR — Merchant Discount Rate

### 3.1 Что это

**MDR (Merchant Discount Rate)** — комиссия, которую торговец платит эквайеру за приём карт.

**Другие названия:**
- Merchant fee
- Processing fee
- Торговая уступка

### 3.2 Структура MDR

```
┌─────────────────────────────────────────────────────────────┐
│                    СТРУКТУРА MDR                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   MDR (2.5%) = Interchange + Scheme fee + Acquirer margin   │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐   │
│   │                                                     │   │
│   │  Interchange    │  Scheme fee   │  Acquirer margin  │   │
│   │     1.5%        │    0.2%       │      0.8%         │   │
│   │  (→ Эмитент)    │  (→ ПС)       │  (→ Эквайер)      │   │
│   │                                                     │   │
│   └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 Типичные ставки MDR

| Категория | MDR | Комментарий |
|-----------|-----|-------------|
| Супермаркеты | 1.5-2% | Низкая маржа, высокий оборот |
| Рестораны | 2-2.5% | Средний риск |
| Онлайн-магазины | 2.5-3.5% | Выше риск мошенничества |
| Туризм | 2-3% | Высокий средний чек |
| High-risk (gambling) | 5-10% | Высокий риск chargebacks |

### 3.4 Факторы, влияющие на MDR

| Фактор | Влияние |
|--------|---------|
| Категория бизнеса (MCC) | Высокий риск = выше MDR |
| Оборот | Больше оборот = ниже MDR |
| Тип транзакции | CNP дороже CP |
| История chargebacks | Много споров = выше MDR |
| Средний чек | Влияет на фиксированную часть |

## 4. Interchange Fee

### 4.1 Что это

**Interchange fee** — комиссия, которую банк-эквайер платит банку-эмитенту за каждую транзакцию.

**Это основной источник дохода эмитента от карточных операций.**

### 4.2 Кто устанавливает

Interchange устанавливается **платёжной системой**, не банками.

- Visa публикует Visa Interchange Rates
- Mastercard публикует Mastercard Interchange Rates
- Ставки различаются по странам и категориям

### 4.3 Факторы, влияющие на interchange

| Фактор | Влияние | Пример |
|--------|---------|--------|
| Тип карты | Кредитные > Дебетовые | Credit: 1.8%, Debit: 0.5% |
| Категория карты | Premium > Standard | Platinum: +0.3% |
| Тип транзакции | CNP > CP | Online: +0.5% |
| MCC торговца | Разные категории | Grocery: ниже |
| Регион | Отличается по странам | ЕС: регулируется |

### 4.4 Примеры interchange

**Россия (примерные значения):**

| Тип карты | Card Present | Card Not Present |
|-----------|--------------|------------------|
| Дебетовая Standard | 1.0% | 1.5% |
| Дебетовая Gold | 1.2% | 1.7% |
| Кредитная Standard | 1.5% | 2.0% |
| Кредитная Platinum | 1.8% | 2.3% |

### 4.5 Регулирование interchange

**Европейский союз (IFR):**
- Дебетовые: max 0.2%
- Кредитные: max 0.3%

**США (Durbin Amendment):**
- Дебетовые: ~$0.22 + 0.05%

**Россия:**
- Не регулируется жёстко
- Рыночные ставки

## 5. Scheme Fees

### 5.1 Что это

**Scheme fees** — комиссии, которые платёжная система взимает с банков.

### 5.2 Типы scheme fees

| Тип | Описание | Размер |
|-----|----------|--------|
| Assessment fee | За объём транзакций | 0.1-0.15% |
| Processing fee | За обработку | Фиксированная |
| Cross-border fee | За трансграничные | 0.2-1% |
| Currency conversion | За конвертацию | 0-1% |

### 5.3 Кто платит

- **Эквайер платит** за acquisition
- **Эмитент платит** за issuing
- **Оба платят** за network access

## 6. Расчёт финансовых потоков

### 6.1 Пример транзакции

**Исходные данные:**
- Покупка: 10 000 ₽
- MDR: 2.5%
- Interchange: 1.5%
- Scheme fee: 0.2%
- Acquirer margin: 0.8%

### 6.2 Расчёт

```
┌─────────────────────────────────────────────────────────────┐
│              РАСПРЕДЕЛЕНИЕ 10 000 ₽                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Держатель платит:           10 000 ₽                       │
│                                                             │
│  ├─► Торговец получает:       9 750 ₽ (100% - 2.5% MDR)     │
│  │                                                          │
│  └─► MDR (250 ₽) распределяется:                            │
│      ├─► Эмитент:             150 ₽ (1.5% interchange)      │
│      ├─► Платёжная система:    20 ₽ (0.2% scheme fee)       │
│      └─► Эквайер:              80 ₽ (0.8% margin)           │
│                                                             │
│  ИТОГО:                                                     │
│  ┌───────────────┬────────────┬────────────────────┐        │
│  │ Участник      │ Получает   │ % от транзакции    │        │
│  ├───────────────┼────────────┼────────────────────┤        │
│  │ Торговец      │ 9 750 ₽    │ 97.5%              │        │
│  │ Эмитент       │ 150 ₽      │ 1.5%               │        │
│  │ Эквайер       │ 80 ₽       │ 0.8%               │        │
│  │ ПС            │ 20 ₽       │ 0.2%               │        │
│  └───────────────┴────────────┴────────────────────┘        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 Денежный поток

```
Шаг 1: Авторизация
  Деньги ещё не двигаются, только информация

Шаг 2: Settlement (через 1-2 дня)
  
  Эмитент ─────────────────────────────────────► Эквайер
           9 850 ₽ (10 000 − 150 interchange)
  
  Эквайер ─────────────────────────────────────► Торговец
           9 750 ₽ (10 000 − 250 MDR)
  
  Эквайер ─────────────────────────────────────► ПС
           20 ₽ (scheme fee)
  
  Эмитент ─────────────────────────────────────► ПС
           (scheme fee за issuing, отдельно)
```

## 7. Доходы участников

### 7.1 Доходы эмитента

| Источник | Описание |
|----------|----------|
| Interchange | Основной доход от транзакций |
| Годовое обслуживание | Плата за карту |
| Проценты по кредитам | Для кредитных карт |
| Комиссии за снятие | В чужих банкоматах |
| Cross-sell | Другие продукты |

**Типичная структура:**
```
Доход эмитента от карты:
├── Interchange: 60%
├── Проценты: 25%
├── Комиссии: 10%
└── Другое: 5%
```

### 7.2 Доходы эквайера

| Источник | Описание |
|----------|----------|
| Acquirer margin | Разница между MDR и interchange |
| Аренда терминалов | Плата за оборудование |
| Дополнительные услуги | Отчёты, интеграции |
| Setup fees | Подключение торговца |

### 7.3 Доходы платёжной системы

| Источник | Описание |
|----------|----------|
| Scheme fees | От всех транзакций |
| Лицензии | От банков-участников |
| Value-added services | Fraud detection, analytics |
| Data services | Insights, benchmarks |

## 8. Interchange++ vs Blended pricing

### 8.1 Blended pricing

**Blended (смешанное) ценообразование:**
- Торговец платит единую ставку MDR
- Независимо от типа карты
- Простое, но менее прозрачное

**Пример:**
```
Все карты: 2.5% MDR
- Дебетовая Standard: 2.5%
- Кредитная Platinum: 2.5%
```

### 8.2 Interchange++

**Interchange++ (IC++):**
- Торговец платит реальный interchange
- Плюс фиксированную маржу эквайера
- Прозрачное ценообразование

**Пример:**
```
IC++: Interchange + 0.2% scheme + 0.3% margin

Дебетовая Standard: 1.0% + 0.2% + 0.3% = 1.5%
Кредитная Platinum: 1.8% + 0.2% + 0.3% = 2.3%
```

### 8.3 Сравнение

| Аспект | Blended | IC++ |
|--------|---------|------|
| Простота | ✅ Просто | ❌ Сложнее |
| Прозрачность | ❌ Низкая | ✅ Высокая |
| Предсказуемость | ✅ Да | ❌ Варьируется |
| Для кого | Малый бизнес | Крупный бизнес |

## 9. Специальные случаи

### 9.1 Cross-border транзакции

```
┌─────────────────────────────────────────────────────────────┐
│           CROSS-BORDER ТРАНЗАКЦИЯ                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Российский турист платит в Германии:                       │
│                                                             │
│  Покупка: €100                                              │
│  MDR: 2.5% (платит немецкий торговец)                       │
│  Cross-border interchange: 1.8% (выше обычного)             │
│  Cross-border fee ПС: 0.5%                                  │
│                                                             │
│  Эмитент (Россия):                                          │
│    Получает interchange 1.8%                                │
│    Платит cross-border fee ПС                               │
│                                                             │
│  Конвертация: EUR → RUB                                     │
│    Курс + markup банка                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 9.2 On-us транзакции

**On-us** — когда эмитент и эквайер — один банк.

```
Держатель ─► Торговец
    │            │
    ▼            ▼
┌────────────────────┐
│     ОДИН БАНК      │
│  (Эмитент = Эквайер) │
└────────────────────┘

Interchange остаётся внутри банка
Ниже общие расходы
Возможны скидки для торговцев
```

### 9.3 Refund (возврат)

**При возврате:**
- Торговец получает назад MDR? Зависит от условий
- Interchange возвращается эмитенту? Часто нет
- Схема может отличаться от оригинальной транзакции

## 10. Оптимизация для бизнеса

### 10.1 Для торговцев

**Как снизить MDR:**
1. Увеличить оборот (переговорная сила)
2. Снизить chargeback rate
3. Выбрать IC++ при большом объёме дебетовых карт
4. Использовать правильный MCC
5. Рассмотреть прямое эквайринговое соглашение

### 10.2 Для банков

**Как увеличить доход:**
1. Стимулировать использование карт
2. Продвигать премиальные карты (выше interchange)
3. Развивать кредитный портфель
4. Cross-sell дополнительных услуг

### 10.3 Альтернативные методы

**Сравнение с другими методами:**

| Метод | Комиссия торговца | Скорость |
|-------|-------------------|----------|
| Карты | 1.5-3% | 1-2 дня |
| СБП | 0.4-0.7% | Мгновенно |
| Наличные | 0% | Мгновенно |
| Банковский перевод | 0-1% | 1-3 дня |

## 💡 Key Takeaways

- **MDR = Interchange + Scheme + Margin**: Торговец платит комплексную комиссию
- **Эмитент — главный бенефициар**: Получает наибольшую часть (interchange)
- **Interchange зависит от многих факторов**: Тип карты, канал, регион
- **IC++ — прозрачнее**: Но сложнее для прогнозирования
- **Регулирование снижает interchange**: ЕС ограничил до 0.2-0.3%
