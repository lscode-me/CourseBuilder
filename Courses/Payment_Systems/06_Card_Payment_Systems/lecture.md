## 1. Введение

Когда вы видите логотип Visa или Mastercard на карте, вы видите результат десятилетий развития глобальных платёжных сетей. Эти системы связывают миллионы банков и торговцев по всему миру.

Платёжные системы — это не банки. Они не выдают кредиты и не хранят ваши деньги. Они обеспечивают инфраструктуру и правила для того, чтобы платежи работали.

### 2.2 Правила (Rules)

Платёжные системы устанавливают:
- Кто может быть участником
- Как обрабатывать транзакции
- Какие комиссии взимаются
- Как решать споры
- Требования к безопасности

### 2.3 Сеть (Network)

- Связывает тысячи банков
- Маршрутизирует транзакции
- Обеспечивает доставку сообщений
- Работает 24/7

### 2.4 Бренд (Brand)

- Глобальное узнавание (Visa, Mastercard)
- Доверие торговцев и держателей
- Маркетинг и продвижение
- Гарантии для участников

## 3. Международные платёжные системы

### 3.1 Visa

**История:**
- 1958: BankAmericard (Bank of America)
- 1970: Создание ассоциации National BankAmericard Inc.
- 1976: Ребрендинг в Visa
- 2008: IPO на NYSE

**Масштаб (2023):**
- 4+ миллиарда карт
- 200+ стран
- 46 миллионов торговых точек
- $14+ триллионов платёжного оборота

**Продукты:**
| Продукт | Описание |
|---------|----------|
| Visa Classic | Базовые карты |
| Visa Gold | Расширенные услуги |
| Visa Platinum | Премиальные услуги |
| Visa Infinite | VIP-сегмент |
| Visa Business | Корпоративные карты |

### 3.2 Mastercard

**История:**
- 1966: Interbank Card Association
- 1979: Ребрендинг в Mastercard
- 2006: IPO

**Масштаб (2023):**
- 3+ миллиарда карт
- 210+ стран
- $8+ триллионов платёжного оборота

**Продукты:**
| Продукт | Описание |
|---------|----------|
| Mastercard Standard | Базовые карты |
| Mastercard Gold | Расширенные услуги |
| Mastercard Platinum | Премиальные услуги |
| Mastercard World | Премиум |
| Mastercard World Elite | VIP-сегмент |

### 3.3 American Express (AmEx)

**Особенность:** Трёхсторонняя модель — AmEx сам является эмитентом и эквайером.

**Характеристики:**
- Премиальная аудитория
- Более высокие комиссии для торговцев
- Меньший охват, но лояльная база
- Сильные бонусные программы

### 3.4 Другие международные системы

| Система | Регион | Особенности |
|---------|--------|-------------|
| **UnionPay** | Китай | Крупнейшая по количеству карт |
| **JCB** | Япония | Сильные позиции в Азии |
| **Discover** | США | Небольшая, без годовых комиссий |
| **Diners Club** | Международная | Первая универсальная карта |

## 4. Сравнение Visa и Mastercard

### 4.1 Сходства

- Глобальный охват
- Четырёхсторонняя модель
- Аналогичные продукты
- Сопоставимая безопасность
- Принимаются почти везде

### 4.2 Различия

| Аспект | Visa | Mastercard |
|--------|------|------------|
| Доля рынка | Больше | Меньше |
| Курс конвертации | Чуть отличается | Чуть отличается |
| Дополнительные услуги | Visa Concierge | Mastercard Priceless |
| Технологии | Visa Secure | Mastercard Identity Check |

### 4.3 Практический выбор

**Для держателя карты:**
- Разница минимальна
- Обе принимаются практически везде
- Выбор обычно определяется банком

**Для бизнеса:**
- Комиссии сопоставимы
- Важнее условия эквайера
- Рекомендуется принимать обе

## 5. Национальные платёжные системы

### 5.1 Зачем нужны

**Причины создания:**
- Независимость от иностранных систем
- Снижение комиссий
- Контроль над инфраструктурой
- Геополитические риски
- Развитие местного рынка

### 5.2 Система «Мир» (Россия)

**История:**
- 2014: Создание НСПК (Национальная система платёжных карт)
- 2015: Запуск карт «Мир»
- 2017: Обязательный приём в торговых сетях
- 2019: Запуск СБП

**Характеристики:**
| Параметр | Значение |
|----------|----------|
| Карт выпущено | 200+ млн |
| Доля в РФ | ~35% платежей |
| Международный приём | Ограничен |
| Технологии | EMV, NFC, СБП |

**Особенности:**
- Обязательный для бюджетных выплат
- Кобейджинг с UnionPay, JCB
- Интеграция с СБП

### 5.3 Другие национальные системы

| Страна | Система | Особенности |
|--------|---------|-------------|
| Китай | UnionPay | Крупнейшая в мире по картам |
| Индия | RuPay | 600+ млн карт |
| Бразилия | Elo | Рост за счёт банков |
| Германия | girocard | Дебетовые карты |
| Бельгия | Bancontact | 95% приём в стране |
| Нидерланды | iDEAL | Банковские переводы |

### 5.4 Преимущества и недостатки

**Преимущества:**
- Независимость
- Часто ниже комиссии
- Локальная поддержка
- Быстрое развитие

**Недостатки:**
- Ограниченный приём за рубежом
- Меньше инноваций
- Зависимость от местного рынка

## 7. Interchange и комиссии

### 7.1 Структура комиссий

```
┌─────────────────────────────────────────────────────────────┐
│           СТРУКТУРА КОМИССИЙ (MDR = 2.5%)                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Торговец платит эквайеру: 2.5%                            │
│                                                             │
│   Распределение:                                            │
│   ┌─────────────────────────────────────────────────────┐   │
│   │  Interchange     │  Scheme fee   │  Acquirer fee   │   │
│   │  (→ эмитенту)    │  (→ ПС)       │  (→ эквайеру)   │   │
│   │     1.5%         │    0.2%       │     0.8%        │   │
│   └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 Факторы, влияющие на interchange

| Фактор | Влияние |
|--------|---------|
| Тип карты | Кредитные > Дебетовые |
| Категория | Premium > Standard |
| Тип транзакции | CNP > Card Present |
| Категория торговца | Разные MCC |
| Регион | Отличается по странам |

### 7.3 Регулирование interchange

**ЕС (IFR — Interchange Fee Regulation):**
- Дебетовые: max 0.2%
- Кредитные: max 0.3%

**США (Durbin Amendment):**
- Дебетовые: ~0.05% + $0.22

**Россия:**
- Не регулируется жёстко
- Типично 1-2% для interchange

## 8. Технологии платёжных систем

### 8.1 EMV

Стандарт разработан совместно Europay, Mastercard, Visa:
- Чиповые карты
- Криптографическая аутентификация
- Глобальная совместимость

### 8.2 3-D Secure

| Версия | Название | Особенности |
|--------|----------|-------------|
| 1.0 | Verified by Visa, SecureCode | Pop-up окна, статические пароли |
| 2.0 | Visa Secure, ID Check | Frictionless flow, риск-анализ |
| 2.1+ | Улучшения | Биометрия, SCA (ЕС) |

### 8.3 Токенизация

- **Visa Token Service (VTS)**
- **Mastercard Digital Enablement Service (MDES)**

Позволяют заменять PAN на токены для безопасных платежей.

### 8.4 Платёжные API

Современные платёжные системы предоставляют API:
- Visa Developer Platform
- Mastercard Developers
- Интеграция с fintech

## 9. Membership и участие

### 9.1 Типы участников

| Тип | Описание | Примеры |
|-----|----------|---------|
| Principal Member | Полноправный участник | Крупные банки |
| Associate Member | Через спонсора | Средние банки |
| Participant | Ограниченные права | Fintech, PSP |

### 9.2 Требования для участия

**Для банков:**
- Лицензия ЦБ
- Финансовая устойчивость
- Техническая готовность
- Соответствие требованиям ПС

**Для торговцев:**
- Договор с эквайером
- Соответствие PCI DSS
- Легальный бизнес

### 9.3 Стоимость участия

- Вступительные взносы
- Ежегодные взносы
- Комиссии за транзакции
- Штрафы при нарушениях

## 💡 Key Takeaways

- **Платёжные системы — не банки**: Они устанавливают правила и обеспечивают инфраструктуру
- **Visa и Mastercard доминируют**: Но национальные системы растут
- **Interchange — главный источник дохода**: Эмитенты получают большую часть
- **Правила обязательны**: Нарушения ведут к штрафам и исключению
- **Технологии развиваются**: EMV, 3DS, токенизация, API
