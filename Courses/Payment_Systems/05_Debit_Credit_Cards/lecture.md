## 1. Введение

Дебетовая и кредитная карты выглядят одинаково. Обе принимаются везде, где принимают карты. Но внутри — принципиально разные финансовые продукты.

**Главное отличие:**
- Дебетовая карта = ваши деньги
- Кредитная карта = деньги банка

Понимание этих различий поможет правильно использовать карты и избегать финансовых ловушек.

## 2. Дебетовые карты

### 2.1 Что это

**Дебетовая карта** — карта, привязанная к вашему расчётному счёту. Вы тратите только то, что есть на счёте.

```
┌─────────────────────────────────────────────────────────────┐
│                    ДЕБЕТОВАЯ КАРТА                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Баланс счёта:    50 000 ₽                                 │
│   Доступно:        50 000 ₽                                 │
│                                                             │
│   Покупка 10 000 ₽:                                         │
│   → Баланс после:  40 000 ₽                                 │
│   → Долг банку:    0 ₽                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Как работает

1. Вы получаете зарплату на счёт
2. Карта привязывается к счёту
3. При оплате деньги списываются с вашего счёта
4. Нет денег на счёте = нет возможности платить

### 2.3 Преимущества

| Преимущество | Описание |
|--------------|----------|
| Без долгов | Невозможно потратить больше, чем есть |
| Без процентов | Это ваши деньги, проценты не начисляются |
| Простота | Понятная модель использования |
| Контроль | Легко отслеживать траты |

### 2.4 Недостатки

| Недостаток | Описание |
|------------|----------|
| Нет кредита | При нехватке средств платёж отклоняется |
| Меньше защиты | Деньги списываются сразу |
| Нет грейс-периода | Нет бесплатного кредитования |

### 2.5 Овердрафт

**Овердрафт** — возможность уходить в минус на дебетовой карте.

```
Баланс:        10 000 ₽
Лимит овердрафта:  20 000 ₽
Доступно:      30 000 ₽

Покупка 25 000 ₽:
→ Баланс:     -15 000 ₽
→ Овердрафт:   15 000 ₽ (под процент)
```

**Особенности:**
- Не все дебетовые карты имеют овердрафт
- Проценты начисляются сразу
- Обычно более высокие ставки, чем по кредитным картам

> **⚠️ Внимание:**  
> Несанкционированный овердрафт (технический) может привести к штрафам.

## 3. Кредитные карты

### 3.1 Что это

**Кредитная карта** — карта с кредитным лимитом. Вы тратите деньги банка и возвращаете их позже.

```
┌─────────────────────────────────────────────────────────────┐
│                    КРЕДИТНАЯ КАРТА                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Кредитный лимит: 100 000 ₽                                │
│   Использовано:    30 000 ₽                                 │
│   Доступно:        70 000 ₽                                 │
│                                                             │
│   Покупка 10 000 ₽:                                         │
│   → Использовано:  40 000 ₽                                 │
│   → Доступно:      60 000 ₽                                 │
│   → Долг банку:    40 000 ₽                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Как работает

1. Банк устанавливает кредитный лимит
2. При оплате банк платит за вас
3. Вы должны банку
4. В конце периода нужно вернуть долг

### 3.3 Кредитный лимит

**Кредитный лимит** — максимальная сумма, которую банк готов вам одолжить.

**Зависит от:**
- Дохода
- Кредитной истории
- Отношений с банком
- Типа карты (Classic/Gold/Platinum)

**Типичные лимиты:**
| Категория | Лимит |
|-----------|-------|
| Базовая | 30 000 - 100 000 ₽ |
| Золотая | 100 000 - 300 000 ₽ |
| Платиновая | 300 000 - 1 000 000 ₽ |
| Премиальная | 1 000 000+ ₽ |

### 3.4 Преимущества

| Преимущество | Описание |
|--------------|----------|
| Грейс-период | До 55 дней бесплатного кредита |
| Защита | Оспаривать проще (деньги не ваши) |
| Кэшбэк/мили | Бонусные программы |
| Резерв | Деньги на экстренные случаи |

### 3.5 Недостатки

| Недостаток | Описание |
|------------|----------|
| Высокие проценты | 20-40% годовых |
| Риск долгов | Легко накопить задолженность |
| Комиссии | За снятие наличных, обслуживание |
| Сложность | Много условий и правил |

## 4. Грейс-период

### 4.1 Что это

**Грейс-период (льготный период)** — время, в течение которого можно пользоваться кредитом без процентов.

```
┌─────────────────────────────────────────────────────────────┐
│                     ГРЕЙС-ПЕРИОД                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1 марта ────────────────────────────────► 31 марта         │
│  │         Расчётный период                     │           │
│  │         (покупки накапливаются)              │           │
│  │                                              │           │
│  │                                              ▼           │
│  │                              ┌──────────────────────┐    │
│  │                              │    Выписка/счёт      │    │
│  │                              │    Долг: 50 000 ₽    │    │
│  │                              └──────────────────────┘    │
│  │                                              │           │
│  │                                              ▼           │
│  │                              1 апреля ────► 25 апреля    │
│  │                              Платёжный период            │
│  │                              (нужно погасить)            │
│  │                                                          │
│  │◄─────────────────── Грейс-период (до 55 дней) ─────────►│
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 Как рассчитывается

**Пример: Грейс-период до 55 дней**

- Расчётный период: 1-31 марта (30 дней)
- Дата выписки: 31 марта
- Платёжный период: 25 дней
- Максимальный грейс: 30 + 25 = 55 дней

**Покупка 1 марта:**
- Грейс-период: 55 дней (до 25 апреля)

**Покупка 31 марта:**
- Грейс-период: 25 дней (до 25 апреля)

> **💡 Важно:**  
> Покупки в начале расчётного периода получают больший грейс-период!

### 4.3 Условия сохранения грейс-периода

**Чтобы не платить проценты:**
1. Погасить **весь** долг до конца платёжного периода
2. Не допускать просрочек
3. У некоторых банков — не снимать наличные

### 4.4 Что ломает грейс-период

| Действие | Последствие |
|----------|-------------|
| Частичное погашение | Проценты на остаток |
| Снятие наличных | Проценты сразу |
| Просрочка | Проценты + штраф |
| Переводы | Зависит от банка |

## 5. Проценты и комиссии

### 5.1 Процентная ставка

**Годовая ставка (APR)**: типично 20-40%

**Расчёт ежедневных процентов:**
```
Дневная ставка = Годовая ставка / 365

Пример:
Годовая: 36%
Дневная: 36% / 365 = 0.0986% в день

Долг 100 000 ₽ за 30 дней:
100 000 × 0.0986% × 30 = 2 958 ₽
```

### 5.2 Минимальный платёж

**Минимальный платёж** — сумма, которую нужно заплатить, чтобы избежать просрочки.

**Обычно:**
- 3-10% от долга
- Не менее фиксированной суммы (500-1000 ₽)
- Включает начисленные проценты

**Пример:**
```
Долг: 50 000 ₽
Минимальный платёж: 5% = 2 500 ₽

Оплатив 2 500 ₽:
- Нет просрочки
- Но проценты начисляются на 47 500 ₽
```

> **⚠️ Ловушка минимального платежа:**  
> Платя только минимум, вы годами выплачиваете долг и переплачиваете огромные суммы!

### 5.3 Комиссии

| Комиссия | Размер | Когда |
|----------|--------|-------|
| Годовое обслуживание | 0 - 15 000 ₽ | Раз в год |
| Снятие наличных | 3-5% (мин. 300-500 ₽) | За операцию |
| SMS-уведомления | 0 - 99 ₽/мес | Ежемесячно |
| Штраф за просрочку | 500-700 ₽ + % | При просрочке |

### 5.4 Снятие наличных

**Почему снимать наличные с кредитки — плохая идея:**

1. **Комиссия**: 3-5% сразу
2. **Нет грейс-периода**: проценты с первого дня
3. **Более высокая ставка**: иногда отдельная ставка для cash
4. **Лимит**: обычно ниже кредитного

**Пример:**
```
Снятие 10 000 ₽:
- Комиссия: 500 ₽ (5%)
- Проценты за 30 дней: 300 ₽ (36% годовых)
- Итого переплата: 800 ₽ (8%)
```

## 6. Сравнение дебетовых и кредитных карт

### 6.1 Таблица сравнения

| Характеристика | Дебетовая | Кредитная |
|----------------|-----------|-----------|
| Источник денег | Ваш счёт | Кредит банка |
| Лимит | Баланс счёта | Кредитный лимит |
| Проценты | Нет (или на остаток) | 20-40% годовых |
| Грейс-период | Нет | Есть (до 55 дней) |
| Снятие наличных | Бесплатно* | С комиссией |
| Овердрафт | Возможен | Не применим |
| Защита от мошенничества | Средняя | Выше |
| Влияние на кредитную историю | Нет | Есть |

*в своих банкоматах

### 6.2 Когда использовать дебетовую

✅ **Используйте дебетовую:**
- Для повседневных покупок
- Для снятия наличных
- Когда хотите контролировать траты
- Для получения зарплаты

### 6.3 Когда использовать кредитную

✅ **Используйте кредитную:**
- Для онлайн-покупок (лучше защита)
- Для бронирования (залоги)
- Для накопления бонусов
- Когда можете вернуть в грейс-период
- В путешествиях (лучший курс, страховка)

## 7. Prepaid карты (предоплаченные)

### 7.1 Что это

**Prepaid карта** — карта с заранее внесённой суммой. Не привязана к банковскому счёту.

```
┌─────────────────────────────────────────────────────────────┐
│                    PREPAID КАРТА                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Пополнено:       10 000 ₽                                 │
│   Потрачено:        3 000 ₽                                 │
│   Остаток:          7 000 ₽                                 │
│                                                             │
│   - Нет кредита                                             │
│   - Нет привязки к счёту                                    │
│   - Нет овердрафта                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 Типы prepaid карт

| Тип | Описание | Пример |
|-----|----------|--------|
| Подарочные | Фиксированная сумма | Gift cards |
| Пополняемые | Можно докладывать | Travel cards |
| Виртуальные | Только онлайн | Для интернет-покупок |
| Зарплатные (некоторые) | Выплата зарплаты | Payroll cards |

### 7.3 Преимущества и недостатки

**Преимущества:**
- Ограниченный риск потерь
- Не нужен банковский счёт
- Анонимность (некоторые)
- Контроль расходов

**Недостатки:**
- Часто высокие комиссии
- Меньше защиты
- Не строит кредитную историю
- Лимиты на пополнение

## 8. Категории карт

### 8.1 По статусу

| Категория | Лимит | Годовое обслуживание | Бонусы |
|-----------|-------|---------------------|--------|
| Classic/Standard | Базовый | 0-1 500 ₽ | Минимальные |

| Platinum | Высокий | 5 000-15 000 ₽ | Премиальные |

### 8.2 Дополнительные услуги

**Gold и выше:**

- Повышенный кэшбэк

### 8.3 Кобрендовые карты

**Кобренд** — карта, выпущенная совместно с партнёром.

**Примеры:**

| Спортивный клуб | Скидки на билеты |
| Благотворительность | Отчисления в фонд |

## 9. Кредитная история

### 9.1 Влияние карт

**Кредитная карта влияет на историю:**
- Своевременные платежи = +
- Просрочки = −
- Высокая утилизация = −
- Длительность истории = +

**Дебетовая карта НЕ влияет на кредитную историю.**

### 9.2 Утилизация кредитного лимита

**Утилизация** = Использованный лимит / Общий лимит

```
Лимит: 100 000 ₽
Использовано: 70 000 ₽
Утилизация: 70%
```

**Рекомендация:** Держите утилизацию ниже 30%

| Утилизация | Влияние |
|------------|---------|
| 0-30% | Положительное |
| 30-50% | Нейтральное |
| 50-70% | Негативное |
| 70%+ | Сильно негативное |

## 10. Практические советы

### 10.1 Как использовать кредитную карту правильно

1. **Погашайте полностью** в грейс-период
2. **Не снимайте наличные**
3. **Следите за утилизацией** (< 30%)
4. **Не опаздывайте с платежами**
5. **Используйте для бонусов**, не для кредита

### 10.2 Как выбрать карту

**Вопросы для выбора:**
1. Какой тип: дебетовая или кредитная?
2. Какой кэшбэк или бонусы важны?
3. Какова стоимость обслуживания?
4. Какой нужен лимит?
5. Есть ли бесплатный грейс-период?

### 10.3 Чего избегать

❌ **Не делайте:**
- Оплачивать только минимальный платёж
- Снимать наличные с кредитки
- Использовать весь лимит
- Игнорировать выписки
- Открывать много карт

---

## 💡 Key Takeaways

- **Дебетовая = ваши деньги**: Тратите только то, что есть на счёте
- **Кредитная = деньги банка**: Тратите кредит, который нужно вернуть
- **Грейс-период — главное преимущество**: До 55 дней бесплатного кредита
- **Минимальный платёж — ловушка**: Проценты накапливаются, долг растёт
- **Снятие наличных с кредитки дорого**: Комиссия + проценты сразу
