## 1. Что такое эквайринг

**Эквайринг** — услуга банка по приёму безналичных платежей от держателей карт в пользу торговца.

**Банк-эквайер:**
- Предоставляет терминалы
- Обрабатывает транзакции
- Переводит деньги торговцу
- Несёт риски по chargebacks

---

## 2. Виды эквайринга

### 2.1 Торговый эквайринг

**POS-терминалы в торговых точках:**
- Магазины, рестораны, АЗС
- Физическое присутствие карты
- Более низкие комиссии
- Ниже риск мошенничества

### 2.2 Интернет-эквайринг

**Приём платежей онлайн:**
- Интернет-магазины, сервисы
- Card Not Present (CNP)
- Выше комиссии
- Требуется 3-D Secure

### 2.3 Мобильный эквайринг (mPOS)

**Смартфон + ридер карт:**
- Для малого бизнеса, курьеров
- Гибкость и мобильность
- Простое подключение

### 2.4 Soft POS

**Смартфон как терминал:**
- NFC-приём без дополнительного оборудования
- Новейшая технология
- Сертификация PCI

## 3. Процесс подключения

### 3.1 Этапы

1. **Заявка** — подача документов
2. **Проверка** — KYC, оценка рисков
3. **Договор** — подписание соглашения
4. **Интеграция** — установка терминалов или API
5. **Тестирование** — проверка работы
6. **Запуск** — начало приёма платежей

### 3.2 Документы

- Учредительные документы
- Выписка из ЕГРЮЛ/ЕГРИП
- Лицензии (если требуются)
- Финансовая отчётность
- Описание бизнеса

### 3.3 Оценка рисков

| Фактор | На что влияет |
|--------|---------------|
| Категория бизнеса | Уровень MDR, одобрение |
| История | Условия договора |
| Оборот | Лимиты, комиссии |
| Chargeback history | Может быть отказ |

## 4. Терминалы

### 4.1 Типы терминалов

| Тип | Описание | Применение |
|-----|----------|------------|
| Стационарный | Проводное подключение | Кассы магазинов |
| Мобильный | GPRS/Wi-Fi | Рестораны, доставка |
| mPOS | Ридер + смартфон | Малый бизнес |
| Soft POS | Только смартфон | Микробизнес |
| Интегрированный | В составе кассы | Сетевой ритейл |

### 4.2 Функции терминала

- Считывание карты (магнитная полоса, чип, NFC)
- Ввод суммы и PIN
- Связь с эквайером
- Печать чека
- Возвраты и отмены

---

## 5. Комиссии эквайринга

### 5.1 MDR (Merchant Discount Rate)

**Типичные ставки в России:**

| Категория | MDR |
|-----------|-----|
| Супермаркеты | 1.5-1.8% |
| Рестораны | 1.8-2.2% |
| Онлайн-магазины | 2.5-3.5% |
| Услуги | 2.0-2.5% |
| High-risk | 5%+ |

### 5.2 Дополнительные комиссии

| Комиссия | Размер |
|----------|--------|
| Аренда терминала | 500-3000 ₽/мес |
| Подключение | 0-10 000 ₽ |
| Минимальная комиссия | 15-30 ₽/транзакция |
| SMS-уведомления | 1-3 ₽/SMS |

### 5.3 Модели ценообразования

**Blended:** Единая ставка для всех карт
**IC++:** Interchange + маржа (прозрачнее)

## 6. Интернет-эквайринг

### 6.1 Схема работы

```
Покупатель → Сайт → Платёжный шлюз → Эквайер → ПС → Эмитент
```

### 6.2 Платёжные шлюзы

**Примеры:**
- ЮKassa
- CloudPayments
- Robokassa
- Stripe, PayPal (международные)

### 6.3 Интеграция

- **Redirect** — переход на страницу шлюза
- **Embedded** — форма на сайте
- **API** — полная кастомизация
- **Плагины** — для CMS (Wordpress, Bitrix)

## 7. 3-D Secure для онлайна

### 7.1 Что это

**3-D Secure** — протокол дополнительной аутентификации для CNP-транзакций.

### 7.2 Версии

| Версия | Особенности |
|--------|-------------|
| 3DS 1.0 | Pop-up, статические пароли |
| 3DS 2.0 | Frictionless, риск-анализ, биометрия |

### 7.3 Liability shift

**При успешной 3-D Secure:**
- Ответственность за мошенничество переходит к эмитенту
- Торговец защищён от chargebacks по фроду

---

## 8. Риски эквайринга

### 8.1 Для эквайера

- **Chargebacks** — торговец может не вернуть
- **Мошенничество** — поддельные транзакции
- **Банкротство торговца** — невозможность взыскать

### 8.2 Для торговца

- **Заморозка средств** — при подозрении на фрод
- **Повышение комиссий** — при высоком chargeback rate
- **Отключение** — при нарушениях

---

## 9. Выбор эквайера

### 9.1 Критерии

| Критерий | На что смотреть |
|----------|-----------------|
| MDR | Сравнить ставки |
| Сроки выплат | T+1 vs T+3 |
| Поддержка | 24/7, качество |
| Интеграция | API, плагины |
| Дополнительные услуги | Аналитика, рассрочка |

### 9.2 Платёжные агрегаторы

**Агрегаторы** (ЮKassa, CloudPayments):
- Быстрое подключение
- Выше комиссии
- Меньше требований

**Прямой эквайринг:**
- Ниже комиссии
- Дольше подключение
- Больше требований

---

## 💡 Key Takeaways

- **Эквайринг** — услуга приёма карт для торговцев
- **Торговый vs интернет** — разные риски и комиссии
- **MDR зависит от многих факторов** — категория, оборот, история
- **3-D Secure обязателен для онлайна** — защита от фрода
- **Агрегаторы проще, прямой эквайринг дешевле**
