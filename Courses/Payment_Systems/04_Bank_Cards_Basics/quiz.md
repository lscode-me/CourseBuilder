## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | ISO/IEC 7810 ID-1 определяет размеры карты: 85.60 × 53.98 × 0.76 мм. |
| 2 | B | PAN = Primary Account Number — основной номер счёта (номер карты). |
| 3 | C | MII (Major Industry Identifier) — первая цифра определяет отрасль эмитента. |
| 4 | B | BIN/IIN состоит из первых 6-8 цифр и идентифицирует банк-эмитент. |
| 5 | B | Алгоритм Луна используется для проверки контрольной (последней) цифры номера карты. |
| 6 | B | CVV2 для Visa расположен на обороте карты, справа от полосы для подписи. |
| 7 | B | PCI DSS строго запрещает хранение CVV2 после авторизации транзакции. |
| 8 | C | Магнитная полоса содержит три дорожки (Track 1, 2, 3), хотя Track 3 обычно не используется. |
| 9 | B | EMV = Europay, Mastercard, Visa — стандарт чиповых карт. |
| 10 | B | ARQC = Authorization Request Cryptogram — криптограмма, генерируемая чипом. |
| 11 | B | Данные магнитной полосы статичны и могут быть скопированы (skimming). |
| 12 | B | ATC = Application Transaction Counter — счётчик транзакций для защиты от replay. |
| 13 | B | NFC в банковских картах работает на частоте 13.56 МГц (стандарт ISO 14443). |
| 14 | B | Лимит без PIN защищает от крупных потерь при краже/потере карты. |
| 15 | B | Токенизация — замена реального PAN на суррогатный номер (токен). |
| 16 | A | DPAN = Device Primary Account Number — токен, привязанный к устройству. |
| 17 | B | Service Code (3 цифры) определяет правила использования карты. |
| 18 | B | Track 2 содержит PAN, срок действия, service code и CVV1. |
| 19 | C | Online PIN отправляется на проверку банку-эмитенту. |
| 20 | B | Голограмма — защитный элемент от подделки карты. |
