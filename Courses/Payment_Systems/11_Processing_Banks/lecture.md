## 1. Процессинговый центр

### 1.1 Что такое процессинговый центр

**Процессинговый центр (процессор)** — технологическая платформа для обработки платёжных транзакций, обеспечивающая связь между участниками платёжной системы.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    РОЛЬ ПРОЦЕССИНГОВОГО ЦЕНТРА                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ПРОЦЕССОР — это "мозг" платёжной инфраструктуры банка                    │
│                                                                             │
│   ┌─────────────┐                                                          │
│   │ Терминалы   │──┐                                                       │
│   │ POS/ATM     │  │                                                       │
│   └─────────────┘  │     ┌──────────────────────────┐                      │
│                    │     │                          │                      │
│   ┌─────────────┐  │     │    ПРОЦЕССИНГОВЫЙ       │     ┌─────────────┐  │
│   │ E-commerce  │──┼────>│        ЦЕНТР            │────>│ Платёжные   │  │
│   │ Платежи     │  │     │                          │     │ системы     │  │
│   └─────────────┘  │     │  • Авторизация          │     │ Visa, MC    │  │
│                    │     │  • Маршрутизация         │     └─────────────┘  │
│   ┌─────────────┐  │     │  • Fraud detection      │                      │
│   │ Mobile      │──┘     │  • Card management      │     ┌─────────────┐  │
│   │ Payments    │        │  • Clearing             │────>│ Банки-      │  │
│   └─────────────┘        │  • Reporting            │     │ партнёры    │  │
│                          │                          │     └─────────────┘  │
│                          └──────────────────────────┘                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 Функции процессингового центра

| Функция | Описание |
|---------|----------|
| **Маршрутизация** | Направление транзакций к правильному получателю (эмитенту, ПС) |
| **Авторизация** | Обработка запросов, проверка лимитов, принятие решений (для эмитентского процессинга) |
| **Управление картами** | Выпуск, перевыпуск, блокировка, изменение лимитов, PIN management |
| **Fraud-мониторинг** | Анализ транзакций в реальном времени, scoring, блокировка подозрительных |
| **Клиринг** | Обмен файлами с платёжными системами, расчёт нетто-позиций |
| **Reconciliation** | Сверка транзакций между участниками |
| **Токенизация** | Замена PAN на токены для безопасных платежей |
| **3-D Secure** | Поддержка протокола аутентификации (ACS) |
| **Reporting** | Отчётность для банка, регулятора, ПС |

## 2. Банк-эмитент

### 2.1 Роль и функции эмитента

**Банк-эмитент (Issuer)** — банк, выпускающий платёжные карты и обслуживающий держателей карт.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ФУНКЦИИ БАНКА-ЭМИТЕНТА                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ВЫПУСК И УПРАВЛЕНИЕ КАРТАМИ:                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Андеррайтинг — оценка клиента для выдачи карты                    │  │
│   │ • Выпуск карт (пластик, виртуальные, токенизированные)             │  │
│   │ • Персонализация — эмбоссирование, печать данных                   │  │
│   │ • Доставка — курьером, самовывоз, instant issue                    │  │
│   │ • Перевыпуск — плановый и экстренный                               │  │
│   │ • PIN management — генерация, изменение, разблокировка             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ОБСЛУЖИВАНИЕ СЧЕТОВ:                                                      │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Ведение счетов держателей карт                                    │  │
│   │ • Управление лимитами (дневной, месячный, по категориям)           │  │
│   │ • Начисление процентов (кредитные карты)                           │  │
│   │ • Программы лояльности (кэшбэк, бонусы, мили)                      │  │
│   │ • Выписки и уведомления                                             │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   АВТОРИЗАЦИЯ:                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Получение запроса от сети (через ПС или напрямую)                │  │
│   │ • Проверка статуса карты (активна, заблокирована, expired)         │  │
│   │ • Проверка баланса/кредитного лимита                                │  │
│   │ • Fraud screening — анализ на мошенничество                        │  │
│   │ • Принятие решения (approve/decline)                                │  │
│   │ • Hold средств (для debit) или credit limit (для credit)          │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   DISPUTE MANAGEMENT:                                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Приём претензий от держателей                                     │  │
│   │ • Инициация chargeback                                              │  │
│   │ • Рассмотрение representment от эквайера                           │  │
│   │ • Арбитраж с ПС                                                      │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   КЛИЕНТСКИЙ СЕРВИС:                                                        │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Горячая линия 24/7                                                 │  │
│   │ • Мобильное приложение                                               │  │
│   │ • Интернет-банк                                                      │  │
│   │ • Блокировка карт при утере                                         │  │
│   │ • Оспаривание транзакций                                            │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 Доходы эмитента

| Источник | Описание | Примерная доля |
|----------|----------|----------------|
| **Interchange fee** | Комиссия от каждой транзакции (0.3-2%) | 30-40% |
| **Проценты (кредитные)** | Проценты на кредитную задолженность | 30-50% |
| **Комиссии** | Годовое обслуживание, снятие наличных, конвертация | 10-20% |
| **Cross-sell** | Продажа других продуктов (кредиты, страховки) | 5-10% |
| **Неиспользованные бонусы** | Сгоревшие баллы, кэшбэк | 2-5% |

## 3. Банк-эквайер

### 3.1 Роль и функции эквайера

**Банк-эквайер (Acquirer)** — банк, обслуживающий торговцев и обеспечивающий приём платежей.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ФУНКЦИИ БАНКА-ЭКВАЙЕРА                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ПОДКЛЮЧЕНИЕ ТОРГОВЦЕВ (ONBOARDING):                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Due diligence — проверка бизнеса                                  │  │
│   │ • Risk assessment — оценка риска                                    │  │
│   │ • Договор эквайринга                                                │  │
│   │ • Настройка MID (Merchant ID)                                       │  │
│   │ • Подключение к процессингу                                         │  │
│   │ • Обучение персонала                                                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ОБЕСПЕЧЕНИЕ ТЕРМИНАЛАМИ:                                                  │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • POS-терминалы (продажа или аренда)                                │  │
│   │ • Онлайн-эквайринг (payment gateway)                                │  │
│   │ • Мобильные решения (mPOS, Soft POS)                                │  │
│   │ • Интеграция с кассовым ПО                                          │  │
│   │ • Техническая поддержка                                              │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ОБРАБОТКА ТРАНЗАКЦИЙ:                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Приём транзакций от терминалов                                    │  │
│   │ • Маршрутизация к платёжным системам                                │  │
│   │ • Получение авторизации                                              │  │
│   │ • Сбор транзакций в batch                                           │  │
│   │ • Отправка на клиринг                                               │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ВЫПЛАТЫ ТОРГОВЦАМ:                                                        │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Settlement — зачисление средств на счёт торговца                 │  │
│   │ • Net settlement — за вычетом MDR                                   │  │
│   │ • Сроки: T+1, T+3, T+7 (зависит от договора)                       │  │
│   │ • Резервирование (для высокорисковых)                               │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   УПРАВЛЕНИЕ РИСКАМИ:                                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Мониторинг chargeback ratio торговцев                             │  │
│   │ • Fraud monitoring                                                   │  │
│   │ • Compliance проверки                                                │  │
│   │ • Блокировка подозрительных мерчантов                               │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   CHARGEBACK MANAGEMENT:                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ • Получение претензий от эмитентов                                  │  │
│   │ • Передача торговцу                                                  │  │
│   │ • Representment (оспаривание в пользу торговца)                    │  │

### 3.2 Доходы эквайера

| Источник | Формула | Примечание |
|----------|---------|------------|
| **Acquirer margin** | MDR − Interchange − Scheme fees | Основной доход, обычно 0.1-0.5% |
| **Аренда терминалов** | Фиксированная ежемесячная плата | 500-3000 ₽/мес за терминал |
| **Gateway fees** | Per-transaction fee | Для интернет-эквайринга |
| **Дополнительные услуги** | DCC, рассрочка, analytics | Margin services |
| **Chargeback fees** | За каждый chargeback | 500-5000 ₽ с торговца |

## 4. On-us транзакции

### 4.1 Что такое On-us

**On-us транзакция** — когда эмитент и эквайер — один и тот же банк.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ON-US vs OFF-US ТРАНЗАКЦИИ                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   OFF-US (стандартная):                                                     │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                      │  │
│   │   Держатель ──────────────────────────────────────> Торговец        │  │
│   │   (Банк A)                                          (Банк B)        │  │
│   │       │                                                │            │  │
│   │       ▼                                                ▼            │  │
│   │   Эмитент                                          Эквайер         │  │
│   │   (Банк A)  <───── Платёжная система ─────>       (Банк B)         │  │
│   │                    (Visa/MC/Мир)                                    │  │
│   │                                                                      │  │
│   │   Участники: 4 стороны                                              │  │
│   │   Interchange: платится                                             │  │
│   │   Scheme fees: платятся                                             │  │
│   │   Latency: выше (больше hops)                                       │  │
│   │                                                                      │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   ON-US:                                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │                                                                      │  │
│   │   Держатель ──────────────────────────────────────> Торговец        │  │
│   │   (Сбербанк)                                       (Сбербанк)       │  │
│   │       │                                                │            │  │
│   │       └────────────────────┬───────────────────────────┘            │  │
│   │                            ▼                                        │  │
│   │                      ┌──────────┐                                   │  │
│   │                      │ Сбербанк │                                   │  │

│   │                                                                      │  │
│   │   Участники: 2 стороны (банк = issuer + acquirer)                   │  │
│   │   Interchange: внутренний (не платится внешним)                    │  │
│   │   Scheme fees: минимальные (только если через сеть ПС)             │  │

└─────────────────────────────────────────────────────────────────────────────┘

### 4.2 Преимущества On-us

| Преимущество | Описание |
|--------------|----------|
| **Нет внешнего interchange** | Банк сохраняет всю комиссию |
| **Быстрее расчёты** | Меньше участников, проще settlement |
| **Полный контроль** | Видимость обеих сторон транзакции |
| **Лучший fraud detection** | Данные и эмитента, и эквайера |
| **Лучший сервис** | Единый процесс dispute resolution |

### 4.3 Крупные игроки с обоими направлениями

|------|---------|-----------|------------|

| **ВТБ** | #2 | #2-3 | ~20% |
| **Тинькофф** | #3-4 | Развивает | Растёт |

## 💡 Key Takeaways

- **Процессинг — технологическая основа** платежей; может быть in-house, outsourced или hybrid
- **Эмитент** выпускает карты, авторизует транзакции, управляет fraud и рисками держателей
- **Эквайер** подключает торговцев, обеспечивает терминалы, управляет chargebacks
- **On-us транзакции** выгоднее — банк сохраняет interchange и имеет полный контроль
- **Членство в ПС** бывает Principal (полные права) и Associate (через спонсора)
- **HSM** — критический компонент для защиты криптографических ключей
- **PCI DSS** обязателен для всех участников процессинга
- **Cloud и API** — ключевые тренды трансформации процессинга
