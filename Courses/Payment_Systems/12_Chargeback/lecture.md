## 1. Что такое Chargeback

### 1.1 Определение

**Chargeback** — принудительный возврат средств держателю карты по инициативе банка-эмитента.

**Ключевые особенности:**
- Инициируется эмитентом (не торговцем)
- Деньги списываются с торговца
- Торговец может оспорить
- Регулируется правилами ПС

### 1.2 Зачем это нужно

**Защита держателя карты:**
- От мошенничества
- От недобросовестных торговцев
- От ошибок (двойные списания)

**Баланс интересов:**
- Держатель защищён
- Торговец может ответить
- Платёжная система арбитражит

---

## 2. Причины Chargeback

### 2.1 Основные категории

| Категория | Код (Visa) | Описание |
|-----------|------------|----------|
| Мошенничество | 10.x | Карта использована без разрешения |
| Товар/услуга | 13.x | Не получен, не соответствует |
| Обработка | 12.x | Технические ошибки, дубликаты |
| Авторизация | 11.x | Не было авторизации |

### 2.2 Типичные причины

**Fraud (мошенничество):**
- Украденные данные карты
- Скомпрометированная карта
- Friendly fraud (ложные заявления)

**Consumer disputes:**
- Товар не получен
- Товар не соответствует описанию
- Услуга не оказана
- Отмена подписки не сработала

**Processing errors:**
- Двойное списание
- Неверная сумма
- Транзакция после отмены

### 2.3 Reason Codes

**Visa:**
- 10.1 — EMV Liability Shift Counterfeit Fraud
- 10.4 — Other Fraud - Card-Absent Environment
- 13.1 — Merchandise/Services Not Received
- 13.3 — Not as Described or Defective

**Mastercard:**
- 4837 — No Cardholder Authorization
- 4853 — Cardholder Dispute
- 4863 — Cardholder Does Not Recognize

## 3. Процесс Chargeback

### 3.1 Упрощённая схема

```
┌──────────────────────────────────────────────────────────────┐
│                  ПРОЦЕСС CHARGEBACK                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. Держатель          2. Эмитент          3. Эквайер       │
│     заявляет              проверяет           уведомляет    │
│     ↓                     ↓                   ↓             │
│  ┌─────────┐          ┌─────────┐         ┌─────────┐       │
│  │ "Я не   │ ───────► │Chargeback│ ──────►│ Списать │       │
│  │ платил!"│          │         │         │с торговца│      │
│  └─────────┘          └─────────┘         └─────────┘       │
│                                                              │
│  4. Торговец может ответить (Representment)                  │
│                                                              │
│  ┌─────────┐          ┌─────────┐         ┌─────────┐       │
│  │Документы│ ───────► │Эквайер  │ ───────►│ Эмитент │       │
│  │Доказат. │          │         │         │         │       │
│  └─────────┘          └─────────┘         └─────────┘       │
│                                                              │
│  5. Решение или арбитраж                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 Этапы

1. **Претензия держателя** — обращается в банк
2. **Проверка эмитентом** — валидность претензии
3. **First Chargeback** — эмитент инициирует возврат
4. **Уведомление торговца** — через эквайера
5. **Representment** — торговец может ответить
6. **Second Chargeback** — если эмитент не согласен
7. **Arbitration** — решение платёжной системы

---

## 4. Сроки

### 4.1 Сроки подачи

| Платёжная система | Срок для держателя |
|-------------------|-------------------|
| Visa | 120 дней от транзакции |
| Mastercard | 120 дней |
| МИР | 60-120 дней |

### 4.2 Сроки ответа

| Этап | Срок |
|------|------|
| Chargeback | 120 дней от транзакции |
| Representment | 30-45 дней от chargeback |
| Second Chargeback | 30 дней от representment |
| Arbitration | Зависит от ПС |

### 4.3 Исключения

- Отложенная доставка — сроки от даты доставки
- Подписки — от последнего списания
- Особые категории — могут быть короче/длиннее

---

## 5. Финансовые последствия

### 5.1 Для торговца

```
Оригинальная транзакция: 10 000 ₽
Chargeback:              -10 000 ₽
Комиссия за chargeback:  -500 ₽ (фиксированная)
─────────────────────────────────
Итого потери:            10 500 ₽ + товар/услуга
```

### 5.2 Комиссии за chargeback

| Тип | Размер |
|-----|--------|
| Стандартная | $15-25 / 500-1000 ₽ |
| High-risk | $25-100 |
| При арбитраже | $300-500 |

### 5.3 Chargeback Ratio

**Chargeback ratio** = Chargebacks / Транзакции × 100%

| Уровень | Последствия |
|---------|-------------|
| < 0.9% | Норма |
| 0.9-1% | Предупреждение |
| > 1% | Штрафы, повышение комиссий |
| > 2% | Риск отключения |

## 6. Friendly Fraud

### 6.1 Что это

**Friendly fraud** — когда держатель заявляет chargeback, хотя:
- Сам совершил покупку
- Получил товар/услугу
- Просто "передумал" или хочет не платить

### 6.2 Масштаб проблемы

- До 70% chargebacks — friendly fraud
- Растёт с развитием e-commerce
- Сложно доказать

### 6.3 Примеры

- "Я не помню эту покупку"
- "Это купил ребёнок без разрешения"
- "Товар не соответствует" (хотя соответствует)
- "Отмена подписки не сработала" (не пытался отменить)

---

## 7. Влияние на бизнес

### 7.1 Прямые потери

- Сумма транзакции
- Комиссия за chargeback
- Стоимость товара/услуги
- Время на обработку

### 7.2 Косвенные потери

- Повышение MDR
- Удержание средств (reserve)
- Риск отключения от эквайринга
- Репутационные потери

### 7.3 Мониторинговые программы

**Visa Dispute Monitoring Program:**
- Порог: 0.9% или 100 chargebacks
- Штрафы до $50,000/месяц
- Обязательный план улучшений

**Mastercard Excessive Chargeback Program:**
- Аналогичные требования
- Прогрессивные штрафы

## 8. Права торговца

### 8.1 Representment

**Торговец имеет право:**
- Оспорить chargeback
- Предоставить доказательства
- Получить возврат средств

### 8.2 Что предоставить

- Подтверждение доставки
- Подпись клиента
- Переписка с клиентом
- Доказательство использования услуги
- IP-адрес, device fingerprint

### 8.3 Когда оспаривать

**Стоит оспаривать:**
- Есть убедительные доказательства
- Сумма оправдывает затраты
- Явный friendly fraud

**Не стоит оспаривать:**
- Действительно ошибка торговца
- Нет доказательств
- Мелкая сумма (дешевле принять)

## 9. Предотвращение Chargebacks

### 9.1 Лучшие практики

| Практика | Эффект |
|----------|--------|
| Ясный descriptor | Клиент узнаёт покупку |
| Быстрая доставка + трекинг | Подтверждение получения |
| Отзывчивая поддержка | Решение до chargeback |
| 3-D Secure | Liability shift |
| Fraud detection | Блокировка подозрительных |

### 9.2 Descriptor

**Billing descriptor** — название в выписке клиента.

**Плохо:** "ACME CORP LLC"
**Хорошо:** "SHOP.RU*Заказ 12345"

### 9.3 Предупреждения (Alerts)

Сервисы раннего предупреждения:
- Ethoca Alerts (Mastercard)
- Verifi CDRN (Visa)

Позволяют вернуть деньги до chargeback.

## 💡 Key Takeaways

- **Chargeback — принудительный возврат** по инициативе эмитента
- **120 дней** — типичный срок для подачи
- **Friendly fraud** — до 70% chargebacks
- **Ratio > 1%** — штрафы и риск отключения
- **Торговец может оспорить** — representment с доказательствами
