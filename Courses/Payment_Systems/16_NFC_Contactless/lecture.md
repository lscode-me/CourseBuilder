## 1. Технология NFC

### 1.1 Что это

**NFC (Near Field Communication)** — технология беспроводной связи малого радиуса действия.

**Характеристики:**
- Частота: 13.56 МГц
- Дальность: до 4 см
- Скорость: 424 кбит/с
- Стандарт: ISO 14443

### 1.2 Режимы работы

| Режим | Описание |
|-------|----------|
| Card emulation | Устройство работает как карта |
| Reader | Устройство читает карту |
| P2P | Обмен между устройствами |

## 2. Бесконтактные карты

### 2.1 Как работают

1. Карта подносится к терминалу (< 4 см)
2. Терминал создаёт электромагнитное поле
3. Поле индуцирует ток в антенне карты
4. Чип получает питание и активируется
5. Происходит обмен данными
6. Генерируется криптограмма (EMV)

### 2.2 Лимиты без PIN

| Страна | Лимит |
|--------|-------|
| Россия | 3 000 - 5 000 ₽ |
| Великобритания | £100 |
| Еврозона | €50 |

## 3. Мобильные кошельки

### 3.1 Основные игроки

| Кошелёк | Платформа | Запуск |
|---------|-----------|--------|
| Apple Pay | iOS | 2014 |
| Google Pay | Android | 2015 |
| Samsung Pay | Samsung | 2015 |
| Mir Pay | Android (Россия) | 2019 |

### 3.2 Как работают

```
1. Добавление карты → Верификация эмитентом
2. Генерация DPAN (Device PAN)
3. DPAN хранится в Secure Element
4. При оплате: DPAN + криптограмма
```

### 3.3 Secure Element

**Secure Element** — защищённый чип для хранения криптоключей:
- В SIM-карте
- В чипе устройства
- В облаке (HCE)

---

## 4. Токенизация

### 4.1 Схема

```
Реальный PAN:     4276 1234 5678 9012
                         ↓
Token (DPAN):     4276 9999 0000 1111

DPAN работает только:
- На конкретном устройстве
- С криптограммой
```

### 4.2 Преимущества

- Реальный PAN не передаётся
- Токен бесполезен без устройства
- Можно отозвать без замены карты
- Ограничение по merchant/channel

### 4.3 Token Service Providers

| ПС | Сервис |
|----|--------|
| Visa | VTS (Visa Token Service) |
| Mastercard | MDES |
| МИР | НСПК токенизация |

## 5. Безопасность

### 5.1 Аутентификация

| Метод | Описание |
|-------|----------|
| Touch ID | Отпечаток пальца |
| Face ID | Распознавание лица |
| PIN устройства | Код разблокировки |

### 5.2 Защитные механизмы

- Биометрия обязательна для оплаты
- Данные не покидают устройство
- Криптограмма уникальна для транзакции
- Нельзя скопировать токен

---

## 6. Samsung Pay MST

### 6.1 Особенность

**MST (Magnetic Secure Transmission)** — эмуляция магнитной полосы.

Работает на терминалах без NFC!

### 6.2 Как работает

Устройство генерирует магнитное поле, имитирующее свайп карты.

### 6.3 Ограничения

- Только Samsung
- Постепенно убирается
- Менее безопасно

---

## 7. Для бизнеса

### 7.1 Приём NFC

- Современные терминалы поддерживают NFC
- Tap to Phone (Soft POS) — смартфон как терминал

### 7.2 Преимущества

- Быстрее обслуживание
- Выше конверсия
- Гигиеничнее (пандемия)
- Меньше износ терминала

---

## 💡 Key Takeaways

- **NFC** — бесконтактная связь до 4 см
- **Мобильные кошельки** используют токенизацию (DPAN)
- **Secure Element** защищает криптоключи
- **Биометрия** обязательна для оплаты
- **Реальный PAN** никогда не передаётся
