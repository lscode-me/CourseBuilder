## 1. Основы блокчейна и криптоплатежей

### 1.1 Что такое блокчейн

**Блокчейн** — распределённый реестр (Distributed Ledger Technology, DLT), где транзакции записываются в связанные блоки, защищённые криптографией.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         СТРУКТУРА БЛОКЧЕЙНА                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌────────────┐      ┌────────────┐      ┌────────────┐      ┌──────────┐ │
│   │  Блок #1   │──────│  Блок #2   │──────│  Блок #3   │──────│  Блок N  │ │
│   │ (Genesis)  │      │            │      │            │      │          │ │
│   ├────────────┤      ├────────────┤      ├────────────┤      ├──────────┤ │
│   │ Hash: 0x0  │      │ Prev: 0xA  │      │ Prev: 0xB  │      │ Prev:0xC │ │
│   │ Txns: []   │      │ Hash: 0xA  │      │ Hash: 0xB  │      │ Hash:0xC │ │
│   │ Nonce: 123 │      │ Txns: [...│      │ Txns: [...]│      │ Txns:[.] │ │
│   │ Time: T0   │      │ Time: T1   │      │ Time: T2   │      │ Time: TN │ │
│   └────────────┘      └────────────┘      └────────────┘      └──────────┘ │
│                                                                             │
│   Каждый блок содержит:                                                     │
│   • Hash предыдущего блока (связь цепочки)                                 │
│   • Собственный hash (уникальный идентификатор)                            │
│   • Список транзакций                                                       │
│   • Временная метка                                                         │
│   • Nonce (для Proof of Work)                                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 Как работают криптоплатежи

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      ПРОЦЕСС КРИПТОПЛАТЕЖА                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. СОЗДАНИЕ ТРАНЗАКЦИИ                                                    │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Отправитель создаёт транзакцию:                                     │  │
│   │ • From: адрес_отправителя (публичный ключ)                          │  │
│   │ • To: адрес_получателя                                               │  │
│   │ • Amount: сумма                                                      │  │
│   │ • Fee: комиссия майнерам/валидаторам                                │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   2. ПОДПИСАНИЕ                                                             │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Приватный ключ отправителя создаёт цифровую подпись                 │  │
│   │ → Подтверждает владение средствами                                   │  │
│   │ → Делает транзакцию неизменяемой                                    │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   3. BROADCAST                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Транзакция отправляется в сеть (mempool)                            │  │
│   │ → Распространяется между нодами                                     │  │
│   │ → Ожидает включения в блок                                          │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   4. ВАЛИДАЦИЯ И ВКЛЮЧЕНИЕ В БЛОК                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Майнеры/валидаторы:                                                  │  │
│   │ • Проверяют подпись и баланс                                        │  │
│   │ • Включают в блок                                                    │  │
│   │ • Создают новый блок                                                 │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                              │                                              │
│                              ▼                                              │
│   5. ПОДТВЕРЖДЕНИЯ                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Каждый новый блок = дополнительное подтверждение                    │  │
│   │ • 1 подтверждение: блок с транзакцией найден                        │  │
│   │ • 3 подтверждения: обычно достаточно для малых сумм                │  │
│   │ • 6 подтверждений: стандарт для Bitcoin (~60 мин)                   │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 1.3 Сравнение с традиционными платежами

| Аспект | Традиционные платежи | Криптоплатежи |
|--------|---------------------|---------------|
| Посредники | Банки, платёжные системы | Нет (P2P) |
| Скорость | Секунды — дни | Секунды — минуты |
| Комиссия | % от суммы | Фиксированная (зависит от сети) |
| Отмена транзакции | Возможна (чарджбэк) | Невозможна |
| Приватность | Полная идентификация | Псевдоанонимность |
| Время работы | Рабочие часы/дни | 24/7/365 |
| География | Ограничения | Без границ |
| Требования | Банковский счёт | Только кошелёк |
| Контроль | Централизованный | Децентрализованный |

## 2. Bitcoin как платёжное средство

### 2.1 Характеристики Bitcoin

**Bitcoin (BTC)** — первая криптовалюта, созданная в 2009 году Сатоши Накамото.

| Параметр | Значение |
|----------|----------|
| Максимальная эмиссия | 21 000 000 BTC |
| Время блока | ~10 минут |
| Размер блока | 1-4 MB (с SegWit) |
| Консенсус | Proof of Work (SHA-256) |
| Halving | Каждые 210 000 блоков (~4 года) |
| Транзакций в секунду | 3-7 TPS (on-chain) |

### 2.2 Проблемы Bitcoin для платежей

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ПРОБЛЕМЫ BITCOIN ДЛЯ ПЛАТЕЖЕЙ                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   🔴 ВОЛАТИЛЬНОСТЬ                                                          │
│   • Курс может измениться на 5-10% за день                                 │
│   • Сложно устанавливать цены                                               │
│   • Риск для продавца и покупателя                                         │
│                                                                             │
│   🔴 МЕДЛЕННОСТЬ                                                            │
│   • 10 минут на 1 подтверждение                                            │
│   • 60 минут для 6 подтверждений (стандарт)                                │
│   • Не подходит для POS-транзакций                                         │
│                                                                             │
│   🔴 ВЫСОКИЕ КОМИССИИ                                                       │
│   • При загрузке сети: $10-50 за транзакцию                                │
│   • Не подходит для микроплатежей                                          │
│   • Комиссия не зависит от суммы                                           │
│                                                                             │
│   🔴 МАСШТАБИРУЕМОСТЬ                                                       │
│   • 7 TPS vs 65 000 TPS у Visa                                             │
│   • Ограничение размера блока                                               │
│   • Дорогая запись в блокчейн                                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.3 Lightning Network — решение для платежей

**Lightning Network** — Layer 2 решение для мгновенных платежей Bitcoin.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       LIGHTNING NETWORK                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ПРИНЦИП РАБОТЫ:                                                           │
│                                                                             │
│   1. ОТКРЫТИЕ КАНАЛА                                                        │
│   ┌────────────────────────────────────────────────────────────────────┐   │
│   │  Алиса ────────[on-chain TX: 0.1 BTC]────────> Payment Channel     │   │
│   │         Создаётся мультисиг-адрес, средства блокируются            │   │
│   └────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   2. ПЛАТЕЖИ ВНУТРИ КАНАЛА                                                  │
│   ┌────────────────────────────────────────────────────────────────────┐   │
│   │  Алиса ←═════[мгновенные off-chain платежи]═════→ Боб              │   │
│   │         Баланс канала обновляется без записи в блокчейн            │   │
│   │         • Платёж 1: Алиса → Боб: 0.01 BTC                          │   │
│   │         • Платёж 2: Боб → Алиса: 0.005 BTC                         │   │
│   │         • Платёж 3: Алиса → Боб: 0.02 BTC                          │   │
│   └────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   3. МАРШРУТИЗАЦИЯ ЧЕРЕЗ УЗЛЫ                                               │
│   ┌────────────────────────────────────────────────────────────────────┐   │
│   │  Алиса ──[канал]── Нода1 ──[канал]── Нода2 ──[канал]── Карл       │   │
│   │  (Платёж находит путь через сеть каналов)                          │   │
│   └────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   4. ЗАКРЫТИЕ КАНАЛА                                                        │
│   ┌────────────────────────────────────────────────────────────────────┐   │
│   │  Финальный баланс записывается on-chain                            │   │
│   │  Алиса: 0.065 BTC, Боб: 0.035 BTC                                  │   │
│   └────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│   ПРЕИМУЩЕСТВА:                                                             │
│   ✓ Мгновенные платежи (миллисекунды)                                      │
│   ✓ Комиссии < 1 сатоши (практически бесплатно)                            │
│   ✓ Микроплатежи (доли цента)                                              │
│   ✓ Приватность (off-chain)                                                 │
│   ✓ Масштабируемость (миллионы TPS)                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.4 Bitcoin-платёжные процессоры

## 3. Стейблкоины

### 3.1 Что такое стейблкоин

**Стейблкоин** — криптовалюта, привязанная к стабильному активу (обычно USD), сохраняющая преимущества блокчейна без волатильности.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        ЗАЧЕМ НУЖНЫ СТЕЙБЛКОИНЫ                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ПРОБЛЕМА                        РЕШЕНИЕ                                   │
│   ─────────                       ───────                                   │
│   Bitcoin волатильный         →   Стабильная цена ($1 = 1 USDT)            │
│   Сложно торговать            →   Легко входить/выходить из позиций        │
│   Невозможно планировать      →   Предсказуемость для бизнеса              │
│   Традиционные переводы       →   Быстрые международные переводы           │
│   дорогие и медленные             за минуты и центы                        │
│                                                                             │
│   ПРИМЕНЕНИЯ:                                                               │
│   • Международные переводы (remittances)                                   │
│   • B2B расчёты между странами                                             │
│   • Оплата фрилансеров                                                      │
│   • Торговля на криптобиржах                                                │
│   • DeFi протоколы (lending, yield farming)                                 │
│   • Хеджирование от волатильности                                          │
│   • Хранение средств в странах с нестабильной валютой                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 Типы стейблкоинов по обеспечению

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      ТИПЫ СТЕЙБЛКОИНОВ                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   1. FIAT-BACKED (обеспечены фиатом)                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Механизм: На каждый токен в банке хранится $1                       │  │
│   │                                                                      │  │
│   │ Примеры: USDT, USDC, TUSD, USDP                                     │  │
│   │                                                                      │  │
│   │ Плюсы:                           Минусы:                            │  │
│   │ ✓ Простой и понятный механизм   ✗ Требует доверия к эмитенту       │  │
│   │ ✓ Стабильность 1:1              ✗ Централизованный контроль        │  │
│   │ ✓ Легко конвертировать          ✗ Риск заморозки средств           │  │
│   │                                  ✗ Регуляторные риски               │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   2. CRYPTO-BACKED (обеспечены криптовалютой)                              │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Механизм: Overcollateralization (залог > 100%)                      │  │
│   │                                                                      │  │
│   │ Пример DAI:                                                          │  │
│   │ • Залог ETH стоимостью $150 → получаешь 100 DAI ($100)              │  │
│   │ • Если ETH падает, нужно довнести залог или произойдёт ликвидация  │  │
│   │                                                                      │  │
│   │ Плюсы:                           Минусы:                            │  │
│   │ ✓ Децентрализованный             ✗ Сложный механизм                 │  │
│   │ ✓ Прозрачный on-chain            ✗ Неэффективность капитала        │  │
│   │ ✓ Нет доверия к компании         ✗ Риск каскадных ликвидаций       │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   3. ALGORITHMIC (алгоритмические)                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐  │
│   │ Механизм: Алгоритм регулирует предложение                           │  │
│   │                                                                      │  │
│   │ • Цена > $1 → выпуск новых токенов                                  │  │
│   │ • Цена < $1 → сжигание токенов или арбитраж                        │  │
│   │                                                                      │  │
│   │ ⚠️ ВЫСОКИЙ РИСК: UST/LUNA крах в мае 2022                          │  │
│   │    $40 млрд капитализации → ~$0 за несколько дней                  │  │
│   │                                                                      │  │
│   │ Плюсы:                           Минусы:                            │  │
│   │ ✓ Эффективность капитала         ✗ Экспериментальные               │  │
│   │ ✓ Полностью децентрализованные   ✗ Высокий риск depeg             │  │
│   │                                  ✗ Исторически терпели крах        │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. CBDC (цифровые валюты центральных банков)

### 4.1 Что такое CBDC

**CBDC (Central Bank Digital Currency)** — цифровая форма национальной валюты, выпускаемая и контролируемая центральным банком.

```
┌─────────────────────────────────────────────────────────────────────────────┐

### 7.1 Типы кошельков

│   │                                                                      │  │

│   ┌─────────────────────────────────────────────────────────────────────┐  │

│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 7.2 Рекомендации по безопасности

| Уровень | Действие | Описание |
|---------|----------|----------|
| 🔴 Критично | Seed-фраза офлайн | Никогда не храните в облаке или на телефоне |
| 🔴 Критично | Проверка адреса | Сверяйте все символы перед отправкой |
| 🟠 Важно | Hardware wallet | Для сумм > $1000 используйте холодное хранение |

### 8.2 Требования для криптобизнеса

| Требование | Описание | Примеры |
|------------|----------|---------|
| **Лицензия VASP** | Virtual Asset Service Provider | Биржи, custodians |
| **KYC (Know Your Customer)** | Идентификация клиентов | Паспорт, selfie, proof of address |
| **AML (Anti-Money Laundering)** | Противодействие отмыванию | Мониторинг транзакций, SAR |
| **Travel Rule** | Передача данных об отправителе/получателе | FATF требование для переводов > $1000 |
| **Налоговая отчётность** | Декларирование доходов | Form 1099 (США), уведомления в РФ |

### 8.3 MiCA (ЕС)

**MiCA (Markets in Crypto-Assets Regulation)** — единый регуляторный framework для криптоактивов в ЕС (с 2024).

| Категория | Требования |
|-----------|------------|
| **Стейблкоины (ART, EMT)** | Лицензия EMI, резервные требования, лимиты объёма |
| **Крипто-сервисы (CASP)** | Лицензия CASP, капитальные требования, защита потребителей |
| **Эмитенты токенов** | White paper, ответственность за информацию |

## 💡 Key Takeaways

- **Криптоплатежи** — P2P переводы без посредников на основе блокчейна
- **Волатильность Bitcoin** решается через **стейблкоины** (USDT, USDC) и **Lightning Network**
- **Стейблкоины** различаются по типу обеспечения: fiat-backed наиболее надёжны
- **CBDC** — цифровые деньги центральных банков с полным государственным контролем
- **Для бизнеса** криптоплатежи проще принимать через процессоры (BitPay, BTCPay Server)
- **Регулирование** развивается — MiCA в ЕС, лицензии VASP по всему миру
- **Безопасность** требует разделения hot/cold кошельков и защиты seed-фразы
- **Будущее** за интеграцией крипто в традиционные финансы и улучшением UX
