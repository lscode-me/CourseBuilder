# Криптовалюты и блокчейн-платежи
## Stablecoins, CBDC и децентрализованные платежи

---

## 🎯 Learning Objectives

- Понимать основы криптовалютных платежей
- Знать стейблкоины и их применение
- Понимать CBDC и их отличия от криптовалют

---

## 1. Основы криптоплатежей

### 1.1 Как работают

```
Отправитель → Подписывает транзакцию → Сеть блокчейна → Подтверждение → Получатель
```

### 1.2 Особенности

| Аспект | Традиционные | Криптоплатежи |
|--------|--------------|---------------|
| Посредники | Банки, ПС | Нет (P2P) |
| Скорость | Секунды-дни | Секунды-минуты |
| Комиссия | % от суммы | Фиксированная |
| Отмена | Возможна | Невозможна |
| Анонимность | Нет | Псевдоанонимность |

---

## 2. Bitcoin платежи

### 2.1 Характеристики

- Первая криптовалюта
- Высокая волатильность
- Медленные транзакции (10 мин)
- Высокие комиссии (при загрузке)

### 2.2 Lightning Network

- Layer 2 решение
- Мгновенные платежи
- Минимальные комиссии
- Для микроплатежей

### 2.3 Для бизнеса

- BitPay, Coinbase Commerce
- Конвертация в фиат
- Защита от волатильности

---

## 3. Стейблкоины

### 3.1 Что это

**Стейблкоин** — криптовалюта с привязкой к фиату (обычно USD).

### 3.2 Типы

| Тип | Обеспечение | Примеры |
|-----|-------------|---------|
| Fiat-backed | USD в банке | USDT, USDC |
| Crypto-backed | Криптовалюта | DAI |
| Algorithmic | Алгоритм | UST (крах 2022) |

### 3.3 Популярные

| Стейблкоин | Сеть | Капитализация |
|------------|------|---------------|
| USDT (Tether) | Multi-chain | ~$80B |
| USDC (Circle) | Multi-chain | ~$30B |
| DAI | Ethereum | ~$5B |

### 3.4 Применение

- Международные переводы
- B2B платежи
- Хедж от волатильности
- DeFi

---

## 4. CBDC (цифровые валюты ЦБ)

### 4.1 Что это

**CBDC** — цифровая валюта, выпущенная центральным банком.

### 4.2 Отличия от криптовалют

| Аспект | Криптовалюты | CBDC |
|--------|--------------|------|
| Эмитент | Децентрализованно | Центральный банк |
| Контроль | Нет | Полный |
| Анонимность | Псевдоанонимность | Нет |
| Волатильность | Высокая | Нет |

### 4.3 Проекты

| Страна | Проект | Статус |
|--------|--------|--------|
| Китай | e-CNY | Пилот |
| Россия | Цифровой рубль | Пилот |
| ЕС | Digital Euro | Разработка |
| США | Исследование | Ранняя стадия |

### 4.4 Возможности CBDC

- Программируемые деньги
- Целевые выплаты
- Отслеживание всех транзакций
- Отрицательные ставки

## 5. Приём криптоплатежей

### 5.1 Способы

1. **Напрямую** — кошелёк торговца
2. **Процессор** — BitPay, Coinbase Commerce
3. **Агрегатор** — NOWPayments

### 5.2 Процессоры

| Процессор | Комиссия | Особенности |
|-----------|----------|-------------|
| BitPay | 1% | Конвертация в фиат |
| Coinbase Commerce | 0% | Остаётся в крипто |
| CoinGate | 1% | Много криптовалют |

### 5.3 Пример интеграции

```json
// Создание инвойса
POST /invoices
{
  "amount": 100.00,
  "currency": "USD",
  "crypto_currency": "BTC",
  "callback_url": "https://merchant.com/webhook"
}

// Ответ
{
  "invoice_id": "INV-123",
  "payment_address": "bc1q...",
  "amount_crypto": 0.0025,
  "expires_at": "2024-01-15T12:30:00Z"
}
```

## 6. Риски криптоплатежей

### 6.1 Для торговца

| Риск | Решение |
|------|---------|
| Волатильность | Моментальная конвертация |
| Регуляторный | Комплаенс, лицензии |
| Техническая сложность | Использовать процессоры |
| Фрод | Дождаться подтверждений |

### 6.2 Для покупателя

- Ошибочный перевод необратим
- Потеря ключей = потеря средств
- Мошеннические схемы

## 7. Международные переводы

### 7.1 Традиционные vs Крипто

| Аспект | SWIFT | Стейблкоины |
|--------|-------|-------------|
| Скорость | 1-5 дней | Минуты |
| Комиссия | $20-50+ | $0.1-1 |
| Доступность | Банковский счёт | Кошелёк |
| Лимиты | Ограничения | Нет |

### 7.2 Применение

- Ремиттансы (переводы мигрантов)
- B2B между странами
- Оплата фрилансеров
