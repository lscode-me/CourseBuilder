## 1. Этапы диспута

### 1.1 Обзор

```
Претензия → First Chargeback → Representment → Second Chargeback → Arbitration
   │              │                  │                │               │
   ▼              ▼                  ▼                ▼               ▼
Держатель     Эмитент            Торговец         Эмитент            ПС
заявляет      возвращает         отвечает        не согласен      решает
              деньги             доказательства
```

---

## 2. First Chargeback

### 2.1 Инициация

1. Держатель обращается в банк
2. Эмитент проверяет заявление
3. Эмитент создаёт chargeback
4. Сообщение идёт через ПС к эквайеру
5. Эквайер уведомляет торговца
6. Деньги списываются с торговца

### 2.2 Информация в chargeback

- Номер транзакции
- Сумма
- Reason code
- Дата транзакции
- Описание причины

---

## 3. Representment

### 3.1 Решение торговца

**Принять chargeback:**
- Признать ошибку
- Нет доказательств
- Экономически нецелесообразно оспаривать

**Оспорить (Representment):**
- Есть доказательства
- Сумма значительная
- Явный friendly fraud

### 3.2 Compelling Evidence

| Причина chargeback | Необходимые доказательства |
|--------------------|---------------------------|
| Товар не получен | Tracking, подпись, фото |
| Мошенничество | 3DS, IP, device fingerprint |
| Не соответствует | Описание товара, переписка |
| Подписка | Terms, история оплат |

### 3.3 Формат ответа

- Сопроводительное письмо
- Документы-доказательства
- Ссылки на правила ПС

---

## 4. Second Chargeback (Pre-Arbitration)

### 4.1 Когда возникает

Если эмитент не согласен с representment:
- Представленные доказательства недостаточны
- Держатель настаивает
- Новые аргументы

### 4.2 Действия торговца

1. Принять (не оспаривать)
2. Оспорить и идти в арбитраж

---

## 5. Arbitration

### 5.1 Процесс

1. Одна из сторон подаёт на арбитраж
2. Платёжная система рассматривает
3. Решение обязательно для сторон
4. Проигравший платит комиссию

### 5.2 Стоимость

| Платёжная система | Комиссия арбитража |
|-------------------|--------------------|
| Visa | $300-500 |
| Mastercard | $300-500 |

### 5.3 Когда идти в арбитраж

✅ **Да:**
- Крупная сумма
- Железные доказательства
- Принципиальный случай

❌ **Нет:**
- Мелкая сумма
- Слабые доказательства
- Высокие шансы проиграть

---

## 6. Сроки на каждом этапе

| Этап | Срок |
|------|------|
| First Chargeback | 120 дней от транзакции |
| Representment | 30-45 дней |
| Second Chargeback | 30 дней |
| Arbitration filing | 10-30 дней |

---

## 7. Win Rate

### 7.1 Статистика

- Средний win rate representment: 20-40%
- С хорошими доказательствами: до 70%
- Без доказательств: < 10%

### 7.2 Факторы успеха

| Фактор | Влияние |
|--------|---------|
| Качество доказательств | Высокое |
| Тип reason code | Среднее |
| Сумма транзакции | Низкое |
| История торговца | Низкое |

---

## 8. Best Practices

### 8.1 Для торговца

1. **Отвечайте быстро** — не пропускайте сроки
2. **Собирайте доказательства** — с момента покупки
3. **Знайте reason codes** — разные требования
4. **Используйте шаблоны** — стандартизируйте ответы
5. **Анализируйте** — учитесь на проигрышах

### 8.2 Документирование

- Сохраняйте всю переписку
- Используйте tracking с подписью
- Логируйте IP и device data
- Храните screenshots

---

## 💡 Key Takeaways

- **Процесс многоэтапный** — от претензии до арбитража
- **Representment — право торговца** — нужны доказательства
- **Сроки критичны** — пропуск = проигрыш
- **Арбитраж дорогой** — только для важных случаев
- **Win rate зависит от доказательств**
