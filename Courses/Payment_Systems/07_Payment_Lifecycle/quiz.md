## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Авторизация обычно занимает 2-3 секунды. |
| 2 | B | Запрос проходит: Терминал → Эквайер → Платёжная система → Эмитент. |
| 3 | B | BIN используется для определения банка-эмитента и маршрутизации запроса. |
| 4 | B | ARQC — криптограмма, подтверждающая подлинность карты в EMV-транзакции. |
| 5 | C | Эмитент проверяет данные о карте и держателе, не о торговце. |
| 6 | B | Код 00 означает "Approved" — транзакция одобрена. |
| 7 | B | Код 51 означает "Insufficient funds" — недостаточно средств. |
| 8 | B | Код 05 не раскрывает причину из соображений безопасности. |
| 9 | B | После авторизации средства блокируются (холд), но фактически не списываются. |
| 10 | B | Authorization Code — уникальный 6-символьный код одобренной транзакции. |
| 11 | B | Pre-auth резервирует сумму, когда финальная сумма неизвестна (отели, аренда). |
| 12 | B | Capture — подтверждение и фактическое списание суммы после pre-auth. |
| 13 | C | Для отелей и аренды авто холд может держаться до 30 дней. |
| 14 | B | Void — отмена транзакции до клиринга/расчётов. |
| 15 | B | Offline-авторизация происходит, когда терминал не может связаться с эмитентом. |
| 16 | B | ISO 8583 — стандартный формат сообщений финансовых транзакций. |
| 17 | C | Цвет карты не анализируется при fraud-проверке. |
| 18 | B | При timeout возникает ошибка связи, статус транзакции неизвестен. |
| 19 | B | Stand-in — одобрение платёжной системой при недоступности эмитента. |
| 20 | B | Доступно = 50 000 − 1 500 = 48 500 ₽ (баланс минус холд). |
