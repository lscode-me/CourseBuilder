## 1. Введение

Когда вы платите картой за границей или покупаете на иностранном сайте, происходит валютная конвертация. Кажется простым: рубли превращаются в евро или доллары. Но кто устанавливает курс? Кто зарабатывает? И можно ли платить выгоднее?

Понимание валютных механизмов поможет:
- Не переплачивать при платежах
- Выбирать правильную валюту
- Понимать выписку по карте

## 2. Валюты в карточных платежах

### 2.1 Три валюты в транзакции

В международном платеже могут участвовать три валюты:

| Валюта | Описание | Пример |
|--------|----------|--------|
| **Transaction currency** | Валюта, в которой выставлен счёт | Цена в магазине: €50 |
| **Billing currency** | Валюта счёта держателя | Карта привязана к счёту в ₽ |
| **Settlement currency** | Валюта расчётов между банками | Обычно USD или EUR |

### 2.2 Пример мультивалютной транзакции

Российский турист платит в Германии:

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Покупка: €50          Списание: 5 250 ₽                    │
│                                                             │
│  ┌─────────┐    €50    ┌─────────┐    $53    ┌─────────┐   │
│  │ Магазин │ ───────►  │ Эквайер │ ───────►  │  Visa   │   │
│  └─────────┘           └─────────┘           └────┬────┘   │
│                                                   │        │
│                                              $53  │        │
│                                                   ▼        │
│  ┌─────────┐   5 250 ₽ ┌─────────┐    $53    ┌─────────┐   │
│  │ Клиент  │ ◄──────── │ Эмитент │ ◄──────── │  Visa   │   │
│  └─────────┘           └─────────┘           └─────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 Где происходит конвертация

**Конвертация может происходить:**
1. **На стороне эквайера** — редко
2. **В платёжной системе** — при Settlement
3. **На стороне эмитента** — при списании со счёта

Чаще всего конвертация происходит на стороне эмитента или платёжной системы.

## 3. Валютные курсы

### 3.1 Типы курсов

| Тип | Описание | Кто устанавливает |
|-----|----------|-------------------|
| **Межбанковский** | Реальный рыночный курс | Рынок (Forex) |
| **Курс ЦБ** | Официальный курс | Центральный банк |
| **Курс платёжной системы** | Для расчётов между банками | Visa, Mastercard |
| **Курс банка** | Для конвертации клиенту | Ваш банк-эмитент |

### 3.2 Межбанковский курс

**Interbank rate** — курс, по которому крупные банки торгуют валютой между собой.

- Самый выгодный курс
- Недоступен обычным клиентам напрямую
- Меняется каждую секунду
- Разница между покупкой и продажей минимальна

**Пример:** EUR/USD = 1.08 межбанковский

### 3.3 Спред (Spread)

**Спред** — разница между курсом покупки и продажи валюты.

```
Покупка (Bid):  1.0750
Продажа (Ask):  1.0850
Спред:          0.0100 (≈0.9%)
```

**Кто зарабатывает на спреде:**
- Банки
- Обменные пункты
- Платёжные системы

### 3.4 Markup (наценка)

**Markup** — дополнительная наценка сверх межбанковского курса.

```
Межбанковский курс:     1.0800
Markup банка:           +2%
Курс для клиента:       1.1016
```

**Типичные наценки:**
- Платёжные системы: 0-1%
- Банки: 1-3%
- Обменные пункты: 2-5%

## 4. Курсы платёжных систем

### 4.1 Visa и Mastercard

Обе платёжные системы публикуют свои курсы:

**Visa:**
- [Currency Converter](https://usa.visa.com/support/consumer/travel-support/exchange-rate-calculator.html)
- Курс обновляется ежедневно
- Применяется markup 0-3%

**Mastercard:**
- [Currency Conversion Calculator](https://www.mastercard.us/en-us/personal/get-support/convert-currency.html)
- Курс обновляется ежедневно
- Конкурентный курс

### 4.2 Когда применяется курс

**Важно:** Курс применяется в момент Settlement, а не авторизации!

```
День 1 (понедельник):
  - Покупка за €100
  - Курс ЦБ: 1 EUR = 98 ₽
  - Авторизация: холд ~9 800 ₽
  
День 2 (вторник):
  - Settlement (расчёты)
  - Курс изменился: 1 EUR = 100 ₽
  - Фактическое списание: 10 000 ₽
```

> **⚠️ Внимание:**  
> Сумма списания может отличаться от суммы холда из-за изменения курса!

### 4.3 Расчёт полной стоимости

**Формула:**

```
Итоговая сумма = Сумма покупки × Курс ПС × (1 + Markup банка) × (1 + Комиссия)
```

**Пример:**
- Покупка: €100
- Курс Visa EUR/RUB: 98.50
- Markup банка: 2%
- Комиссия за конвертацию: 0%

```
100 × 98.50 × 1.02 = 10 047 ₽
```

## 5. Dynamic Currency Conversion (DCC)

### 5.1 Что такое DCC

**DCC (Dynamic Currency Conversion)** — услуга, при которой конвертация происходит в точке продажи, а не в вашем банке.

**Как это выглядит:**

```
На экране терминала:

Сумма: €50

Выберите валюту списания:
[  €50.00 (EUR)  ]
[  5 500 ₽ (RUB) ]  ← DCC

Конвертация по курсу: 1 EUR = 110 ₽
```

### 5.2 Как работает DCC

```
БЕЗ DCC:                          С DCC:
€50 → Visa → Банк → ₽            €50 → DCC оператор → ₽
Конвертация: ваш банк            Конвертация: терминал
Курс: выгодный                   Курс: невыгодный
```

### 5.3 Почему DCC невыгоден

**Типичные наценки DCC: 5-8%**

| Способ | Курс EUR/RUB | За €50 заплатите |
|--------|--------------|------------------|
| Курс банка (2% markup) | 100.00 | 5 000 ₽ |
| DCC курс (7% markup) | 107.00 | 5 350 ₽ |
| **Переплата** | | **350 ₽** |

### 5.4 Кто зарабатывает на DCC

- **DCC-провайдер** (процессинговая компания)
- **Эквайер**
- **Торговец** (получает часть комиссии)

> **💡 Совет:**  
> Всегда выбирайте оплату в местной валюте (валюте магазина). Отклоняйте предложение DCC!

### 5.5 Как избежать DCC

1. **На терминале:** Выберите "Local currency" или "EUR/USD"
2. **Онлайн:** Выбирайте цену в валюте сайта
3. **Банкомат:** Отклоните "конвертацию" — выберите валюту счёта банкомата

## 6. Мультивалютные карты и счета

### 6.1 Карта с мультивалютным счётом

Некоторые банки позволяют держать несколько валют:

```
┌────────────────────────────┐
│    Мультивалютная карта    │
├────────────────────────────┤
│  Счёт в RUB: 50 000 ₽      │
│  Счёт в USD: $500          │
│  Счёт в EUR: €300          │
└────────────────────────────┘
```

**Логика списания:**
1. Если есть нужная валюта — списывается с неё
2. Если нет — конвертация из основной валюты

### 6.2 Преимущества

- **Нет конвертации** при платежах в поддерживаемых валютах
- **Контроль курса** — можно заранее купить валюту
- **Прозрачность** — знаете, сколько потратили

### 6.3 Недостатки

- Нужно следить за балансами
- Может быть комиссия за ведение счёта
- Не все валюты поддерживаются

## 7. Конвертация при расчётах

### 7.1 Settlement в платёжных системах

Visa и Mastercard ведут расчёты преимущественно в USD:

```
Транзакция в JPY:
  JPY → USD (курс Visa) → USD settlement
  
Эмитент в России:
  USD → RUB (курс эмитента) → списание с клиента
```

### 7.2 Двойная конвертация

При некоторых транзакциях конвертация происходит дважды:

```
Покупка в Японии (JPY) картой в рублях:

JPY → USD (Visa)          ← первая конвертация
USD → RUB (ваш банк)      ← вторая конвертация
```

**Каждая конвертация имеет свой спред!**

### 7.3 Как минимизировать потери

| Стратегия | Эффект |
|-----------|--------|
| Платить в основных валютах (USD, EUR) | Меньше двойных конвертаций |
| Использовать мультивалютные карты | Без конвертации |
| Избегать DCC | Экономия 5-8% |
| Отслеживать курсы | Оптимальное время покупки |

## 8. Курсовые риски

### 8.1 Виды курсовых рисков

**Для держателя карты:**
- Курс изменился между авторизацией и списанием
- Неожиданная сумма в выписке

**Для торговца:**
- Продал в EUR, получил в местной валюте по невыгодному курсу
- Возврат по другому курсу

**Для бизнеса:**
- Планировал расходы, курс изменился
- Валютная выручка обесценилась

### 8.2 Пример курсового риска

```
Бронирование отеля:
  1 марта: Бронь €500, курс 95 ₽
           Ожидание: 47 500 ₽
           
  15 марта: Списание, курс 105 ₽
            Факт: 52 500 ₽
            
  Разница: 5 000 ₽ (10.5%)
```

### 8.3 Способы защиты

**Для физических лиц:**
- Мультивалютные карты
- Покупка валюты заранее
- Рублёвые карты для местных расходов

**Для бизнеса:**
- Хеджирование (форварды, опционы)
- Валютные оговорки в контрактах
- Диверсификация валютной структуры

## 9. Комиссии за валютные операции

### 9.1 Типы комиссий

| Комиссия | Кто взимает | Размер |
|----------|-------------|--------|
| Cross-border fee | Платёжная система | 0.2-1% |
| Currency conversion fee | Банк-эмитент | 0-3% |
| Foreign transaction fee | Банк-эмитент | 0-2% |
| DCC markup | DCC-провайдер | 3-8% |

### 9.2 Как узнать комиссии

**Где искать:**
- Тарифы банка на сайте
- Договор на обслуживание карты
- Правила платёжной системы

**Пример из тарифов:**
```
Комиссия за операции в иностранной валюте:
- Конвертация: курс ЦБ + 2%
- Дополнительная комиссия: 1% от суммы

Итого: ~3% сверх курса ЦБ
```

### 9.3 Сравнение стоимости

**Покупка €100 разными способами:**

| Способ | Курс | Комиссия | Итого ₽ |
|--------|------|----------|---------|
| Обменный пункт | 102 | 0 | 10 200 |
| Карта банка A | 98 | 3% | 10 094 |
| Карта банка B | 99 | 1% | 9 999 |
| Карта без комиссий | 98 | 0% | 9 800 |
| DCC | 108 | 0 | 10 800 |

## 10. Практические рекомендации

### 10.1 Для путешественников

1. **Заведите карту без комиссий** за валютные операции
2. **Отказывайтесь от DCC** — всегда платите в местной валюте
3. **Снимайте крупные суммы** — фиксированные комиссии меньше относительно
4. **Платите картой** — курс обычно лучше, чем в обменниках
5. **Следите за курсом** — откладывайте крупные покупки

### 10.2 Для онлайн-покупок

1. **Сравнивайте цены** в разных валютах
2. **Проверяйте, нет ли DCC** на сайте
3. **Используйте виртуальные карты** с нужной валютой
4. **Учитывайте возможные пошлины** и НДС

### 10.3 Для бизнеса

1. **Ведите учёт** в функциональной валюте
2. **Хеджируйте риски** при значительных объёмах
3. **Выбирайте банки** с выгодными курсами
4. **Анализируйте потери** на конвертации

## 💡 Key Takeaways

- **Три валюты**: транзакции, списания, расчётов — могут отличаться
- **Курс Settlement**: применяется в момент расчётов, не авторизации
- **DCC — это ловушка**: всегда выбирайте оплату в местной валюте
- **Мультивалютные карты**: лучший способ избежать конвертации
- **Комиссии складываются**: markup + fee могут составлять 3-5%
