# Курс: Git

## Описание курса

Курс по системе контроля версий Git. Для разработчиков любого уровня, которые хотят освоить Git от базовых команд до продвинутых workflows и командной работы.

## Цели курса

После прохождения курса слушатель будет:
- понимать основные принципы и концепции Git
- уметь применять полученные знания на практике
- ориентироваться в терминологии и инструментарии

## Целевая аудитория

- Разработчики и IT-специалисты
- Студенты технических специальностей
- Все, кто хочет изучить Git

## Предварительные требования

- Базовое понимание работы в терминале
- Любая операционная система (Windows, macOS, Linux)
- Желание изучить систему контроля версий

## План курса

1. **Введение в Git** - что такое Git, история, зачем нужен контроль версий, установка и настройка
2. **Основы работы** - init, add, commit, status, log — базовый цикл работы
3. **Ветвление** - ветки, создание, переключение, удаление, HEAD и detached state
4. **Слияние веток** - слияние веток, fast-forward, три-way merge, конфликты и их разрешение
5. **Удаленные репозитории** - remote, fetch, pull, push, origin, работа с GitHub/GitLab
6. **Rebase** - rebase vs merge, interactive rebase, переписывание истории
7. **Stash** - временное сохранение изменений, stash pop, apply, drop
8. **Откат изменений** - reset, revert, checkout — откат изменений, soft/mixed/hard
9. **Рабочие процессы** - GitFlow, trunk-based development, feature branches, release branches
10. **Код-ревью** - pull requests, merge requests, код-ревью, best practices
11. **Хуки** - pre-commit, pre-push, автоматизация проверок
12. **Продвинутые техники** - cherry-pick, bisect, reflog, submodules, worktrees
13. **Архитектура Git** - внутри git, bare, blobs, references, hash, diff
13. **GitArchitecture** - внутри git, bare, blobs, references, hash, diff

Примерная длительность: 12-15 часов
