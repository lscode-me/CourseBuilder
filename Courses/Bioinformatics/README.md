# Биоинформатика для Инженеров

Добро пожаловать в курс по биоинформатике! Этот курс создан специально для инженеров-программистов, которые хотят войти в область Life Sciences. Мы объясняем все биологические концепции простым языком, используя аналогии из IT и много схем.

## Обзор Курса

Биоинформатика — это применение вычислительных методов для анализа биологических данных. Если вы работали с обработкой данных, логами, или ETL-пайплайнами — многие концепции покажутся вам знакомыми. Геномные данные — это просто очень большие текстовые файлы со специфической структурой, которые нужно обрабатывать и анализировать.

**Что вы изучите:**

- Базовые биологические концепции, необходимые для работы (ДНК, гены, мутации)
- Форматы файлов в биоинформатике (аналог JSON, CSV, но для геномных данных)
- Пайплайны обработки данных (от сырых данных до результатов)
- CLI-инструменты для работы с биоданными (аналог grep, awk, sed для геномики)

### 3. Форматы Файлов в Биоинформатике

Глубокое погружение в стандартные форматы данных биоинформатики.

**Темы:**

- FASTQ - сырые данные секвенирования (аналог логов)
- SAM/BAM - выровненные риды (аналог индексированных БД)
- VCF - файлы вариантов (аналог diff файлов)
- BED - координаты регионов (аналог конфиг-файлов)
- FASTA - референсные последовательности

**Материалы:**

- [Lecture](03_File_Formats/lecture.md) - Детальный разбор всех форматов

## 🛠️ Требования

### Необходимые Инструменты

- **Python:** 3.8+ с pip

- **ОС:** Linux (Ubuntu 20.04+) или macOS

- **Место на диске:** минимум 50GB для работы с данными

- **RAM:** минимум 8GB (рекомендуется 16GB)

### Биоинформатические Инструменты

- `samtools` - работа с alignment файлами
- `bcftools` - работа с variant файлами
- `bedtools` - геномные интервалы
- `bwa` - выравнивание
- `seqtk` - работа с FASTQ

### Python Библиотеки

- `biopython` - основная библиотека для биоинформатики
- `pysam` - работа с SAM/BAM файлами
- `pandas` - анализ табличных данных
- `numpy` - численные вычисления

### Установка (Ubuntu/Debian)

```bash
# Обновить систему
sudo apt update && sudo apt upgrade -y

# Установить биоинформатические инструменты

sudo apt install -y samtools bcftools bedtools bwa seqtk

# Установить Python библиотеки

pip install biopython pysam pandas numpy matplotlib jupyter
```

### Установка (macOS)

```bash
# Используем Homebrew

brew install samtools bcftools bedtools bwa seqtk

# Python библиотеки

pip3 install biopython pysam pandas numpy matplotlib jupyter
```
