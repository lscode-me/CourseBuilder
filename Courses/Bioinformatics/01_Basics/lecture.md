## 1. ДНК — Текстовая Информация в Клетках

### 1.1 Что такое ДНК?

**ДНК (дезоксирибонуклеиновая кислота)** — это молекула, которая хранит генетическую информацию организма. С точки зрения данных, ДНК — это очень длинная последовательность из 4 символов: **A, C, G, T**.

**Важное уточнение:** ДНК хранит не только "наследственную" информацию в узком смысле. Да, ДНК передаётся от родителей к детям, но её главная функция — хранить **инструкции для жизнедеятельности клетки**:

- Как синтезировать белки
- Когда и в каких условиях включать/выключать гены
- Как реагировать на сигналы окружающей среды
- Как делиться и дифференцироваться

ДНК — это не просто "архив предков", а **активно используемая инструкция**, которая читается и интерпретируется каждый момент жизни клетки.

```python
# Пример фрагмента ДНК

dna_sequence = "ATCGATCGATCGATCG"
```

Эти 4 символа называются **нуклеотиды** (или **основания**):

- **A** = Аденин

- **C** = Цитозин  

- **G** = Гуанин

- **T** = Тимин

**Важно:** ДНК — это реальная физическая молекула в ваших клетках, но для работы с данными мы представляем её как текстовую строку.

### 1.1.1 Химическая Структура Нуклеотидов

Нуклеотид состоит из трёх компонентов:

1. **Азотистое основание** (A, C, G, T) — несёт информацию
2. **Сахар** (дезоксирибоза для ДНК, рибоза для РНК) — основа структуры
3. **Фосфатная группа** (PO₄³⁻) — связывает нуклеотиды в цепь

**Формулы азотистых оснований:**

| Основание | Формула | Тип | Молекулярная масса |
|-----------|---------|-----|-------------------|
| **Аденин (A)** | C₅H₅N₅ | Пурин (двойное кольцо) | 135.13 г/моль |
| **Гуанин (G)** | C₅H₅N₅O | Пурин (двойное кольцо) | 151.13 г/моль |
| **Цитозин (C)** | C₄H₅N₃O | Пиримидин (одно кольцо) | 111.10 г/моль |
| **Тимин (T)** | C₅H₆N₂O₂ | Пиримидин (одно кольцо) | 126.11 г/моль |
| **Урацил (U)** | C₄H₄N₂O₂ | Пиримидин (в РНК вместо T) | 112.09 г/моль |

**Структура полного нуклеотида (дезоксиаденозинмонофосфат, dAMP):**
```
      NH₂
       |
   N===C
  //    \\
 N       C-N
 |       ||  \
 C===N   C    CH
  \     /
   Аденин (C₅H₅N₅)
      |
   Дезоксирибоза (C₅H₁₀O₄)
      |
   Фосфат (PO₄)
```

**Формула полного нуклеотида ДНК (в среднем):** C₁₀H₁₄N₄O₆P (для dAMP)

**Почему пурины спариваются с пиримидинами?**
- A (пурин, 2 кольца) ↔ T (пиримидин, 1 кольцо) — **2 водородные связи**
- G (пурин, 2 кольца) ↔ C (пиримидин, 1 кольцо) — **3 водородные связи**

Это обеспечивает постоянную ширину двойной спирали (~2 нм) — всегда большое + маленькое основание.

**Связь G-C прочнее, чем A-T** — это влияет на температуру плавления ДНК (разделения цепей). Чем выше GC-содержание, тем стабильнее молекула.

### 1.1.2 Где Хранится ДНК в Организме?

**Основное место хранения — ядро клетки:**

Большинство клеток человека содержат ядро, внутри которого находится ДНК в виде хромосом. ДНК в ядре называется **ядерной ДНК (nuclear DNA)**.

```
Клетка человека:
┌─────────────────────────────────────┐
│                                     │
│    ┌───────────────────┐            │
│    │       ЯДРО        │            │
│    │   ┌───────────┐   │            │
│    │   │ Хромосомы │   │  ← 46 хромосом, ~3.2 млрд нуклеотидов
│    │   │   (ДНК)   │                │
│    │   └───────────┘   │            │
│    └───────────────────┘            │
│                                     │
│    (○) (○) (○)  ← Митохондрии       │  ← ~16,500 нуклеотидов каждая
│                  (своя ДНК!)        │
│                                     │
└─────────────────────────────────────┘
```

**Митохондриальная ДНК (mtDNA):**

- Митохондрии — "энергетические станции" клетки — имеют **собственную ДНК**
- Размер: ~16,569 нуклеотидов (крошечная по сравнению с ядерной)
- Количество копий: **100-10,000 копий** mtDNA на клетку (зависит от типа ткани)
- Особенность: наследуется только **от матери**
- Кодирует: 37 генов (13 белков, 22 тРНК, 2 рРНК)

**Клетки БЕЗ ДНК (у человека):**

| Тип клеток | Почему нет ДНК | Примечание |
|------------|----------------|------------|
| **Эритроциты (красные клетки крови)** | Теряют ядро при созревании | Освобождают место для гемоглобина |
| **Тромбоциты (кровяные пластинки)** | Это фрагменты клеток, не полноценные клетки | Отщепляются от мегакариоцитов |
| **Роговой слой кожи** | Мёртвые кератиноциты | Защитный слой |
| **Хрусталик глаза** | Клетки теряют органеллы | Для прозрачности |

**Практический вывод для биоинформатики:**

```python
# При заборе образцов для секвенирования:

# ✅ Подходят для выделения ДНК:

good_samples = [
    "Буккальный эпителий (щека)",    # ~500 клеток достаточно
    "Лейкоциты (белые клетки крови)", # Из пробирки с ЭДТА
    "Слюна",                          # Содержит эпителиальные клетки
    "Волосяные фолликулы",            # Корни волос с луковицей
    "Биопсия тканей",                 # Любая ткань с ядерными клетками
]

# ❌ НЕ подходят (нет ядерной ДНК):

bad_samples = [
    "Сыворотка крови",        # Только плазма, без клеток
    "Чистые эритроциты",      # Нет ядра
    "Стержень волоса",        # Мёртвые клетки без ДНК
]

# 🔬 Особый случай — цельная кровь:
# Цельная кровь ПОДХОДИТ для выделения ДНК, потому что содержит
# лейкоциты (белые клетки крови), у которых ЕСТЬ ядро.
# Эритроциты (красные клетки) действительно не имеют ДНК,
# но их отделяют при обработке образца.
```

**Количество ДНК в разных образцах:**

| Образец | Типичный объём | Выход ДНК |
|---------|---------------|-----------|
| Цельная кровь | 5-10 мл | 100-300 мкг |
| Буккальный мазок | 1 мазок | 1-10 мкг |
| Слюна | 2 мл | 5-50 мкг |
| Волос с фолликулом | 5-10 волос | 0.1-1 мкг |

**Для NGS секвенирования обычно требуется 100 нг — 1 мкг ДНК.**

**Масштаб:** Каждая молекула ДНК (хромосома) содержит от **~50 до ~250 миллионов пар нуклеотидов**. У человека 46 таких молекул в каждой клетке, которые вместе составляют ~3.2 миллиарда пар нуклеотидов.

### 1.2 Геном — Полная ДНК Организма

**Геном** — это вся ДНК организма, полный набор его наследственной информации.

**Связь:** ДНК (молекула) → Геном (вся ДНК целиком)

Размеры геномов разных организмов:

| Организм | Размер генома | Эквивалент в текстовом файле |
|----------|---------------|----------|
| E.coli (бактерия) | 4.6 миллиона нуклеотидов | ~5 MB |
| Человек | 3.2 миллиарда нуклеотидов | ~3.2 GB |
| Пшеница | 17 миллиардов нуклеотидов | ~17 GB |

**Откуда эти числа?** Эти размеры определены экспериментально с помощью секвенирования (чтения ДНК). Геном человека был полностью прочитан в рамках проекта "Геном человека" (завершён в 2003 году). Размеры постоянны для вида, но могут незначительно варьироваться между особями (±0.1%).

**Для инженера:** Геном человека — это 3.2 миллиарда символов из алфавита {A, C, G, T}. Если сохранить в текстовый файл (1 байт на символ), получится ~3.2 GB.

### 1.3 Комплементарность — Двойная Спираль

**ДНК двухцепочечная** — состоит из двух комплементарных цепей, скрученных в двойную спираль.

**Правила спаривания (комплементарности):**

- **A** (аденин) всегда напротив **T** (тимин)

- **C** (цитозин) всегда напротив **G** (гуанин)

```
Цепь 1:  5'-A T C G A T-3'
         | | | | | |
Цепь 2:  3'-T A G C T A-5'
```

**Почему это важно:**

1. **Избыточность информации:** Зная одну цепь, можно восстановить вторую
2. **Репликация:** При делении клетки каждая цепь служит матрицей для создания новой
3. **Починка ДНК:** Если повреждена одна цепь, вторая служит шаблоном для восстановления

**Направленность цепей:**

- Цепи имеют направление: **5' → 3'** и **3' → 5'**
- Цепи антипараллельны (идут в противоположных направлениях)
- В биоинформатике обычно записывают цепь в направлении 5' → 3'

```python
def complement(sequence):
    """Получить комплементарную последовательность"""
    complement_map = {'A': 'T', 'T': 'A', 'C': 'G', 'G': 'C'}
    return ''.join(complement_map[base] for base in sequence)

# Пример

seq = "ATCGATCG"  # 5' → 3' направление
comp = complement(seq)  # TAGCTAGC
print(f"Исходная цепь:         5'-{seq}-3'")
print(f"Комплементарная цепь:  3'-{comp}-5'")
```

## 2. Гены — Инструкции для Создания Белков

### 2.1 Что такое ген?

**Ген** — это участок ДНК (конкретная последовательность нуклеотидов), который содержит инструкцию для создания белка или функциональной РНК.

**Связь:** Геном (вся ДНК) → Гены (отдельные участки ДНК с инструкциями)

```python
# Геном — вся ДНК

genome = "ATCGATCGATCGATCG..." # 3.2 миллиарда букв

# Ген — участок этой ДНК с позиции X до позиции Y

gene_BRCA1 = genome[43044295:43125483]  # Пример: ген BRCA1 на хромосоме 17
# Этот участок содержит инструкцию для белка, который чинит повреждения ДНК
```

**Сколько генов у человека?**
- У человека примерно **20,000-25,000 генов**
- Это определено экспериментально путем анализа генома
- Гены составляют только **~2%** всего генома человека

**Типичные размеры гена:**

- Маленький ген: ~1,000-5,000 нуклеотидов
- Средний ген: ~10,000-50,000 нуклеотидов  
- Большой ген: ~100,000-2,000,000 нуклеотидов (например, ген дистрофина DMD ~2.4 млн нуклеотидов)

**Что в остальных ~98% генома?**
- **Интроны** — некодирующие участки внутри самих генов (об этом ниже)

- **Регуляторные элементы** — последовательности, которые управляют включением/выключением генов

- **Повторяющиеся последовательности** — одинаковые участки, повторенные много раз

- **Межгенные области** — участки между генами, функция многих пока неизвестна

### 2.2 От гена к белку: ДНК vs РНК

Для создания белка используются две разные молекулы: ДНК (хранение) и РНК (рабочая копия).

**ДНК (дезоксирибонуклеиновая кислота):**

- Двухцепочечная молекула (двойная спираль)
- Алфавит: A, C, G, **T** (тимин)
- Местонахождение: хранится в ядре клетки
- Функция: постоянное хранилище генетической информации
- Стабильность: очень стабильна, долговечна

**РНК (рибонуклеиновая кислота):**

- Одноцепочечная молекула
- Алфавит: A, C, G, **U** (урацил вместо тимина!)
- Местонахождение: создается в ядре, работает в цитоплазме
- Функция: временная рабочая копия для создания белков
- Стабильность: менее стабильна, быстро разрушается после использования

```python
# ДНК использует T (Тимин)

dna = "ATCGATCG"

# РНК использует U (Урацил) вместо T

rna = "AUCGAUCG"

# Функция транскрипции

def transcribe(dna):
    """ДНК → РНК: заменяем T на U"""
    return dna.replace('T', 'U')

print(transcribe("ATCG"))  # Output: AUCG
```

**Процесс от гена к белку:**

```
ДНК (ген) --(транскрипция)--> РНК --(трансляция)--> Белок
```

| Этап | Что происходит | Где происходит | Длительность |
|------|----------------|----------------|--------------|
| **Транскрипция** | ДНК копируется в РНК | Ядро клетки | ~Минуты |
| **Трансляция** | РНК используется как матрица для создания белка | Рибосомы (в цитоплазме) | ~Секунды-минуты |
| **Функция белка** | Белок выполняет работу в клетке | Различные органеллы | Часы-дни |

**Типичные размеры белка:**

- Маленький белок: ~50-100 аминокислот (кодируется 150-300 нуклеотидами)
- Средний белок: ~300-500 аминокислот (кодируется ~900-1,500 нуклеотидами)
- Большой белок: ~1,000-3,000 аминокислот (например, белок титин ~34,000 аминокислот)

### 2.2.1 Состав и Структура Белков

**Из чего состоит белок?**

Белок — это полимер (длинная цепочка), состоящий из **аминокислот**, соединённых **пептидными связями**.

```
Аминокислота 1    Аминокислота 2    Аминокислота 3
     │                 │                 │
 H₂N─CH─COOH ──── H₂N─CH─COOH ──── H₂N─CH─COOH
     │                 │                 │
     R₁                R₂                R₃
     
         ↓ образование пептидных связей (с выделением воды)
         
 H₂N─CH─CO─NH─CH─CO─NH─CH─COOH  + 2H₂O
     │        │        │
     R₁       R₂       R₃
     
     └────── Полипептидная цепь ──────┘
```

**Общая формула аминокислоты:**

```
        H
        |
   H₂N─C─COOH
        |
        R
        
Где:
- H₂N — аминогруппа (amino group)
- COOH — карбоксильная группа (carboxyl group)  
- R — боковая цепь (определяет тип аминокислоты)
```

**20 Стандартных Аминокислот:**

| Аминокислота | 3-буквы | 1-буква | Формула боковой цепи R | Свойства |
|--------------|---------|---------|------------------------|----------|
| **Глицин** | Gly | G | H | Самая простая |
| **Аланин** | Ala | A | CH₃ | Гидрофобная |
| **Валин** | Val | V | CH(CH₃)₂ | Гидрофобная |
| **Лейцин** | Leu | L | CH₂CH(CH₃)₂ | Гидрофобная |
| **Изолейцин** | Ile | I | CH(CH₃)CH₂CH₃ | Гидрофобная |
| **Метионин** | Met | M | CH₂CH₂SCH₃ | Содержит серу, старт |
| **Фенилаланин** | Phe | F | CH₂C₆H₅ | Ароматическая |
| **Триптофан** | Trp | W | CH₂-индол | Ароматическая, самая большая |
| **Пролин** | Pro | P | -(CH₂)₃- (цикл) | Создаёт изгибы |
| **Серин** | Ser | S | CH₂OH | Гидрофильная |
| **Треонин** | Thr | T | CH(OH)CH₃ | Гидрофильная |
| **Цистеин** | Cys | C | CH₂SH | Образует дисульфидные связи |
| **Тирозин** | Tyr | Y | CH₂-C₆H₄-OH | Ароматическая |
| **Аспарагин** | Asn | N | CH₂CONH₂ | Полярная |
| **Глутамин** | Gln | Q | CH₂CH₂CONH₂ | Полярная |
| **Аспарагиновая кислота** | Asp | D | CH₂COOH | Отрицательно заряженная |
| **Глутаминовая кислота** | Glu | E | CH₂CH₂COOH | Отрицательно заряженная |
| **Лизин** | Lys | K | (CH₂)₄NH₂ | Положительно заряженная |
| **Аргинин** | Arg | R | (CH₂)₃NH-C(=NH)NH₂ | Положительно заряженная |
| **Гистидин** | His | H | CH₂-имидазол | Положительно заряженная |

**Средняя молекулярная масса аминокислоты:** ~110 Да (дальтон)

**Классификация по свойствам:**

```python
amino_acids = {
    # Гидрофобные (неполярные) - внутри белка
    'hydrophobic': ['G', 'A', 'V', 'L', 'I', 'M', 'F', 'W', 'P'],
    
    # Гидрофильные (полярные незаряженные) - на поверхности
    'polar': ['S', 'T', 'C', 'Y', 'N', 'Q'],
    
    # Положительно заряженные (основные)
    'positive': ['K', 'R', 'H'],
    
    # Отрицательно заряженные (кислые)
    'negative': ['D', 'E'],
}

**Уровни структуры белка:**

| Уровень | Что определяет | Пример |
|---------|---------------|--------|
| **Первичная** | Последовательность аминокислот | Met-Ala-Gly-Leu-... |
| **Вторичная** | Локальные структуры (α-спирали, β-листы) | Спираль из 10-15 аминокислот |
| **Третичная** | 3D укладка всей цепи | Глобула, домены |
| **Четвертичная** | Комплекс из нескольких цепей | Гемоглобин (4 субъединицы) |

**Пример: Гемоглобин**

Количество аминокислот: 574 (4 субъединицы: 2α + 2β)
Содержит: 4 атома железа (в геме)
```

**Расчёт молекулярной массы белка:**

```python
def calculate_protein_mass(sequence):
    """
    Приблизительный расчёт массы белка
    Средняя масса аминокислотного остатка ~110 Да
    При образовании пептидной связи теряется H₂O (~18 Да)
    """
    avg_residue_mass = 110  # Дальтон
    water_mass = 18
    
    n_residues = len(sequence)
    # Масса = (n × средняя масса) - (n-1) × масса воды + концы
    mass = n_residues * avg_residue_mass - (n_residues - 1) * water_mass
    
    return mass

# Пример

print(f"Длина: {len(protein)} аминокислот")
print(f"Примерная масса: {calculate_protein_mass(protein):,} Да")
# ~5,600 Да для 51 аминокислоты
```

### 2.3 Структура гена: Экзоны и Интроны

**Важное открытие:** Ген — это не непрерывная последовательность. Внутри гена есть кодирующие и некодирующие участки.

**Структура типичного гена:**

```
Ген в ДНК:
[Промотор] [Экзон 1] [Интрон] [Экзон 2] [Интрон] [Экзон 3] [Терминатор]
```

**Связь с геномом и ДНК:**

- **Геном** = вся ДНК (3.2 миллиарда букв)
  - **Ген** = участок генома (например, 10,000 букв)
    - **Экзоны** = кодирующие части гена (например, 3 участка по 200 букв каждый = 600 букв кодируют белок)
    - **Интроны** = некодирующие части гена (остальные 9,400 букв между экзонами)

**Определения:**

- **Экзоны** — участки гена, которые содержат реальную инструкцию для белка. Эти последовательности будут использованы для создания белка.

- **Интроны** — участки гена, которые находятся между экзонами, но не кодируют белок. Они будут удалены в процессе обработки.

- **Промотор** — участок ДНК перед геном, который служит сигналом "здесь начинается ген".

- **Терминатор** — сигнал "здесь ген заканчивается".

**Процесс от гена к белку:**

```
Шаг 1: Транскрипция (копирование ДНК в РНК)
ДНК:  [Экзон 1][Интрон][Экзон 2][Интрон][Экзон 3]
        ↓ копируется целиком
РНК:  [Экзон 1][Интрон][Экзон 2][Интрон][Экзон 3]  ← pre-mRNA (незрелая РНК)

Шаг 2: Сплайсинг (вырезание интронов)
РНК:  [Экзон 1][Интрон][Экзон 2][Интрон][Экзон 3]
        ↓ интроны удаляются, экзоны соединяются
мРНК: [Экзон 1][Экзон 2][Экзон 3]  ← mature mRNA (зрелая РНК)

Шаг 3: Трансляция (создание белка по инструкции)
мРНК: [Экзон 1][Экзон 2][Экзон 3]
        ↓ читается и создается белок
Белок: [Последовательность аминокислот]
```

**Ключевые термины:**

- **Pre-mRNA (незрелая мРНК)** — РНК копия гена сразу после транскрипции, содержит как экзоны, так и интроны

- **Mature mRNA (зрелая мРНК)** — финальная РНК после сплайсинга, содержит только экзоны. Именно она используется для создания белка

**Почему так устроено?** Интроны позволяют создавать разные варианты белка из одного гена (альтернативный сплайсинг — можно включить или исключить разные экзоны). Это увеличивает разнообразие белков без увеличения числа генов.

**Типичные размеры экзонов и интронов:**

- Экзон: ~50-200 нуклеотидов (в среднем ~150 нуклеотидов)
- Интрон: ~100-10,000+ нуклеотидов (в среднем ~3,000-5,000 нуклеотидов)
- Количество экзонов в гене: от 1 до 363 (в среднем ~8-10 экзонов на ген)

**Пример с числами (ген BRCA1):**

- Длина гена в ДНК: ~81,000 нуклеотидов
- Количество экзонов: 24
- Длина всех экзонов вместе: ~5,700 нуклеотидов (7% гена)
- Длина всех интронов: ~75,300 нуклеотидов (93% гена)
- Длина финального белка: 1,863 аминокислоты

**Вывод:** Большая часть гена (93%) — это интроны, которые вырезаются. Только 7% попадает в белок.

## 💡 Key Takeaways

- **ДНК как текст**: ДНК — это длинная текстовая последовательность из символов A, C, G и T, которая хранит инструкции для работы клетки. Геном человека содержит ~3.2 млрд пар нуклеотидов, что эквивалентно нескольким гигабайтам текстовых данных.

- **Геном vs гены**: Геном — вся ДНК организма, а гены — отдельные участки, несущие инструкции для белков или РНК. При этом только ~2% генома кодирует белки, а остальное — регуляторные и другие некодирующие области.

- **От ДНК к белку**: Поток информации идёт по схеме ДНК → РНК → Белок. ДНК выступает в роли долговременного хранилища, РНК — рабочей копии, а белки — исполнителей, выполняющих функции в клетке.

- **Структура генов**: Гены состоят из экзонов и интронов, причём интроны вырезаются в процессе сплайсинга, а экзоны соединяются в зрелую мРНК. Это позволяет за счёт альтернативного сплайсинга получать несколько вариантов белков из одного гена.

- **Практический аспект образцов**: Разные типы биологических образцов дают разный выход ДНК и по‑разному подходят для NGS. Важно понимать, какие ткани содержат ядра и митохондрии и где ДНК практически отсутствует.
