| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Эпигенетика изучает изменения экспрессии без изменения последовательности ДНК. |
| 2 | C | Метильная группа (-CH₃) добавляется к цитозину в CpG сайтах. |
| 3 | C | CpG = цитозин (C) стоит перед гуанином (G). |
| 4 | B | Метилирование промотора обычно выключает ген. |
| 5 | B | Гистоны — белки для упаковки ДНК в нуклеосомы. |
| 6 | D | Ацетилирование (H3K27ac) открывает хроматин и активирует транскрипцию. |
| 7 | C | Многие факторы влияют на эпигенетику: возраст, питание, стресс, среда. |
| 8 | C | Эпигенетические часы оценивают биологический возраст по метилированию. |
| 9 | A | SNP — замена одного нуклеотида на другой. |
| 10 | C | STR — короткие тандемные повторы (2-6 нуклеотидов). |
| 11 | C | STR используются для идентификации личности и установления родства. |
| 12 | A | CNV — вариации числа копий участков ДНК. |
| 13 | B | GWAS — полногеномный поиск ассоциаций между SNP и признаками. |
| 14 | A | Стандартный порог GWAS: p < 5×10⁻⁸ (коррекция на множественное тестирование). |
