| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Эпигенетика изучает изменения экспрессии без изменения последовательности ДНК. |

| 3 | D | CpG = цитозин (C) стоит перед гуанином (G). |
| 4 | A | Метилирование промотора обычно выключает ген. |
| 5 | B | Гистоны — белки для упаковки ДНК в нуклеосомы. |
| 6 | D | Ацетилирование (H3K27ac) открывает хроматин и активирует транскрипцию. |
| 7 | A | Многие факторы влияют на эпигенетику: возраст, питание, стресс, среда. |
| 8 | D | Эпигенетические часы оценивают биологический возраст по метилированию. |
| 9 | A | SNP — замена одного нуклеотида на другой. |
| 10 | A | STR — короткие тандемные повторы (2-6 нуклеотидов). |
| 11 | C | STR используются для идентификации личности и установления родства. |
| 12 | C | CNV — вариации числа копий участков ДНК. |
| 13 | C | GWAS — полногеномный поиск ассоциаций между SNP и признаками. |
