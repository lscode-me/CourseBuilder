## 2. Эпигенетика: Регуляция Поверх ДНК

### 1.1 Что такое эпигенетика?

**Эпигенетика** (от греч. "эпи" — над, сверху) — это наука об изменениях в экспрессии генов, которые **не изменяют саму последовательность ДНК**, но могут передаваться при делении клеток и даже между поколениями.

**Ключевая идея:** Два человека (или две клетки) могут иметь идентичную последовательность ДНК, но совершенно разные паттерны работы генов.

**Аналогия:** Если ДНК — это книга, то эпигенетика — это закладки, подчёркивания и заметки на полях. Текст книги не меняется, но читается по-разному.

```
Последовательность ДНК:     ATCGATCGATCG... (одинаковая у всех клеток)
                                  ↓
Эпигенетические метки:      ●  ●     ●  ●   (разные в разных клетках)
                                  ↓
Экспрессия:                 [ген ВКЛ] или [ген ВЫКЛ]
```

### 1.2 Основные эпигенетические механизмы

| Механизм | Что происходит | Влияние на ген |
|----------|----------------|----------------|
| **Метилирование ДНК** | К цитозину (C) добавляется метильная группа (-CH₃) | Обычно **выключает** ген |
| **Модификация гистонов** | Химические метки на белках-гистонах, вокруг которых намотана ДНК | Может включать или выключать |
| **Ремоделирование хроматина** | Изменение плотности упаковки ДНК | Плотная упаковка = ген недоступен |
| **Некодирующие РНК** | Регуляторные РНК, не кодирующие белки | Могут подавлять экспрессию генов |

### 1.3 Метилирование ДНК

**Метилирование** — это добавление метильной группы (-CH₃) к нуклеотиду цитозин (C). Это самый изученный эпигенетический механизм.

**Где происходит метилирование:**
- В основном в **CpG сайтах** — местах, где цитозин (C) стоит перед гуанином (G)
- В геноме человека ~28 миллионов CpG сайтов
- Особенно важны **CpG островки** — участки с высокой концентрацией CpG, часто расположенные в промоторах генов

```
Немелированный цитозин:     5'-...ATCG ATCG...
                                      ↑
                                  CpG сайт
                                      ↓
                            Ген АКТИВЕН (может читаться)

Метилированный цитозин:     5'-...ATmCG ATmCG...
                                      ↑
                              метильная группа (-CH₃)
                                      ↓
                            Ген ВЫКЛЮЧЕН (не читается)
```

**Как это работает:**
1. Метильная группа физически мешает связыванию транскрипционных факторов
2. Метилированная ДНК привлекает белки, которые компактизируют хроматин
3. Результат: ген становится недоступен для транскрипции

```python
# Пример: анализ метилирования
def analyze_methylation(cpg_sites):
    """
    Анализ уровня метилирования в регионе
    
    cpg_sites: список словарей с информацией о каждом CpG сайте
    """
    methylated = sum(1 for site in cpg_sites if site['methylated'])
    total = len(cpg_sites)
    methylation_level = methylated / total * 100
    
    if methylation_level > 70:
        return f"Высокое метилирование ({methylation_level:.1f}%) - ген вероятно ВЫКЛЮЧЕН"
    elif methylation_level < 30:
        return f"Низкое метилирование ({methylation_level:.1f}%) - ген вероятно АКТИВЕН"
    else:
        return f"Промежуточный уровень ({methylation_level:.1f}%) - требуется дополнительный анализ"

# Пример данных
promoter_cpg_sites = [
    {'position': 1000, 'methylated': False},
    {'position': 1020, 'methylated': False},
    {'position': 1045, 'methylated': True},
    {'position': 1060, 'methylated': False},
    {'position': 1080, 'methylated': False},
]

print(analyze_methylation(promoter_cpg_sites))
# Output: "Низкое метилирование (20.0%) - ген вероятно АКТИВЕН"
```

### 1.4 Модификация гистонов

**Гистоны** — это белки, вокруг которых намотана ДНК (как нитка вокруг катушки). Химические модификации гистонов влияют на доступность ДНК.

**Структура хроматина:**
```
    ДНК (двойная спираль)
         ↓
┌─────────────────────────────┐
│  ~~~~~~●~~~~~~●~~~~~~●~~~~  │  ● = нуклеосома (ДНК + гистоны)
│        │      │      │      │
│     гистоны (H2A, H2B, H3, H4)
└─────────────────────────────┘
         ↓
Компактная упаковка → Хромосома
```

**Основные модификации гистонов:**

| Модификация | Обозначение | Эффект |
|-------------|-------------|--------|
| **Ацетилирование** | H3K9ac, H3K27ac | Активация гена (открытый хроматин) |
| **Метилирование** | H3K4me3 | Активация гена |
| **Метилирование** | H3K9me3, H3K27me3 | Репрессия гена (закрытый хроматин) |
| **Фосфорилирование** | H3S10p | Конденсация хромосом при делении |

**Обозначения:** H3K9ac = гистон H3, лизин (K) в позиции 9, ацетилирование (ac)

```python
# Пример: интерпретация гистоновых меток
def interpret_histone_marks(marks):
    """
    Интерпретация набора гистоновых модификаций
    """
    activating = ['H3K4me3', 'H3K27ac', 'H3K9ac', 'H3K36me3']
    repressive = ['H3K9me3', 'H3K27me3', 'H4K20me3']
    
    active_count = sum(1 for m in marks if m in activating)
    repressive_count = sum(1 for m in marks if m in repressive)
    
    if active_count > repressive_count:
        return "Активный промотор/энхансер"
    elif repressive_count > active_count:
        return "Репрессированный регион"
    else:
        return "Бивалентный или poised регион"

# Пример
gene_marks = ['H3K4me3', 'H3K27ac']
print(interpret_histone_marks(gene_marks))
# Output: "Активный промотор/энхансер"
```

### 1.5 Что влияет на эпигенетику?

Эпигенетический профиль не статичен — он меняется под воздействием внешних и внутренних факторов:

| Фактор | Как влияет | Примеры |
|--------|------------|---------|
| **Возраст** | Накопление эпигенетических изменений | "Эпигенетические часы" — можно оценить биологический возраст по метилированию |
| **Питание** | Доноры метильных групп из пищи | Фолиевая кислота, витамин B12, метионин влияют на метилирование |
| **Стресс** | Изменяет паттерны метилирования | Хронический стресс меняет экспрессию генов стресс-ответа |
| **Окружающая среда** | Токсины, загрязнение | Курение изменяет метилирование >7000 CpG сайтов |
| **Физическая активность** | Влияет на экспрессию метаболических генов | Тренировки меняют эпигенетику мышц и метаболизма |
| **Ранний опыт** | Формирует базовые паттерны | Качество ухода в детстве влияет на эпигенетику генов стресса |

**Эпигенетические часы (Horvath clock):**

```python
# Упрощённый пример эпигенетических часов
def estimate_biological_age(methylation_data, clock_cpg_sites):
    """
    Оценка биологического возраста по метилированию
    
    Реальные часы используют 353-500+ CpG сайтов
    и сложные регрессионные модели
    """
    # Взвешенная сумма уровней метилирования
    weighted_sum = sum(
        methylation_data.get(cpg, 0) * weight 
        for cpg, weight in clock_cpg_sites.items()
    )
    
    # Преобразование в возраст (упрощённо)
    biological_age = 20 + weighted_sum * 50
    
    return biological_age

# Пример: биологический возраст может отличаться от хронологического
# Здоровый образ жизни → биол. возраст < хронологического
# Курение, стресс → биол. возраст > хронологического
```

### 1.6 Почему эпигенетика важна?

**1. Объясняет различия однояйцевых близнецов:**
- Одинаковая ДНК, но разные эпигенетические профили со временем
- Объясняет, почему один близнец может заболеть, а другой нет

**2. Связь генетики и среды:**
- Эпигенетика — это "мост" между генами и окружающей средой
- Объясняет, как образ жизни влияет на работу генов

**3. Роль в заболеваниях:**
- **Рак:** Аберрантное метилирование генов-супрессоров опухолей
- **Нейродегенеративные заболевания:** Изменения в паттернах модификации гистонов
- **Метаболические расстройства:** Эпигенетическое программирование в утробе

**4. Потенциал терапии:**
- Эпигенетические изменения **обратимы** (в отличие от мутаций ДНК)
- Уже существуют эпигенетические препараты (ингибиторы DNMT, HDAC)

```python
# Пример: эпигенетические изменения при раке
def detect_tumor_suppressor_silencing(gene_methylation):
    """
    Обнаружение аберрантного метилирования генов-супрессоров опухолей
    """
    tumor_suppressors = {
        'BRCA1': 'Рак молочной железы',
        'MLH1': 'Колоректальный рак',
        'CDKN2A': 'Различные типы рака',
        'VHL': 'Рак почки',
        'RB1': 'Ретинобластома',
    }
    
    silenced_genes = []
    for gene, methylation_level in gene_methylation.items():
        if gene in tumor_suppressors and methylation_level > 0.7:
            silenced_genes.append({
                'gene': gene,
                'methylation': methylation_level,
                'associated_cancer': tumor_suppressors[gene]
            })
    
    return silenced_genes
```

## 2. Генетические Маркеры

### 2.1 Что такое генетический маркер?

**Генетический маркер** — это определённый участок ДНК с известным расположением в геноме, который можно использовать для:

- Идентификации индивида
- Связи с признаком или заболеванием
- Отслеживания наследования

**Ключевое свойство:** Маркер должен быть **полиморфным** — иметь разные варианты (аллели) в популяции.

### 2.2 Типы генетических маркеров

| Тип маркера | Описание | Частота | Применение |
|-------------|----------|---------|------------|
| **SNP** | Однонуклеотидные полиморфизмы | ~10 млн у человека | GWAS, фармакогенетика |
| **STR/Микросателлиты** | Короткие повторяющиеся последовательности (2-6 букв) | ~100,000 | ДНК-дактилоскопия, отцовство |
| **CNV** | Вариации числа копий участков ДНК | ~1,000 | Онкология, редкие заболевания |
| **Индели** | Вставки/делеции 1-50 нуклеотидов | ~1 млн | Диагностика заболеваний |

### 2.3 SNP — Однонуклеотидные Полиморфизмы

**SNP (Single Nucleotide Polymorphism)** — замена одного нуклеотида, которая встречается в популяции с частотой >1%.

```
                     rs12345 (ID маркера в базе данных dbSNP)
                         ↓
Референс:    ...ATCGATCGATCGATCG...
                     ↑
Вариант 1:   ...ATCGATCAATCGATCG...  (аллель A) — частота 60%
Вариант 2:   ...ATCGATCGATCGATCG...  (аллель G) — частота 40%

Человек может иметь генотип: AA, AG, или GG
```

**Характеристики SNP:**
- В геноме человека ~10 миллионов известных SNP
- В среднем один SNP на каждые ~300 нуклеотидов
- Большинство нейтральны, но некоторые влияют на признаки и болезни

```python
# Пример: работа с SNP данными
class SNP:
    def __init__(self, rsid, chromosome, position, ref_allele, alt_allele):
        self.rsid = rsid              # ID в базе данных (rs12345)
        self.chromosome = chromosome   # Хромосома
        self.position = position       # Позиция в хромосоме
        self.ref_allele = ref_allele   # Референсный аллель
        self.alt_allele = alt_allele   # Альтернативный аллель
    
    def __repr__(self):
        return f"{self.rsid}: chr{self.chromosome}:{self.position} {self.ref_allele}>{self.alt_allele}"

# Пример SNP, связанного с метаболизмом кофеина
cyp1a2_snp = SNP(
    rsid="rs762551",
    chromosome=15,
    position=75041917,
    ref_allele="A",
    alt_allele="C"
)

def interpret_caffeine_metabolism(genotype):
    """
    rs762551 влияет на скорость метаболизма кофеина
    """
    if genotype == "AA":
        return "Быстрый метаболизм кофеина"
    elif genotype == "AC":
        return "Средний метаболизм кофеина"
    else:  # CC
        return "Медленный метаболизм кофеина"
```

### 2.4 STR — Микросателлиты

**STR (Short Tandem Repeats)** — короткие последовательности (2-6 нуклеотидов), повторённые много раз подряд.

```
Пример STR локуса D13S317:
                    (GATA)n - повтор из 4 букв

Человек 1:  ...GATA GATA GATA GATA GATA GATA GATA...  = 7 повторов
Человек 2:  ...GATA GATA GATA GATA GATA GATA GATA GATA GATA GATA GATA...  = 11 повторов
Человек 3:  ...GATA GATA GATA GATA GATA GATA GATA GATA GATA...  = 9 повторов
```

**Применение STR:**
- **ДНК-дактилоскопия:** Используется 13-20 STR локусов (CODIS)
- **Установление отцовства:** Сравнение STR-профилей
- **Идентификация жертв катастроф**

```python
# Пример: сравнение STR-профилей
def compare_str_profiles(profile1, profile2, loci):
    """
    Сравнение двух STR-профилей
    
    profile: словарь {локус: (аллель1, аллель2)}
    """
    matches = 0
    for locus in loci:
        alleles1 = set(profile1.get(locus, ()))
        alleles2 = set(profile2.get(locus, ()))
        
        # Проверяем перекрытие аллелей
        if alleles1 & alleles2:  # Есть общие аллели
            matches += 1
    
    match_rate = matches / len(loci)
    return match_rate

# Пример: проверка отцовства
child_profile = {
    'D13S317': (8, 11),    # Унаследовал 8 или 11 от каждого родителя
    'D7S820': (10, 12),
    'D3S1358': (15, 17),
}

alleged_father = {
    'D13S317': (8, 9),     # Имеет аллель 8 — может передать ребёнку
    'D7S820': (10, 10),    # Имеет аллель 10 — может передать
    'D3S1358': (14, 17),   # Имеет аллель 17 — может передать
}

# Все аллели ребёнка должны быть у родителей
# match_rate = 1.0 — отцовство не исключено
# match_rate < 1.0 — отцовство исключено
```

### 2.5 CNV — Вариации Числа Копий

**CNV (Copy Number Variation)** — участки ДНК от 1 кб до нескольких Мб, количество копий которых варьирует между людьми.

```
Нормальный геном:    [Ген A] [Ген B] [Ген C] [Ген D]
                        1       1       1       1     (по 2 копии каждого гена)

CNV - делеция:       [Ген A]    -    [Ген C] [Ген D]
                        1       0       1       1     (ген B удалён)

CNV - дупликация:    [Ген A] [Ген B] [Ген B] [Ген C] [Ген D]
                        1       2       2       1       1     (ген B удвоен)

CNV - амплификация:  [Ген A] [Ген B] [Ген B] [Ген B] [Ген B] [Ген C] [Ген D]
                        1       4       4       4       4       1       1     (много копий)
```

**Клиническое значение CNV:**
- **Делеция 22q11.2** — синдром Ди Джорджи
- **Амплификация HER2** — агрессивный рак молочной железы (мишень для терапии)
- **Делеция SMN1** — спинальная мышечная атрофия

```python
# Пример: детекция CNV
def detect_cnv(read_depth, normal_depth, threshold=0.5):
    """
    Обнаружение CNV по глубине покрытия
    
    read_depth: наблюдаемая глубина покрытия в регионе
    normal_depth: ожидаемая нормальная глубина
    threshold: порог для детекции (log2 ratio)
    """
    import math
    
    ratio = read_depth / normal_depth
    log2_ratio = math.log2(ratio)
    
    if log2_ratio < -threshold:
        return f"Делеция (log2 ratio: {log2_ratio:.2f})"
    elif log2_ratio > threshold:
        return f"Амплификация (log2 ratio: {log2_ratio:.2f})"
    else:
        return f"Норма (log2 ratio: {log2_ratio:.2f})"

# Примеры
print(detect_cnv(15, 30))   # Делеция (половина от нормы)
print(detect_cnv(60, 30))   # Амплификация (вдвое больше нормы)
print(detect_cnv(28, 30))   # Норма
```

## 3. Применение Маркеров

### 3.1 Медицинская диагностика

| Область | Маркер | Применение |
|---------|--------|------------|
| **Кардиология** | rs1801133 (MTHFR) | Риск сердечно-сосудистых заболеваний |
| **Онкология** | BRCA1/2 мутации | Риск рака молочной железы/яичников |
| **Гематология** | HFE мутации | Гемохроматоз |
| **Неврология** | APOE ε4 | Риск болезни Альцгеймера |

### 3.2 Фармакогенетика

**Фармакогенетика** — подбор лекарств и дозировок на основе генотипа пациента.

| Ген | Маркер | Препарат | Рекомендация |
|-----|--------|----------|--------------|
| **CYP2C19** | *2, *3 | Клопидогрел | Слабые метаболизаторы — альтернативный препарат |
| **CYP2D6** | Множ. аллели | Кодеин | Ультрабыстрые метаболизаторы — снижение дозы |
| **VKORC1** | rs9923231 | Варфарин | Корректировка дозы по генотипу |
| **HLA-B*5701** | — | Абакавир | Носители — противопоказан (гиперчувствительность) |

```python
# Пример: рекомендации по варфарину
def warfarin_dosing(vkorc1_genotype, cyp2c9_genotype):
    """
    Расчёт стартовой дозы варфарина по генотипу
    
    Упрощённый алгоритм на основе клинических рекомендаций
    """
    base_dose = 5.0  # мг/день
    
    # Корректировка по VKORC1
    vkorc1_adjustment = {
        'GG': 1.0,   # Нормальный метаболизм
        'GA': 0.75,  # Промежуточный
        'AA': 0.5,   # Чувствительность к варфарину
    }
    
    # Корректировка по CYP2C9
    cyp2c9_adjustment = {
        '*1/*1': 1.0,   # Нормальный метаболизм
        '*1/*2': 0.8,   # Промежуточный
        '*1/*3': 0.65,  # Сниженный метаболизм
        '*2/*2': 0.6,
        '*2/*3': 0.45,
        '*3/*3': 0.3,   # Очень медленный метаболизм
    }
    
    dose = base_dose * vkorc1_adjustment.get(vkorc1_genotype, 1.0) \
                     * cyp2c9_adjustment.get(cyp2c9_genotype, 1.0)
    
    return round(dose, 1)

# Пример
print(f"Рекомендуемая доза: {warfarin_dosing('GA', '*1/*3')} мг/день")
# Output: Рекомендуемая доза: 2.4 мг/день
```

### 3.3 Криминалистика

**ДНК-профилирование** использует STR-маркеры для идентификации личности.

**CODIS (Combined DNA Index System):**
- Система FBI для хранения ДНК-профилей
- Использует 20 STR локусов (с 2017 года)
- Вероятность случайного совпадения: < 1 на квинтиллион

```python
# Пример: расчёт вероятности случайного совпадения
def random_match_probability(allele_frequencies, profile):
    """
    Расчёт вероятности случайного совпадения профиля
    
    allele_frequencies: словарь {локус: {аллель: частота}}
    profile: словарь {локус: (аллель1, аллель2)}
    """
    probability = 1.0
    
    for locus, (allele1, allele2) in profile.items():
        freq1 = allele_frequencies[locus].get(allele1, 0.01)
        freq2 = allele_frequencies[locus].get(allele2, 0.01)
        
        if allele1 == allele2:
            # Гомозигота: p²
            locus_prob = freq1 ** 2
        else:
            # Гетерозигота: 2pq
            locus_prob = 2 * freq1 * freq2
        
        probability *= locus_prob
    
    return probability

# При 20 локусах вероятность случайного совпадения ~10^-24
```

## 4. GWAS — Полногеномные Ассоциативные Исследования

### 4.1 Что такое GWAS?

**GWAS (Genome-Wide Association Study)** — метод поиска генетических вариантов (обычно SNP), связанных с признаком или заболеванием.

**Принцип:**
1. Собрать группу людей с признаком (случаи) и без него (контроль)
2. Генотипировать сотни тысяч SNP у всех участников
3. Сравнить частоты каждого SNP между группами
4. SNP с значимо разной частотой — потенциальные маркеры

```
           Случаи (болезнь)    Контроль (здоровы)
SNP rs123:     AA: 60%             AA: 30%
               AG: 30%             AG: 50%
               GG: 10%             GG: 20%
               
→ Аллель A чаще у больных → rs123 ассоциирован с болезнью
```

### 4.2 Манхэттенский график

**Манхэттенский график** — стандартная визуализация результатов GWAS:

- Ось X: позиции SNP по хромосомам
- Ось Y: -log10(p-value) — значимость ассоциации
- Пик выше порога (обычно p < 5×10⁻⁸) — значимый сигнал

```
-log10(p)
    |
 12 |                    *
 10 |                   ***
  8 |-------------------***------- порог значимости (5×10⁻⁸)
  6 |     *    *       *****  *
  4 |   * ** * ** *   ******* **
  2 | ********************* *****
    +---------------------------------> позиция в геноме
      chr1  chr2  chr3  ... chr22
```

### 4.3 Реализация GWAS

```python
import numpy as np
from scipy import stats

def gwas_analysis(genotypes, phenotypes, snp_ids):
    """
    Упрощённый GWAS анализ
    
    genotypes: матрица (n_samples × n_snps), значения 0, 1, 2
    phenotypes: вектор (n_samples,), 0 = контроль, 1 = случай
    snp_ids: список ID SNP
    """
    results = []
    
    for i, snp_id in enumerate(snp_ids):
        snp_genotypes = genotypes[:, i]
        
        # Подсчёт аллелей в каждой группе
        cases = snp_genotypes[phenotypes == 1]
        controls = snp_genotypes[phenotypes == 0]
        
        # Chi-square тест (упрощённо)
        # В реальности используется логистическая регрессия
        contingency_table = [
            [np.sum(cases == 0), np.sum(cases == 1) + np.sum(cases == 2)],
            [np.sum(controls == 0), np.sum(controls == 1) + np.sum(controls == 2)]
        ]
        
        chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)
        
        # Расчёт отношения шансов (Odds Ratio)
        a, b = contingency_table[0]
        c, d = contingency_table[1]
        odds_ratio = (a * d) / (b * c) if b * c > 0 else np.inf
        
        results.append({
            'snp': snp_id,
            'p_value': p_value,
            'odds_ratio': odds_ratio,
            'significant': p_value < 5e-8
        })
    
    return sorted(results, key=lambda x: x['p_value'])

# Стандартный порог значимости для GWAS
GWAS_SIGNIFICANCE_THRESHOLD = 5e-8  # Коррекция на множественное тестирование
```

### 4.4 Ограничения GWAS

| Ограничение | Описание |
|-------------|----------|
| **Ассоциация ≠ причина** | Найденный SNP может быть связан с причинным вариантом, но не быть им |
| **Недостающая наследуемость** | GWAS объясняет лишь часть наследственной вариации признаков |
| **Популяционная специфичность** | Результаты могут не воспроизводиться в других популяциях |
| **Редкие варианты** | GWAS плохо детектирует редкие варианты с сильным эффектом |

## 6. Практический Пример: Интеграция Данных

```python
class PatientGenomicProfile:
    """
    Интегрированный геномный профиль пациента
    """
    def __init__(self, patient_id):
        self.patient_id = patient_id
        self.snps = {}          # SNP генотипы
        self.methylation = {}   # Уровни метилирования
        self.expression = {}    # Экспрессия генов
    
    def add_snp(self, rsid, genotype):
        self.snps[rsid] = genotype
    
    def add_methylation(self, gene, level):
        self.methylation[gene] = level
    
    def add_expression(self, gene, tpm):
        self.expression[gene] = tpm
    
    def get_pharmacogenomic_recommendations(self):
        """Рекомендации по фармакогенетике"""
        recommendations = []
        
        # Пример: варфарин
        if 'rs9923231' in self.snps:
            genotype = self.snps['rs9923231']
            if genotype in ['AA', 'GA']:
                recommendations.append({
                    'drug': 'Варфарин',
                    'recommendation': 'Снизить стартовую дозу',
                    'genotype': genotype
                })
        
        return recommendations
    
    def get_epigenetic_age(self):
        """Оценка эпигенетического возраста"""
        # Упрощённая модель
        if not self.methylation:
            return None
        
        avg_methylation = sum(self.methylation.values()) / len(self.methylation)
        # Реальные часы используют сложные модели
        return 20 + avg_methylation * 60
    
    def generate_report(self):
        """Генерация отчёта"""
        report = f"=== Геномный профиль пациента {self.patient_id} ===\n\n"
        
        report += f"SNP маркеров: {len(self.snps)}\n"
        report += f"Генов с данными метилирования: {len(self.methylation)}\n"
        report += f"Генов с данными экспрессии: {len(self.expression)}\n\n"
        
        recommendations = self.get_pharmacogenomic_recommendations()
        if recommendations:
            report += "Фармакогенетические рекомендации:\n"
            for rec in recommendations:
                report += f"  - {rec['drug']}: {rec['recommendation']}\n"
        
        epigenetic_age = self.get_epigenetic_age()
        if epigenetic_age:
            report += f"\nЭпигенетический возраст: ~{epigenetic_age:.0f} лет\n"
        
        return report

# Пример использования
patient = PatientGenomicProfile("P001")
patient.add_snp("rs9923231", "GA")
patient.add_snp("rs762551", "AA")
patient.add_methylation("BRCA1", 0.15)
patient.add_methylation("MLH1", 0.20)
patient.add_expression("TP53", 45.2)

print(patient.generate_report())
```

### Эпигенетика

**Что такое эпигенетика?**
- Изменения в работе генов **без изменения последовательности ДНК**
- Главный механизм: **метилирование ДНК**
- Метилирование обычно **выключает** ген

**Что влияет на эпигенетику?**
- Возраст, питание, стресс, окружающая среда, физическая активность

### Генетические маркеры

**Типы маркеров:**
- **SNP** — замена одного нуклеотида (самый частый)
- **STR** — повторы для идентификации
- **CNV** — вариации числа копий

**Применение:**
- Диагностика заболеваний
- Фармакогенетика
- Криминалистика
- GWAS-исследования
