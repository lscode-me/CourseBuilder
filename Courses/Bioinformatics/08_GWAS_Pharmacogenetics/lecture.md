## 2. Фармакогенетика: Концепции

Фармакогенетика изучает, **как генетические различия между людьми влияют на фармакокинетику и фармакодинамику** лекарств.

Классическая схема:

- Ген → белок (фермент, транспортер, рецептор)
- Белок влияет на **ADME** (Absorption, Distribution, Metabolism, Excretion) или чувствительность к препарату
- Полиморфизмы в генах этих белков → различия в ответе и рисках побочных эффектов

```python
from dataclasses import dataclass

@dataclass
class PharmVariant:
    gene: str
    variant: str
    phenotype: str
    recommendation: str

warfarin_vkorc1 = PharmVariant(
    gene="VKORC1",
    variant="rs9923231 A-аллель",
    phenotype="повышенная чувствительность к варфарину",
    recommendation="начинать с более низкой дозы и титровать осторожно",
)

print(warfarin_vkorc1)
```

## 4. GWAS — Полногеномные Ассоциативные Исследования

### 4.1 Что такое GWAS?

**GWAS (Genome-Wide Association Study)** — метод поиска генетических вариантов (обычно SNP), связанных с признаком или заболеванием.

**Принцип:**

1. Собрать группу людей с признаком (случаи) и без него (контроль)
2. Генотипировать сотни тысяч SNP у всех участников
3. Сравнить частоты каждого SNP между группами
4. SNP с значимо разной частотой — потенциальные маркеры

```
           Случаи (болезнь)    Контроль (здоровы)
SNP rs123:     AA: 60%             AA: 30%
               AG: 30%             AG: 50%
               GG: 10%             GG: 20%
               
→ Аллель A чаще у больных → rs123 ассоциирован с болезнью
```

### 4.2 Манхэттенский график

**Манхэттенский график** — стандартная визуализация результатов GWAS:

- Ось X: позиции SNP по хромосомам
- Ось Y: -log10(p-value) — значимость ассоциации
- Пик выше порога (обычно p < 5×10⁻⁸) — значимый сигнал

```
-log10(p)
    |
 12 |                    *
 10 |                   ***
  8 |-------------------***------- порог значимости (5×10⁻⁸)
  6 |     *    *       *****  *
  4 |   * ** * ** *   ******* **
  2 | ********************* *****
    +---------------------------------> позиция в геноме
      chr1  chr2  chr3  ... chr22
```

### 4.3 Реализация GWAS

```python
import numpy as np
from scipy import stats

def gwas_analysis(genotypes, phenotypes, snp_ids):
    """
    Упрощённый GWAS анализ
    
    genotypes: матрица (n_samples × n_snps), значения 0, 1, 2
    phenotypes: вектор (n_samples,), 0 = контроль, 1 = случай
    snp_ids: список ID SNP
    """
    results = []
    
    for i, snp_id in enumerate(snp_ids):
        snp_genotypes = genotypes[:, i]
        
        # Подсчёт аллелей в каждой группе
        cases = snp_genotypes[phenotypes == 1]
        controls = snp_genotypes[phenotypes == 0]
        
        # Chi-square тест (упрощённо)
        # В реальности используется логистическая регрессия
        contingency_table = [
            [np.sum(cases == 0), np.sum(cases == 1) + np.sum(cases == 2)],
            [np.sum(controls == 0), np.sum(controls == 1) + np.sum(controls == 2)]
        ]
        
        chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)
        
        # Расчёт отношения шансов (Odds Ratio)
        a, b = contingency_table[0]
        c, d = contingency_table[1]
        odds_ratio = (a * d) / (b * c) if b * c > 0 else np.inf
        
        results.append({
            'snp': snp_id,
            'p_value': p_value,
            'odds_ratio': odds_ratio,
            'significant': p_value < 5e-8
        })
    
    return sorted(results, key=lambda x: x['p_value'])

# Стандартный порог значимости для GWAS

GWAS_SIGNIFICANCE_THRESHOLD = 5e-8  # Коррекция на множественное тестирование
```

### 4.4 Ограничения GWAS

| Ограничение | Описание |
|-------------|----------|
| **Ассоциация ≠ причина** | Найденный SNP может быть связан с причинным вариантом, но не быть им |
| **Недостающая наследуемость** | GWAS объясняет лишь часть наследственной вариации признаков |
| **Популяционная специфичность** | Результаты могут не воспроизводиться в других популяциях |
| **Редкие варианты** | GWAS плохо детектирует редкие варианты с сильным эффектом |

## 5. Биомаркеры: Расширенная Концепция

### 5.1 Типы биомаркеров

**Биомаркер** — любой измеримый показатель, связанный с биологическим состоянием.

```
Биомаркеры по типу данных:

┌─────────────────────────────────────────────────────────────┐
│                      БИОМАРКЕРЫ                             │
├─────────────┬─────────────┬─────────────┬───────────────────┤
│ Геномные    │ Эпигеном.   │ Транскрипт. │ Протеомные/Метаб. │
│             │             │             │                   │
│ • SNP       │ • Метилир.  │ • мРНК      │ • Белки           │
│ • CNV       │ • Гистоны   │ • микроРНК  │ • Метаболиты      │
│ • Мутации   │             │             │ • Гормоны         │
├─────────────┴─────────────┴─────────────┴───────────────────┤
│ Постоянные ←──────────────────────────────────→ Динамичные  │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 Примеры биомаркеров

| Категория | Биомаркер | Применение |
|-----------|-----------|------------|
| **Геномный** | BRCA1/2 мутации | Риск рака (постоянный) |
| **Эпигенетический** | Метилирование SEPT9 | Скрининг колоректального рака |
| **Транскриптомный** | Oncotype DX (21 ген) | Прогноз рака молочной железы |
| **Протеомный** | PSA | Скрининг рака простаты |
| **Метаболомный** | HbA1c | Контроль диабета |

## 6. Практический Пример: Интеграция Данных

```python
class PatientGenomicProfile:
    """
    Интегрированный геномный профиль пациента
    """
    def __init__(self, patient_id):
        self.patient_id = patient_id
        self.snps = {}          # SNP генотипы
        self.methylation = {}   # Уровни метилирования
        self.expression = {}    # Экспрессия генов
    
    def add_snp(self, rsid, genotype):
        self.snps[rsid] = genotype
    
    def add_methylation(self, gene, level):
        self.methylation[gene] = level
    
    def add_expression(self, gene, tpm):
        self.expression[gene] = tpm
    
    def get_pharmacogenomic_recommendations(self):
        """Рекомендации по фармакогенетике"""
        recommendations = []
        
        # Пример: варфарин
        if 'rs9923231' in self.snps:
            genotype = self.snps['rs9923231']
            if genotype in ['AA', 'GA']:
                recommendations.append({
                    'drug': 'Варфарин',
                    'recommendation': 'Снизить стартовую дозу',
                    'genotype': genotype
                })
        
        return recommendations
    
    def get_epigenetic_age(self):
        """Оценка эпигенетического возраста"""
        # Упрощённая модель
        if not self.methylation:
            return None
        
        avg_methylation = sum(self.methylation.values()) / len(self.methylation)
        # Реальные часы используют сложные модели
        return 20 + avg_methylation * 60
    
    def generate_report(self):
        """Генерация отчёта"""
        report = f"=== Геномный профиль пациента {self.patient_id} ===\n\n"
        
        report += f"SNP маркеров: {len(self.snps)}\n"
        report += f"Генов с данными метилирования: {len(self.methylation)}\n"
        report += f"Генов с данными экспрессии: {len(self.expression)}\n\n"
        
        recommendations = self.get_pharmacogenomic_recommendations()
        if recommendations:
            report += "Фармакогенетические рекомендации:\n"
            for rec in recommendations:
                report += f"  - {rec['drug']}: {rec['recommendation']}\n"
        
        epigenetic_age = self.get_epigenetic_age()
        if epigenetic_age:
            report += f"\nЭпигенетический возраст: ~{epigenetic_age:.0f} лет\n"
        
        return report

# Пример использования

patient = PatientGenomicProfile("P001")
patient.add_snp("rs9923231", "GA")
patient.add_snp("rs762551", "AA")
patient.add_methylation("BRCA1", 0.15)
patient.add_methylation("MLH1", 0.20)
patient.add_expression("TP53", 45.2)

print(patient.generate_report())
```

### Эпигенетика

**Что такое эпигенетика?**
- Изменения в работе генов **без изменения последовательности ДНК**
- Главный механизм: **метилирование ДНК**
- Метилирование обычно **выключает** ген

**Что влияет на эпигенетику?**
- Возраст, питание, стресс, окружающая среда, физическая активность

### Генетические маркеры

**Типы маркеров:**

- **SNP** — замена одного нуклеотида (самый частый)

- **STR** — повторы для идентификации

- **CNV** — вариации числа копий

**Применение:**

- Диагностика заболеваний
- Фармакогенетика
- Криминалистика
- GWAS-исследования

## 💡 Key Takeaways

- **Эпигенетика** — регуляция генов без изменения последовательности ДНК (метилирование, гистоны)

- **Метилирование CpG** — добавление метильной группы к цитозину, обычно подавляет экспрессию гена

- **GWAS** — поиск ассоциаций между вариантами и признаками/заболеваниями на популяционном уровне

- **P-value < 5×10⁻⁸** — стандартный порог genome-wide significance в GWAS

- **Фармакогенетика** — влияние генетических вариантов на метаболизм и эффективность лекарств
