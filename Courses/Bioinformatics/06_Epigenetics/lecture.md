## 2. Эпигенетика: Регуляция Поверх ДНК

### 1.1 Что такое эпигенетика?

**Эпигенетика** (от греч. "эпи" — над, сверху) — это наука об изменениях в экспрессии генов, которые **не изменяют саму последовательность ДНК**, но могут передаваться при делении клеток и даже между поколениями.

**Ключевая идея:** Два человека (или две клетки) могут иметь идентичную последовательность ДНК, но совершенно разные паттерны работы генов.

**Аналогия:** Если ДНК — это книга, то эпигенетика — это закладки, подчёркивания и заметки на полях. Текст книги не меняется, но читается по-разному.

```

Последовательность ДНК:     ATCGATCGATCG... (одинаковая у всех клеток)
                                  ↓
Эпигенетические метки:      ●  ●     ●  ●   (разные в разных клетках)
                                  ↓
Экспрессия:                 [ген ВКЛ] или [ген ВЫКЛ]

```

### 1.2 Основные эпигенетические механизмы

| Механизм | Что происходит | Влияние на ген |
|----------|----------------|----------------|
| **Метилирование ДНК** | К цитозину (C) добавляется метильная группа (-CH₃) | Обычно **выключает** ген |
| **Модификация гистонов** | Химические метки на белках-гистонах, вокруг которых намотана ДНК | Может включать или выключать |
| **Ремоделирование хроматина** | Изменение плотности упаковки ДНК | Плотная упаковка = ген недоступен |
| **Некодирующие РНК** | Регуляторные РНК, не кодирующие белки | Могут подавлять экспрессию генов |

### 1.3 Метилирование ДНК

**Метилирование** — это добавление метильной группы (-CH₃) к нуклеотиду цитозин (C). Это самый изученный эпигенетический механизм.

**Где происходит метилирование:**

- В основном в **CpG сайтах** — местах, где цитозин (C) стоит перед гуанином (G)
- В геноме человека ~28 миллионов CpG сайтов
- Особенно важны **CpG островки** — участки с высокой концентрацией CpG, часто расположенные в промоторах генов

```

Немелированный цитозин:     5'-...ATCG ATCG...
                                      ↑
                                  CpG сайт
                                      ↓
                            Ген АКТИВЕН (может читаться)

Метилированный цитозин:     5'-...ATmCG ATmCG...
                                      ↑
                              метильная группа (-CH₃)
                                      ↓
                            Ген ВЫКЛЮЧЕН (не читается)

```

**Как это работает:**

1. Метильная группа физически мешает связыванию транскрипционных факторов
2. Метилированная ДНК привлекает белки, которые компактизируют хроматин
3. Результат: ген становится недоступен для транскрипции

```python
# Пример: анализ метилирования
def analyze_methylation(cpg_sites):
    """
    Анализ уровня метилирования в регионе
    
    cpg_sites: список словарей с информацией о каждом CpG сайте
    """
    methylated = sum(1 for site in cpg_sites if site['methylated'])
    total = len(cpg_sites)
    methylation_level = methylated / total * 100
    
    if methylation_level > 70:
        return f"Высокое метилирование ({methylation_level:.1f}%) - ген вероятно ВЫКЛЮЧЕН"
    elif methylation_level < 30:
        return f"Низкое метилирование ({methylation_level:.1f}%) - ген вероятно АКТИВЕН"
    else:
        return f"Промежуточный уровень ({methylation_level:.1f}%) - требуется дополнительный анализ"

# Пример данных
promoter_cpg_sites = [
    {'position': 1000, 'methylated': False},
    {'position': 1020, 'methylated': False},
    {'position': 1045, 'methylated': True},
    {'position': 1060, 'methylated': False},
    {'position': 1080, 'methylated': False},
]

print(analyze_methylation(promoter_cpg_sites))
# Output: "Низкое метилирование (20.0%) - ген вероятно АКТИВЕН"

```

### 1.4 Модификация гистонов

**Гистоны** — это белки, вокруг которых намотана ДНК (как нитка вокруг катушки). Химические модификации гистонов влияют на доступность ДНК.

**Структура хроматина:**
```

    ДНК (двойная спираль)
         ↓
┌─────────────────────────────┐
│  ~~~~~~●~~~~~~●~~~~~~●~~~~  │  ● = нуклеосома (ДНК + гистоны)
│        │      │      │      │
│     гистоны (H2A, H2B, H3, H4)
└─────────────────────────────┘
         ↓
Компактная упаковка → Хромосома

```

**Основные модификации гистонов:**

| Модификация | Обозначение | Эффект |
|-------------|-------------|--------|
| **Ацетилирование** | H3K9ac, H3K27ac | Активация гена (открытый хроматин) |
| **Метилирование** | H3K4me3 | Активация гена |
| **Метилирование** | H3K9me3, H3K27me3 | Репрессия гена (закрытый хроматин) |
| **Фосфорилирование** | H3S10p | Конденсация хромосом при делении |

**Обозначения:** H3K9ac = гистон H3, лизин (K) в позиции 9, ацетилирование (ac)

```python
# Пример: интерпретация гистоновых меток
def interpret_histone_marks(marks):
    """
    Интерпретация набора гистоновых модификаций
    """
    activating = ['H3K4me3', 'H3K27ac', 'H3K9ac', 'H3K36me3']
    repressive = ['H3K9me3', 'H3K27me3', 'H4K20me3']
    
    active_count = sum(1 for m in marks if m in activating)
    repressive_count = sum(1 for m in marks if m in repressive)
    
    if active_count > repressive_count:
        return "Активный промотор/энхансер"
    elif repressive_count > active_count:
        return "Репрессированный регион"
    else:
        return "Бивалентный или poised регион"

# Пример
gene_marks = ['H3K4me3', 'H3K27ac']
print(interpret_histone_marks(gene_marks))
# Output: "Активный промотор/энхансер"

```

### 1.5 Что влияет на эпигенетику?

Эпигенетический профиль не статичен — он меняется под воздействием внешних и внутренних факторов:

| Фактор | Как влияет | Примеры |
|--------|------------|---------|
| **Возраст** | Накопление эпигенетических изменений | "Эпигенетические часы" — можно оценить биологический возраст по метилированию |
| **Питание** | Доноры метильных групп из пищи | Фолиевая кислота, витамин B12, метионин влияют на метилирование |
| **Стресс** | Изменяет паттерны метилирования | Хронический стресс меняет экспрессию генов стресс-ответа |
| **Окружающая среда** | Токсины, загрязнение | Курение изменяет метилирование >7000 CpG сайтов |
| **Физическая активность** | Влияет на экспрессию метаболических генов | Тренировки меняют эпигенетику мышц и метаболизма |
| **Ранний опыт** | Формирует базовые паттерны | Качество ухода в детстве влияет на эпигенетику генов стресса |

**Эпигенетические часы (Horvath clock):**

```python
# Упрощённый пример эпигенетических часов
def estimate_biological_age(methylation_data, clock_cpg_sites):
    """
    Оценка биологического возраста по метилированию
    
    Реальные часы используют 353-500+ CpG сайтов
    и сложные регрессионные модели
    """
    # Взвешенная сумма уровней метилирования
    weighted_sum = sum(
        methylation_data.get(cpg, 0) * weight 
        for cpg, weight in clock_cpg_sites.items()
    )
    
    # Преобразование в возраст (упрощённо)
    biological_age = 20 + weighted_sum * 50
    
    return biological_age

# Пример: биологический возраст может отличаться от хронологического
# Здоровый образ жизни → биол. возраст < хронологического
# Курение, стресс → биол. возраст > хронологического

```

### 1.6 Почему эпигенетика важна?

**1. Объясняет различия однояйцевых близнецов:**

- Одинаковая ДНК, но разные эпигенетические профили со временем
- Объясняет, почему один близнец может заболеть, а другой нет

**2. Связь генетики и среды:**

- Эпигенетика — это "мост" между генами и окружающей средой
- Объясняет, как образ жизни влияет на работу генов

**3. Роль в заболеваниях:**

- **Рак:** Аберрантное метилирование генов-супрессоров опухолей

- **Нейродегенеративные заболевания:** Изменения в паттернах модификации гистонов

- **Метаболические расстройства:** Эпигенетическое программирование в утробе

**4. Потенциал терапии:**

- Эпигенетические изменения **обратимы** (в отличие от мутаций ДНК)
- Уже существуют эпигенетические препараты (ингибиторы DNMT, HDAC)

```python
# Пример: эпигенетические изменения при раке
def detect_tumor_suppressor_silencing(gene_methylation):
    """
    Обнаружение аберрантного метилирования генов-супрессоров опухолей
    """
    tumor_suppressors = {
        'BRCA1': 'Рак молочной железы',
        'MLH1': 'Колоректальный рак',
        'CDKN2A': 'Различные типы рака',
        'VHL': 'Рак почки',
        'RB1': 'Ретинобластома',
    }
    
    silenced_genes = []
    for gene, methylation_level in gene_methylation.items():
        if gene in tumor_suppressors and methylation_level > 0.7:
            silenced_genes.append({
                'gene': gene,
                'methylation': methylation_level,
                'associated_cancer': tumor_suppressors[gene]
            })
    
    return silenced_genes
    
```

## 3. Эпигенетические Данные и Технологии

### 3.1 Источники эпигенетических данных

В реальных проектах вы будете работать не с "абстрактным метилированием", а с конкретными типами данных:

- **BS-seq (Bisulfite Sequencing)** — золотой стандарт для измерения метилирования ДНК на уровне отдельных CpG сайтов

- **ChIP-seq** — данные по модификациям гистонов и белкам, связывающимся с ДНК

- **ATAC-seq / DNase-seq** — данные о "открытом" хроматине (участки, доступные для транскрипции)

- **Массивы метилирования (Illumina 450K/EPIC)** — дешёвый способ измерить метилирование в сотнях тысяч CpG

```python
# Упрощённое представление данных метилирования из BS-seq
from dataclasses import dataclass
from statistics import mean

@dataclass
class CpGMethylation:
    chrom: str
    position: int
    methylated_reads: int
    unmethylated_reads: int

    @property
    def beta(self) -> float:
        """Доля метилированных чтений (0.0–1.0)"""
        total = self.methylated_reads + self.unmethylated_reads
        return self.methylated_reads / total if total > 0 else 0.0


def region_methylation(cpg_list: list[CpGMethylation]) -> float:
    """Средний уровень метилирования региона"""
    if not cpg_list:
        return 0.0
    return mean(cpg.beta for cpg in cpg_list)


promoter = [
    CpGMethylation("chr17", 43044295, methylated_reads=5, unmethylated_reads=45),
    CpGMethylation("chr17", 43044310, methylated_reads=10, unmethylated_reads=40),
    CpGMethylation("chr17", 43044330, methylated_reads=30, unmethylated_reads=20),
]

print(f"Среднее метилирование промотора: {region_methylation(promoter)*100:.1f}%")
```

### 3.2 Дифференциальное метилирование

Частая задача — найти CpG или регионы, которые **по-разному метилированы** между группами (например, "здоровые" vs "больные").

```python

def differential_methylation(cases: list[float], controls: list[float], threshold: float = 0.2):
    """
    Очень упрощённая метрика дифференциального метилирования.
    
    cases / controls: списки beta-значений (0.0–1.0) для CpG сайта
    threshold: порог по разнице средних (20% = 0.2)
    """
    mean_cases = mean(cases)
    mean_controls = mean(controls)
    diff = mean_cases - mean_controls
    
    status = "no_change"
    if abs(diff) >= threshold:
        status = "hypermethylated" if diff > 0 else "hypomethylated"
    
    return {
        "mean_cases": mean_cases,
        "mean_controls": mean_controls,
        "diff": diff,
        "status": status,
    }


case_values = [0.8, 0.85, 0.9]    # больные
control_values = [0.2, 0.25, 0.3] # контролі
print(differential_methylation(case_values, control_values))
```

## 4. Эпигенетика и Заболевания

### 4.1 Онкология

В онкологии эпигенетика используется **наравне с мутациями**:

- Гиперметилирование промоторов генов-супрессоров опухолей (BRCA1, MLH1, CDKN2A)
- Глобальная гипометиляция генома → геномная нестабильность
- Специфические паттерны модификаций гистонов в онкогенах

```python

def classify_tumor_profile(mutations: list[str], methylation: dict[str, float]) -> list[str]:
    """
    Игрушечный пример интеграции мутаций и эпигенетики
    """
    flags = []
    
    if "BRCA1_LOF" in mutations or methylation.get("BRCA1_promoter", 0) > 0.7:
        flags.append("defective_DNA_repair")
    
    if methylation.get("MLH1_promoter", 0) > 0.7:
        flags.append("mismatch_repair_defect")
    
    if methylation.get("global", 0) < 0.3:
        flags.append("global_hypomethylation")
    
    return flags
```

### 4.2 Эпигенетические биомаркеры

| Область | Биомаркер | Что измеряется | Применение |
|--------|-----------|----------------|------------|
| Онкология | Метилирование промотора **SEPT9** | CpG-метки в плазме крови | Скрининг колоректального рака |
| Онкология | Метилирование **MGMT** | Метилирование промотора в опухоли мозга | Выбор терапии темозоломидом |
| Диагностика | Эпигенетические часы (Horvath, Hannum) | Метилирование сотен CpG | Оценка биологического возраста |
| Иммунология | Метилирование генов цитокинов | Метилирование промоторов IL6, TNF и др. | Оценка хронического воспаления |

## 5. Практика: Мини-пайплайн Эпигенетического Анализа

### 5.1 Этапы анализа метилирования

1. Получить **сырые данные** (FASTQ от BS-seq или IDAT файлы от метил-массивов)
2. Провести **QC** (качество чтений, распределение интенсивностей)
3. Выполнить **выравнивание** на референс с учётом бисульфит-преобразования
4. Подсчитать **beta-значения** по CpG сайтам или регионам
5. Найти **дифференциально метилированные** CpG/регионы между группами
6. Связать эпигенетические изменения с генами и путями (pathways)

```python

    """
    def __init__(self, fastq_paths: list[str], reference: str):
        self.fastq_paths = fastq_paths
        self.reference = reference
    
    def run_qc(self):
        print("1) QC: проверка качества FASTQ (FastQC и др.)")
    
    def align(self):
        print("2) Выравнивание с учётом бисульфит-преобразования (bismark/bwa-meth)")
```

## 💡 Key Takeaways

- **Эпигенетика** описывает изменения в экспрессии генов **без изменения последовательности ДНК** (метилирование, модификации гистонов, ремоделирование хроматина).

- **Метилирование CpG** в промоторах, как правило, **выключает** гены, а неметилированные промоторы соответствуют активным генам.

- **Гистоновые модификации** формируют "язык" хроматина, который определяет, какие регионы генома открыты или закрыты для транскрипции.

- **Эпигенетические профили динамичны** и зависят от возраста, образа жизни и окружающей среды, создавая связь между генетикой и средой.

- **Эпигенетика важна в медицине**: от эпигенетических биомаркеров и "эпигенетических часов" до таргетных терапий, нацеленных на ферменты, изменяющие метки.
