## Question 14: Кодовый пример detect_cnv

Рассмотрим упрощённую функцию:

```python

import math

def detect_cnv(read_depth, normal_depth, threshold=0.5):
    ratio = read_depth / normal_depth
    log2_ratio = math.log2(ratio)
    if log2_ratio < -threshold:
        return "Deletion"
    elif log2_ratio > threshold:
        return "Amplification"
    else:
        return "Normal"
```

Какой результат вернёт `detect_cnv(15, 30)`?
