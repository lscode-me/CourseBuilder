## 1. Введение

Генетические маркеры — это "маячки" в геноме, по которым мы можем отслеживать наследование, искать ассоциации с признаками и строить прикладные тесты (диагностические панели, фармакогенетические тесты, ДНК‑паспорта).

С точки зрения инженера, маркер — это **координата в геноме + набор возможных значений (аллелей) + частоты в популяции + связь с фенотипом**.

---

## 2. Генетические Маркеры

### 2.1 Что такое генетический маркер?

**Генетический маркер** — это определённый участок ДНК с известным расположением в геноме, который можно использовать для:

- Идентификации индивида
- Связи с признаком или заболеванием
- Отслеживания наследования

**Ключевое свойство:** Маркер должен быть **полиморфным** — иметь разные варианты (аллели) в популяции.

### 2.2 Типы генетических маркеров

| Тип маркера | Описание | Частота | Применение |
|-------------|----------|---------|------------|
| **SNP** | Однонуклеотидные полиморфизмы | ~10 млн у человека | GWAS, фармакогенетика |
| **STR/Микросателлиты** | Короткие повторяющиеся последовательности (2-6 букв) | ~100,000 | ДНК-дактилоскопия, отцовство |
| **CNV** | Вариации числа копий участков ДНК | ~1,000 | Онкология, редкие заболевания |
| **Индели** | Вставки/делеции 1-50 нуклеотидов | ~1 млн | Диагностика заболеваний |

### 2.3 SNP — Однонуклеотидные Полиморфизмы

**SNP (Single Nucleotide Polymorphism)** — замена одного нуклеотида, которая встречается в популяции с частотой >1%.

```

                     rs12345 (ID маркера в базе данных dbSNP)
                         ↓
Референс:    ...ATCGATCGATCGATCG...
                     ↑
Вариант 1:   ...ATCGATCAATCGATCG...  (аллель A) — частота 60%
Вариант 2:   ...ATCGATCGATCGATCG...  (аллель G) — частота 40%

Человек может иметь генотип: AA, AG, или GG

```

**Характеристики SNP:**

- В геноме человека ~10 миллионов известных SNP
- В среднем один SNP на каждые ~300 нуклеотидов
- Большинство нейтральны, но некоторые влияют на признаки и болезни

```python
# Пример: работа с SNP данными
class SNP:
    def __init__(self, rsid, chromosome, position, ref_allele, alt_allele):
        self.rsid = rsid              # ID в базе данных (rs12345)
        self.chromosome = chromosome   # Хромосома
        self.position = position       # Позиция в хромосоме
        self.ref_allele = ref_allele   # Референсный аллель
        self.alt_allele = alt_allele   # Альтернативный аллель
    
    def __repr__(self):
        return f"{self.rsid}: chr{self.chromosome}:{self.position} {self.ref_allele}>{self.alt_allele}"

# Пример SNP, связанного с метаболизмом кофеина
cyp1a2_snp = SNP(
    rsid="rs762551",
    chromosome=15,
    position=75041917,
    ref_allele="A",
    alt_allele="C"
)

def interpret_caffeine_metabolism(genotype):
    """
    rs762551 влияет на скорость метаболизма кофеина
    """
    if genotype == "AA":
        return "Быстрый метаболизм кофеина"
    elif genotype == "AC":
        return "Средний метаболизм кофеина"
    else:  # CC
        return "Медленный метаболизм кофеина"

```

### 2.4 STR — Микросателлиты

**STR (Short Tandem Repeats)** — короткие последовательности (2-6 нуклеотидов), повторённые много раз подряд.

```

Пример STR локуса D13S317:
                    (GATA)n - повтор из 4 букв

Человек 1:  ...GATA GATA GATA GATA GATA GATA GATA...  = 7 повторов
Человек 2:  ...GATA GATA GATA GATA GATA GATA GATA GATA GATA GATA GATA...  = 11 повторов
Человек 3:  ...GATA GATA GATA GATA GATA GATA GATA GATA GATA...  = 9 повторов

```

**Применение STR:**

- **ДНК-дактилоскопия:** Используется 13-20 STR локусов (CODIS)

- **Установление отцовства:** Сравнение STR-профилей

- **Идентификация жертв катастроф**

```python
# Пример: сравнение STR-профилей
def compare_str_profiles(profile1, profile2, loci):
    """
    Сравнение двух STR-профилей
    
    profile: словарь {локус: (аллель1, аллель2)}
    """
    matches = 0
    for locus in loci:
        alleles1 = set(profile1.get(locus, ()))
        alleles2 = set(profile2.get(locus, ()))
        
        # Проверяем перекрытие аллелей
        if alleles1 & alleles2:  # Есть общие аллели
            matches += 1
    
    match_rate = matches / len(loci)
    return match_rate

# Пример: проверка отцовства
child_profile = {
    'D13S317': (8, 11),    # Унаследовал 8 или 11 от каждого родителя
    'D7S820': (10, 12),
    'D3S1358': (15, 17),
}

alleged_father = {
    'D13S317': (8, 9),     # Имеет аллель 8 — может передать ребёнку
    'D7S820': (10, 10),    # Имеет аллель 10 — может передать
    'D3S1358': (14, 17),   # Имеет аллель 17 — может передать
}

# Все аллели ребёнка должны быть у родителей
# match_rate = 1.0 — отцовство не исключено
# match_rate < 1.0 — отцовство исключено

```

### 2.5 CNV — Вариации Числа Копий

**CNV (Copy Number Variation)** — участки ДНК от 1 кб до нескольких Мб, количество копий которых варьирует между людьми.

```

Нормальный геном:    [Ген A] [Ген B] [Ген C] [Ген D]
                        1       1       1       1     (по 2 копии каждого гена)

CNV - делеция:       [Ген A]    -    [Ген C] [Ген D]
                        1       0       1       1     (ген B удалён)

CNV - дупликация:    [Ген A] [Ген B] [Ген B] [Ген C] [Ген D]
                        1       2       2       1       1     (ген B удвоен)

CNV - амплификация:  [Ген A] [Ген B] [Ген B] [Ген B] [Ген B] [Ген C] [Ген D]
                        1       4       4       4       4       1       1     (много копий)

```

**Клиническое значение CNV:**

- **Делеция 22q11.2** — синдром Ди Джорджи

- **Амплификация HER2** — агрессивный рак молочной железы (мишень для терапии)

- **Делеция SMN1** — спинальная мышечная атрофия

```python
# Пример: детекция CNV
def detect_cnv(read_depth, normal_depth, threshold=0.5):
    """
    Обнаружение CNV по глубине покрытия
    
    read_depth: наблюдаемая глубина покрытия в регионе
    normal_depth: ожидаемая нормальная глубина
    threshold: порог для детекции (log2 ratio)
    """
    import math
    
    ratio = read_depth / normal_depth
    log2_ratio = math.log2(ratio)
    
    if log2_ratio < -threshold:
        return f"Делеция (log2 ratio: {log2_ratio:.2f})"
    elif log2_ratio > threshold:
        return f"Амплификация (log2 ratio: {log2_ratio:.2f})"
    else:
        return f"Норма (log2 ratio: {log2_ratio:.2f})"

# Примеры
print(detect_cnv(15, 30))   # Делеция (половина от нормы)
print(detect_cnv(60, 30))   # Амплификация (вдвое больше нормы)
print(detect_cnv(28, 30))   # Норма

```

### 3.2 Фармакогенетика

**Фармакогенетика** — подбор лекарств и дозировок на основе генотипа пациента.

| Ген | Маркер | Препарат | Рекомендация |
|-----|--------|----------|--------------|
| **CYP2C19** | *2, *3 | Клопидогрел | Слабые метаболизаторы — альтернативный препарат |
| **CYP2D6** | Множ. аллели | Кодеин | Ультрабыстрые метаболизаторы — снижение дозы |
| **VKORC1** | rs9923231 | Варфарин | Корректировка дозы по генотипу |
| **HLA-B*5701** | — | Абакавир | Носители — противопоказан (гиперчувствительность) |

```python
# Пример: рекомендации по варфарину
def warfarin_dosing(vkorc1_genotype, cyp2c9_genotype):
    """
    Расчёт стартовой дозы варфарина по генотипу
    
    Упрощённый алгоритм на основе клинических рекомендаций
    """
    base_dose = 5.0  # мг/день
    
    # Корректировка по VKORC1
    vkorc1_adjustment = {
        'GG': 1.0,   # Нормальный метаболизм
        'GA': 0.75,  # Промежуточный
        'AA': 0.5,   # Чувствительность к варфарину
    }
    
    # Корректировка по CYP2C9
    cyp2c9_adjustment = {
        '*1/*1': 1.0,   # Нормальный метаболизм
        '*1/*2': 0.8,   # Промежуточный
        '*1/*3': 0.65,  # Сниженный метаболизм
        '*2/*2': 0.6,
        '*2/*3': 0.45,
        '*3/*3': 0.3,   # Очень медленный метаболизм
    }
    
    dose = base_dose * vkorc1_adjustment.get(vkorc1_genotype, 1.0) \
                     * cyp2c9_adjustment.get(cyp2c9_genotype, 1.0)
    
    return round(dose, 1)

# Пример
print(f"Рекомендуемая доза: {warfarin_dosing('GA', '*1/*3')} мг/день")
# Output: Рекомендуемая доза: 2.4 мг/день

```

### 3.3 Криминалистика

**ДНК-профилирование** использует STR-маркеры для идентификации личности.

**CODIS (Combined DNA Index System):**

- Система FBI для хранения ДНК-профилей
- Использует 20 STR локусов (с 2017 года)
- Вероятность случайного совпадения: < 1 на квинтиллион

```python
# Пример: расчёт вероятности случайного совпадения
def random_match_probability(allele_frequencies, profile):
    """
    Расчёт вероятности случайного совпадения профиля
    
    allele_frequencies: словарь {локус: {аллель: частота}}
    profile: словарь {локус: (аллель1, аллель2)}
    """
    probability = 1.0
    
    for locus, (allele1, allele2) in profile.items():
        freq1 = allele_frequencies[locus].get(allele1, 0.01)
        freq2 = allele_frequencies[locus].get(allele2, 0.01)
        
        if allele1 == allele2:
            # Гомозигота: p²
            locus_prob = freq1 ** 2
        else:
            # Гетерозигота: 2pq
            locus_prob = 2 * freq1 * freq2
        
        probability *= locus_prob
    
    return probability

# При 20 локусах вероятность случайного совпадения ~10^-24

```

## 4. Практика: Выбор Типа Маркера под Задачу

### 4.1 Сравнение маркеров

| Тип маркера | Что измеряем | Плюсы | Минусы | Типичные задачи |
|-------------|-------------|-------|--------|-----------------|
| **SNP** | Замены 1 нуклеотида | Очень много, стабильны, легко типировать | Небольшой вклад каждого варианта | GWAS, фармакогенетика, панели риска |
| **STR** | Короткие повторы | Высокая информативность на локус | Сложнее анализировать, нестабильность | ДНК‑дактилоскопия, отцовство |
| **CNV** | Число копий регионов | Сильный эффект на фенотип | Сложный вызов, большие артефакты | Онкология, редкие синдромы |

```python

def choose_marker_type(task: str) -> str:
    """
    Упрощённый "решатель" типа маркера по задаче.
    """
    task = task.lower()
    if "отцовств" in task or "идентифик" in task:
        return "STR (микросателлиты) — для ДНК-профилирования"
    if "фармакоген" in task or "доза" in task:
        return "SNP панель в ключевых генах метаболизма"
    if "редкий синдром" in task or "делец" in task or "дуплик" in task:
        return "CNV анализ (aCGH, WGS с CNV вызовом)"
    if "ассоциац" in task or "признак" in task:
        return "SNP (GWAS или таргетная панель)"
    return "Нужен комбинированный подход (SNP + CNV +, при необходимости, STR)"
```

## 💡 Key Takeaways

- **Генетический маркер** — это позиция в геноме с несколькими вариантами (аллелями), которую можно надёжно измерить и связать с фенотипом.

- **SNP** — самый массовый тип маркеров (миллионы в геноме), основа GWAS и большинства генетических тестов.

- **STR** — очень информативны для идентификации личности и родства, поэтому используются в криминалистике и тестах на отцовство.

- **CNV** и крупные перестройки могут оказывать мощный эффект на фенотип и часто участвуют в редких наследственных синдромах и онкологии.

- **Выбор типа маркера зависит от задачи**: диагностика, фармакогенетика, популяционная генетика или криминалистика требуют разных панелей.
