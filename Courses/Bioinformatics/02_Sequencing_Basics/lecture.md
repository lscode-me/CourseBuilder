## 3. Секвенирование — Чтение ДНК

### 3.1 Технические ограничения

**Секвенирование** — это процесс определения последовательности нуклеотидов в ДНК.

**Проблема:** Современные технологии секвенирования не могут прочитать геном от начала до конца одним непрерывным куском. Вместо этого они читают множество коротких фрагментов.

**Технические параметры (на 2025 год):**

- Технология Illumina (самая распространенная): читает фрагменты по **100-150 нуклеотидов**
- Технология PacBio/Oxford Nanopore (более новые): могут читать до **10,000-100,000 нуклеотидов**, но с большей частотой ошибок

**Почему так?** Это физические ограничения методов секвенирования — химические реакции, используемые для чтения ДНК, эффективно работают только на коротких участках.

**Сравнение масштабов:**

- Рид (Illumina): ~150 нуклеотидов → примерно размер одного экзона
- Рид (PacBio): ~10,000-100,000 нуклеотидов → может покрыть небольшой ген целиком
- Ген: ~10,000-50,000 нуклеотидов → требует множества коротких ридов или несколько длинных
- Хромосома: ~50-250 миллионов нуклеотидов → требует миллионы ридов для полного покрытия

### 3.2 Процесс секвенирования

```

Полная ДНК (геном)
    ↓
Разрезать на миллионы случайных фрагментов
    ↓
Прочитать каждый фрагмент (получаем "риды")
    ↓
Собрать обратно, используя перекрытия (assembly)
    ↓
Или выровнять на известный референс (alignment)

```

### 3.3 Риды (Reads)

**Рид** — это короткий фрагмент ДНК, который мы прочитали.

```python
# Оригинальная ДНК
original = "ATCGATCGATCGATCGATCG"

# Секвенирование даёт нам много коротких фрагментов (ридов)
reads = [
    "ATCGATCG",      # рид 1
    "CGATCGAT",      # рид 2
    "GATCGATC",      # рид 3
    # ... миллионы других ридов
]

```

**Покрытие (Coverage):** Метрика качества секвенирования — сколько раз каждая позиция в геноме прочитана в среднем.

- **30x coverage** = каждая позиция прочитана в среднем 30 раз

- **Типичные значения:** 30x-50x для клинических исследований, 10x-15x для популяционных исследований

- **Почему важно:** Если каждая позиция прочитана много раз, можно отличить настоящую мутацию от ошибки секвенирования

**Пример расчета:**

- Геном человека: 3.2 миллиарда нуклеотидов
- Длина рида: 150 нуклеотидов
- Желаемое покрытие: 30x
- Необходимое количество ридов: (3.2 млрд × 30) / 150 ≈ **640 миллионов ридов**

### 3.4 Референс-геном

В большинстве случаев мы не собираем геном с нуля, а **выравниваем** (align) риды на референсный геном — уже известную эталонную последовательность.

**Референсный геном человека:**

- Версии: GRCh37 (2009), GRCh38 (2013, текущая стандартная версия)
- Это составная последовательность из геномов нескольких людей
- Служит "картой" для сравнения

```

Референс:  ...ATCGGTACCGTAGCTAAGC...
                  ||||||||
Рид 1:            GTACCGTA
                      |||||||
Рид 2:                CGTAGCT

Пример с мутацией:
Референс:  ...ATCGGTACCGTAGCTAAGC...
                  ||||*|||
Рид 3:            GTACAGTA  (замена C→A в позиции 5)

```

**Процесс:** Каждый прочитанный рид сравнивается с референсом, чтобы найти, где именно в геноме он находится. Риды перекрываются, покрывая весь геном. Если рид отличается от референса (как Рид 3), это и есть мутация.

## 4. Мутации — Изменения в ДНК

### 4.1 Что такое мутация?

**Мутация** (или **вариант**) — это изменение в последовательности ДНК. Это место, где ваша ДНК отличается от референсного генома.

**Референсный геном** — это эталонная последовательность ДНК человека, составленная из геномов нескольких людей и используемая как стандарт для сравнения.

**Пример:**
```bash

Референс:    A T C G A T C G A T C G
Ваша ДНК:    A T C G G T C G A T C G
                     ↑
                   мутация (A→G)

```

У каждого человека примерно **4-5 миллионов** отличий от референса. Это нормально — мутации делают нас уникальными.

### 4.2 Типы мутаций

| Тип | Описание | Пример |
|-----|----------|--------|
| **SNP** (Single Nucleotide Polymorphism) | Замена одного нуклеотида на другой | `ATC`**G**`ATC` → `ATC`**A**`ATC` |
| **Insertion** (Вставка) | Добавление одного или нескольких нуклеотидов | `ATCATC` → `ATC`**GGG**`ATC` |
| **Deletion** (Делеция) | Удаление одного или нескольких нуклеотидов | `ATC`~~`GAT`~~`C` → `ATCC` |
| **Indel** | Комбинация вставки и делеции | Одновременное удаление и вставка |

```python
# SNP (замена)
ref = "ATCGATC"
var = "ATCAATC"  # G→A

# Insertion (вставка)
ref = "ATCGATC"
var = "ATCGGGGATC"  # Вставлено "GGG"

# Deletion (делеция)

ref = "ATCGATC"
var = "ATC--TC"  # Удалено "GA"

```

### 4.3 Почему мутации важны?

**Клинические варианты** — мутации, которые влияют на здоровье.

#### Классификация мутаций по влиянию:

| Тип | Описание | Частота | Пример |
|-----|----------|---------|--------|
| **Патогенные (Pathogenic)** | Вызывают или предрасполагают к заболеванию | Редкие | Мутация в BRCA1 → повышенный риск рака |
| **Вероятно патогенные** | Скорее всего вредные, но не доказано | Редкие | Новые варианты в генах болезней |
| **Неопределенные (VUS)** | Неизвестное значение | Средние | Найден вариант, но нет данных |
| **Вероятно доброкачественные** | Скорее всего безвредные | Частые | Варианты в некодирующих регионах |
| **Доброкачественные (Benign)** | Безвредные, нормальные вариации | Очень частые | Цвет глаз, группа крови |

**VUS (Variant of Uncertain Significance)** — вариант с неопределенным клиническим значением. Это самая сложная категория для клинической интерпретации: вариант найден, но недостаточно данных, чтобы определить, патогенный он или доброкачественный. Требует дополнительного исследования.

**Важно:** У каждого человека ~4-5 миллионов вариантов по сравнению с референсом. Только единицы могут быть патогенными!

#### Что делает мутацию патогенной?

**Патогенная мутация** — это изменение в ДНК, которое:

1. **Нарушает функцию важного белка** (например, ломает ген, отвечающий за починку ДНК)
2. **Подтверждено клиническими данными** (люди с этой мутацией болеют)
3. **Не встречается или редко встречается** у здоровых людей

**Примеры патогенных мутаций:**

- **BRCA1/BRCA2** — повышают риск рака груди/яичников в 5-10 раз

- **CFTR** — вызывают муковисцидоз

- **HBB** — вызывают серповидноклеточную анемию

**Как мутации влияют на белки:**

**Доброкачественная мутация (не влияет на функцию):**
```

Было:  ДНК ...ATC... → РНК ...AUC... → Изолейцин
                ↓ одна буква C→T
Стало: ДНК ...ATT... → РНК ...AUU... → Изолейцин (та же аминокислота!)

```
**Результат:** Изменилась одна буква в ДНК (C→T), но благодаря избыточности генетического кода оба кодона (AUC и AUU) кодируют одну и ту же аминокислоту — изолейцин. Белок не изменился, функция сохранена.

**Патогенная мутация (ломает белок):**
```

Было:  ДНК ...TGG... → РНК ...UGG... → Триптофан → белок работает
                ↓ одна буква G→A
Стало: ДНК ...TGA... → РНК ...UGA... → STOP! → белок обрывается

```
**Результат:** Также изменилась только одна буква в ДНК (G→A), но теперь вместо кодона триптофана (UGG) получился стоп-кодон (UGA). Синтез белка прерывается, белок неполный и не может выполнять свою функцию.

**Ключевой вывод:** В обоих примерах изменилась только **одна буква** в ДНК, но последствия кардинально разные:

- В первом случае — никаких последствий (та же аминокислота)
- Во втором случае — белок сломан (появился стоп-кодон)

Это показывает, что не само количество изменений определяет патогенность, а **где именно** и **как именно** изменилась последовательность.

**Пример с геном BRCA1:**

- Нормальный ген → рабочий белок, который чинит повреждения ДНК
- Мутация создает стоп-кодон → белок обрывается → не чинит ДНК → накопление мутаций → повышенный риск рака

#### Как определяют патогенность?

```python

def is_pathogenic(variant):
    """Упрощенный алгоритм оценки патогенности"""
    score = 0
    
    # 1. Влияние на белок
    if variant.causes_protein_truncation():  # Обрывает белок
        score += 5
    if variant.in_critical_domain():  # В важном участке
        score += 3
    
    # 2. Частота в популяции
    if variant.frequency < 0.001:  # Очень редкий (< 0.1%)
        score += 2
    
    # 3. Клинические данные
    if variant.found_in_patients():  # Встречается у больных
        score += 4
    if variant.segregates_with_disease():  # Наследуется вместе с болезнью
        score += 3
    
    # 4. Предсказания алгоритмов
    if variant.predicted_damaging():  # Алгоритмы предсказывают вред
        score += 1
    
    # Классификация
    if score >= 10:
        return "Pathogenic"
    elif score >= 6:
        return "Likely pathogenic"
    elif score >= 3:
        return "VUS (Uncertain significance)"
    else:
        return "Benign"

# Пример использования

variant = Variant("chr17:43044295", "G>A")  # Мутация в BRCA1
print(is_pathogenic(variant))  # Output: "Pathogenic"

```

## 5. Хромосомы и Геном

### 5.1 Структура генома человека

Геном человека разбит на **хромосомы** — отдельные молекулы ДНК.

**Количество хромосом:**

- **23 пары** = **46 хромосом** в каждой клетке (диплоидный набор)
- По одной хромосоме из каждой пары от мамы и папы
- **22 пары** — аутосомные хромосомы (одинаковые у всех)

- **1 пара** — половые хромосомы (XX у женщин, XY у мужчин)

**Важно:** Когда говорят "у человека 23 хромосомы", имеют в виду 23 **типа** хромосом. В каждой клетке их по две копии, то есть **46 штук** всего.

**Размеры хромосом:**

Каждая хромосома имеет разную длину. Эти размеры определены экспериментально при секвенировании генома человека (проект "Геном человека", 1990-2003).

- Длина каждой хромосомы измерена при полном секвенировании генома

- Наименование "chr1", "chr2" и т.д. — стандартная нотация
- Хромосома 1 — самая длинная, хромосома Y — самая короткая (не считая митохондриальную)

**Структура данных:** С точки зрения хранения, геном можно представить как набор из 24 отдельных последовательностей (файлов), каждая от 16 тысяч до 248 миллионов символов.

### 5.2 Позиции в геноме

Любую позицию в геноме можно точно указать с помощью координат:

```

chr17:43044295
  ↑       ↑
хромосома  позиция (номер нуклеотида)

```

**Формат:** `chr[номер]:позиция`

**Примеры:**
```python
# Мутация в гене BRCA1
variant_position = "chr17:43044295"

# Начало гена TP53
gene_start = "chr17:7661779"

# Позиция на половой хромосоме

x_position = "chrX:123456789"

```

**Важно:**

- Позиция — это номер нуклеотида от начала хромосомы (нумерация обычно с 1)
- Эта система координат стандартна и используется во всех базах данных
- Для обозначения участка используется диапазон: `chr17:43044295-43125483` (ген BRCA1)

## 6. Основная Терминология

### Словарь биоинформатики

| Термин | Определение | Пример |
|--------|-------------|--------|
| **Геном** | Полная ДНК организма, вся наследственная информация | Геном человека = 3.2 миллиарда нуклеотидов |
| **Хромосома** | Отдельная молекула ДНК, часть генома | У человека 46 хромосом (23 пары) |
| **Ген** | Участок ДНК, содержащий инструкцию для создания белка | Ген BRCA1 (связан с раком груди) |
| **Нуклеотид** | Одна "буква" в ДНК (A, C, G, T) | Последовательность: ATCG |
| **Экзон** | Кодирующая часть гена (попадает в белок) | В гене BRCA1 24 экзона |
| **Интрон** | Некодирующая часть гена (удаляется при обработке) | Составляют ~93% длины гена BRCA1 |
| **Pre-mRNA** | Незрелая мРНК с интронами, сразу после транскрипции | Содержит экзоны и интроны |
| **Mature mRNA** | Зрелая мРНК после сплайсинга, только экзоны | Используется для создания белка |
| **Сплайсинг** | Процесс вырезания интронов из pre-mRNA | Происходит после транскрипции |
| **Белок** | Молекула, которая выполняет работу в клетке | Инсулин, гемоглобин, антитела |
| **Аминокислота** | Одна "буква" в последовательности белка | В белках используется 20 аминокислот |
| **Кодон** | 3 нуклеотида в РНК, кодирующие 1 аминокислоту | AUG = метионин (старт-кодон) |
| **Рид (Read)** | Короткий фрагмент ДНК, прочитанный секвенатором | Обычно 100-150 нуклеотидов |
| **Референс** | Эталонная последовательность генома для сравнения | GRCh38 - текущий референс человека |
| **Вариант/Мутация** | Отличие вашей ДНК от референса | Замена A на G в позиции chr17:43044295 |
| **SNP** | Замена одного нуклеотида на другой | A→G, C→T |
| **Indel** | Вставка или удаление нуклеотидов | Вставка GGG или удаление ATC |
| **Патогенная мутация** | Вариант, который может вызывать заболевание | Мутация в BRCA1, вызывающая риск рака |
| **VUS** | Вариант неопределенного значения (Variant of Uncertain Significance) | Вариант найден, но неизвестно патогенный он или нет |
| **Аллель** | Один из вариантов гена | Аллель A или аллель B группы крови |
| **Генотип** | Набор аллелей у конкретного человека | AA, AB или BB (группа крови) |
| **Фенотип** | Наблюдаемые характеристики организма | Цвет глаз, рост, предрасположенность к болезням |
| **Покрытие (Coverage)** | Сколько раз каждая позиция прочитана | 30x coverage = каждая позиция прочитана 30 раз |

### 7.1 Поток информации

```

ДНК  →  РНК  →  Белок  →  Функция
(код)  (копия) (программа) (результат)
```

### 7.2 Генетический код: Кодоны

**Кодон** — это последовательность из **3 нуклеотидов**, которая кодирует одну аминокислоту (или стоп-сигнал).

**Математика кодонов:**

- В РНК 4 буквы: A, U, G, C
- Кодон состоит из 3 позиций
- Возможных комбинаций: 4³ = **64 кодона**

**Распределение кодонов:**

- **61 кодон** кодируют 20 аминокислот (есть избыточность — несколько кодонов могут кодировать одну аминокислоту)

- **3 кодона** — стоп-сигналы (UAA, UAG, UGA)

- **1 кодон** (AUG) — старт-сигнал (также кодирует метионин)

```python
# Пример генетического кода
genetic_code = {
    # Старт-кодон (также кодирует метионин)
    'AUG': 'Met',  # Всегда первая аминокислота в белке
    
    # Примеры других кодонов
    'UUU': 'Phe', 'UUC': 'Phe',  # Фенилаланин (2 кодона)
    'UUA': 'Leu', 'UUG': 'Leu', 'CUU': 'Leu',  # Лейцин (6 кодонов!)
    'UCU': 'Ser', 'UCC': 'Ser', 'UCA': 'Ser',  # Серин
    'UAU': 'Tyr', 'UAC': 'Tyr',  # Тирозин
    'UGU': 'Cys', 'UGC': 'Cys',  # Цистеин
    'UGG': 'Trp',  # Триптофан (единственный кодон!)
    
    # Стоп-кодоны
    'UAA': 'STOP', 'UAG': 'STOP', 'UGA': 'STOP',
    # ... всего 64 кодона
}

# Всего 20 стандартных аминокислот в белках

amino_acids_count = 20
codons_count = 64  # 4³ = 64

```

### 7.3 Пример: От ДНК к белку с кодом

```python
# 1. ДНК - постоянное хранилище информации в ядре
dna_sequence = "ATGCGATCGATCGTAGC"  # Участок гена

# 2. Транскрипция: ДНК → РНК
def transcribe(dna):
    """
    Транскрипция - процесс создания РНК копии с ДНК
    Правило: A→A, T→U, C→C, G→G
    """
    rna = dna.replace('T', 'U')
    return rna

rna_sequence = transcribe(dna_sequence)
print(f"ДНК: {dna_sequence}")
print(f"РНК: {rna_sequence}")
# Вывод: AUGCGAUCGAUCGUAGC

# 3. Трансляция: РНК → Белок
def translate(rna):
    """
    Трансляция - процесс создания белка по РНК матрице
    Каждые 3 нуклеотида (кодон) кодируют 1 аминокислоту
    """
    # Генетический код (упрощенный)
    codon_table = {
        'AUG': 'Met',  # Старт-кодон
        'UGC': 'Cys',
        'GAU': 'Asp',
        'CGU': 'Arg',
        'CGA': 'Arg',
        'UCG': 'Ser',
        'AUC': 'Ile',
        'GUA': 'Val',
        'GC': 'Ala',
        'UAG': 'STOP',
        'UAA': 'STOP',
        'UGA': 'STOP',
    }
    
    protein = []
    for i in range(0, len(rna), 3):
        codon = rna[i:i+3]
        if len(codon) == 3:  # Только полные кодоны
            amino_acid = codon_table.get(codon, '?')
            if amino_acid == 'STOP':
                break
            protein.append(amino_acid)
    
    return '-'.join(protein)

protein_sequence = translate(rna_sequence)
print(f"Белок: {protein_sequence}")
# Вывод: Met-Arg-Ser-Ile-Val

# Итого:
# ДНК (15 нуклеотидов) → РНК (15 нуклеотидов) → Белок (5 аминокислот)

```

**Ключевые моменты:**

- 3 нуклеотида в РНК = 1 аминокислота в белке
- Белок всегда короче исходной ДНК последовательности (в 3 раза по количеству "букв")
- Кодон AUG всегда означает начало белка
- Кодоны UAG, UAA, UGA означают конец белка

## 8. Регуляция Генов: От ДНК к Фенотипу

### 8.1 Почему не все гены работают одновременно?

Все клетки вашего тела содержат **одинаковую ДНК** (за редкими исключениями). Но клетка печени совсем не похожа на нейрон или клетку мышцы. Почему?

**Ключевая концепция:** Важно не только **какие** гены есть в геноме, но и **какие из них активны** в данный момент в данной клетке.

```

Одна и та же ДНК → Разная экспрессия генов → Разные клетки

Стволовая клетка:  [Ген A: ВКЛ] [Ген B: ВКЛ] [Ген C: ВЫКЛ] [Ген D: ВЫКЛ]
        ↓
Нейрон:            [Ген A: ВЫКЛ] [Ген B: ВКЛ] [Ген C: ВКЛ] [Ген D: ВЫКЛ]
Клетка печени:     [Ген A: ВКЛ] [Ген B: ВЫКЛ] [Ген C: ВЫКЛ] [Ген D: ВКЛ]
Мышечная клетка:   [Ген A: ВЫКЛ] [Ген B: ВЫКЛ] [Ген C: ВКЛ] [Ген D: ВКЛ]

```

### 8.2 Тканеспецифичная Экспрессия Генов

**Экспрессия гена** — это процесс, когда информация из гена используется для создания функционального продукта (обычно белка).

**Тканеспецифичная экспрессия** — разные ткани экспрессируют разные наборы генов:

| Ткань | Примеры активных генов | Что делают |
|-------|------------------------|------------|
| **Печень** | ALB, CYP450, APOB | Синтез альбумина, детоксикация, метаболизм |
| **Мышцы** | MYH, ACTA, TTN | Сокращение, структура мышц |
| **Мозг** | SYN1, GRIA1, NEFL | Передача сигналов, нейропластичность |
| **Сердце** | MYH7, TNNT2, SCN5A | Сердечное сокращение, проводимость |
| **Кровь** | HBB, HBA | Транспорт кислорода (гемоглобин) |

**Практический пример:**
```python
# Упрощенная модель экспрессии генов в разных тканях
gene_expression = {
    'liver': {
        'ALB': 1000,      # Альбумин - очень высоко в печени
        'HBB': 0,         # Гемоглобин - не экспрессируется
        'MYH7': 0,        # Сердечный миозин - не экспрессируется
        'CYP3A4': 500,    # Фермент детоксикации
    },
    'heart': {
        'ALB': 0,
        'HBB': 0,
        'MYH7': 800,      # Сердечный миозин - высоко в сердце
        'CYP3A4': 10,
    },
    'blood': {
        'ALB': 0,
        'HBB': 2000,      # Гемоглобин - очень высоко в крови
        'MYH7': 0,
        'CYP3A4': 0,
    }
}

# Мутация в гене MYH7 опасна для сердца, но не влияет на печень
# потому что в печени этот ген просто не работает!

```

**Почему это важно для биоинформатики:**

1. **Интерпретация мутаций:** Мутация в гене, который не экспрессируется в данной ткани, не повлияет на эту ткань
2. **Анализ экспрессии (RNA-seq):** Можно определить, какие гены активны в образце ткани
3. **Тканеспецифичные заболевания:** Объясняет, почему мутации в одном гене вызывают болезни разных органов

**Дальнейшее изучение:** Механизмы регуляции генов, включая эпигенетику (метилирование, модификация гистонов) и генетические маркеры (SNP, STR, CNV), подробно рассмотрены в отдельном модуле "Эпигенетика и Генетические Маркеры".

## 9. Практический Пример на Python

### 9.1 Работа с последовательностями ДНК

```python

from collections import Counter

# Функция для подсчёта GC-содержания
def gc_content(sequence):
    """
    GC-содержание - процент нуклеотидов G и C в последовательности
    
    Формула: (количество G + количество C) / общая длина * 100%
    
    Это важная характеристика ДНК:
    - Влияет на стабильность молекулы (G-C связь сильнее A-T)
    - Различается у разных организмов (человек ~40%, бактерии 30-70%)
    - Помогает в анализе последовательностей
    """
    sequence = sequence.upper()
    gc_count = sequence.count('G') + sequence.count('C')
    total = len(sequence)
    return (gc_count / total) * 100

# Примеры
dna1 = "ATCGATCG"
print(f"Последовательность: {dna1}")
print(f"GC content: {gc_content(dna1):.2f}%")
# В "ATCGATCG": 4 буквы (G или C) из 8 → 50%

dna2 = "ATATATAT"
print(f"\nПоследовательность: {dna2}")
print(f"GC content: {gc_content(dna2):.2f}%")
# В "ATATATAT": 0 букв (G или C) из 8 → 0%

dna3 = "GGGGCCCC"
print(f"\nПоследовательность: {dna3}")
print(f"GC content: {gc_content(dna3):.2f}%")
# В "GGGGCCCC": все 8 букв - это G или C из 8 → 100%


# Обратная комплементарная последовательность
def reverse_complement(sequence):
    """
    Обратная комплементарная последовательность
    Часто нужна, т.к. ДНК двухцепочечная и может читаться в обе стороны
    """
    complement = {'A': 'T', 'T': 'A', 'C': 'G', 'G': 'C'}
    return ''.join(complement[base] for base in reversed(sequence.upper()))

# Пример
dna = "ATCGATCG"
print(f"Original:            {dna}")
print(f"Reverse complement:  {reverse_complement(dna)}")
# Output: CGATCGAT


# Поиск простых повторов
def find_repeats(sequence, k=3):
    """
    Находит повторяющиеся k-меры (подстроки длины k)
    Полезно для поиска простых повторов
    """
    kmers = [sequence[i:i+k] for i in range(len(sequence)-k+1)]
    counts = Counter(kmers)
    return {kmer: count for kmer, count in counts.items() if count > 1}

# Пример
dna = "ATCGATCGATCGATCG"
print(find_repeats(dna, k=3))
# Output: {'ATC': 4, 'TCG': 4, 'CGA': 4, 'GAT': 4}

```

## 10. Частые Ошибки и Заблуждения

### 1. "Найденная мутация в гене означает болезнь"

**НЕПРАВИЛЬНО:** "У пациента мутация в BRCA1 → у него будет рак"

**ПРАВИЛЬНО:** "У пациента патогенная мутация в BRCA1 → повышенный риск рака груди/яичников (~70% вероятность вместо ~12% у населения)"

**Объяснение:** 

- Не все мутации в гене патогенны (большинство нейтральны)
- Даже патогенная мутация часто повышает риск, а не гарантирует болезнь
- Болезни — результат взаимодействия генов, окружающей среды, образа жизни

### 2. "У пациента 5 миллионов мутаций — это плохо!"

**НЕПРАВИЛЬНО:** Паника из-за большого числа найденных вариантов

**ПРАВИЛЬНО:** 

- 4-5 миллионов вариантов от референса — **норма** для любого человека
- Из них только ~20,000 попадают в кодирующие области (гены)
- Из них только единицы могут быть патогенными
- Важно не количество, а **клиническая значимость** каждого варианта

**Пример числа:**

- Всего вариантов: ~5,000,000
- В генах: ~20,000
- Патогенных/вероятно патогенных: 0-10

### 3. "Чем выше покрытие, тем лучше"

**НЕПРАВИЛЬНО:** "Делаем 1000x покрытие, чтобы быть уверенными"

**ПРАВИЛЬНО:** 

- **30x coverage** — стандарт для большинства клинических применений

- **50-100x** — для поиска редких мутаций (например, в раковых опухолях)

- **1000x** — избыточно для обычных задач, не улучшает точность значительно

**Почему не больше?**
- Стоимость растет линейно с покрытием
- После 30x точность растет незначительно
- Ошибки секвенирования случайны — 30 независимых прочтений достаточно для их исключения

### Основы ДНК и РНК

**Сколько букв в алфавите ДНК?**
- **4 буквы:** A, C, G, T (аденин, цитозин, гуанин, тимин)

**Чем РНК отличается от ДНК?**
- ДНК: двухцепочечная, содержит **T** (тимин)
- РНК: одноцепочечная, содержит **U** (урацил вместо тимина)

**Комплементарность:**

В двухцепочечной ДНК (цепь к цепи):

- A ↔ T (аденин спаривается с тимином)
- C ↔ G (цитозин спаривается с гуанином)

При транскрипции (ДНК → РНК):

- A (в ДНК) → U (в РНК)
- T (в ДНК) → A (в РНК)
- C (в ДНК) → G (в РНК)
- G (в ДНК) → C (в РНК)

### Размеры и структура

**Размер генома человека:**

- ~3.2 миллиарда пар оснований
- ~3.2 GB текстовой информации

**Количество хромосом:**

- **46 хромосом** в каждой клетке (23 пары)
- 22 пары аутосомных + 1 пара половых (XX или XY)

**Процент генов в геноме:**

- Только **~2%** — кодирующие последовательности (гены)
- ~98% — интроны, регуляторные элементы, повторы

### Центральная догма

**Последовательность процессов:**
```

ДНК → РНК → Белок
(транскрипция) (трансляция)

```

**Транскрипция:** ДНК → РНК (создание копии)
**Трансляция:** РНК → Белок (создание белка)

### Экзоны и Интроны

**Что происходит с интронами?**
- **Интроны вырезаются** в процессе сплайсинга
- В белок попадают **только экзоны**

### Кодоны

**Сколько нуклеотидов в кодоне?**
- **3 нуклеотида** = 1 кодон

**Сколько возможных кодонов?**
- 4³ = **64 кодона**
- 61 кодируют аминокислоты
- 3 — стоп-сигналы

### Секвенирование

**Типичная длина рида:**

- **100-150 букв** (пар оснований)
- Современные технологии (Illumina)

**Что означает "30x coverage"?**
- Каждая позиция в геноме прочитана в среднем **30 раз**
- Чем выше покрытие, тем точнее результат

**Что такое референс-геном?**
- **Эталонная последовательность** для сравнения
- Составлена из геномов нескольких людей
- Используется как стандарт

### Мутации

**Что такое SNP?**
- **Single Nucleotide Polymorphism** (произносится "снип")

- **Замена одного нуклеотида** на другой
- Самый распространённый тип вариантов

**Что такое патогенная мутация?**
- Мутация, которая **может вызывать заболевание**
- Подтверждена клиническими данными
- Редко встречается у здоровых людей

### Экспрессия генов

**Почему разные ткани разные, если ДНК одинаковая?**
- Разные гены **включены/выключены** в разных тканях
- Это называется **тканеспецифичная экспрессия**
- Пример: гемоглобин активен в крови, но выключен в печени

**Подробнее об эпигенетике и маркерах:**

- См. отдельный модуль "Эпигенетика и Генетические Маркеры"

### GC-содержание

**Как считать GC-содержание?**

```

GC% = (количество G + количество C) / общая длина × 100%

```

**Пример:** "ATCGATCG"
- G и C: 4 штуки
- Всего: 8 букв
- GC-содержание: 4/8 × 100% = **50%**

- ✅ **РНК** — временная рабочая копия ДНК с нуклеотидами (A, C, G, U вместо T)
- ✅ **Гены** — участки ДНК, содержащие инструкции для создания белков (~20,000 генов, только ~2% генома)
- ✅ **Экзоны и интроны** — кодирующие и некодирующие части генов (интроны вырезаются при обработке)
- ✅ **Кодоны** — тройки нуклеотидов в РНК, кодирующие аминокислоты (64 возможных кодона)
- ✅ **Центральная догма** — ДНК → РНК → Белок (транскрипция → трансляция)
- ✅ **Тканеспецифичная экспрессия** — разные ткани активируют разные наборы генов из одной ДНК
- ✅ **Секвенирование** — процесс чтения ДНК короткими фрагментами (риды 100-150 нуклеотидов)
- ✅ **Покрытие** — сколько раз каждая позиция прочитана (30x = стандарт для клинических целей)
- ✅ **Мутации** — отличия от референсного генома (SNP, вставки, делеции)
- ✅ **Патогенные мутации** — варианты, которые могут вызывать заболевания (редки: 0-10 из 5 млн вариантов)
- ✅ **Технические параметры** — откуда берутся числа размеров хромосом и генов
- ✅ **Как работать с последовательностями ДНК** на Python

### Ключевые выводы для инженера

1. **Данные:** Геномные данные — это большие текстовые файлы с простой структурой
2. **Обработка:** Обработка геномных данных похожа на обработку логов или больших текстовых файлов
3. **Референс:** Всегда есть эталонная последовательность для сравнения
4. **Вариантность:** Находить отличия от референса — основная задача
5. **Масштаб:** Объёмы данных большие (сотни GB для одного генома)

## 💡 Key Takeaways

- **ДНК — это данные**: Геном представляется как строка из 4 символов (A, C, G, T), человеческий геном ~3 млрд символов

- **Секвенирование создаёт reads**: Современные технологии дают короткие (150 bp) или длинные (10+ kb) фрагменты с разными характеристиками ошибок

- **Варианты — отличия от референса**: SNP, Indel, SV — основные типы мутаций, которые мы ищем в данных

- **Качество данных критично**: Phred score показывает вероятность ошибки, Q30 = 1 ошибка на 1000 оснований

- **Биология ≠ точная наука**: Данные шумные, нужны статистические методы и популяционные базы данных
