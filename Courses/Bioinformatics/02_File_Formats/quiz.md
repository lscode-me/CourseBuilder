## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | `>` начинает заголовок новой последовательности в FASTA. |
| 2 | D | Q30 = ошибка 1 на 1000 (точность 99.9%). |
| 3 | B | BAM — бинарная сжатая версия SAM. |
| 4 | B | 80M2I18M = 80 совпадений, 2 вставки, 18 совпадений. |
| 5 | B | 1/1 = гомозигота по альтернативному аллелю (ALT/ALT). |
| 6 | C | BED 0-based: [100, 200) = 100 нуклеотидов. |
| 7 | B | FLAG 4 означает unmapped read. |
| 8 | A | SNP — замена одного нуклеотида: A→G. |
| 9 | D | BAM индексируется в .bai файл. |
| 10 | B | MAPQ показывает качество выравнивания (вероятность ошибки). |
| 11 | B | Делеция: REF длиннее ALT (ATCG→A = удалили TCG). |
| 12 | B | VCF использует 1-based координаты. |
| 13 | C | FASTQ: @ID, последовательность, +, quality (4 строки). |
| 14 | C | SeqIO.parse() — итератор для чтения записей из файла. |
| 15 | B | Soft clip (S) — не выровнено, но последовательность сохранена. |
| 16 | B | samtools faidx создаёт .fai индекс для FASTA. |
| 17 | C | Инсерция: ALT длиннее REF (A→ATCG = вставили TCG). |
| 18 | C | bam.fetch(chrom, start, end) — чтение ридов из региона. |
| 19 | D | 0\|1 — фазированная гетерозигота (известно, от какого родителя). |
| 20 | D | FASTQ ~100-200 GB, BAM ~30-60 GB, VCF ~1-5 GB для целого генома. |
