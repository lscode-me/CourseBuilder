## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | `>` начинает заголовок новой последовательности в FASTA. |
| 2 | B | Q30 = ошибка 1 на 1000 (точность 99.9%). |
| 3 | B | BAM — бинарная сжатая версия SAM. |
| 4 | C | 80M2I18M = 80 совпадений, 2 вставки, 18 совпадений. |
| 5 | A | 1/1 = гомозигота по альтернативному аллелю (ALT/ALT). |
| 6 | C | BED 0-based: [100, 200) = 100 нуклеотидов. |
| 7 | B | FLAG 4 означает unmapped read. |
| 8 | B | SNP — замена одного нуклеотида: A→G. |
| 9 | A | BAM индексируется в .bai файл. |
| 10 | D | MAPQ показывает качество выравнивания (вероятность ошибки). |
| 11 | A | Делеция: REF длиннее ALT (ATCG→A = удалили TCG). |
| 12 | D | VCF использует 1-based координаты. |
| 13 | D | FASTQ: @ID, последовательность, +, quality (4 строки). |
| 14 | A | SeqIO.parse() — итератор для чтения записей из файла. |
| 15 | B | Soft clip (S) — не выровнено, но последовательность сохранена. |
| 16 | B | samtools faidx создаёт .fai индекс для FASTA. |
| 17 | C | Инсерция: ALT длиннее REF (A→ATCG = вставили TCG). |
| 18 | B | bam.fetch(chrom, start, end) — чтение ридов из региона. |
| 19 | A | 0\|1 — фазированная гетерозигота (известно, от какого родителя). |
| 20 | A | FASTQ ~100-200 GB, BAM ~30-60 GB, VCF ~1-5 GB для целого генома. |
