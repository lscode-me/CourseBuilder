## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Короткое объявление `:=` работает только внутри функций. |
| 2 | C | Zero value для string — пустая строка `""`. |
| 3 | B | Zero value для bool — `false`. |
| 4 | A | Литералы с точкой по умолчанию имеют тип `float64`. |
| 5 | B | `int8` — знаковое 8-битное: от -128 до 127. |
| 6 | A | `byte` — алиас для `uint8`. |
| 7 | A | `len()` возвращает байты. "Привет" в UTF-8 занимает 12 байт (2 байта на кириллический символ). |
| 8 | B | Константы нельзя изменять — они immutable. |
| 9 | D | `iota` начинается с 0: A=0, B=1, C=2. |
| 10 | B | _ пропускает 0, KB=1024, MB=1048576 (1024²). |
| 11 | B | Целочисленное деление отбрасывает дробную часть: 7/3=2. |
| 12 | A | `i++` — statement, не expression. Можно использовать отдельно. |
| 13 | D | `&&` имеет приоритет выше `||`: (true && false) || true = false || true = true. |
| 14 | D | AND: 1100 & 1010 = 1000 (8). |
| 15 | D | 1 << 4 = 1 * 2⁴ = 16. |
| 16 | D | `float64(x)` — синтаксис преобразования типов в Go. |
| 17 | B | `string(65)` создаёт строку из руны с кодом 65 = "A". |
| 18 | A | `strconv.Itoa()` — Integer to ASCII string. |
| 19 | C | Внутренний x затеняет внешний. Выводит 2, затем 1. |
| 20 | A | Неиспользуемые переменные — ошибка компиляции в Go. |
| 21 | B | 255 в hex = 0xFF (16*15 + 15 = 255). |
| 22 | A | Go 1.13+ позволяет использовать `_` как разделитель. |
| 23 | D | IEEE 754 floating point имеет погрешность представления. |
| 24 | D | Обмен значениями: a становится 2, b становится 1. |
| 25 | C | В Go нет оператора возведения в степень `**=`. |
| 26 | D | `rune` — алиас для `int32` (Unicode code point). |
| 27 | A | `complex(3, 4)` или литерал `3 + 4i`. |
| 28 | B | Переполнение uint8: 255 + 1 = 0 (wrap around). |
| 29 | C | `%` — оператор остатка от деления (modulo). |
| 30 | C | XOR: 1100 ^ 1010 = 0110 (6). |
