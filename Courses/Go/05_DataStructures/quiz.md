## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Массив: `[N]T`, слайс: `[]T`. Размер — ключевое отличие. |
| 2 | C | Массив int инициализируется нулями: [0 0 0]. |
| 3 | A | Размер массива — часть типа. [3]int ≠ [5]int. |
| 4 | C | `make([]int, length, capacity)` — length=5, capacity=10. |
| 5 | B | `var s []int` создаёт nil слайс. |
| 6 | D | cap возвращает ёмкость — сколько элементов вместится без перевыделения. |
| 7 | C | `[1:4]` — от индекса 1 до 3 включительно: [1 2 3]. |
| 8 | B | append возвращает новый слайс. Нужно присвоить обратно. |
| 9 | C | При нехватке capacity создаётся новый array с большей ёмкостью. |
| 10 | C | copy возвращает количество скопированных элементов. |
| 11 | B | Запись в nil map вызывает panic. |
| 12 | A | `v, ok := m["key"]` — идиоматический способ проверки. |
| 13 | D | `delete(m, "key")` — встроенная функция удаления. |
| 14 | A | Порядок итерации по map не определён и случаен. |
| 15 | B | `type Name struct { }` — правильный синтаксис. |
| 16 | C | Zero value для string — пустая строка "". |
| 17 | B | Go автоматически разыменовывает указатель: `ptr.Field` работает. |
| 18 | B | Embedding — анонимное поле структуры для "наследования" полей. |
| 19 | A | `json:"-"` исключает поле из JSON-сериализации. |
| 20 | C | Слайсы можно сравнивать только с nil. |
| 21 | B | make для слайсов возвращает слайс, не указатель. |
| 22 | B | `append(s[:i], s[i+1:]...)` — удаление с сохранением порядка. |
| 23 | B | Массивы — значения, передаются по значению (копируются). |
| 24 | C | Слайс содержит ссылку на underlying array. |
| 25 | D | `map[T]struct{}` — эффективный способ реализации Set. |
| 26 | A | `map[string]int{}` создаёт пустую, инициализированную map. |
| 27 | B | Через точечную нотацию: `person.Address.City`. |
| 28 | C | omitempty пропускает zero value при сериализации. |
| 29 | B | `slice...` распаковывает слайс в отдельные аргументы. |
| 30 | C | len=3 (текущая длина), cap=10 (ёмкость). |
