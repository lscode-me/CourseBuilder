# Курс: Testing

## Описание курса

Курс по тестированию программного обеспечения. Для разработчиков и QA инженеров, которые хотят освоить современные подходы к тестированию.

## Цели курса

После прохождения курса слушатель будет:
- понимать принципы и методологии тестирования
- уметь писать автоматизированные тесты
- знать инструменты для различных видов тестирования

## Целевая аудитория

- Разработчики всех уровней
- QA инженеры
- DevOps инженеры
- Тимлиды и менеджеры проектов

## Предварительные требования

- Базовое понимание программирования
- Знакомство с любым языком программирования
- Понимание принципов разработки ПО

## План курса

1. **Введение в тестирование** - зачем нужно тестирование, виды тестирования
2. **Юнит-тесты** - принципы написания, mocking, coverage
3. **Интеграционные тесты** - тестирование взаимодействий
4. **Функциональные тесты** - end-to-end тестирование
5. **Тест-дизайн** - техники создания тест-кейсов
6. **Автоматизация тестирования** - фреймворки, инструменты
7. **Тестирование API** - REST API testing, contract testing
8. **UI тестирование** - Selenium, Playwright, accessibility
9. **Производительность** - load testing, stress testing
10. **Безопасность** - security testing, vulnerability scanning
11. **CI/CD и тестирование** - pipeline integration
12. **Лучшие практики** - стратегии тестирования, метрики

Примерная длительность: 15-20 часов
