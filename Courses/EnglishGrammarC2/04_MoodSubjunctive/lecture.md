## 1. What Is Grammatical Mood?

### 1.1 The Three Moods in English

**Mood** expresses the speaker's attitude toward the reality of what they're saying:

| Mood | Function | Example |
|------|----------|---------|
| **Indicative** | Stating facts | "She goes to school." |
| **Imperative** | Commands | "Go to school!" |
| **Subjunctive** | Unreal, hypothetical, demanded | "I suggest she go to school." |

### 1.2 The English Subjunctive: Weak but Present

English has a **weak subjunctive** compared to Romance languages. It survives in:

- **Were-subjunctive**: "If I were you..."
- **Mandative subjunctive**: "I recommend that he be present."
- **Formulaic expressions**: "God save the Queen", "Be that as it may"

### 1.3 Why C2 Learners Need This

At C2, you encounter subjunctive in:

- Formal writing
- Legal and official documents
- Academic prose
- Fixed expressions
- Sophisticated speech

Using subjunctive correctly signals **educated, native-like** English.

## 2. The Were-Subjunctive

### 2.1 "If I Were" vs "If I Was"

In hypothetical/unreal conditions, **were** is used for all persons:

```
SUBJUNCTIVE (formal/standard):
If I were rich, I would travel the world.
If she were here, she would help.
If it were possible, I would do it.

INDICATIVE (informal/common):
If I was rich, I would travel the world.
If she was here, she would help.
```

### 2.2 When to Use Were

**Use "were" (subjunctive) in:**

**1. Second Conditional (present unreal):**
```
"If I were the president, I would change things."
"If she were older, she could apply."
```

**2. "I wish" + past unreal:**
```
"I wish I were taller."
"I wish she were here."
```

**3. "If only" constructions:**
```
"If only it were that simple!"
"If only he were more careful."
```

**4. "As if / As though" (unreal comparison):**
```
"He acts as if he were the boss."
"She talks as though she were an expert."
```

**5. "Would rather / sooner" (hypothetical preference):**
```
"I would rather she were here."
"I'd sooner he were told the truth."
```

### 2.3 Was vs Were: Usage Notes

**"Was"** is increasingly common in informal speech:
```
Informal: "If I was you, I'd apologize."
Formal: "If I were you, I'd apologize."
```

**For C2/formal contexts:**
- Use "were" in writing
- Use "were" in formal speech
- "Was" is acceptable in casual conversation

### 2.4 "Were to" for Emphasis

"Were + to-infinitive" adds emphasis or formality to conditions:

```
Standard:
"If he arrived late, we would start without him."

Emphatic/Formal:
"If he were to arrive late, we would start without him."

"Were he to arrive late, we would start without him."
(with inversion — very formal)
```

### 2.5 Russian Speakers' Errors

**Error 1: Using "would" in both clauses**
```
❌ "If I would be rich, I would travel."
✅ "If I were rich, I would travel."
```

**Error 2: Using "was" where "were" is expected**
```
❌ "I wish I was there." (informal, but not wrong)
✅ "I wish I were there." (standard/formal)
```

## 3. The Mandative Subjunctive

### 3.1 What It Is

The **mandative subjunctive** uses the **base form** of the verb (no -s, no past) after verbs/expressions of demand, suggestion, or necessity:

```
"I suggest that he BE present."
"They demanded that she LEAVE immediately."
"It's essential that he ATTEND the meeting."
```

Note: The verb is **be**, **leave**, **attend** — not "is", "leaves", "attends".

### 3.2 Triggering Verbs

Verbs that trigger mandative subjunctive:

| Demand | Suggestion | Necessity |
|--------|------------|-----------|
| demand | suggest | require |
| insist | propose | ask |
| order | recommend | prefer |
| command | advise | request |

```
"The committee recommended that the rule be changed."
"I insist that he apologize."
"They demanded that she be fired."
```

### 3.3 Triggering Adjectives/Nouns

Adjectives and nouns also trigger it:

```
ADJECTIVES:
"It is essential that he be present."
"It's important that she attend."
"It's vital that they be informed."
"It's necessary that action be taken."

NOUNS:
"My recommendation is that he resign."
"There's a requirement that all students attend."
```

### 3.4 Negative Subjunctive

Negation comes **before** the base verb:

```
"I suggest that he NOT be late."
"They insisted that she NOT leave."
"It's essential that we NOT forget."
```

Note: "not + base form" — no auxiliary "do".

### 3.5 American vs British Usage

**American English:** Mandative subjunctive is common
```
"I suggest that he be informed." ✓ AmE preferred
```

**British English:** "Should + infinitive" is often preferred
```
"I suggest that he should be informed." ✓ BrE alternative
"I suggest that he is informed." ✓ BrE informal
```

**For C2:** Know both. Use subjunctive in formal writing regardless of variety.

### 3.6 Examples by Trigger

**With SUGGEST:**
```
"I suggest that the meeting be postponed."
"She suggested that he apply for the job."
```

**With RECOMMEND:**
```
"The doctor recommended that she take rest."
"We recommend that all members attend."
```

**With INSIST:**
```
"He insisted that she be present."
"They insist that payment be made immediately."
```

**With IT IS ESSENTIAL:**
```
"It is essential that this remain confidential."
"It's crucial that we act quickly."
```

## 4. Formulaic Subjunctives

### 4.1 Fixed Expressions

Some subjunctive forms survive in **fixed phrases**:

```
"God save the Queen!"
"God bless you!"
"Heaven forbid!"
"So be it."
"Be that as it may..."
"Come what may..."
"Suffice it to say..."
"If need be..."
"Far be it from me to..."
"Long live the King!"
```

These are **memorized chunks**, not productive grammar.

### 4.2 Usage Notes

These expressions are:

- Fixed (don't change them)
- Often formal or archaic
- Sometimes ironic in modern usage

```
"Heaven forbid that I should suggest otherwise!"
(often used ironically)

"Far be it from me to criticize, but..."
(polite preface to criticism)
```

## 5. "Wish" Constructions in Depth

### 5.1 Three Time Frames

| Time | Form | Example |
|------|------|---------|
| **Present** | Past Simple / were | "I wish I knew the answer." |
| **Past** | Past Perfect | "I wish I had studied harder." |
| **Future** | Would + infinitive | "I wish you would stop that." |

### 5.2 Present Wish (Unreal Now)

For **current situations you want to be different**:

```
"I wish I were taller." (but I'm not)
"I wish I spoke Chinese." (but I don't)
"I wish it weren't raining." (but it is)
```

### 5.3 Past Wish (Regret)

For **past situations you regret**:

```
"I wish I had studied medicine." (but I didn't)
"I wish we hadn't argued." (but we did)
"I wish she had told me earlier." (but she didn't)
```

### 5.4 Future Wish (Desire for Change)

For **requesting someone change behavior**:

```
"I wish you would be quiet." (please stop being noisy)
"I wish he would call me." (I want him to call)
"I wish it would stop raining." (I want the rain to stop)
```

Note: **Cannot use "I wish I would..."** — illogical.

### 5.5 "If Only" — Stronger Wish

"If only" is **more emphatic** than "I wish":

```
"If only I had more time!"
"If only she were here!"
"If only I had known earlier!"
```

## 6. "Would Rather" and "Would Sooner"

### 6.1 Preference About Others

When expressing preference about **someone else's actions**:

```
"I would rather you came tomorrow." (not "come")
"I'd sooner she didn't know." (not "doesn't know")
"Would you rather I left?"
```

Note: Uses **past tense for present/future unreality**.

### 6.2 Preference About Self

When expressing preference about **your own actions**:

```
"I would rather stay home."
"I'd sooner die than admit that."
```

Note: Uses **infinitive without "to"** for your own actions.

### 6.3 Past Preference (About Past Events)

```
"I would rather you had told me earlier."
"I'd sooner we hadn't met at all."
```

Uses **past perfect** for unreal past.

## 7. Advanced Conditional Patterns

### 7.1 Mixed Conditionals (Review + Extension)

**Past condition → Present result:**
```
"If I had studied medicine, I would be a doctor now."
(I didn't study medicine → I'm not a doctor)
```

**Present condition → Past result:**
```
"If I weren't so lazy, I would have finished already."
(I am lazy → I haven't finished)
```

### 7.2 Inversion in Conditionals

Formal/literary English can **invert** condition clauses without "if":

```
Standard: "If I had known..."
Inverted: "Had I known..."

Standard: "If she were here..."
Inverted: "Were she here..."

Standard: "If you should need help..."
Inverted: "Should you need help..."
```

More on inversion in Module 06.

### 7.3 "Supposing" and "Provided"

Other ways to introduce conditions:

```
"Supposing you were offered the job, would you take it?"
"Provided (that) he agrees, we can proceed."
"Assuming the weather holds, we'll go ahead."
```

## 8. Common Errors by Russian Speakers

### 8.1 Using "Would" in If-Clause

**The classic error:**

```
❌ "If I would have time, I would help you."
✅ "If I had time, I would help you."

❌ "If I would be you, I would apologize."
✅ "If I were you, I would apologize."
```

**Why it happens:** Russian uses бы in both clauses: "Если бы я был..."

### 8.2 Tense Confusion in Wishes

```
❌ "I wish I can speak French."
✅ "I wish I could speak French."

❌ "I wish I am taller."
✅ "I wish I were taller."
```

### 8.3 Missing Subjunctive in Formal Contexts

```
❌ "It's essential that he comes on time."
✅ "It's essential that he come on time."

❌ "I suggest that she takes the exam."
✅ "I suggest that she take the exam."
```

### 8.4 "Would" with First Person in Wish

```
❌ "I wish I would be smarter."
✅ "I wish I were smarter."
(For present state)

✅ "I wish I would just relax." 
(Possible if expressing frustration with own inability)
```

## 9. Register and Usage Guide

### 9.1 When to Use Subjunctive

| Context | Were-subjunctive | Mandative subjunctive |
|---------|------------------|----------------------|
| Formal writing | Always | Standard |
| Academic | Always | Standard |
| Legal documents | Always | Standard |
| Formal speech | Preferred | Common |
| Everyday speech | Optional | Less common |
| Casual writing | Optional | Often avoided |

### 9.2 Alternatives to Mandative Subjunctive

In less formal contexts:

```
Subjunctive: "I suggest that he be present."
Should-form: "I suggest that he should be present."
Indicative: "I suggest that he is present." (BrE informal)
To-infinitive: "I suggest for him to be present." (informal)
```

### 9.3 When NOT to Use Subjunctive

Don't use mandative subjunctive when:

- The clause is a fact (indicative meaning)
- The context is very informal

```
"She suggested that it was a good idea." (reporting fact)
vs.
"She suggested that it be postponed." (recommendation)
```

## 10. Practice Patterns

### 10.1 Pattern Transformation

Convert to subjunctive forms:

```
"I recommend that he should leave."
→ "I recommend that he leave."

"If I was the boss, I would change things."
→ "If I were the boss, I would change things."

"It's essential that everyone attends."
→ "It's essential that everyone attend."
```

### 10.2 Identify the Error

```
1. "If I would be rich, I would help everyone."
   Error: "would be" → should be "were"

2. "I wish I can travel more."
   Error: "can" → should be "could"

3. "The committee insisted that the report was submitted."
   Error: "was submitted" → should be "be submitted"
```

---

## 💡 Key Takeaways

- **Were-subjunctive**: Use "were" for all persons in unreal conditions ("If I were...")
- **Mandative subjunctive**: Use base form after suggest, recommend, insist, essential ("that he be...")
- **Wish constructions**: Past tense for present unreal; Past Perfect for past regret
- **Would rather + others**: Past tense ("I'd rather you came")
- **No "would" in if-clause**: The main mistake Russian speakers make
