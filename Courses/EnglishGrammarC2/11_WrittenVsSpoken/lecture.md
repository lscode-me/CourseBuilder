## 1. Two Different Grammars

### 1.1 The Myth

**Myth:** There's one "correct" grammar; spoken English is "sloppy."

**Reality:** Written and spoken English have **different** grammatical systems, both systematic and rule-governed.

### 1.2 Key Differences

| Written | Spoken |
|---------|--------|
| Planned | Spontaneous |
| Edited | Real-time |
| Dense | Fragmented |
| Complete sentences | Phrases, fragments |
| Precise | Vague |
| Formal | Casual |

### 1.3 Why This Matters

If you speak like you write, you sound:

- Robotic
- Overly formal
- Non-native
- Unnatural

```

❌ (Spoken) "I would like to inform you that I shall not be attending."
✓ (Spoken) "Hey, I can't make it."

```

## 2. Features of Spoken Grammar

### 2.1 Ellipsis (Omission)

Spoken English **omits** many elements:

**Subject omission:**
```

"Sounds good." (= It sounds good)
"Looks like rain." (= It looks like rain)
"Don't know." (= I don't know)
"Can't help you there." (= I can't help you there)

```

**Auxiliary omission:**
```

"You coming?" (= Are you coming?)
"Anyone want coffee?" (= Does anyone want coffee?)
"She gone?" (= Has she gone?)

```

**Article omission:**
```

"Want coffee?" (= Do you want coffee?)
"Got a minute?" (= Have you got a minute?)

```

### 2.2 Heads and Tails

**Heads (left dislocation):**
```

"Your sister, is she coming?"
"That restaurant, it's really expensive."
"The meeting tomorrow, what time does it start?"

```

**Tails (right dislocation):**
```

"She's nice, your sister."
"It's really expensive, that restaurant."
"He's very clever, John."

```

### 2.3 Discourse Markers

**Organizing talk:**
```

"Right, so..."
"Anyway..."
"The thing is..."
"I mean..."
"You know..."
"Like..."
"Basically..."
"So basically..."

```

**Responding:**
```

"Oh really?"
"Right."
"I see."
"No way!"
"Fair enough."

```

### 2.4 Fillers

**Hesitation markers:**
```

"um", "uh", "er"
"well..."
"let me see..."
"how can I put it..."

```

These are **normal**, not errors.

## 3. Vague Language

### 3.1 What Is Vague Language?

**Vague language** = deliberately imprecise language:

```

"There were about twenty people."
"It cost something like fifty dollars."
"We arrived around six-ish."

```

### 3.2 Why Use Vague Language?

- Avoids over-precision
- Sounds natural
- Shows informality
- Creates solidarity

```

❌ (Sounds strange) "We arrived at exactly 18:37."
✓ (Natural) "We arrived around six-ish."

```

### 3.3 Vague Language Markers

**Quantity:**
```

about, around, approximately, roughly
a few, several, quite a few
loads of, tons of, masses of (informal)

```

**Categories:**
```

...and stuff (like that)
...and things (like that)
...or something (like that)
...or whatever

```

**Softeners:**
```

sort of, kind of, a bit
like (as filler)
"It was, like, really boring."
"I'm kind of tired."

```

### 3.4 Examples

```

"There were like thirty people or something."
"It cost around fifty quid and stuff."
"We arrived at sixish or so."
"I'm sort of feeling a bit tired."

```

## 4. Spoken Response Tokens

### 4.1 Backchannels

Sounds/words showing you're listening:

```

"Mm-hmm"
"Uh-huh"
"Yeah"
"Right"
"I see"
"Oh really?"
"No way!"

```

### 4.2 Response Words

```

"Absolutely!"
"Exactly!"
"Definitely!"
"Totally!"
"Fair enough."
"Same here."
"Tell me about it!"

```

### 4.3 Agreement/Disagreement

**Agreeing:**
```

"Yeah, totally."
"I know, right?"
"Absolutely."
"That's so true."

```

**Soft disagreement:**
```

"Yeah, but..."
"I don't know about that..."
"Maybe, but..."
"I take your point, but..."

```

## 5. Question Forms in Spoken English

### 5.1 Rising Intonation Questions

**Statements become questions with rising tone:**

```

"You're coming?" ↗ (rising)
"She said that?" ↗
"We're meeting tomorrow?" ↗

```

### 5.2 Tag Questions

**Very common in spoken English:**

```

"It's nice, isn't it?"
"You're coming, aren't you?"
"She can help, can't she?"
"That was good, wasn't it?"

```

**Invariant tags (informal):**
```

"You're coming, yeah?"
"That's good, right?"
"She said that, no?"

```

### 5.3 Echo Questions

**Expressing surprise:**
```

A: "I quit my job."
B: "You did WHAT?" / "You quit your JOB?"

```

## 6. Sentence Structure Differences

### 6.1 Written: Complex Sentences

```

"Although the weather was poor, which had been forecast, 
we decided to proceed with the outdoor event, having made 
preparations for this eventuality."

```

### 6.2 Spoken: Simple Units Chained Together

```

"So the weather was really bad, right? Like they said it would be.
But anyway, we went ahead with the thing outside. We'd kind of
planned for that, you know?"

```

### 6.3 Spoken Features

**Coordination over subordination:**
```

Written: "Although it rained, we continued."
Spoken: "It rained, but we kept going."

```

**Short units:**
```

Written: "I went to the store to buy groceries and encountered..."
Spoken: "I went to the store. Got some groceries. And then..."

```

**Repetition:**
```

"It was good. Really good. Really, really good actually."

```

## 7. Verb Forms in Spoken English

### 7.1 Contractions (Always Used)

```

I'm, you're, he's, she's, we're, they're
I've, you've, he's, she's, we've, they've
I'll, you'll, he'll, she'll, we'll, they'll
can't, won't, wouldn't, couldn't, shouldn't

```

### 7.2 Gonna, Wanna, Gotta

**Very common in speech:**

```

"I'm gonna [going to] do it."
"Do you wanna [want to] come?"
"I gotta [have got to] go."
"You shoulda [should have] seen it!"
"I coulda [could have] done that."

```

Note: Don't write these (except in very informal contexts).

### 7.3 Progressive for Attitude

**More common in speech for emotion:**
```

"She's always complaining!"
"You're constantly interrupting!"
"He's forever losing his keys!"

```

## 8. Reporting in Spoken English

### 8.1 Direct Speech with "Be Like"

Very common in informal spoken English:

```

"And I'm like, 'No way!' And she's like, 'Yeah, totally.'"
"He was like, 'What are you doing?' And I'm like, 'Nothing.'"

```

### 8.2 "Go" for Speech

Informal, especially among younger speakers:

```

"And she goes, 'Are you serious?'"
"He went, 'I don't believe you.'"

```

### 8.3 "All" for Emphasis

Very informal:

```

"I was all, 'What are you talking about?'"
"She was all confused."

```

## 9. Russian Speakers' Issues

### 9.1 Speaking Too Formally

```

❌ "I would like to purchase a coffee."
✓ "Can I get a coffee?"

❌ "Could you inform me of the time?"
✓ "What time is it?" / "Got the time?"

```

### 9.2 Missing Discourse Markers

```

❌ "I went to the store. I bought milk."
✓ "So I went to the store, right? And I got some milk."

```

### 9.3 Missing Vague Language

```

❌ "There were twenty-three people exactly."
✓ "There were like twenty-something people."

```

### 9.4 Full Forms in Speech

```

❌ "I am going to go to the store."
✓ "I'm gonna go to the store."

```

## 10. When to Use What

### 10.1 Match Mode to Context

**Use written grammar for:**

- Academic papers
- Formal reports
- Business documents
- Official correspondence

**Use spoken grammar for:**

- Conversations
- Casual emails
- Informal presentations
- Social media

### 10.2 Danger of Hyper-Formality

Speaking too formally:

- Creates distance
- Sounds robotic
- Marks you as non-native
- Makes people uncomfortable

### 10.3 Finding the Balance

Learn both systems and **switch** as needed.

---

## 💡 Key Takeaways

- **Written and spoken** have different grammatical systems

- **Ellipsis is normal**: "Sounds good", "Got a minute?"

- **Vague language** is natural: "like", "about", "or something"

- **Discourse markers** organize speech: "So", "Anyway", "The thing is"

- **Contractions always** in speech: "I'm", "gonna", "wanna"

- **Russian speakers** often sound too formal in spoken English
