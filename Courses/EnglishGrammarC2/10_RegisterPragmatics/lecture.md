## 1. What Is Pragmatics?

### 1.1 Definition

**Pragmatics** = the study of meaning in context:

- What speakers **mean** vs what they **say**
- How context affects interpretation
- Social rules of language use

### 1.2 Example

```

A: "Can you pass the salt?"

Literal meaning: "Are you physically able to pass the salt?"
Pragmatic meaning: "Please pass the salt."

```

### 1.3 Why It Matters at C2

At C2, you understand **implied meaning** and produce **appropriate** language:

```

C1: Understands "Can you pass the salt?" is a request
C2: Knows WHEN to say "Can you...", "Could you...", 
    "Would you mind...", "I don't suppose you could..."
    and the social effect of each

```

## 2. Face and Politeness

### 2.1 Face Theory

**Face** = public self-image that everyone wants to protect:

**Positive face:** Want to be liked, appreciated, accepted
**Negative face:** Want to be free, not imposed upon

### 2.2 Face-Threatening Acts (FTAs)

Some speech acts **threaten face**:

| Act | Threatens |
|-----|-----------|
| Requests | Hearer's negative face (imposes) |
| Criticism | Hearer's positive face (attacks image) |
| Refusals | Hearer's positive face (rejects them) |
| Orders | Hearer's negative face (removes freedom) |
| Disagreement | Hearer's positive face |

### 2.3 Politeness Strategies

**Bald on record (direct):**
```

"Give me the report."
→ Most direct, can be rude

```

**Positive politeness (be friendly):**
```

"Hey, could you grab me that report? You're a star!"
→ Appeals to positive face (you're great)

```

**Negative politeness (be indirect):**
```

"I was wondering if you might be able to send the report?"
→ Minimizes imposition, gives "out"

```

**Off record (hint):**
```

"I haven't seen the report yet..."
→ Implies request without stating

```

## 3. Indirectness in English

### 3.1 Why English Is Indirect

English professional culture values **indirectness** for:

- Showing respect
- Giving "outs"
- Avoiding confrontation
- Maintaining harmony

### 3.2 Request Strategies (Ranked by Politeness)

```

LEAST POLITE
    │
    │  Imperative: "Give me the file."
    │  
    │  Need statement: "I need the file."
    │  
    │  Direct question: "Can you give me the file?"
    │  
    │  Conditional: "Could you give me the file?"
    │  
    │  Past modal: "I was wondering if you could..."
    │  
    │  Negated modal: "I don't suppose you could..."
    │
MOST POLITE

```

### 3.3 Examples in Context

**Casual (friend):**
```

"Pass me that."
"Can you grab me a coffee?"

```

**Professional (colleague):**
```

"Could you send me the report when you get a chance?"
"Would you mind looking at this?"

```

**Formal (senior/stranger):**
```

"I was wondering if you might be able to..."
"I don't suppose there's any chance you could..."

```

## 4. Pragmatic Meaning

### 4.1 Understatement

English often **understates** to be polite or modest:

```

"That's not bad." = It's good
"She's not unintelligent." = She's quite intelligent
"It could be better." = It's not good
"I'm not entirely convinced." = I disagree

```

### 4.2 Polite Deflection

Seemingly positive comments can be **negative**:

```

"That's interesting." = I don't agree / It's not very good
"I see what you mean." = But I disagree
"That's one way of looking at it." = I see it differently
"I'll bear that in mind." = I probably won't do it

```

### 4.3 Social Formulas

Phrases that don't mean what they literally say:

```

"How are you?" = Greeting (not actual health inquiry)
"We should do lunch sometime." = Social formula (often no intention)
"I'll let you go." = I want to end this conversation
"No worries." = You're forgiven / It's fine

```

### 4.4 Implied Criticism

**Soft criticism patterns:**

```

"With respect..." = I'm about to disagree
"Correct me if I'm wrong, but..." = I think you're wrong
"I take your point, however..." = I disagree
"There might be some merit in that, but..." = I don't fully agree

```

## 5. Register

### 5.1 The Register Continuum

```

FROZEN      Legal documents, religious texts
            "Wherefore art thou..."
            
FORMAL      Academic writing, official documents
            "It is hereby requested that..."
            
CONSULTATIVE Professional, business
            "I'd like to suggest that we..."
            
CASUAL      Friends, familiar colleagues
            "So basically what happened was..."
            
INTIMATE    Close relationships
            "Gimme that."

```

### 5.2 Register Features

| Feature | Formal | Informal |
|---------|--------|----------|
| Vocabulary | utilize, commence | use, start |
| Contractions | No | Yes |
| Phrasal verbs | Avoided | Common |
| Passive | Common | Less common |
| Personal pronouns | We (impersonal) | I, you |
| Sentences | Longer, complex | Shorter |

### 5.3 Register Mismatch

**Too formal:**
```

❌ (To friend) "I would be most grateful if you could pass the salt."
✓ "Pass the salt, would you?"

```

**Too informal:**
```

❌ (Business email) "Hey! Can you guys check this out ASAP?"
✓ "Dear colleagues, I would appreciate your review of this document."

```

## 6. Professional Communication

### 6.1 Email Register

**Opening:**
```

Formal: "Dear Mr. Smith,"
Standard: "Dear John,"
Semi-formal: "Hello John,"
Informal: "Hi John," / "John,"

```

**Requests:**
```

Formal: "I would be grateful if you could..."
Standard: "Could you please..."
Less formal: "Would you mind..."

```

**Closing:**
```

Formal: "Yours sincerely," / "Best regards,"
Standard: "Kind regards," / "Best,"
Informal: "Thanks," / "Cheers,"

```

### 6.2 Giving Feedback

**Critical but diplomatic:**
```

❌ "This is wrong."
✓ "I wonder if there might be another way to approach this."
✓ "There may be some room for refinement here."
✓ "This could potentially be strengthened."

```

### 6.3 Disagreeing

**Diplomatic disagreement:**
```

❌ "I disagree."
✓ "I see it slightly differently."
✓ "I wonder whether we might consider..."
✓ "That's an interesting perspective. Have you thought about...?"
✓ "I take your point, but..."

```

### 6.4 Refusing

**Diplomatic refusal:**
```

❌ "No, I can't do that."
✓ "I'm afraid that might be difficult."
✓ "Unfortunately, I'm not sure I'd be able to commit to that."
✓ "That could be challenging given the current constraints."

```

## 7. Russian vs English Pragmatics

### 7.1 Directness Difference

Russian communication is **more direct** than English:

```

Russian-influenced (too direct in English):
❌ "Your presentation was bad."
❌ "Give me the report."
❌ "I disagree with you."

English pragmatic equivalents:
✓ "There might be some areas we could work on."
✓ "Would you mind sending me the report?"
✓ "I wonder if there might be another perspective."

```

### 7.2 Compliment Responses

**Russian:** Often deflect or minimize compliments
**English:** Accept gracefully

```

❌ "Your presentation was great!" — "Oh, it was nothing special."
✓ "Your presentation was great!" — "Thank you! I'm glad it went well."

```

### 7.3 Small Talk Expectations

**Russian:** Less small talk, quicker to business
**English:** Small talk expected before business

```

❌ (Starting email) "Please send me the report."
✓ (Starting email) "I hope this finds you well. I was wondering if..."

```

### 7.4 "Please" Usage

**Russian "пожалуйста"** ≠ English "please" exactly:

```

In English, "please" alone can seem abrupt:
❌ "Report, please."
✓ "Could you send me the report, please?"

```

## 8. Speech Acts

### 8.1 What Are Speech Acts?

**Speech acts** = things we DO with language:

| Act | Example |
|-----|---------|
| Requesting | "Could you help me?" |
| Apologizing | "I'm so sorry about that." |
| Thanking | "Thank you so much." |
| Promising | "I'll definitely do it." |
| Refusing | "I'm afraid I can't." |
| Complimenting | "That's a great idea!" |

### 8.2 Indirect Speech Acts

Often, the **form** doesn't match the **function**:

```

"Can you reach that shelf?" 
Form: Question about ability
Function: Request

"It's cold in here."
Form: Statement
Function: Request (close the window)

"I have a meeting at 3."
Form: Statement
Function: Declining invitation

```

### 8.3 Softening Devices

**Hedges:**
```

"sort of", "kind of", "a bit", "maybe"
"It's sort of difficult." = It's quite difficult

```

**Downtoners:**
```

"just", "perhaps", "possibly"
"I was just wondering if..."
"Could you possibly help?"

```

## 9. Cultural Considerations

### 9.1 British vs American Pragmatics

**British English:** More indirect, more hedging
**American English:** More direct (but still indirect vs Russian)

```

British: "I'm not entirely sure that's the best approach."
American: "I'm not sure that's the best approach."
Russian-influenced: "That approach is wrong."

```

### 9.2 Irony and Sarcasm

English uses **irony** frequently:

```

"Great weather!" (when it's raining)
"Well, that went well." (when it went badly)
"Oh, wonderful." (when something bad happened)

```

### 9.3 Self-Deprecation

English speakers often **diminish** their own achievements:

```

"I just got lucky."
"It wasn't really that difficult."
"Anyone could have done it."

```

## 10. Practice: Register Transformation

### 10.1 Make These More Polite

```

Direct: "Send me the file."
→ "Could you please send me the file?"
→ "Would you mind sending me the file?"
→ "I was wondering if you could send me the file."

Direct: "That's wrong."
→ "I'm not sure that's quite right."
→ "There might be an issue there."
→ "I wonder if we might look at this differently."

```

### 10.2 Interpret These

```

"That's an interesting approach."
→ Probably means: I have doubts about this approach

"I'll bear that in mind."
→ Probably means: I probably won't do it

"With the greatest respect..."
→ Probably means: I'm about to disagree

```

## 💡 Key Takeaways

- **Pragmatics** = meaning in context; what people really mean

- **Face-saving** is crucial in English professional communication

- **Indirectness** shows respect; directness can seem rude

- **Register** must match context; too formal or informal sounds off

- **Russian speakers** typically need to be more indirect in English

- **Implied meaning** is common: "That's interesting" may not be praise
