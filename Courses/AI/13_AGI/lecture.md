## 2. Мифы об AGI

### 2.1 Миф: LLM уже достигли AGI

```python

myth_llm_is_agi = {
    "Миф": "ChatGPT/Claude — это уже AGI",
    
    "Реальность": """
    LLM — это sophisticated pattern matching:
    - Нет persistent memory (забывает между сессиями)
    - Нет понимания мира (только статистические паттерны)
    - Нет goals или agency (делает то, что просят)
    - Нет self-improvement (не обучается в runtime)
    - Галлюцинирует факты
    """
}
```

### 2.2 Миф: AGI через несколько лет

```python

myth_agi_soon = {
    "Миф": "AGI будет через 2-5 лет",
    
    "Реальность": """
    Никто точно не знает:
    - OpenAI говорит "скоро" (маркетинг)
    - Ученые скептичны (нет плана)
    - Прошлые прогнозы провалились
    - Нет консенсуса что такое AGI
    """
}
```

### 2.3 Миф: AGI заменит всех программистов

```python

myth_replacement = {
    "Миф": "AI заменит программистов к 2025",
    
    "Реальность": """
    AI — инструмент, не замена:
    - Нужен контроль качества
    - Нужно понимание бизнеса
    - AI делает ошибки
    - Архитектура остаётся за человеком
    - Работа трансформируется, не исчезает
    """
}
```

### 2.4 Миф: Масштабирование = AGI

```python

myth_scaling = {
    "Миф": "Просто увеличим модель и получим AGI",
    
    "Реальность": """
    Scaling laws имеют пределы:
    - Больше параметров ≠ понимание
    - Данных не бесконечно
    - Вычислений не бесконечно
    - Архитектура может быть ограничением
    - Нужны новые прорывы
    """
}
```

## 3. Что LLM не умеют

### 3.1 Фундаментальные ограничения

```python

llm_limitations = {
    "Нет мировой модели": """
        LLM не понимает физику мира.
        Предсказывает следующий токен,
        не моделирует причинность.
    """,
    
    "Нет persistent learning": """
        Не обучается на новых данных в runtime.
        Знания "заморожены" на дату обучения.
    """,
    
    "Нет planning": """
        Не планирует наперёд.
        Генерирует token за token.
    """,
    
    "Нет self-awareness": """
        Не понимает свои ограничения.
        "Уверенно" галлюцинирует.
    """
}
```

## 💡 Key Takeaways

- **AGI ≠ LLM** — современные модели это Narrow AI, не General AI

- **Мифы повсюду** — AGI "скоро", AI заменит всех — это хайп, не реальность

- **LLM имеют фундаментальные ограничения** — нет мировой модели, памяти, понимания

- **Прогнозы ненадёжны** — никто не знает когда будет AGI

- **Прагматичный подход** — используйте AI как инструмент, понимая ограничения
