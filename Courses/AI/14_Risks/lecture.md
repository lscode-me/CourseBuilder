## 1. Bias и ответственность

### 1.1 Что такое Bias

```
┌─────────────────────────────────────────────────────────────┐
│                   AI Bias (Предвзятость)                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Bias в данных                                              │
│  ├── Исторические предрассудки в обучающих данных           │
│  ├── Недостаточная репрезентация групп                      │
│  └── Примеры: гендер, раса, география                       │
│                                                             │
│  Bias в модели                                              │
│  ├── Усиливает паттерны из данных                           │
│  ├── Может дискриминировать                                 │
│  └── Сложно обнаружить и исправить                          │
│                                                             │
│  Последствия                                                │
│  ├── Несправедливые решения                                 │
│  ├── Усиление неравенства                                   │
│  └── Юридические и репутационные риски                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 Примеры bias

```python
bias_examples = {
    "Найм": """

        где мужчины получали больше офферов.
        Результат: модель занижает женщин-кандидатов.
    """,
    "Кредитование": """
        Модель обучена на данных где определённые ZIP-коды
        (исторически minority neighborhoods) получали меньше кредитов.

    "Healthcare": """
        Модель предсказания рисков обучена преимущественно
        на данных одной популяции.
        Результат: хуже работает для других групп.
    """,
    "Изображения": """
        Генерация "CEO" даёт преимущественно белых мужчин.
        "Nurse" — преимущественно женщин.
    """
}
```

## 2. Риски AI систем

### 2.1 Технические риски

```python
technical_risks = {
    "Галлюцинации": {
        "проблема": "Модель уверенно генерирует неправду",
        "mitigation": "Verification, grounding, RAG"
    },
    "Prompt injection": {
        "проблема": "Атаки через входные данные",
        "mitigation": "Input validation, sandboxing"
    },
    "Data leakage": {
        "проблема": "Модель раскрывает обучающие данные",
        "mitigation": "Privacy training, filtering"
    },
    "Model theft": {
```

## 💡 Key Takeaways

- **Bias реален** — AI наследует и усиливает предрассудки из данных

- **Риски многоуровневые** — технические (галлюцинации), бизнес (вендор lock-in), этические (дискриминация)

- **Профессии трансформируются** — не "AI заменит людей", а "люди с AI заменят людей без AI"

- **Governance критичен** — компаниям нужны политики и мониторинг AI

- **Инженеры остаются нужны** — но роль смещается от кодирования к оркестрации и валидации
