## 1. Рождение AI (1950-е годы)

### 1.1 Тест Тьюринга (1950)

История AI начинается со статьи Алана Тьюринга "Computing Machinery and Intelligence" (1950). Тьюринг предложил тест для определения, может ли машина мыслить:

```
┌─────────────────────────────────────────────────────────────┐
│                      Тест Тьюринга                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│      Человек A              Судья              Компьютер B   │
│         │                     │                     │        │
│         │    (текстовое       │      текстовое)     │        │
│         │     общение)        │      общение        │        │
│         │◄───────────────────►│◄───────────────────►│        │
│         │                     │                     │        │
│                              │                              │
│         Если судья не может отличить человека от машины,    │
│                    машина проходит тест                     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

> **💡 Pro Tip:**  
> Тест Тьюринга — философский эксперимент, а не научный критерий. Современные чат-боты могут "обмануть" судью, не обладая пониманием.

### 1.2 Дартмутская конференция (1956)

Термин "Artificial Intelligence" был официально введён на летней конференции в Дартмутском колледже:

```
Дартмутская конференция (1956)
Участники: John McCarthy, Marvin Minsky, Claude Shannon, и др.

Исходная гипотеза:
"Every aspect of learning or any other feature of intelligence 
can in principle be so precisely described that a machine can 
be made to simulate it."

Оптимистичный прогноз:
"Мы думаем, что значительный прогресс будет достигнут,
если группа учёных будет работать над этим одно лето"
```

Так родилось целое направление исследований. Оптимизм участников оказался сильно преувеличенным — решение «проблемы AI» заняло не лето, а более 60 лет.

### 1.3 Перцептрон (1958)

Фрэнк Розенблатт создал перцептрон — первую обучаемую нейронную сеть:

```python
# Концептуальная модель перцептрона
class Perceptron:
    def __init__(self, n_inputs):
        self.weights = [0.0] * n_inputs
        self.bias = 0.0
    
    def predict(self, inputs):
        """Простой линейный классификатор"""
        total = sum(w * x for w, x in zip(self.weights, inputs))
        total += self.bias
        return 1 if total > 0 else 0
    
    def train(self, inputs, target, learning_rate=0.1):
        """Обучение по правилу перцептрона"""
        prediction = self.predict(inputs)
        error = target - prediction
        for i in range(len(self.weights)):
            self.weights[i] += learning_rate * error * inputs[i]
        self.bias += learning_rate * error
```

Перцептрон мог обучаться классифицировать простые паттерны, что вызвало огромный энтузиазм.

### 2.2 Символический AI

Доминирующий подход того времени — символический AI (GOFAI: Good Old-Fashioned AI):

```python
# Пример символического подхода: правила экспертной системы
rules = {
    "IF patient has fever AND cough THEN possible flu": 0.7,
    "IF patient has fever AND rash THEN possible measles": 0.8,
    "IF patient has headache AND stiff neck THEN possible meningitis": 0.9
}

# Знания представлены явными правилами
def diagnose(symptoms):
    """Символический подход: явные правила"""
    possible_diagnoses = []
    for rule, confidence in rules.items():
        if all(symptom in rule for symptom in symptoms):
            diagnosis = rule.split("THEN")[1].strip()
            possible_diagnoses.append((diagnosis, confidence))
    return sorted(possible_diagnoses, key=lambda x: -x[1])
```

**Проблемы символического подхода:**

| Проблема | Описание |
|----------|----------|
| Knowledge acquisition | Эксперты не могут формализовать все свои знания |
| Brittleness | Системы ломаются на edge cases |
| Common sense | Невозможно закодировать здравый смысл |
| Scalability | Экспоненциальный рост правил |

## 3. Возрождение и вторая зима (1980-е — 1990-е)

### 3.1 Backpropagation (1986)

Алгоритм обратного распространения ошибки (backpropagation) позволил обучать многослойные нейросети:

```python
# Концептуально: backpropagation позволяет 
# обучать глубокие сети

# 1. Forward pass: вычисляем output
# 2. Вычисляем ошибку (loss)
# 3. Backward pass: распространяем градиенты назад
# 4. Обновляем веса

def train_step(network, x, y_true, learning_rate=0.01):
    # Forward pass
    y_pred = network.forward(x)
    
    # Compute loss
    loss = compute_loss(y_pred, y_true)
    
    # Backward pass
    gradients = network.backward(loss)
    
    # Update weights
    for layer, grad in zip(network.layers, gradients):
        layer.weights -= learning_rate * grad
    
    return loss
```

Теперь проблема XOR стала решаемой с помощью многослойной сети!

## 4. Становление Machine Learning (1990-е — 2000-е)

### 4.1 Статистический подход

В 1990-х фокус сместился с символического AI на статистические методы:

```python
# Пример: наивный байесовский классификатор
from collections import defaultdict
import math

class NaiveBayes:
    def __init__(self):
        self.class_probs = {}
        self.word_probs = defaultdict(lambda: defaultdict(float))
    
    def fit(self, documents, labels):
        """Обучение на примерах, а не на правилах"""
        # Подсчёт вероятностей из данных
        for doc, label in zip(documents, labels):
            self.class_probs[label] = self.class_probs.get(label, 0) + 1
            for word in doc.split():
                self.word_probs[label][word] += 1
        
        # Нормализация
        total = sum(self.class_probs.values())
        for label in self.class_probs:
            self.class_probs[label] /= total
    
    def predict(self, document):
        """Предсказание на основе статистики"""
        best_label = None
        best_prob = float('-inf')
        
        for label, class_prob in self.class_probs.items():
            prob = math.log(class_prob)
            for word in document.split():
                prob += math.log(self.word_probs[label].get(word, 1e-10))
            
            if prob > best_prob:
                best_prob = prob
                best_label = label
        
        return best_label
```

**Ключевое изменение парадигмы:**

| Символический AI | Machine Learning |
|-----------------|------------------|
| Правила пишет человек | Правила выводятся из данных |
| Требует экспертных знаний | Требует примеров |
| Хрупкий | Более устойчивый |
| Понятный | Менее интерпретируемый |

### 7.3 Парадигма "Pretrain + Fine-tune"

Современный подход к применению AI:

```
┌─────────────────────────────────────────────────────────────┐
│              Pretrain + Fine-tune Pipeline                   │

│                                                              │

│  ────────────────────────────────────────────────           │

│  • Тысячи GPU на недели/месяцы                              │

│  • Результат: foundation model                              │
│                                                              │

│  • Часы/дни обучения                                        │
│  • Тысячи долларов                                          │
│  • Результат: специализированная модель                     │
│                                                              │
│  Этап 3: Prompting (бесплатно, делают все)                  │
│  ────────────────────────────────────────────────           │
│  • Инструкции в тексте                                      │
│  • Мгновенно                                                │
```

## 💡 Key Takeaways

- **AI прошёл через циклы подъёмов и спадов** — энтузиазм сменялся разочарованием при невыполнении обещаний. История учит реализму

- **Символический AI уступил статистическому** — явные правила заменили обучение на данных. Это фундаментальный сдвиг парадигмы

- **2012 — начало эпохи Deep Learning** — AlexNet показал мощь GPU и глубоких сетей. После этого нейросети стали доминировать

- **2017 — Transformer изменил всё** — архитектура, позволившая масштабироваться и создать современные LLM

- **Foundation Models — новая парадигма** — большие предобученные модели, адаптируемые под задачи через fine-tuning и prompting
