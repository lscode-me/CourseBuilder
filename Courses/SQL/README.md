# SQL — от основ до инженерного уровня

Курс даёт системное понимание SQL — от простых запросов до проектирования схем, оптимизации и использования SQL в аналитике, data engineering и system design.

## 🎯 Для кого этот курс

- Разработчики (backend, fullstack)
- Data Engineers и Data Analysts
- Инженеры баз данных
- Все, кто работает с данными и хочет писать эффективный SQL

## 🎓 После прохождения курса

Вы будете:

- Уверенно писать SQL-запросы любой сложности
- Понимать основы реляционных баз данных и их внутреннее устройство
- Уметь проектировать таблицы и связи между ними
- Понимать индексы и планы выполнения запросов
- Писать эффективный и поддерживаемый SQL
- Понимать роль SQL в аналитике и data engineering

## 📖 Как проходить курс

1. **Последовательно** — модули построены от простого к сложному
2. **С практикой** — пробуйте все примеры запросов
3. **С квизами** — проверяйте понимание после каждой лекции
4. **С экспериментированием** — модифицируйте примеры и смотрите результаты

## ⚡ Особенности курса

- **Практичность** — все примеры работают и могут быть выполнены

- **Системность** — от базового синтаксиса до архитектурных решений

- **Актуальность** — современные практики и инструменты

- **Глубина** — понимание не только "как", но и "почему"

## 🔧 Требования

- Базовое понимание работы с данными
- Доступ к любой SQL-совместимой СУБД (PostgreSQL, MySQL, SQLite и др.)
- Готовность экспериментировать с запросами
