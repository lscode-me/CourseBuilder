## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | `SELECT *` выбирает все столбцы из таблицы. Звёздочка означает "все столбцы" |
| 2 | C | В SQL можно использовать как `!=`, так и `<>` для проверки "не равно" |
| 3 | B | Символ `%` в LIKE означает любую последовательность символов (0 или более). `_` означает один символ |
| 4 | C | BETWEEN включает границы. `BETWEEN 25 AND 30` эквивалентно `>= 25 AND <= 30` |
| 5 | B | Для проверки NULL нужно использовать `IS NULL` или `IS NOT NULL`. `= NULL` не работает |
| 6 | D | `ORDER BY age DESC` сортирует по возрасту по убыванию (от большего к меньшему) |
| 7 | C | `LIMIT 5 OFFSET 10` пропускает первые 10 строк и возвращает следующие 5 строк |
| 8 | A | `IN (25, 30, 35)` проверяет, входит ли значение в список. Вернёт пользователей с возрастом 25, 30 или 35 |
| 9 | C | `age >= 25 AND age <= 30` вернёт пользователей от 25 до 30 лет включительно |
| 10 | B | `DISTINCT` убирает дубликаты из результата запроса |
| 11 | D | Оба синтаксиса `AS user_name` и просто `user_name` работают для создания алиаса |
| 12 | A | Порядок выполнения: FROM (выбор таблицы) → WHERE (фильтрация) → SELECT (выбор столбцов) → ORDER BY (сортировка) → LIMIT (ограничение) |
| 13 | C | `LIKE '%@gmail.com'` найдёт все email, заканчивающиеся на "@gmail.com". `%` означает любую последовательность символов |
| 14 | A | Запрос сначала сортирует по возрасту по убыванию, затем среди одинаковых возрастов сортирует по имени по возрастанию |
| 15 | A | `NOT IN (25, 30)` вернёт пользователей, возраст которых не равен 25 и не равен 30 |
| 16 | B | `ILIKE` доступен только в PostgreSQL. В других СУБД используется `LIKE` (регистрозависимый) |
| 17 | C | `BETWEEN 25 AND 30` эквивалентно `>= 25 AND <= 30` (включает границы) |
| 18 | A | Без ORDER BY порядок строк не гарантирован. LIMIT может вернуть разные строки при каждом выполнении |
| 19 | B | SELECT * менее читаем, скрывает реальные столбцы и может ухудшить производительность, особенно при JOIN |
| 20 | A | `age < 20 OR age > 30` вернёт пользователей младше 20 или старше 30 лет |
| 21 | C | Символ `_` в LIKE означает ровно один любой символ. `%` означает любую последовательность |
| 22 | D | `ORDER BY 2` означает сортировку по второму столбцу в SELECT (age). Можно использовать, но менее читаемо |
| 23 | D | В PostgreSQL правильный синтаксис `LIMIT 10 OFFSET 20`. В MySQL можно использовать `LIMIT 20, 10` |
| 24 | B | `DISTINCT` применяется ко всей строке, убирая дубликаты по комбинации всех указанных столбцов |
| 25 | C | Функции в WHERE используются как `LENGTH(name) > 5`. Синтаксис зависит от СУБД, но общий принцип одинаков |
