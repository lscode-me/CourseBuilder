## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | INTEGER в PostgreSQL занимает 4 байта и хранит значения от -2,147,483,648 до 2,147,483,647 |
| 2 | D | DECIMAL обеспечивает точную арифметику без ошибок округления, что критично для денег. REAL использует плавающую точку и может давать ошибки |
| 3 | B | VARCHAR хранит строки переменной длины (экономит место), CHAR — фиксированной длины (всегда занимает указанное количество символов) |
| 4 | B | Для проверки NULL нужно использовать `IS NULL` или `IS NOT NULL`. `= NULL` не работает из-за трёхзначной логики |
| 5 | D | В SQL `NULL = NULL` возвращает NULL (UNKNOWN), а не TRUE. Это часть трёхзначной логики SQL |
| 6 | D | TIMESTAMP хранит дату и время вместе. DATE — только дату, TIME — только время |
| 7 | C | COALESCE возвращает первое не-NULL значение из списка аргументов. Полезно для замены NULL на значение по умолчанию |
| 8 | C | SERIAL автоматически увеличивает значение при вставке новой строки. Используется для автоинкрементных первичных ключей |
| 9 | B | TEXT используется для длинного контента без известной максимальной длины. VARCHAR лучше для строк с ограничением |
| 10 | A | Стандартный формат DATE в SQL — YYYY-MM-DD (ISO 8601), например '2024-12-25' |
| 11 | C | PostgreSQL имеет встроенный тип BOOLEAN для хранения true/false значений |
| 12 | A | NULLIF возвращает NULL, если два значения равны. Полезно для преобразования определённых значений в NULL |
| 13 | A | SMALLINT следует использовать, когда значения гарантированно в диапазоне -32,768 до 32,767, для экономии памяти |
| 14 | A | TIMESTAMPTZ (TIMESTAMP WITH TIME ZONE) хранит время с учётом часового пояса, что важно для глобальных приложений |
| 15 | C | `TRUE AND NULL` возвращает NULL (UNKNOWN), так как результат зависит от неизвестного значения NULL |
| 16 | C | `DECIMAL(10, 2)` означает 10 цифр всего, из которых 2 после запятой. Например, 12345678.90 |
| 17 | D | Указание максимальной длины для VARCHAR помогает в валидации, оптимизации индексов и экономии памяти |
| 18 | B | Явное преобразование типов делает код понятнее и обеспечивает переносимость между разными СУБД |
| 19 | D | NULL означает отсутствие значения, а пустая строка '' — это реальное значение (пустая строка). Это разные вещи |
| 20 | B | BIGINT используется для больших чисел, превышающих диапазон INTEGER (например, timestamp в миллисекундах) |
| 21 | D | EXTRACT извлекает часть из даты/времени: EXTRACT(YEAR FROM date), EXTRACT(MONTH FROM date) и т.д. |
| 22 | C | REAL используется для быстрых вычислений с плавающей точкой, где не критична точность (например, научные расчёты) |
| 23 | B | CHAR дополняет строку пробелами справа до указанной длины. VARCHAR хранит только реальную длину |
| 24 | C | Из-за трёхзначной логики `age != 25` вернёт FALSE для NULL, поэтому строки с NULL не войдут в результат |
| 25 | D | `CURRENT_DATE + INTERVAL '7 days'` возвращает дату через 7 дней от текущей даты |
