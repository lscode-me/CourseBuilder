## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | INNER JOIN возвращает только строки, где есть совпадение в обеих таблицах по условию ON |
| 2 | C | LEFT JOIN возвращает все строки из левой таблицы и совпадающие из правой. Если совпадения нет, правые столбцы NULL |
| 3 | A | RIGHT JOIN возвращает все строки из правой таблицы и совпадающие из левой. Если совпадения нет, левые столбцы NULL |
| 4 | B | FULL JOIN возвращает все строки из обеих таблиц. Если совпадения нет, соответствующие столбцы NULL |
| 5 | C | ON определяет условие соединения таблиц, WHERE фильтрует результат после соединения |
| 6 | D | LEFT JOIN с WHERE order.id IS NULL найдёт строки из левой таблицы без совпадений в правой |
| 7 | D | CROSS JOIN возвращает декартово произведение — все комбинации строк из обеих таблиц |
| 8 | B | Self JOIN — это соединение таблицы с самой собой, часто используется для иерархических данных |
| 9 | C | Можно использовать цепочку JOIN для соединения нескольких таблиц в одном запросе |
| 10 | B | Алиасы делают запросы читаемее и помогают избежать конфликтов имён столбцов |
| 11 | D | В SQL NULL не равно NULL. Поэтому NULL в ключах соединения не создаёт совпадений |
| 12 | C | Индексы на ключах соединения значительно ускоряют JOIN операции |
| 13 | B | Для INNER JOIN порядок не влияет на результат. Для LEFT/RIGHT JOIN порядок важен |
| 14 | D | В ON можно использовать несколько условий с AND/OR для сложных условий соединения |
| 15 | C | LEFT JOIN возвращает все строки из левой таблицы, даже если нет совпадений. INNER JOIN только совпадения |
| 16 | C | RIGHT JOIN можно переписать как LEFT JOIN, поменяв порядок таблиц, поэтому используется реже |
| 17 | A | FULL JOIN полезен, когда нужно найти все несоответствия в обеих таблицах (данные только в одной) |
| 18 | C | CROSS JOIN может создать огромное количество строк (n × m), что может быть проблемой для больших таблиц |
| 19 | C | Можно использовать агрегатные функции с JOIN, используя GROUP BY для группировки |
| 20 | C | Можно использовать несколько столбцов в ON: ON t1.col1 = t2.col1 AND t1.col2 = t2.col2 |
| 21 | A | WHERE для фильтрации правой таблицы после LEFT JOIN может превратить его в INNER JOIN (NULL отфильтруются) |
| 22 | D | Оптимизатор запросов может изменить порядок JOIN для улучшения производительности |
| 23 | A | Можно использовать подзапросы в ON условии JOIN для сложных условий соединения |
| 24 | D | NATURAL JOIN автоматически соединяет таблицы по столбцам с одинаковыми именами (редко используется) |
| 25 | D | Наличие индексов на ключах соединения критично для производительности JOIN |
