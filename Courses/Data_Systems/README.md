# Data Structures & Systems — от алгоритмов к архитектуре

## Описание курса

Этот курс является продолжением курса **«Структуры данных — от новичка до экспертного уровня»** и смещает фокус с отдельных структур данных на:

- алгоритмы и сложность,
- использование структур данных в базах данных,
- распределённые структуры данных,
- проектирование систем через призму структур данных.

> **Архитектура системы — это, по сути, выбор и композиция структур данных.**

Упор делается на инженерное мышление, trade-offs и реальные системы, а не на академическую теорию.

---

## 🎯 Цели курса

После прохождения курса вы будете:

- понимать связь алгоритмов и структур данных
- уметь анализировать сложность решений
- понимать, как структуры данных используются в БД
- знать основные подходы к распределённым структурам данных
- уметь рассуждать о system design через выбор DS

## 📋 Предварительные требования
