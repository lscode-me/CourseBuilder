## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Множество узлов, скрывающих сложность взаимодействия за единым интерфейсом |
| 2 | D | "Сеть надежна" — первое из 8 заблуждений (Fallacies) распределенных вычислений |
| 3 | C | При разделении (P) нужно выбрать либо C (отказ в обслуживании), либо A (отдача старых данных) |
| 4 | B | Сеть физически ненадежна. Отказ от P означает выключение системы при любом лаге сети |
| 5 | C | CP системы жертвуют доступностью ради сохранения корректности данных |
| 6 | C | AP системы продолжают работать, накапливая конфликты, которые решаются позже |
| 7 | D | PACELC уточняет, что Trade-off "Latency vs Consistency" существует всегда, не только при сбоях |
| 8 | B | Иллюзия работы с одной копией данных. Самая дорогая гарантия |
| 9 | B | Слабая, но практичная гарантия. Данные "разъезжаются", но потом сходятся |
| 10 | A | Важно для сохранения логики диалогов и зависимых операций |
| 11 | D | Ожидание подтверждения от всех реплик (C) долгое. Чтение с одной (A) быстрое, но может быть устаревшим |
| 12 | A | Физическая проблема связи, изолирующая группы серверов |
| 13 | A | Опасное состояние, ведущее к потере данных или логическим конфликтам, если нет арбитра |
| 14 | A | N/2 + 1 узел обычно необходим для гарантии Consistency при записи |
| 15 | C | Это критично для UX — пользователь должен видеть свои действия сразу |
| 16 | C | Блокировка ресурсов на время голосования убивает производительность и надежность (SPOF) |
| 17 | D | Saga реализует длинные транзакции асинхронно, без длительных блокировок |
| 18 | A | NTP дает погрешность. Порядок событий по времени может быть неверным |
| 19 | C | Zookeeper/HBase требуют строгого консенсуса для работы |
| 20 | B | DNS должна работать всегда, даже если обновившийся IP еще не везде прописался |

## Scoring Guide

- **18-20 правильных (90-100%)**: Отлично! Вы понимаете распределенные компромиссы.

- **14-17 правильных (70-89%)**: Хорошо. Повторите CAP и PACELC.

- **10-13 правильных (50-69%)**: Удовлетворительно. Разберитесь с типами согласованности.

- **Менее 10 правильных (< 50%)**: Нужно перечитать лекцию.
