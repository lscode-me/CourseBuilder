## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Level 7 ссылается на 7-й уровень модели OSI (Application Layer) |
| 2 | C | Pipe (\|) — стандартный разделитель полей в HL7 v2 |
| 3 | B | MSH-9 содержит Message Type (например, ADT^A01) |
| 4 | B | ADT^A01 — Admit/госпитализация пациента |
| 5 | B | PID-5 — Patient Name |
| 6 | C | YYYYMMDD — стандартный формат даты в HL7 |
| 7 | B | OBX (Observation Result) содержит результаты наблюдений |
| 8 | A | H = High — результат выше нормы |
| 9 | B | ORU^R01 — Observation Result для лабораторных результатов |
| 10 | B | ORM^O01 — Order Message для назначений |
| 11 | B | Caret (^) разделяет компоненты |
| 12 | B | I = Inpatient (стационарный пациент) |
| 13 | C | \F\ — escape-последовательность для pipe |
| 14 | B | MLLP — Minimal Lower Layer Protocol для TCP передачи |
| 15 | B | MSH-10 — Message Control ID (уникальный идентификатор) |
| 16 | B | Версии 2.3-2.5 наиболее распространены |
| 17 | B | EVN содержит информацию о событии |
| 18 | C | Тильда (~) для повторяющихся полей |
| 19 | B | OBR — Observation Request (информация о заказе) |
| 20 | B | PID-3 — Patient Identifier List (включая MRN) |
