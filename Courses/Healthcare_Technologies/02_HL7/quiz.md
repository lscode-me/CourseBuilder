## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Level 7 ссылается на 7-й уровень модели OSI (Application Layer) |
| 2 | A | Pipe (\|) — стандартный разделитель полей в HL7 v2 |
| 3 | A | MSH-9 содержит Message Type (например, ADT^A01) |
| 4 | C | ADT^A01 — Admit/госпитализация пациента |
| 5 | D | PID-5 — Patient Name |
| 6 | A | YYYYMMDD — стандартный формат даты в HL7 |
| 7 | B | OBX (Observation Result) содержит результаты наблюдений |
| 8 | A | H = High — результат выше нормы |
| 9 | B | ORU^R01 — Observation Result для лабораторных результатов |
| 10 | D | ORM^O01 — Order Message для назначений |
| 11 | C | Caret (^) разделяет компоненты |
| 12 | A | I = Inpatient (стационарный пациент) |
| 13 | A | \F\ — escape-последовательность для pipe |
| 14 | D | MLLP — Minimal Lower Layer Protocol для TCP передачи |
| 15 | C | MSH-10 — Message Control ID (уникальный идентификатор) |
| 16 | B | Версии 2.3-2.5 наиболее распространены |
| 17 | A | EVN содержит информацию о событии |
| 18 | C | Тильда (~) для повторяющихся полей |
| 19 | C | OBR — Observation Request (информация о заказе) |
| 20 | C | PID-3 — Patient Identifier List (включая MRN) |
