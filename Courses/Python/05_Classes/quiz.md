## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | `class` — ключевое слово для определения класса. |
| 2 | A | `self` — ссылка на текущий экземпляр, позволяет обращаться к его атрибутам и методам. |
| 3 | D | `__init__` — инициализатор, вызывается после создания экземпляра. `__new__` создаёт сам объект. |
| 4 | B | Каждый экземпляр имеет свой атрибут name. dog1.name = "Rex". |
| 5 | C | Атрибуты класса общие для всех экземпляров; атрибуты экземпляра уникальны. |
| 6 | C | Синтаксис наследования: `class Child(Parent):`. |
| 7 | B | `super()` даёт доступ к методам родительского класса. |
| 8 | D | Метод переопределён в дочернем классе, вызывается его версия. |
| 9 | A | `isinstance(obj, Class)` проверяет, является ли obj экземпляром Class или его подкласса. |
| 10 | A | `_name` — конвенция для "protected", `__name` — name mangling для "private". |
| 11 | A | Name mangling: `__private` становится `_MyClass__private`. |
| 12 | B | `@property` позволяет определять getter для атрибута как метод. |
| 13 | D | Статический метод не получает self или cls, это обычная функция внутри класса. |
| 14 | D | `@classmethod` получает класс (cls) вместо экземпляра (self). |
| 15 | A | Python поддерживает множественное наследование. |
| 16 | B | MRO определяет порядок поиска методов в иерархии наследования (алгоритм C3). |
| 17 | C | `__str__` — читаемое представление, `__repr__` — однозначное (для отладки). |
| 18 | B | `__len__` вызывается при `len(obj)`. |
| 19 | D | `__add__` реализует `+`. `__radd__` для правого операнда. |
| 20 | B | Без `__eq__` сравнивается идентичность объектов (как `is`). |
| 21 | B | `from abc import ABC, abstractmethod`, затем `class MyABC(ABC):` с `@abstractmethod`. |
| 22 | A | `@dataclass` автоматически генерирует стандартные методы класса. |
| 23 | A | `__slots__` заменяет `__dict__`, экономя память для большого количества объектов. |
| 24 | B | Композиция ("has-a") предпочтительнее наследования ("is-a") для гибкости. |
| 25 | B | Duck typing: важно поведение объекта, а не его тип. |
