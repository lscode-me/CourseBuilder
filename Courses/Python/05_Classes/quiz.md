## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | `class` — ключевое слово для определения класса. |
| 2 | C | `self` — ссылка на текущий экземпляр, позволяет обращаться к его атрибутам и методам. |
| 3 | A | `__init__` — инициализатор, вызывается после создания экземпляра. `__new__` создаёт сам объект. |
| 4 | B | Каждый экземпляр имеет свой атрибут name. dog1.name = "Rex". |
| 5 | D | Атрибуты класса общие для всех экземпляров; атрибуты экземпляра уникальны. |
| 6 | B | Синтаксис наследования: `class Child(Parent):`. |
| 7 | C | `super()` даёт доступ к методам родительского класса. |
| 8 | B | Метод переопределён в дочернем классе, вызывается его версия. |
| 9 | D | `isinstance(obj, Class)` проверяет, является ли obj экземпляром Class или его подкласса. |
| 10 | B | `_name` — конвенция для "protected", `__name` — name mangling для "private". |
| 11 | A | Name mangling: `__private` становится `_MyClass__private`. |
| 12 | C | `@property` позволяет определять getter для атрибута как метод. |
| 13 | B | Статический метод не получает self или cls, это обычная функция внутри класса. |
| 14 | C | `@classmethod` получает класс (cls) вместо экземпляра (self). |
| 15 | D | Python поддерживает множественное наследование. |
| 16 | D | MRO определяет порядок поиска методов в иерархии наследования (алгоритм C3). |
| 17 | C | `__str__` — читаемое представление, `__repr__` — однозначное (для отладки). |
| 18 | D | `__len__` вызывается при `len(obj)`. |
| 19 | A | `__add__` реализует `+`. `__radd__` для правого операнда. |
| 20 | A | Без `__eq__` сравнивается идентичность объектов (как `is`). |
| 21 | A | `from abc import ABC, abstractmethod`, затем `class MyABC(ABC):` с `@abstractmethod`. |
| 22 | C | `@dataclass` автоматически генерирует стандартные методы класса. |
| 23 | A | `__slots__` заменяет `__dict__`, экономя память для большого количества объектов. |
| 24 | A | Композиция ("has-a") предпочтительнее наследования ("is-a") для гибкости. |
| 25 | C | Duck typing: важно поведение объекта, а не его тип. |
