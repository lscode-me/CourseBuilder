## Answer Key

| # | Answer | Explanation |

| 1 | B | Современные вычисления организованы как система слоёв абстракций. |
| 2 | C | Слои дают гибкость — можно менять один слой без влияния на другие. |
| 3 | C | Существуют модели IaaS, PaaS, SaaS. |
