## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Feedback loop занимал часы или дни — одна ошибка требовала переделки всей стопки карт. Это делало разработку очень медленной и дорогой. |
| 2 | C | CLI остаётся актуальным благодаря своей мощности (pipes, scripting), эффективности для экспертов, низким требованиям к ресурсам и возможности remote access. |
| 3 | C | Xerox Alto (1973) был первым компьютером с GUI, включавшим windows, icons и mouse. Это стало основой для всех последующих графических интерфейсов. |
| 4 | D | WIMP означает Windows, Icons, Menus, Pointer — это стандартная парадигма графических интерфейсов, используемая в большинстве современных ОС. |
| 5 | B | iPhone (2007) революционизировал UI благодаря capacitive multitouch с gestures (pinch, swipe) без необходимости в стилусе, что сделало интерфейс более интуитивным. |
| 6 | C | Voice UI не заменяет другие интерфейсы, потому что он медленнее для сложных задач, не предоставляет visual feedback, имеет проблемы с privacy, акцентами и шумом. |
| 7 | A | Responsive design нужен, чтобы один интерфейс мог адаптироваться к разным размерам экранов (desktop, tablet, phone), обеспечивая оптимальный опыт на любом устройстве. |
| 8 | C | AR (Augmented Reality) накладывает цифровую информацию на реальный мир, в то время как VR (Virtual Reality) обеспечивает полное погружение в виртуальную среду. |
| 9 | D | Ключевой trade-off: CLI эффективен для экспертов и автоматизации, в то время как GUI легче для обучения и discovery функций. |
| 10 | B | Accessibility важна, потому что ~15% населения имеют ограничения, и хороший accessibility улучшает UX для всех пользователей, не только для людей с инвалидностью. |
