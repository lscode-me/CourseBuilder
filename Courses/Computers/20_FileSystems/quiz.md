## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Выполнение программ не является задачей файловой системы — это задача операционной системы. |
| 2 | B | Inode — это структура с metadata файла (permissions, owner, размер, timestamps) и указателями на data blocks. |
| 3 | C | FAT32 имеет ограничение на размер файла до 4 GB. |
| 4 | B | ext3 добавил journaling к ext2 для защиты от corruption при сбое. |
| 5 | C | NTFS характеризуется journaling, ACL, encryption, large files (16 EB теоретически), используется в Windows. |
| 6 | A | Journaling решает проблему inconsistency при сбое питания между операциями (write-ahead logging). |
| 7 | C | Режим data + metadata (полный journal) обеспечивает максимальную надёжность, но медленнее. |
| 8 | C | Copy-on-Write означает запись новой версии блока и обновление указателя, а не перезапись на месте. |
| 9 | D | CoW файловые системы всегда consistent благодаря atomic updates. |
| 10 | B | Btrfs характеризуется CoW, built-in RAID, snapshots, compression, data checksums. |
| 11 | D | ZFS combines FS + Volume Manager, имеет CoW, software RAID, snapshots, data integrity (checksums везде). |
| 12 | B | Snapshots в CoW FS работают через запоминание указателя на root, занимают место только для изменённых блоков. |
| 13 | A | Deduplication — это хранение одинаковых блоков один раз с несколькими указателями на них. |
| 14 | B | On-the-fly сжатие экономит место и может ускорить I/O, так как меньше данных читается с диска. |
| 15 | B | APFS характеризуется CoW, snapshots, space sharing, encryption, оптимизировано для SSD. |
| 16 | D | F2FS оптимизирована для SSD/flash, учитывает износ flash, log-structured. |
| 17 | A | exFAT — это Extended FAT без ограничения 4 GB файлов, проще NTFS, используется на SD картах и флешках >32 GB. |
| 18 | C | NFS (Network File System) — это remote file access, сервер экспортирует каталоги, клиенты монтируют как локальные. |
| 19 | B | Объектные хранилища не имеют иерархии, используют объекты + metadata, HTTP API, massive scale. |
| 20 | B | ext4 лучше для общего использования в Linux — хороший баланс производительности и надёжности. |
