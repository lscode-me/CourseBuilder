| 7 | D | Character devices характеризуются sequential access, примеры: keyboard, serial port. |
| 8 | B | Block devices характеризуются random access, блоками, примеры: HDD, SSD. |
| 9 | C | Network devices характеризуются packet-based подходом, примеры: Ethernet, WiFi. |
| 10 | B | Interrupt Controller — это устройство для управления прерываниями, примеры: Intel 8259 PIC, современный APIC. |
| 11 | C | Основная проблема Polling — CPU тратит время на ожидание (busy waiting), не может делать другую работу, неэффективно для медленных устройств. |
| 12 | D | Interrupt-Driven I/O имеет overhead на переключение контекста (сохранение/восстановление регистров) при обработке прерывания. |

| 18 | B | Network device характеризуется packet-based подходом (пакетная передача), примеры: Ethernet, WiFi, Bluetooth. |
| 19 | C | PCI характеризуется parallel bus (32/64-bit), Plug and Play (автоматическое определение), Configuration space (регистры конфигурации). |
| 20 | C | USB 3.0 имеет скорость 5 Gbps (SuperSpeed), что в ~10 раз быстрее USB 2.0 (480 Mbps). |
| 21 | D | SATA 3.0 имеет скорость 6 Gbps (600 MB/s), что в 2 раза быстрее SATA 2.0 (3 Gbps). |
| 22 | D | Double buffering нужна для плавной передачи данных: пока один буфер передаётся через DMA, готовится следующий буфер. |
