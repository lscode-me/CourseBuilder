## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Протокол контекстного менеджера требует `__enter__` и `__exit__` |
| 2 | D | `with open(...) as f:` — f получает результат `__enter__` |
| 3 | C | `return True` в `__exit__` подавляет исключение |
| 4 | B | @contextmanager требует функцию-генератор с yield |
| 5 | A | Через запятую: `with A(), B(), C():` |
| 6 | C | `__exit__` всегда вызывается и получает информацию об исключении |
