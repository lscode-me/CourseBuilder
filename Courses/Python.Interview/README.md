# 🐍 Подготовка к техническому интервью Python Developer

## О курсе

Этот курс предназначен для подготовки инженеров к техническим интервью на позицию Python Developer (Junior — Lead). Материал охватывает ключевые темы Python Core, базы данных, сетевые протоколы, Linux/Docker и параллельное программирование.

**Формат:**

- Краткие лекции с ответами для интервью
- Примеры кода, которые просят написать
- Квизы для самопроверки

## ⚠️ Важно для интервью

- **Live coding обязателен** — отказ рассматривается как red flag

- **Думайте вслух** — объясняйте ход мыслей

- **Задавайте уточняющие вопросы** — это показывает инженерный подход

- **Пишите рабочий код** — даже если не оптимальный
