## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Junction table — стандартный способ реализации many-to-many |
| 2 | D | 1NF требует атомарных значений (одно значение в ячейке) |
| 3 | D | Составной ключ гарантирует уникальность пары book-author |
| 4 | D | LEFT JOIN сохраняет все записи левой таблицы, заполняя NULL для отсутствующих |
| 5 | D | Денормализация — trade-off между скоростью чтения и сложностью обновления |
| 6 | D | Одна таблица приводит к дублированию и аномалиям данных |
