## Answer Key

| # | Ответ | Пояснение |
|---|-------|-----------|
| 1 | B | Junction table — стандартный способ реализации many-to-many |
| 2 | B | 1NF требует атомарных значений (одно значение в ячейке) |
| 3 | B | Составной ключ гарантирует уникальность пары book-author |
| 4 | C | LEFT JOIN сохраняет все записи левой таблицы, заполняя NULL для отсутствующих |
| 5 | B | Денормализация — trade-off между скоростью чтения и сложностью обновления |
| 6 | B | Одна таблица приводит к дублированию и аномалиям данных |
