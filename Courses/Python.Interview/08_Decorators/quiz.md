## Answer Key

| # | Ответ | Пояснение |
|---|-------|-----------|
| 1 | B | Декоратор принимает функцию и возвращает изменённую функцию |
| 2 | B | `@deco` эквивалентно `func = deco(func)` |
| 3 | B | `@wraps` сохраняет `__name__`, `__doc__` и другие атрибуты |
| 4 | B | Декораторы применяются снизу вверх: deco2, затем deco1 |
| 5 | B | LRU cache кэширует результаты для одинаковых аргументов |
| 6 | C | Внешняя функция (аргументы) → decorator → wrapper |
