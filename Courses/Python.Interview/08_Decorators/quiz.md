## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Декоратор принимает функцию и возвращает изменённую функцию |
| 2 | B | `@deco` эквивалентно `func = deco(func)` |
| 3 | D | `@wraps` сохраняет `__name__`, `__doc__` и другие атрибуты |
| 4 | B | Декораторы применяются снизу вверх: deco2, затем deco1 |
| 5 | A | LRU cache кэширует результаты для одинаковых аргументов |
| 6 | A | Внешняя функция (аргументы) → decorator → wrapper |
