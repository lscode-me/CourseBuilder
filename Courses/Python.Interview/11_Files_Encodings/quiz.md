## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | `open()` по умолчанию использует `locale.getpreferredencoding()`, что может привести к ошибкам на разных ОС. |
| 2 | C | Флаг `'b'` (binary) указывает Python возвращать данные в виде байтов. |
| 3 | D | Итерация по объекту файла читает его построчно, используя буфер и не загружая весь файл в RAM. |
| 4 | C | `errors='replace'` заменяет ошибки на символ-заполнитель. |
| 5 | C | `flush()` сбрасывает внутренние буферы Python в буфер ОС или на диск. |
| 6 | A | `Path.read_text()` — это удобный метод, который сам открывает и закрывает файл. |
