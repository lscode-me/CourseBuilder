# Работа с файлами и кодировками

## Что нужно знать для интервью

Работа с файлами — это не только чтение и запись. Интервьюер может спросить про различие между текстовым и бинарным режимами, как Python внутри хранит строки, какие бывают ошибки кодировки и как правильно закрывать ресурсы (что мы уже касались в модуле про Context Managers).

---

## 🔑 Ключевые понятия

### Режимы открытия файлов

При использовании `open(file, mode)`, параметр `mode` определяет тип данных и права доступа:

- `'r'` — чтение (по умолчанию).
- `'w'` — запись (перезаписывает файл).
- `'a'` — добавление в конец.
- `'t'` — текстовый режим (по умолчанию, возвращает `str`).
- `'b'` — бинарный режим (возвращает `bytes`).

**Важно:** В текстовом режиме Python прозрачно обрабатывает символы переноса строк (`\n`, `\r\n`) в зависимости от платформы.

### Кодировки (Encodings)

По умолчанию `open()` использует системную кодировку. Это частая причина ошибок `UnicodeDecodeError` при переносе кода между Windows (часто `cp1251`) и Linux/macOS (`utf-8`).

**Ответ на интервью:**
> "Всегда явно указывайте `encoding='utf-8'` при открытии текстовых файлов, чтобы избежать платформозависимых багов."

## 💻 Код, который нужно уметь писать

### 1. Правильное чтение файла

Используйте контекстный менеджер и итерацию по строкам (это экономит память).

```python

with open('data.txt', 'r', encoding='utf-8') as f:
    for line in f:
        process(line.strip())
```

### 2. Работа с бинарными данными

В бинарном режиме кодировка не указывается.

```python

with open('image.jpg', 'rb') as f:
    content = f.read(1024)  # Читаем первый килобайт
    print(type(content))   # <class 'bytes'>
```

### 3. Обработка ошибок кодировки

Иногда файлы содержат битые данные. Параметр `errors` позволяет выбрать стратегию поведения:

```python
# 'strict' (по умолчанию) — выкинет UnicodeDecodeError
# 'ignore' — просто пропустит битые символы
# 'replace' — заменит их на спецсимвол (обычно знак вопроса в ромбе)

with open('corrupted.txt', 'r', encoding='utf-8', errors='replace') as f:
    content = f.read()
```

## ❓ Типичные вопросы на интервью

### Q: В чем разница между `f.read()`, `f.readline()` и `f.readlines()`?

**A:**

- `read(n)` — читает всё содержимое или `n` символов/байт. Опасно при больших файлах (может переполнить RAM).
- `readline()` — читает одну строку.
- `readlines()` — читает все строки и возвращает их списком. Также грузит весь файл в память.

### Q: Зачем нужно делать `f.flush()`?

**A:**
> "Python (и ОС) используют буферизацию при записи. Данные не попадают на диск мгновенно. `flush()` принудительно выталкивает данные из буфера в файл, не закрывая его."

### Q: Что такое BOM (Byte Order Mark)?

**A:**
> "Это специальный символ в начале файла (например, в UTF-8), который указывает на порядок байтов. В Python для работы с такими файлами используется кодировка `utf-8-sig`."

## 💻 Быстрый способ работы с путями: `pathlib`

Начиная с Python 3.4, рекомендуется использовать `pathlib` вместо `os.path`.

```python

from pathlib import Path

p = Path('data/results.txt')
p.write_text('Hello World', encoding='utf-8')  # Автоматически открывает и закрывает
content = p.read_text(encoding='utf-8')
```
