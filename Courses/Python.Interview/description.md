# 🐍 Курс: Подготовка к техническому интервью Python Developer

## Описание курса

Этот курс предназначен для подготовки инженеров к техническим интервью на позицию Python Developer (Junior — Lead, уровни A1–A4). Материал охватывает ключевые темы, которые чаще всего встречаются на собеседованиях: Python Core, базы данных, сетевые протоколы, Linux/Docker и параллельное программирование.

**Формат курса:**

- Каждый топик содержит **краткий конспект** — то, что нужно уметь объяснить на интервью
- Примеры кода, которые могут попросить написать или объяснить
- Типичные вопросы интервьюеров с ожидаемыми ответами
- Квиз для самопроверки

**Важно:** Live coding — обязательная часть Python-интервью. Отказ от написания кода рассматривается как red flag.

---

## 🎯 Цели курса

После прохождения курса вы сможете:

- Уверенно отвечать на вопросы по Python Core
- Писать код на интервью (генераторы, декораторы, итераторы)
- Объяснять разницу между процессами и потоками, понимать GIL
- Проектировать схемы баз данных (нормальные формы, связи)
- Отвечать на вопросы по HTTP, TCP/IP, DNS
- Демонстрировать знание Linux и Docker

## 📝 Формат каждого топика

Каждый топик содержит:

1. **lecture.md** — краткий конспект для ответов на интервью:
   - Ключевые концепции (что нужно знать)
   - Примеры кода (что нужно уметь написать)
   - Типичные вопросы и ожидаемые ответы
   - Ссылки на дополнительные материалы

2. **quiz.md** — вопросы для самопроверки:
   - 5-10 вопросов по материалу топика
   - Ответы с пояснениями

## 🎓 Как использовать курс

1. **Изучите lecture.md** — прочитайте конспект и убедитесь, что понимаете каждый пункт
2. **Напишите код** — попробуйте написать примеры самостоятельно
3. **Пройдите quiz.md** — проверьте понимание материала
4. **Практикуйтесь вслух** — объясняйте концепции как будто на интервью

## ⚠️ Важные напоминания для интервью

- **Думайте вслух** — объясняйте ход мыслей при решении задач
- **Задавайте уточняющие вопросы** — это показывает инженерный подход
- **Не бойтесь сказать "не знаю"** — лучше честно признать, чем угадывать
- **Пишите рабочий код** — даже если не оптимальный, он должен работать
