# Курс: Структуры данных — от новичка до экспертного уровня

## Описание курса

Структуры данных (Data Structures, DS) — это фундамент программирования,
алгоритмов и архитектуры программных систем.

Структуры данных используются не только для хранения информации,
но и для её:
- организации,
- обработки,
- поиска,
- модификации,
- эффективного доступа в памяти.

Практически любое нетривиальное программное решение опирается на выбор структур данных.
Правильный выбор структуры данных напрямую влияет на:
- производительность,
- использование памяти,
- сложность кода,
- масштабируемость системы.

Курс формирует инженерное понимание структур данных
как инструментов с осознанными компромиссами (trade-offs).

## Лекция 3. Линейные структуры данных

- Массивы (Array)
- Связанные списки (Linked List)
- Стек (Stack)
- Очередь (Queue)
- Дек (Deque)

Примеры на Python:

```python
# стек
stack = []
stack.append(1)
stack.pop()

# очередь
from collections import deque
q = deque()
q.append(1)
q.popleft()
```
