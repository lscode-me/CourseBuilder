## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | CSV формат простой, человекочитаемый и универсальный, но не поддерживает метаданные и неэффективен для больших данных. |
| 2 | A | HDF5 предназначен для эффективного хранения больших научных данных с поддержкой метаданных и иерархической структуры. |
| 3 | A | NetCDF используется для геопространственных данных, таких как климатические данные, океанографические измерения. |
| 4 | D | FASTA формат используется для хранения биологических последовательностей (ДНК, РНК, белковые последовательности). |
| 5 | D | Версионирование данных критически важно для отслеживания изменений, обеспечения воспроизводимости и возможности вернуться к предыдущим версиям. |
| 6 | C | Метаданные версии должны включать версию, дату создания, создателя, описание изменений, checksum для проверки целостности. |
| 7 | B | Matplotlib — библиотека для создания статических визуализаций, основа для многих других библиотек визуализации. |
| 8 | C | Seaborn специализируется на статистической визуализации и построена на основе Matplotlib, предоставляя более высокоуровневый интерфейс. |
| 9 | B | Plotly создаёт интерактивные визуализации с возможностью масштабирования, наведения курсора (hover), выбора данных и экспорта. |
| 10 | C | Error bars показывают неопределённость измерений (стандартное отклонение, стандартная ошибка), что критически важно для научных данных. |
| 11 | B | Для небольших таблиц (50MB) без метаданных CSV является подходящим выбором благодаря простоте и универсальности. |
| 12 | D | Для больших массивов данных (5GB) с метаданными следует использовать HDF5 (общие данные) или NetCDF (геопространственные данные). |
| 13 | A | Структура хранения должна разделять raw (исходные), processed (обработанные), derived (производные) данные и metadata. |
| 14 | A | Научная визуализация должна быть ясной (понятной), точной (корректные масштабы), информативной (показывать ошибки) и воспроизводимой (код генерирует тот же график). |
| 15 | C | Colorblind-friendly схемы важны для доступности графиков, чтобы люди с различными типами цветовой слепоты могли их читать. |
| 16 | A | HDF5 поддерживает иерархическую структуру с группами (groups) и датасетами (datasets), что позволяет организовать сложные данные. |
| 17 | C | В HDF5 метаданные хранятся в атрибутах (attrs) групп и датасетов, что позволяет добавлять информацию к данным. |
| 18 | A | BAM (Binary Alignment Map) формат используется для хранения выравниваний биологических последовательностей в бинарном виде. |
| 19 | C | В Matplotlib ошибки измерений показываются через функцию errorbar() с параметрами yerr (вертикальные ошибки) или xerr (горизонтальные ошибки). |
| 20 | D | Box plot показывает распределение данных: медиану (центральная линия), квартили (границы коробки), выбросы (точки за пределами усов). |
| 21 | D | Интерактивность Plotly позволяет масштабировать график, видеть значения при наведении (hover), выбирать данные и экспортировать графики. |
| 22 | D | Checksum (контрольная сумма) используется для проверки целостности данных и обнаружения изменений или повреждений файлов. |
| 23 | A | FASTA формат является стандартом для хранения биологических последовательностей (ДНК, РНК, белки) в текстовом виде. |
| 24 | A | Подгонка кривой (curve fitting) на графике помогает визуализировать тренд в данных и показывает, насколько хорошо модель описывает данные. |
| 25 | B | Лучший подход — отдельные директории для каждой версии (v1.0, v1.1, etc.), что позволяет легко отслеживать изменения и возвращаться к предыдущим версиям. |
