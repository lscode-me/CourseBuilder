## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Непараметрические тесты используются, когда данные не соответствуют предположениям параметрических тестов (например, нормальность распределения). |
| 2 | C | Shapiro-Wilk test используется для проверки нормальности распределения данных перед выбором параметрического или непараметрического теста. |
| 3 | A | ANOVA проверяет равенство средних значений нескольких групп, используя сравнение дисперсий между группами и внутри групп. |
| 4 | C | Нулевая гипотеза (H₀) — это гипотеза об отсутствии эффекта или различий, которую мы проверяем статистическим тестом. |
| 5 | C | p-value < 0.05 означает статистически значимое различие при уровне значимости α=0.05, но не гарантирует, что результат "точно верен". |
| 6 | C | Ошибка первого рода (Type I) — это отклонение нулевой гипотезы, когда она верна, то есть ложное обнаружение эффекта. Контролируется уровнем значимости α. |
| 7 | A | Ошибка второго рода (Type II) — это принятие нулевой гипотезы, когда она неверна, то есть пропуск реального эффекта. Зависит от мощности теста. |
| 8 | B | Мощность теста (Power = 1 - β) — это вероятность обнаружить эффект, если он действительно существует. Зависит от размера эффекта, размера выборки и уровня значимости. |
| 9 | C | Корреляция Pearson используется для нормальных данных с линейной связью. Для ненормальных данных или нелинейных связей используют Spearman или другие методы. |
| 10 | C | Корреляция Spearman используется для ранговых данных или когда данные не соответствуют предположениям нормальности, требуемым для Pearson. |
| 11 | D | Корреляция показывает связь между переменными, но не обязательно причинность. Корреляция может быть вызвана смешивающими переменными или случайностью. |
| 12 | C | Ложная корреляция возникает, когда две переменные коррелируют из-за влияния третьей переменной (смешивающей), а не из-за прямой причинной связи. |
| 13 | B | P-hacking — это манипулирование данными или методами анализа для получения статистически значимых результатов, что является неэтичной практикой. |
| 14 | D | Множественные сравнения увеличивают вероятность ложных положительных результатов (ошибок первого рода), поэтому требуют коррекции уровня значимости. |
| 15 | C | Коррекция Bonferroni делит уровень значимости α на количество тестов (α/n), что уменьшает вероятность ложных положительных результатов при множественных сравнениях. |
| 16 | B | Линейная регрессия позволяет не только измерять связь (как корреляция), но и предсказывать значения зависимой переменной на основе независимой переменной. |
| 17 | C | Экстраполяция опасна, потому что модель может не работать за пределами наблюдаемого диапазона данных, где предположения модели могут не выполняться. |
| 18 | C | Смешивающая переменная влияет и на причину, и на следствие, создавая ложную связь между ними. Контроль таких переменных необходим для установления причинности. |
| 19 | C | Частичная корреляция показывает корреляцию между двумя переменными с контролем (устранением влияния) смешивающих переменных, что помогает выявить прямую связь. |
| 20 | C | Байесовский подход характеризуется обновлением вероятностей на основе данных и априорных знаний, используя теорему Байеса для получения апостериорных вероятностей. |
| 21 | A | Множественная регрессия позволяет моделировать зависимость одной зависимой переменной от нескольких независимых переменных одновременно, контролируя влияние каждой. |
| 22 | A | R² (коэффициент детерминации) показывает долю дисперсии зависимой переменной, которая объясняется моделью регрессии. Чем выше R², тем лучше модель объясняет данные. |
| 23 | A | Post-hoc тесты используются после значимого ANOVA для определения, какие конкретно группы различаются между собой, так как ANOVA показывает только общее различие. |
| 24 | D | Временной порядок важен для причинности, потому что причина должна предшествовать следствию во времени. Если следствие происходит раньше, причинность невозможна. |
| 25 | A | Эксперименты лучше для установления причинности, потому что они позволяют контролировать переменные и рандомизировать условия, что помогает исключить смешивающие факторы и установить причинно-следственные связи. |
