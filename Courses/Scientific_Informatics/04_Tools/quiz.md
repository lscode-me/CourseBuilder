## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Python стал стандартом благодаря простоте синтаксиса, богатой экосистеме библиотек (NumPy, Pandas, SciPy) и активному сообществу разработчиков. |
| 2 | D | NumPy массивы обеспечивают векторизованные операции и значительно более эффективные вычисления по сравнению с Python списками благодаря C-реализации. |
| 3 | A | Векторизация означает применение операции ко всему массиву сразу, что выполняется эффективно на низком уровне, без явных циклов Python. |
| 4 | C | DataFrame в Pandas — это двумерная таблица с индексированными строками и колонками, аналогичная таблице в базе данных или Excel. |
| 5 | D | Метод `pd.read_csv()` используется для загрузки данных из CSV файла в Pandas DataFrame. |
| 6 | D | Метод `groupby()` группирует данные по указанным колонкам, что позволяет применять агрегирующие функции к каждой группе. |
| 7 | C | Модуль `scipy.stats` содержит функции для статистического анализа, включая распределения, тесты и описательную статистику. |
| 8 | C | `stats.t.interval()` вычисляет доверительный интервал для t-распределения с заданным уровнем доверия (0.95), количеством степеней свободы (n-1), средним (loc) и стандартной ошибкой (scale). |
| 9 | D | Jupyter Notebooks обеспечивают интерактивность, позволяют сочетать код с документацией (Markdown) и визуализировать результаты в одном документе. |
| 10 | D | Jupyter поддерживает два основных типа ячеек: Code (для выполнения Python кода) и Markdown (для документации и форматирования текста). |
| 11 | A | Biopython — специализированная библиотека Python для работы с биологическими последовательностями (ДНК, РНК, белки) и биоинформатическими данными. |
| 12 | B | RDKit — популярная библиотека Python для работы с химическими структурами молекул, реакциями и cheminformatics. |

| 14 | B | В NumPy можно вычислить среднее значение либо через метод массива `arr.mean()`, либо через функцию `np.mean(arr)`. |
| 15 | D | Фильтрация DataFrame выполняется через булеву индексацию: `df[df['column'] > value]`, которая возвращает строки, удовлетворяющие условию. |
| 16 | D | `stats.ttest_ind()` выполняет независимый t-test для сравнения средних значений двух групп и возвращает статистику и p-value. |
| 17 | C | `np.array()` создаёт NumPy массив из списка Python или другой последовательности. |
| 18 | C | Метод `agg()` принимает список строк с именами функций агрегации: `agg(['mean', 'std'])` вычисляет среднее и стандартное отклонение. |
| 19 | D | Альтернативы Jupyter включают R Markdown (для R), Quarto (универсальный), Observable (веб-визуализации) и VS Code Notebooks (интеграция в IDE). |
| 20 | A | При выборе инструмента важно учитывать задачу (что нужно решить), данные (формат и объём), производительность и поддержку сообщества. |
| 21 | C | Атрибут `shape` показывает размерность массива — размеры по каждой оси, например (2, 3) для двумерного массива 2×3. |
| 22 | C | Метод `describe()` возвращает описательную статистику: количество (count), среднее (mean), стандартное отклонение (std), минимум, максимум и квартили. |
| 23 | D | Модуль `scipy.optimize` содержит функции для оптимизации, включая минимизацию, максимизацию и решение систем уравнений. |
