## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Научный метод включает наблюдение фактов, формулирование гипотезы, проведение эксперимента, анализ результатов и формулирование вывода. |
| 2 | B | Хорошая гипотеза должна быть проверяемой, специфичной, измеримой и фальсифицируемой. Неопределённость — это недостаток, а не требование. |
| 3 | A | Экспериментальные исследования с контролем переменных позволяют установить причинно-следственные связи, в отличие от наблюдательных исследований. |
| 4 | B | Экспериментальные данные характеризуются контролируемыми условиями, наличием репликаций для надёжности и фиксированными переменными. |
| 5 | B | Наблюдательные данные позволяют установить корреляции между переменными, но не причинно-следственные связи из-за отсутствия контроля условий. |
| 6 | D | Симулированные данные дают полный контроль над параметрами модели и обеспечивают воспроизводимость результатов, но требуют валидации. |
| 7 | D | Структурированные данные имеют чёткую схему и формат, как таблица CSV с фиксированными колонками и типами данных. |
| 8 | C | Неструктурированные данные не имеют фиксированной схемы. Последовательность ДНК — это текст без структурированной схемы. |
| 9 | A | Полуструктурированные данные имеют частичную структуру, как JSON с переменной схемой, где поля могут различаться между записями. |
| 10 | A | Описательные метаданные включают название, описание и ключевые слова, которые помогают понять, что представляют собой данные. |
| 11 | A | Структурные метаданные описывают организацию данных: формат файла, схему данных и размер. |
| 12 | A | Административные метаданные содержат информацию о создателе данных, дате создания и лицензии использования. |
| 13 | A | Метаданные критически важны, так как они обеспечивают воспроизводимость (условия эксперимента), интерпретацию (контекст) и возможность повторного использования данных. |
| 14 | A | Репликации необходимы для повышения надёжности результатов и обеспечения статистической значимости, уменьшая влияние случайных ошибок. |
| 15 | B | Независимая переменная — это то, что исследователь изменяет в эксперименте для изучения её влияния на зависимую переменную. |
| 16 | B | Зависимая переменная — это то, что измеряется в эксперименте и, предположительно, зависит от независимой переменной. |
| 17 | A | Контролируемые переменные фиксируются на постоянном уровне, чтобы исключить их влияние на результаты эксперимента. |
| 18 | B | Dublin Core — это стандарт для базовых описательных метаданных. ISO 19115 — для геопространственных данных, MIAME — для микрочипов. |
| 19 | B | Метаданные содержат информацию об условиях эксперимента, используемых инструментах и параметрах, что необходимо для воспроизведения результатов. |
| 20 | B | Метаданные предоставляют контекст (условия, инструменты, параметры), необходимый для правильной интерпретации данных. |
| 21 | D | Дизайн эксперимента должен включать определение всех переменных (независимых, зависимых, контролируемых) и количество репликаций. |
| 22 | B | Главное отличие: экспериментальные данные получают через контролируемое вмешательство, наблюдательные — через наблюдение без вмешательства. |
| 23 | C | Симулированные данные требуют валидации модели с реальными данными, чтобы убедиться, что модель адекватно отражает реальность. |
| 24 | C | Структурированные данные с чёткой схемой наиболее подходят для табличного анализа, так как имеют фиксированные колонки и типы. |
| 25 | D | Метаданные при публикации позволяют другим исследователям понять контекст, условия получения данных и правильно их интерпретировать и использовать. |
