## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | EDA направлен на понимание структуры данных, выявление паттернов, аномалий и формирование гипотез перед формальным анализом. |
| 2 | A | В измерениях существуют систематические ошибки (постоянное смещение), случайные ошибки (непредсказуемые колебания) и грубые ошибки (ошибки экспериментатора). |
| 3 | D | Систематическая ошибка (bias) — это постоянное смещение от истинного значения, которое повторяется во всех измерениях. |
| 4 | D | Случайная ошибка (noise) — это непредсказуемые колебания вокруг истинного значения, которые варьируются от измерения к измерению. |
| 5 | D | Стандартная ошибка среднего (SEM) показывает неопределённость оценки среднего значения, а не разброс отдельных измерений. |
| 6 | C | 95% доверительный интервал означает, что с вероятностью 95% истинное значение параметра находится в этом интервале. |
| 7 | B | Повторяемость (repeatability) — это способность воспроизвести результаты в тех же условиях (тот же оператор, тот же инструмент). |
| 8 | A | Воспроизводимость (reproducibility) — это способность получить согласованные результаты в разных условиях (разные операторы, инструменты). |
| 9 | C | Установка random seed обеспечивает воспроизводимость случайных процессов, позволяя получить те же результаты при повторном запуске. |
| 10 | B | Jupyter Notebooks объединяют код, результаты выполнения, визуализации и markdown документацию в одном интерактивном документе. |
| 11 | D | Для воспроизводимости необходимо зафиксировать код (версия), данные (версия), окружение (версии пакетов) и параметры анализа. |
| 12 | D | Метод IQR использует границы Q1 - 1.5×IQR и Q3 + 1.5×IQR для выявления выбросов, где IQR = Q3 - Q1. |
| 13 | A | При сложении независимых измерений общая ошибка вычисляется как квадратный корень из суммы квадратов ошибок (пропагация ошибок). |
| 14 | B | Научная сводка должна включать среднее значение, стандартное отклонение, стандартную ошибку среднего и доверительный интервал для оценки надёжности. |
| 15 | D | t-test проверяет различие средних значений двух групп и оценивает статистическую значимость этого различия через p-value. |
| 16 | B | p-value < 0.05 означает статистически значимое различие при уровне значимости α=0.05, но не гарантирует, что результат "точно верен". |
| 17 | A | В EDA используются различные типы визуализаций: гистограммы (распределения), box plots (сравнения), scatter plots (связи), временные ряды. |
| 18 | D | Научный notebook должен иметь логическую структуру с markdown ячейками для объяснений, что делает анализ понятным и воспроизводимым. |
| 19 | A | Описание окружения должно включать версию Python и версии всех используемых пакетов для точного воспроизведения окружения. |
| 20 | B | Git для notebooks позволяет версионировать код, отслеживать изменения в анализе и обеспечивать воспроизводимость через историю коммитов. |
| 21 | B | Альтернативы Jupyter включают R Markdown (для R), Quarto (универсальный), Observable (интерактивная визуализация), VS Code Notebooks (интеграция в IDE). |
| 22 | C | Статистическая мощность — это вероятность обнаружить эффект, если он действительно существует. Зависит от размера выборки и величины эффекта. |
| 23 | C | Многие статистические тесты (например, t-test, ANOVA) предполагают нормальность распределения, поэтому важно проверять это предположение. |
| 24 | D | Корреляционный анализ может установить наличие связи между переменными, но не может установить причинно-следственные связи без дополнительных методов. |
| 25 | B | Best practices для научных notebooks включают организацию структуры, документацию (markdown), версионирование (Git) и очистку перед публикацией. |
