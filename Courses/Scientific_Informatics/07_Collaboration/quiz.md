## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | В научной команде обычно есть исследователи (научные вопросы), инженеры (техническая реализация) и data scientists (анализ данных) с разными фокусами и задачами. |
| 2 | B | Git важен для научных проектов, так как обеспечивает версионирование кода, отслеживание изменений, коллаборацию и воспроизводимость через историю коммитов. |
| 3 | A | В .gitignore для научных проектов должны быть данные (raw, processed), результаты, окружение (venv), временные файлы, чтобы не версионировать большие или чувствительные файлы. |
| 4 | D | Рекомендуемый workflow включает feature branches для изоляции изменений, pull requests для code review, тегирование версий для важных релизов. |
| 5 | C | DVC (Data Version Control) позволяет версионировать большие файлы данных через Git, храня метаданные в Git, а сами данные в удалённом хранилище. |
| 6 | D | Для научного проекта нужна документация: README (общее описание), методы (алгоритмы), API (код), данные (структура, метаданные). |
| 7 | B | Для воспроизводимости нужно зафиксировать версии кода (Git commit), данных (версия), окружения (пакеты) и параметры анализа (random seed, thresholds). |
| 8 | B | Docstrings документируют функции: описывают параметры, возвращаемые значения, примеры использования, что критически важно для понимания и использования кода. |

| 10 | C | Open Science обеспечивает воспроизводимость (можно повторить), проверяемость (можно проверить), коллаборацию (совместная работа) и ускорение науки. |

| 14 | D | Code review должен быть конструктивным (предлагать улучшения), с объяснениями (почему нужны изменения), уважительным и обучающим. |
| 15 | A | Структура проекта должна разделять data/ (данные), code/ (код), docs/ (документация), results/ (результаты) с правильным .gitignore. |
| 16 | A | Git tags используются для тегирования важных версий проекта (релизы, версии для публикаций), что позволяет легко вернуться к конкретной версии. |

## Scoring Guide

Подсчитайте количество правильных ответов:

| Результат | Оценка | Рекомендации |
|-----------|--------|--------------|
| **23-25 правильных (90-100%)** | 🏆 Отлично! | Вы отлично усвоили материал. Переходите к следующему модулю. |
| **18-22 правильных (70-89%)** | ✅ Хорошо | Хороший результат! Повторите темы, в которых ошиблись. |
| **13-17 правильных (50-69%)** | ⚠️ Удовлетворительно | Рекомендуется перечитать соответствующие разделы лекции. |
| **Менее 13 правильных (<50%)** | 📚 Нужно повторить | Внимательно перечитайте лекцию и попробуйте ещё раз. |
