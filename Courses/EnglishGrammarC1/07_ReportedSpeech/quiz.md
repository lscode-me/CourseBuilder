## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Present continuous → Past continuous in backshift. "Is studying" → "was studying." |
| 2 | B | General truths and facts that are still true don't require backshift. |
| 3 | D | "Tell" requires a person object. "She told me that..." is correct. |
| 4 | D | Reported questions use statement word order, and tense shifts back. |
| 5 | D | Yes/No questions use "if/whether" + statement word order. |
| 6 | B | Commands: tell + object + (not) to + infinitive. "Not to" comes together. |
| 7 | A | "Suggest" never takes object + infinitive. Use gerund or that-clause. |
| 8 | B | "Offer" takes to-infinitive. "Offered to help me." |
| 9 | A | "Tomorrow" from Monday = Tuesday. Reporting on Wednesday, specify the actual day. |
| 10 | B | "Can" → "could" in backshift. |
| 11 | C | "Urged" implies strong insistence. "Mentioned" is neutral, "stated" is formal. |
| 12 | C | Present tense in academic reporting indicates the argument/point is still current and relevant. |
| 13 | B | "Warn" + person + to-infinitive + reason clause. |
| 14 | C | "Agreed to do" — agree + to-infinitive for accepting to do something. |
| 15 | D | Present Perfect Continuous → Past Perfect Continuous. "Had been waiting." |
| 16 | D | Statement word order in reported questions: "what my name was." |
| 17 | A | Change "I" to "he," "you" to "me," "tomorrow" to "the next day." |
| 18 | A | "Deny" + gerund. "Denied taking the money." |
| 19 | C | "Promise" can take "that-clause" or "to-infinitive." Both patterns are correct. |
| 20 | B | Scientific facts remain in present tense — "boils" — as this is still true. |
