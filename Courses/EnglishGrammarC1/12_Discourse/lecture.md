## 1. What Is Cohesion?

### 1.1 Definition

**Cohesion** = how sentences and ideas connect to form a unified text.

```

WITHOUT COHESION:
"John went to the store. Mary likes apples. It rained yesterday."
(Disconnected sentences)

WITH COHESION:
"John went to the store to buy apples. However, it was closed. 
Therefore, he had to go to another one."
(Connected, flowing text)

```

### 1.2 Types of Cohesion

1. **Reference**: it, this, that, these, such
2. **Conjunction**: and, but, however, therefore
3. **Substitution**: do so, one, ones
4. **Ellipsis**: omitting repeated elements
5. **Lexical cohesion**: synonyms, repetition

## 2. Discourse Markers (Linking Words)

### 2.1 Adding Information

```

FORMAL:
Furthermore, Moreover, In addition, Additionally, 
Besides, What is more, Not only... but also

INFORMAL:
Also, And, Plus, On top of that, As well

"The project was completed on time. Furthermore, it came in under budget."

```

### 2.2 Contrasting

```

FORMAL:
However, Nevertheless, Nonetheless, On the other hand,
Conversely, In contrast, By contrast, Yet, Still

INFORMAL:
But, Though, Still, Even so, Mind you

"The plan seemed perfect. However, several issues emerged."
"He's young. Nevertheless, he's very experienced."

```

### 2.3 Giving Reasons / Cause

```

Because, Since, As, Due to, Owing to,
Because of, On account of, As a result of

"The event was cancelled due to bad weather."
"Since you're here, let me explain."

```

### 2.4 Showing Results / Consequence

```

FORMAL:
Therefore, Thus, Hence, Consequently, As a result,
Accordingly, For this reason

INFORMAL:
So, That's why

"Sales increased significantly. Consequently, profits rose."

```

### 2.5 Giving Examples

```

For example, For instance, Such as, Including,
Namely, That is (i.e.), In particular, Especially

"Several factors contributed, for example, inflation and unemployment."

```

### 2.6 Expressing Purpose

```

In order to, So as to, So that, With a view to,
For the purpose of

"She studied hard in order to pass the exam."
"The doors were closed so that no one could enter."

```

### 2.7 Summarizing / Concluding

```

In conclusion, To conclude, In summary, To summarize,
In short, In brief, Overall, All in all, On the whole

"In conclusion, the evidence supports the hypothesis."

```

### 2.8 Sequencing

```

First(ly), Second(ly), Third(ly), Finally, Lastly,
To begin with, Subsequently, Then, Next,
Following this, Previously, Meanwhile

"Firstly, we need to analyze the data. Subsequently, we can draw conclusions."

```

## 3. Reference

### 3.1 Pronoun Reference

```

"John called. He wanted to discuss the project."
(He = John)

"The company announced its results. They were disappointing."
(They = results)

```

### 3.2 Demonstrative Reference

```

THIS/THESE: Close, recent, what follows
"I'll tell you this: it won't be easy."
"These ideas will be discussed below."

THAT/THOSE: Distant, earlier, what precedes
"That was a difficult time."
"The problems mentioned above — those need attention."

```

### 3.3 The (Article) for Reference

```

"A man entered. The man was wearing a hat."
(The = the man I just mentioned)

```

### 3.4 Such

```

"There were many delays and errors. Such problems are unacceptable."
(Such = problems like delays and errors)

```

## 4. Substitution & Ellipsis

### 4.1 Substitution with "Do/Does/Did"

```

"She works harder than I do."
(do = work)

"He doesn't like coffee, but his wife does."
(does = likes coffee)

```

### 4.2 Substitution with "One/Ones"

```

"I need a pen. Do you have one?"
(one = a pen)

"These books are boring. I want more interesting ones."
(ones = books)

```

### 4.3 Substitution with "So/Not"

```

"Will it rain?" — "I think so." / "I don't think so."
"Is he coming?" — "I hope so." / "I hope not."

```

### 4.4 Ellipsis (Omission)

```

"She can swim and he can [swim] too."
"I wanted to help but I wasn't able to [help]."
"Some people agreed, others [did] not [agree]."

```

## 5. Text Organization

### 5.1 Paragraphing

Each paragraph = one main idea
- Topic sentence (first)
- Supporting sentences
- Concluding/transitional sentence (last)

### 5.2 Given-New Pattern

Put KNOWN information first, NEW information at the end:

```

"John bought a car. The car is blue."
(Known: the car — New: blue)

NOT: "Blue is the car that John bought."

```

### 5.3 Parallel Structure

Keep similar ideas in similar form:

```

✅ "He likes reading, writing, and swimming."
❌ "He likes reading, to write, and swimming."

✅ "She is intelligent, hardworking, and reliable."
❌ "She is intelligent, works hard, and you can rely on her."

```

## 6. Common Errors

### 6.1 Overuse of "And"

```

❌ "I went to the store and I bought milk and then I came home and I made coffee."
✅ "I went to the store to buy milk. Then I came home and made coffee."

```

### 6.2 Starting Sentences with "And/But"

In formal writing, avoid:
```

INFORMAL: "And that's why I think..."
FORMAL: "Furthermore, this is why..."

INFORMAL: "But there's a problem."
FORMAL: "However, there is a problem."

```

### 6.3 Comma Splice

```

❌ "It was raining, I stayed home."
✅ "It was raining, so I stayed home."
✅ "It was raining. I stayed home."
✅ "It was raining; I stayed home."

```

### 6.4 Wrong Connector

```

❌ "Despite he was tired, he continued."
✅ "Despite being tired, he continued."
✅ "Although he was tired, he continued."

❌ "Because of she was sick..."
✅ "Because she was sick..."
✅ "Because of her sickness..."

```

## 7. Academic Discourse Markers

### 7.1 For IELTS Writing

**Introduction:**
```

"This essay will discuss..." 
"The following essay examines..."

```

**Body paragraphs:**
```

"On the one hand... On the other hand..."
"While some argue that... others maintain that..."
"A further point to consider is..."

```

**Conclusion:**
```

"In conclusion..."
"To summarize the main points..."
"Taking everything into account..."

```

### 7.2 Hedging in Academic Writing

```

"It appears that..."
"This suggests that..."
"It could be argued that..."
"The evidence indicates..."

```

---

## 💡 Key Takeaways

- **Vary connectors**: Don't always use "and," "but," "so"

- **Match register**: Formal writing needs formal markers

- **Reference clearly**: Make sure pronouns have clear antecedents

- **Use substitution**: Avoid repetition with do/one/so

- **Given-new principle**: Known info first, new info last
