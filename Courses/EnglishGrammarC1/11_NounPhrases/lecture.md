## 1. Countable vs Uncountable Review

### 1.1 The Distinction

**COUNTABLE:** Can be counted, have plural

```
book → books, car → cars, idea → ideas
```

**UNCOUNTABLE:** Cannot be counted, no plural

```
water, information, advice, music, news, furniture
```

### 1.2 Russian Interference

Some words countable in Russian are uncountable in English:

```
RUSSIAN (countable)       ENGLISH (uncountable)
совет (советы)       →    advice (NOT advices)
новость (новости)    →    news (NOT a news)
информация           →    information (NOT informations)
мебель               →    furniture (NOT furnitures)
работа               →    work (NOT works for job)
исследование         →    research (NOT researches)
```

### 1.3 Uncountable Nouns That Look Plural

```
news (is)          "The news is good."
physics (is)       "Physics is difficult."
economics (is)     "Economics was his major."
```

## 2. Quantifiers

### 2.1 Much / Many / A Lot Of

| | Countable | Uncountable |
|---|-----------|-------------|
| **Affirmative** | many / a lot of | much / a lot of |
| **Negative** | many / not many | much / not much |
| **Question** | many / how many | much / how much |

```
"I don't have much time." (uncountable)
"I don't have many friends." (countable)
"I have a lot of work." (both contexts)

"How much money do you need?"
"How many books did you buy?"
```

### 2.2 A Lot Of vs Much/Many

**A lot of** — common in affirmative:
```
"I have a lot of friends."
(More natural than "I have many friends" in speech)
```

**Much/Many** — common in negative/questions:
```
"I don't have much time."
"Do you have many questions?"
```

### 2.3 Few / Little vs A Few / A Little

**NEGATIVE meaning (not enough):**
```
"Few people came." (almost nobody — negative)
"I have little money." (almost none — negative)
```

**POSITIVE meaning (some):**
```
"A few people came." (some people — positive)
"I have a little money." (some money — positive)
```

Compare:
```
"She has few friends." (sadly, almost none)
"She has a few friends." (happily, some)
```

### 2.4 Some / Any

**SOME:** Affirmative, offers, requests

```
"I need some help."
"Would you like some coffee?" (offer)
"Can I have some water?" (request)
```

**ANY:** Negative, questions, conditionals

```
"I don't have any money."
"Do you have any questions?"
"If you have any problems, call me."
```

**ANY = "it doesn't matter which":**
```
"Any color is fine."
"You can come any time."
```

### 2.5 No / None / Any

```
"I have no money." (= I don't have any money)
"None of them came." (pronoun)
"Is there any left?" — "No, there's none."
```

## 3. Other Determiners

### 3.1 Each / Every

**EVERY:** All members of a group collectively

```
"Every student passed." (all students as a group)
"Every day is different."
```

**EACH:** Individual members separately

```
"Each student received a certificate." (one by one)
"Each day brings new challenges."
```

### 3.2 All / Both / Half

```
"All (of) the students passed."
"Both (of) my parents are doctors."
"Half (of) the cake is gone."

Note: "of" optional with noun, required with pronoun:
"All students" / "All of them"
```

### 3.3 Either / Neither

```
"Either option is fine." (one or the other)
"Neither answer is correct." (not one, not the other)

"You can have either tea or coffee."
"I like neither tea nor coffee."
```

### 3.4 Another / Other / Others / The Other

```
ANOTHER (singular): "Can I have another cup?"
OTHER (plural/uncountable): "Other people might disagree."
OTHERS (pronoun): "Some stayed, others left."
THE OTHER (specific): "One is red, the other is blue."
```

## 4. Noun Phrase Structure

### 4.1 Pre-modification

**Order:** Determiner + Opinion + Size + Age + Shape + Color + Origin + Material + Purpose + NOUN

```
a     beautiful   large  old   round  brown   Italian  wooden  dining   table
det.  opinion     size   age   shape  color   origin   material purpose NOUN
```

### 4.2 Common Adjective Order

```
"A lovely little old Italian restaurant"
"Big blue Chinese vase"
"Expensive new leather jacket"
```

### 4.3 Post-modification

Using phrases/clauses after the noun:

```
"The man in the blue coat..." (prepositional phrase)
"The book that I bought..." (relative clause)
"Something interesting..." (indefinite + adjective)
"Anyone waiting..." (participle)
```

### 4.4 Complex Noun Phrases

Academic English uses heavy noun phrases:

```
Simple: "The results"
Complex: "The statistically significant results 
          of the longitudinal study 
          conducted over five years"
```

## 5. Common Errors

### 5.1 Uncountable Nouns

```
❌ "I need an advice."
✅ "I need some advice." / "I need a piece of advice."

❌ "She gave me many advices."
✅ "She gave me a lot of advice."

❌ "This informations are useful."
✅ "This information is useful."

❌ "I bought new furnitures."
✅ "I bought new furniture."
```

### 5.2 Much/Many

```
❌ "I have much friends."
✅ "I have many friends."

❌ "I don't have many time."
✅ "I don't have much time."
```

### 5.3 Few/Little

```
❌ "I have few money."
✅ "I have little money."

❌ "There are little people here."
✅ "There are few people here."
```

### 5.4 Some/Any

```
❌ "I don't have some money."
✅ "I don't have any money."

BUT in offers/requests:
✅ "Would you like some coffee?"
```

---

## 💡 Key Takeaways

- **Countability matters**: Different quantifiers for each type

- **Few/a few difference**: Negative vs positive meaning

- **Much in affirmative**: Less common — use "a lot of"

- **Uncountable = singular verb**: "Information is," not "are"

- **Adjective order**: Opinion → Size → Age → Shape → Color → Origin → Material → Purpose
