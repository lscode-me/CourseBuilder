## 1. English Word Order Basics

### 1.1 The Standard Pattern: SVO

English has relatively **fixed word order**:

```
Subject + Verb + Object (+ Adverbial)

"She wrote a letter."
"The dog chased the cat."
"I will call you tomorrow."
```

### 1.2 Russian vs English

Russian has **flexible** word order, English doesn't:

```
RUSSIAN: All these mean the same (with different emphasis):
"Мама мыла раму."
"Раму мыла мама."
"Мыла мама раму."

ENGLISH: These mean different things or are wrong:
"Mom washed the frame." ✓
"The frame washed mom." (Different meaning!)
❌ "Washed mom the frame."
```

### 1.3 Position of Adverbs

**Adverb placement** is a common error area:

| Adverb Type | Position | Example |
|-------------|----------|---------|
| Frequency | Before main verb | "I **always** eat breakfast." |
| Degree | Before adjective/adverb | "She's **very** smart." |
| Time | Beginning or end | "**Yesterday** I saw him." |
| Manner | After verb/object | "She spoke **quietly**." |
| Place | After verb/object | "He works **in London**." |

### 1.4 Common Adverb Errors

```
❌ "I yesterday went shopping."
✅ "I went shopping yesterday." / "Yesterday I went shopping."

❌ "She speaks very well English."
✅ "She speaks English very well."

❌ "I very much like this idea."
✅ "I like this idea very much." / "I really like this idea."
```

## 2. Inversion: Subject-Verb Swap

### 2.1 What Is Inversion?

**Inversion** = auxiliary/verb before subject (like questions):

```
Normal: "She is happy."
Inverted: "Happy is she." (literary)

Normal: "I have never seen such a thing."
Inverted: "Never have I seen such a thing."
```

### 2.2 Inversion After Negative Adverbials

When negative/restrictive adverbs come **first**, use inversion:

```
"Never have I seen such beauty."
"Rarely do we see such talent."
"Seldom had she felt so happy."
"Not only did he arrive late, but he also forgot the report."
"No sooner had I arrived than it started raining."
"Little did she know that..."
"Under no circumstances should you open this door."
"At no time did he admit his mistake."
"Only then did I realize the truth."
"Not until midnight did they arrive."
```

### 2.3 Inversion After "Only"

```
"Only after careful analysis can we draw conclusions."
"Only by working hard will you succeed."
"Only in this way can we solve the problem."
"Only when she left did I notice."
```

### 2.4 Inversion After "So/Such"

```
"So beautiful was the sunset that..."
"Such was his anger that he couldn't speak."
"So quickly did he react that..."
```

### 2.5 Inversion in Conditionals

Formal alternative to "if":

```
"Were I rich, I would travel." (= If I were rich)
"Had I known, I would have helped." (= If I had known)
"Should you need help, call me." (= If you should need)
```

## 3. Fronting: Moving Elements to the Front

### 3.1 Fronting for Emphasis

Moving a word/phrase to the beginning for emphasis:

```
Normal: "I will never accept this."
Fronted: "This I will never accept."

Normal: "She likes coffee, but she hates tea."
Fronted: "Coffee she likes, but tea she hates."
```

### 3.2 Fronting Adverbials

```
"In the garden sat an old man."
"From the window came a strange noise."
"Down came the rain."
"Away flew the bird."
```

### 3.3 Fronting for Information Flow

Known → New information flow:

```
"I bought a new car. The car is blue."
Better: "I bought a new car. Blue, it is not."
Or: "A new car I bought yesterday."
```

## 4. Cleft Sentences

### 4.1 It-Cleft

**Structure:** It + be + focused element + that/who clause

```
Normal: "John broke the window."

Focus on JOHN: "It was John who broke the window."
Focus on WINDOW: "It was the window that John broke."
Focus on breaking: "It was breaking the window that John did."
```

### 4.2 What-Cleft (Pseudo-Cleft)

**Structure:** What + clause + be + focused element

```
"What I need is a coffee."
"What he did was apologize."
"What happened was (that) the car broke down."
"What annoys me is his attitude."
```

### 4.3 All-Cleft

```
"All I want is peace."
"All you need is love."
"All she did was complain."
```

### 4.4 Using Clefts

**For emphasis:**
```
"It was yesterday that I met him." (not today)
"What I said was that..." (clarifying)
```

**For correction:**
```
"No, it wasn't John who called. It was Mike."
```

## 5. End-Weight and End-Focus

### 5.1 The Principle

English tends to put:

- **Longer/heavier** elements at the end

- **New/important** information at the end

```
AWKWARD: "I gave to the woman who had helped me a book."
BETTER: "I gave a book to the woman who had helped me."

AWKWARD: "That he had lied was obvious."
BETTER: "It was obvious that he had lied."
```

### 5.2 Extraposition

Moving clauses to the end:

```
"It is important to be on time." 
(Rather than: "To be on time is important.")

"It surprised me that he came."
(Rather than: "That he came surprised me.")
```

### 5.3 Postponed Subjects

```
"There seems to be a problem."
"There came a knock at the door."
"Here comes the bus."
```

## 6. Question Word Order

### 6.1 Basic Questions

**Yes/No:** Auxiliary + Subject + Verb

```
"Do you like coffee?"
"Are they coming?"
"Has she finished?"
```

**Wh-Questions:** Wh-word + Auxiliary + Subject + Verb

```
"Where do you live?"
"What are they doing?"
"When did it happen?"
```

### 6.2 Subject Questions

When the question word IS the subject, no inversion:

```
"Who called?" (who = subject)
NOT: "Who did call?"

"What happened?" (what = subject)
NOT: "What did happen?"

"Which book is yours?" (which book = subject)
```

### 6.3 Embedded Questions

Indirect/reported questions use **statement order**:

```
❌ "I don't know where is he."
✅ "I don't know where he is."

❌ "Tell me what did you do."
✅ "Tell me what you did."

❌ "She asked where was the bank."
✅ "She asked where the bank was."
```

## 7. Common Russian Speaker Errors

### 7.1 Verb Position

```
❌ "I yesterday bought a book."
✅ "I bought a book yesterday."

❌ "She very well speaks English."
✅ "She speaks English very well."
```

### 7.2 Adverb Position

```
❌ "He walks usually to work."
✅ "He usually walks to work."

❌ "I really want much this job."
✅ "I really want this job very much."
```

### 7.3 Question Formation

```
❌ "You are going where?"
✅ "Where are you going?"

❌ "What means this word?"
✅ "What does this word mean?"
```

### 7.4 Indirect Questions

```
❌ "I wonder where is she."
✅ "I wonder where she is."

❌ "Can you tell me how much costs this?"
✅ "Can you tell me how much this costs?"
```

### 7.5 Fronting Without Inversion (Error)

```
❌ "Very well she plays the piano."
✅ "She plays the piano very well."
(OR literary: "Very well does she play the piano.")
```

## 8. Advanced Patterns

### 8.1 The Emphatic Do

```
"I DO like your dress!" (emphasis on liking)
"She DID call you!" (emphasis on fact)
"Do come in!" (emphatic invitation)
```

### 8.2 Negative Inversion in Style

Used in formal/literary contexts:

```
"Not for a moment did I doubt him."
"In no way am I responsible."
"On no account must you leave."
```

### 8.3 Comparative Inversion

```
"More important than the money is the principle."
"Greater than the risk is the potential reward."
```

---

## 💡 Key Takeaways

- **SVO is default**: Don't randomly change word order like in Russian

- **Inversion for emphasis**: After negative adverbs, only, so/such

- **Fronting is marked**: Creates emphasis, use deliberately

- **Clefts focus information**: It-cleft and what-cleft for different effects

- **Embedded questions**: Statement order, not question order
