## Question 25: Главный девиз налоговой безопасности сегодня

B) "Бумажные документы могут содержать любую информацию"

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Риск — это неопределенность, ведущая к потерям. **Пример налогового риска**: Компания использует агрессивную схему оптимизации, которая экономит $200k/год на налогах. Вероятность обнаружения налоговой: 30%. Если обнаружат: доначисление $200k + штраф 40% = $80k + пени $20k = $300k. Ожидаемая стоимость риска = $300k × 30% = $90k. Экономия $200k, но риск $90k. Чистая выгода $110k, но есть риск потери репутации и блокировки счетов. Риск-менеджмент помогает оценить, стоит ли игра свеч. |
| 2 | D | Попытка переиграть правила математики бизнеса. **Пример искусственного дробления**: Компания выросла из лимитов льгот ($2M/год). Делится на 3 фирмы по $1M каждая, каждая получает льготы. Проблема: Общие учредители, общий IP-адрес, общая бухгалтерия, общие клиенты. Налоговая легко доказывает связь и признаёт дробление фиктивным. Результат: Все 3 компании объединяются для расчёта налога, доначисление $600k + штраф 40% = $840k. Вместо экономии — огромные потери. Математику не обманешь. |
| 3 | A | Косвенные признаки часто сильнее прямых доказательств. **Red Flags (Красные флаги)**: Завышенная цена сделки (выше рыночной), оплата услуги без результата, круговое движение денег, сложная структура без бизнес-цели. **Пример**: Компания платит $2M за "консалтинг" компании на Сейшелах, но нет документов о выполненной работе, нет сотрудников у консалтинговой компании, деньги сразу переводятся дальше. Косвенные признаки (отсутствие substance, круговое движение) сильнее формальных документов. Налоговая доначислит налог на основе косвенных признаков. |
| 4 | D | Подмена понятий для получения неправомерной выгоды. |
| 5 | B | Льготы — это риск ответственности за точность расчетов. |
| 6 | D | Манипуляция международными договорами (Treaties). |
| 7 | B | Барьер для создания структур без бизнес-цели. |
| 8 | D | Право на льготу имеет только тот, кто реально владеет деньгами. |
| 9 | C | Ложь на бумаге при отсутствии действий в реальности. |
| 10 | B | Использование одной маски для прикрытия другой цели. |
| 11 | D | Налоговая снимает "маску" и считает налоги по-настоящему. |
| 12 | B | Проверка на наличие "скелетов в шкафу" перед сделкой. |
| 13 | B | Банки боятся санкций и потери лицензий больше, чем потери клиента. |
| 14 | D | Финансовая ответственность за сознательные махинации. |
| 15 | D | Налоги не могут быть единственным оправданием бизнеса. |
| 16 | D | Работа в "серой" зоне ведет к финансовой изоляции. |
| 17 | B | Эра прозрачности сделала мир очень маленьким для регулятора. |
| 18 | A | Нецелевое использование статуса резидента. |
| 19 | D | Ответственность за плохие советы становится нормой. |
| 20 | D | Ответственное налоговое поведение — часть современной этики. |
| 21 | A | Запрет на использование чужих неудач для своей выгоды. |
| 22 | B | Цифровой след помогает налоговой искать нестыковки. |
| 23 | C | Проблема "фирм-однодневок" актуальна даже в IT. |
| 24 | D | Лучшая защита — это подготовка документов во время работы. |
| 25 | D | Фундаментальный сдвиг в мировом налоговом праве. |
