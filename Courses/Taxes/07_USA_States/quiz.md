## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Система "матрешки": федеральный + штат + (иногда) город. |
| 2 | A | Самая влиятельная финансовая служба в мире. |
| 3 | D | Принцип "богатый платит больше" реализован через ступени (brackets). **Пример прогрессивной шкалы**: Доход $50k → налог 12-22% (эффективная ставка ~15%). Доход $200k → налог 24-37% (эффективная ставка ~25%). Доход $500k → налог 37% на последние доллары (эффективная ставка ~32%). Богатые платят больший процент от дохода, что реализует принцип вертикальной справедливости. Это отличается от плоской шкалы, где все платят одинаковый процент. |
| 4 | D | Это подушка безопасности, гарантирующая необлагаемый минимум. **Пример Standard Deduction**: В 2024 году $14,600 для одиночки. Доход $50k - $14,600 = $35,400 налогооблагаемый доход. Это означает, что первые $14,600 дохода не облагаются налогом вообще. Для семьи из 4 человек Standard Deduction ~$29,200. Это делает эффективную налоговую ставку для низких доходов очень маленькой (почти 0% для доходов <$20k). |
| 5 | D | Техас — один из 9 штатов, сознательно отказавшихся от налога на доход. **Сравнение**: Программист в Калифорнии с зарплатой $150k платит федеральный налог $25.5k + налог штата $7.5k = $33k (22% эффективная ставка). В Техасе: федеральный налог $25.5k + налог штата $0 = $25.5k (17% эффективная ставка). Разница $7.5k/год. Это одна из причин массового переезда IT-специалистов из Кремниевой долины в Остин (Техас). |
| 6 | A | Разница в 10% чистого дохода — мощный стимул для трудовой миграции. |
| 7 | B | Отсутствие каскадного эффекта (налога на налог) как в НДС. |
| 8 | A | Прозрачность налога для покупателя — важная часть американской культуры. |
| 9 | A | Правовая база Делавэра оптимизирована под инвестиции и суды. |
| 10 | A | Один раз на уровне компании, второй — в кармане владельца. |
| 11 | C | Налоги "протекают" сквозь компанию, не задерживаясь на балансе юрлица. |
| 12 | C | Эти взносы гарантируют базовую пенсию и страховку в старости. |
| 13 | A | Фрилансер платит и за себя, и "за работодателя", которого нет. |
| 14 | B | Финансовый "новый год" для большинства американцев. |
| 15 | C | Эту форму заполняют ежегодно десятки миллионов людей. |
| 16 | C | Основной юридический триггер для возникновения налоговых обязательств бизнеса. |
| 17 | D | Освобождает цепочку поставок от лишних налоговых накруток. |
| 18 | B | Уникальность США: налоги привязаны к статусу человека, а не только к месту работы. |
| 19 | B | Механизм избежания двойной оплаты одного и того же налога. |
| 20 | A | Жители мегаполиса платят тройную "цену" за инфраструктуру города. |
| 21 | D | Стимулирование долгосрочного инвестирования в экономику. |
| 22 | D | Подрядчик — это "сам себе бизнес" с точки зрения IRS. |
| 23 | A | Государство всегда заберет свое, если не через доход, то через землю. |
| 24 | C | Глобальный механизм контроля за капиталами граждан США. |
| 25 | C | Форма беспроцентного кредита государству, который возвращается весной. |
