## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Прямой налог берется "у источника" дохода или с владения имуществом. |
| 2 | B | Зарплата, прибыль от продажи активов и пассивный доход — классические объекты PIT / НДФЛ. |
| 3 | C | Работодатель рассчитывает, удерживает и перечисляет налог за работника. |
| 4 | C | Единая ставка (например, 15%) применяется ко всем одинаково. |
| 5 | C | Это позволяет брать больше с тех, кто может себе это позволить, для финансирования общественных благ. |
| 6 | B | В отличие от оборотных налогов, CIT платится только с финансового результата (прибыли). |
| 7 | B | Расходы должны быть направлены на деятельность компании, иначе они не уменьшают налоговую базу. |
| 8 | B | Правило 183 дней — международный стандарт определения налогового дома. |
| 9 | B | Большинство стран применяют "неограниченную налоговую обязанность" для своих резидентов. |
| 10 | B | DTA предотвращают уплату полного налога в двух странах с одного и того же дохода. |
| 11 | C | Налог платится с реализованной прибыли, а не с бумажного роста цены. |
| 12 | B | Налог зависит от ценности имущества, установленной рынком или государством. |
| 13 | B | Вычет уменьшает сумму, с которой будет считаться % налога. |
| 14 | B | Государство субсидирует через налоги социально значимые расходы граждан. |
| 15 | B | Это поощряет инвестиционное поведение граждан вместо простого потребления. |
| 16 | B | Это итоговая цифра: общая сумма налогов поделенная на общий доход. |
| 17 | B | США — одна из немногих стран, применяющих налогообложение на основе гражданства (citizenship-based taxation). |
| 18 | B | Это мера против чрезмерной концентрации капитала в руках немногих семей на протяжении поколений. |
| 19 | B | Идея в том, что "лучше 13% со всего, чем 35% с ничего" (когда все скрывают доходы). |
| 20 | B | Офшоры привлекают капиталы за счет отсутствия налогообложения прибыли. |
| 21 | B | Подоходный налог — с потока денег, налог на богатство — со "склада" (запаса) денег и имущества. |
| 22 | B | Каждая страна устанавливает свои правила связи компании с её территорией. |
| 23 | C | Имущественные налоги традиционно считаются основой местного самоуправления. |
| 24 | B | Это форма возврата ранее удержанного налога (Cashback от государства). |
| 25 | C | Эта знаменитая цитата высечена на здании налоговой службы США (IRS). |
