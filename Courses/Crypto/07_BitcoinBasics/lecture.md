## 1. Whitepaper Сатоши Накамото

31 октября 2008 года Сатоши Накамото опубликовал whitepaper "Bitcoin: A Peer-to-Peer Electronic Cash System".

### 1.1 Основные идеи

**Проблема:**
- Электронные платежи требуют доверия к посредникам
- Высокие комиссии за транзакции
- Возможность отмены транзакций
- Отсутствие истинной цифровой наличности

**Решение:**
- P2P сеть без центрального органа
- Цифровые подписи для владения
- Proof of Work для консенсуса
- Необратимые транзакции

### 1.2 Ключевые концепции

**Децентрализация:**
- Нет центрального сервера
- Все узлы равноправны
- Распределённая база данных

**Необратимость:**
- Транзакции нельзя отменить
- Защита от двойного расходования
- Финансовая свобода

## 2. Транзакции и UTXO

Bitcoin использует модель UTXO (Unspent Transaction Output) вместо балансов счетов.

### 2.1 Модель UTXO

**UTXO:**
- Непотраченные выходы транзакций
- Каждая монета — это UTXO
- Транзакция тратит старые UTXO и создаёт новые

**Пример:**
```python
# Упрощённый пример UTXO
# У Алисы есть UTXO на 1 BTC
utxo_alice = {"tx_id": "abc123", "output_index": 0, "amount": 1.0}

# Алиса хочет отправить 0.3 BTC Бобу
# Транзакция тратит 1 BTC и создаёт:
# - 0.3 BTC для Боба
# - 0.7 BTC обратно Алисе (сдача)

transaction = {
    "inputs": [utxo_alice],
    "outputs": [
        {"address": "bob_address", "amount": 0.3},
        {"address": "alice_address", "amount": 0.7}
    ]
}

print("UTXO модель: каждая транзакция тратит старые и создаёт новые UTXO")
```

**Output:**
```
UTXO модель: каждая транзакция тратит старые и создаёт новые UTXO
```

### 2.2 Структура транзакции

**Компоненты:**
- **Inputs**: Ссылки на предыдущие UTXO
- **Outputs**: Новые UTXO с адресами получателей
- **Signatures**: Цифровые подписи для авторизации

**Валидация:**
- Проверка подписей
- Проверка, что UTXO не потрачены
- Проверка суммы входов >= суммы выходов

## 3. Майнинг

Майнинг — процесс создания новых блоков и получения вознаграждения.

### 3.1 Процесс майнинга

**Шаги:**
1. Сбор транзакций в мемпул
2. Создание блока с транзакциями
3. Поиск nonce для валидного хэша
4. Добавление блока в цепочку
5. Получение награды

**Награда:**
- Блок-награда (новые монеты)
- Комиссии за транзакции

**Пример:**
```python
# Упрощённый пример майнинга
block_reward = 6.25  # BTC (после халвинга)
transaction_fees = 0.1  # BTC

total_reward = block_reward + transaction_fees
print(f"Майнер получает: {total_reward} BTC за блок")
print(f"Из них: {block_reward} BTC награда, {transaction_fees} BTC комиссии")
```

**Output:**
```
Майнер получает: 6.35 BTC за блок
Из них: 6.25 BTC награда, 0.1 BTC комиссии
```

### 3.2 Сложность майнинга

**Difficulty Adjustment:**
- Каждые 2016 блоков (~2 недели)
- Сложность корректируется для поддержания времени блока ~10 минут
- Защита от изменений в вычислительной мощности

## 4. Ограниченная эмиссия

Bitcoin имеет фиксированное максимальное предложение — 21 миллион монет.

### 4.1 График эмиссии

**Халвинги:**
- Каждые 210,000 блоков (~4 года)
- Награда за блок уменьшается вдвое
- Начальная награда: 50 BTC
- Текущая (2024): 3.125 BTC

**График:**
```python
# График эмиссии Bitcoin
halvings = [
    (0, 50),
    (210000, 25),
    (420000, 12.5),
    (630000, 6.25),
    (840000, 3.125),
    (1050000, 1.5625)
]

total_supply = 0
for blocks, reward in halvings:
    blocks_mined = 210000 if blocks > 0 else 0
    total_supply += blocks_mined * reward

print(f"Максимальное предложение: 21,000,000 BTC")
print(f"Эмиссия постепенно замедляется через халвинги")
```

**Output:**
```
Максимальное предложение: 21,000,000 BTC
Эмиссия постепенно замедляется через халвинги
```

### 4.2 Экономические последствия

**Дефляционная модель:**
- Предложение ограничено
- Спрос может расти
- Потенциал роста цены

**Сравнение с фиатом:**
- Фиат: неограниченная эмиссия → инфляция
- Bitcoin: ограниченная эмиссия → дефляция

## 5. Почему Bitcoin — "цифровое золото"

Bitcoin часто сравнивают с золотом из-за схожих свойств.

### 5.1 Сходства с золотом

**Редкость:**
- Ограниченное предложение
- Сложность добычи
- Предсказуемая эмиссия

**Долговечность:**
- Не портится
- Цифровая природа
- Защита от износа

**Делимость:**
- Можно разделить на сатоши (0.00000001 BTC)
- Больше делимость, чем у золота

**Портативность:**
- Легко передавать
- Глобальная доступность
- Быстрые транзакции

### 5.2 Преимущества над золотом

**Проверяемость:**
- Можно проверить подлинность криптографически
- Нет необходимости в экспертизе

**Программируемость:**
- Можно автоматизировать
- Смарт-контракты (через Layer 2)
- Гибкость использования
