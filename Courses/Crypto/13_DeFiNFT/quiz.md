## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | DeFi (Decentralized Finance) — децентрализованные финансовые сервисы на блокчейне без традиционных посредников. |
| 2 | D | Lending в DeFi работает так: пользователи депозируют средства, получают проценты и могут брать кредиты под залог. |
| 3 | C | NFT (Non-Fungible Token) — не взаимозаменяемые токены, представляющие уникальные цифровые активы. |
| 4 | C | Цифровая собственность означает право владения цифровым активом, проверяемое через блокчейн, с возможностью передачи. |
| 5 | C | Web3 — видение децентрализованного интернета на блокчейне с контролем пользователей над данными и активами. |
| 6 | C | Реальные use cases решают реальные проблемы и имеют устойчивую ценность, псевдо-use-cases — только спекуляция без реальной utility. |
