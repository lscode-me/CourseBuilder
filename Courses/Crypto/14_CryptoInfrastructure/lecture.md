## 1. Кошельки

Кошельки — инструменты для хранения и управления криптовалютами.

### 1.1 Типы кошельков

**Горячие кошельки (Hot Wallets):**
- Подключены к интернету
- Удобны для частых транзакций
- Менее безопасны
- Примеры: MetaMask, Trust Wallet

**Холодные кошельки (Cold Wallets):**
- Не подключены к интернету
- Более безопасны
- Для хранения больших сумм
- Примеры: Ledger, Trezor

**Аппаратные кошельки:**
- Физические устройства
- Приватные ключи не покидают устройство
- Баланс безопасности и удобства

### 1.2 Seed фразы

**Mnemonic Phrase:**
- 12 или 24 слова
- Восстанавливает все ключи
- Критически важно хранить безопасно
- Стандарт BIP-39

**Безопасность:**
- Никогда не хранить в цифровом виде
- Записывать на бумаге
- Хранить в безопасном месте
- Не делиться ни с кем

## 2. Ноды

Ноды — компьютеры, поддерживающие блокчейн-сеть.

### 2.1 Типы нод

**Полные ноды (Full Nodes):**
- Хранят полную копию блокчейна
- Проверяют все транзакции
- Поддерживают сеть
- Требуют много места

**Легкие ноды (Light Nodes):**
- Хранят только заголовки блоков
- Запрашивают данные по необходимости
- Меньше места и ресурсов
- Меньше безопасности

**Валидаторы:**
- Создают блоки
- Участвуют в консенсусе
- Получают награды
- Требуют стейкинг

### 2.2 Зачем запускать ноду

**Преимущества:**
- Независимость от других нод
- Больше приватности
- Поддержка сети
- Проверка транзакций

**Недостатки:**
- Требует ресурсов
- Техническая сложность
- Постоянное подключение

## 3. Блокчейн-эксплореры

Блокчейн-эксплореры — веб-инструменты для просмотра данных блокчейна.

### 3.1 Что можно делать

**Просмотр транзакций:**
- История транзакций
- Детали транзакций
- Статус транзакций

**Просмотр блоков:**
- Информация о блоках
- Транзакции в блоках
- Время создания

**Просмотр адресов:**
- Баланс адреса
- История транзакций
- Входящие и исходящие транзакции

**Примеры:**
- Bitcoin: blockchain.com, blockstream.info
- Ethereum: etherscan.io, blockscout.com
- Другие: различные эксплореры для каждого блокчейна

### 3.2 Использование

**Проверка транзакций:**
- Подтверждение получения
- Отслеживание статуса
- Проверка комиссий

**Анализ:**
- Изучение активности
- Анализ адресов
- Исследование блокчейна

## 4. Oracles

Oracles — сервисы, предоставляющие внешние данные в блокчейн.

### 4.1 Проблема

**Блокчейн изолирован:**
- Не может получать внешние данные
- Нет доступа к API
- Нужны внешние источники

**Решение:**
- Oracles предоставляют данные
- Связь с внешним миром
- Критически важны для DeFi

### 4.2 Типы Oracles

**Ценовые Oracles:**
- Цены активов
- Для DeFi протоколов
- Примеры: Chainlink, Band Protocol

**Данные событий:**
- Спортивные результаты
- Погода
- Другие события

**Вычислительные Oracles:**
- Вычисления вне блокчейна
- Сложные вычисления
- Экономия Gas

### 4.3 Проблемы Oracles

**Централизация:**
- Зависимость от провайдеров
- Единая точка отказа
- Риски манипуляции

**Безопасность:**
- Валидация данных
- Защита от атак
- Децентрализация

## 5. Инфраструктурные сервисы

Различные сервисы поддерживают экосистему криптовалют.

### 5.1 Индексация

**Сервисы:**
- Индексация блокчейна
- API для разработчиков
- Упрощение доступа к данным

**Примеры:**
- The Graph
- Alchemy
- Infura

### 5.2 Аналитика

**Сервисы:**
- Анализ данных
- Визуализация
- Отчёты

**Примеры:**
- Dune Analytics
- Nansen
- Glassnode

### 5.3 Разработка

**Инструменты:**
- SDK и библиотеки
- Тестирование
- Деплой

**Примеры:**
- Hardhat
- Truffle
- Web3.js, Ethers.js

## 💡 Key Takeaways

- **Кошельки**: Различные типы для разных целей — горячие для частых транзакций, холодные для хранения.

- **Ноды**: Поддерживают сеть, обеспечивают независимость и приватность, но требуют ресурсов.

- **Блокчейн-эксплореры**: Инструменты для просмотра и анализа данных блокчейна, критически важны для прозрачности.

- **Oracles**: Связывают блокчейн с внешним миром, критически важны для DeFi, но имеют риски централизации.

- **Инфраструктура**: Различные сервисы поддерживают экосистему, упрощая разработку и использование.
