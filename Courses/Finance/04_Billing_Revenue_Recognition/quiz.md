## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Это методология учета, позволяющая разделять факт работы и факт получения денег. |
| 2 | A | По методу начисления выручка признается тогда, когда услуга "произведена" (в марте). |
| 3 | C | Биллабл время — это те задачи, за которые заказчик готов платить согласно договору. |
| 4 | C | Бенч — это операционный риск компании, когда ресурсы простаивают, но оплачиваются. |
| 5 | C | Utilization = 30 (billable) / 40 (total) = 75%. |
| 6 | B | Оставляется запас на отпуска, обучение и административные задачи. |
| 7 | B | Без инвойса клиент формально не знает о необходимости платежа. |
| 8 | B | Это стандартное условие отсрочки платежа в B2B бизнесе. |
| 9 | C | IFRS 15 (Revenue from Contracts with Customers) — глобальный стандарт для признания дохода. |
| 10 | B | Без юридически оформленного договора признание дохода по международным стандартам невозможно. |
| 11 | B | Так как объем работ зафиксирован, мы признаем доход по мере прохождения пути к финалу. |
| 12 | C | Прогресс = 10к (факт) / 50к (план) = 20%. Выручка = 100к (цена) $\times$ 20% = 20к. |
| 13 | B | Дебиторка — это долг клиента перед вами. |
| 14 | B | Этот отчет помогает выявлять проблемных клиентов, задерживающих оплаты. |
| 15 | B | Ситуация "Profit rich, Cash poor" ведет к банкротству. |
| 16 | B | Это доход, который уже заработан, но юридически еще не "упакован" в инвойс (неофактурованный доход). |
| 17 | B | Аванс — это обязательство компании перед клиентом (сделать работу), а не доход. |
| 18 | B | Ключевое понятие в IFRS 15 — переход контроля (Control). |
| 19 | B | Чем ниже DSO, тем быстрее компания превращает свои услуги в реальные деньги. |
| 20 | B | Авансы — лучший способ борьбы с кассовыми разрывами. |
| 21 | B | Списание такого долга уменьшает прибыль компании. |
| 22 | B | Пресейл — это расходы на маркетинг и продажи, которые обычно не выставляются клиенту отдельно. |
| 23 | B | Поскольку доступность ресурсов продается помесячно, доход признается по мере течения времени. |
| 24 | B | PM — первоисточник данных для биллинга; ошибки PM ведут к потере денег или конфликтам с клиентом. |
| 25 | B | Бухгалтерский учет первичнее графика платежей при формировании P&L. |
