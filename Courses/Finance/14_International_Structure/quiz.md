## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | Структура — это скелет бизнеса, обеспечивающий его безопасность и рост. **Пример**: Компания работает в 3 странах (Польша — разработка, США — продажи, Россия — клиенты). Без структуры: все операции через одну компанию в Польше, высокие налоги, сложно работать с зарубежными клиентами. Со структурой: Holding (Кипр) → IP Co (Ирландия) → OpCo (Польша, США). Защита активов, оптимизация налогов, доступ к капиталу. Структура — это стратегический актив. Правильная структура экономит $500k-2M/год на налогах и защищает от рисков. |
| 2 | A | "Мешок с золотом" и "Мозг" компании должны быть защищены. **"Мешок с золотом"** = Деньги (Cash). Должны быть в безопасной юрисдикции с хорошей банковской системой (Сингапур, Швейцария, Кипр). **"Мозг"** = IP (код, патенты, технологии). Должен быть в стране с IP Box (Ирландия, Кипр) для минимизации налогов. Если IP в стране с высоким налогом, при продаже лицензий теряете миллионы. Если деньги в нестабильной стране, рискуете потерять их при кризисе. Структура защищает оба актива. |
| 3 | A | IP — самый ценный актив IT-компании, он требует особого климата. **Пример**: Код и патенты стоят $10M. Если IP находится в Польше (19% налог), при продаже лицензий налог = $1.9M. Если IP в Ирландии (IP Box 6.25%), налог = $625k. Экономия $1.275M! IP должен быть в стране с режимом IP Box (Ирландия, Кипр, Польша) или с низким налогом на роялти. Это критично для IT-компаний, где код — основной актив. IP Box снижает налог на доходы от интеллектуальной собственности в 2-3 раза. |
| 4 | A | Фундамент честной конкуренции и правильного налогообложения. **Transfer Pricing Documentation**: Документация ТЦО доказывает, что цены между связанными компаниями соответствуют рыночным. Это защищает от доначислений налогов и штрафов. Без документации налоговая может пересчитать цены и доначислить налоги на миллионы. Документация включает: анализ функций и рисков, сравнение с независимыми поставщиками, экономический анализ. Это фундамент легальной оптимизации налогов. |
| 5 | C | ТЦО — главный инструмент борьбы с "размыванием" прибыли. **Пример Transfer Pricing**: OpCo (Польша) продаёт услуги IP Co (Ирландия) по $1/час вместо рыночных $50/час. Вся прибыль уходит в Ирландию с низким налогом. Налоговая Польши доначисляет налог исходя из рыночной цены $50/час. ТЦО требует, чтобы цены между связанными компаниями были такими же, как на свободном рынке (Arm's Length Principle). Нужно документально обосновать цены: сравнение с независимыми поставщиками, анализ функций и рисков. Без документации — доначисление налогов + штрафы. |
| 6 | B | Для сервисных подразделений без собственного риска рынка. |
| 7 | A | Справедливое распределение общих затрат бизнеса. |
| 8 | B | Деньги должны работать на всю группу, а не лежать в одном месте. |
| 9 | D | Государство не хочет отпускать прибыль без "выходного налога". |
| 10 | D | Плата за использование "мозгов" компании операционным звеном. |
| 11 | C | Процентный вычет — легальный способ налоговой экономии. |
| 12 | D | Экономия на масштабе за счет стандартизации работы. |
| 13 | B | Процесс сборки "пазла" из разных систем и валют. |
| 14 | B | Исключение двойного счета "внутренней" прибыли. |
| 15 | D | Риск изменения цены ресурсов в валюте исполнения. |
| 16 | D | Концепция ограниченной ответственности (Limited Liability). |
| 17 | D | Время "бумажных" компаний-невидимок прошло. |
| 18 | B | Ключ к эффективному движению капитала между странами. |
| 19 | A | Способ дотянуться до прибыли, спрятанной за границей. |
| 20 | D | Защитная документация на случай налогового спора. |
| 21 | D | Логическое обоснование: кто больше работает/рискует — тот больше получает. |
| 22 | A | Налог на "упущенную выгоду" страны при потере налогоплательщика. |
| 23 | B | Вызов для финансового директора при масштабировании. |
| 24 | C | Единые стандарты — залог прозрачности для акционеров. |
| 25 | D | Устойчивая модель, способная пережить проверки и кризисы. |
