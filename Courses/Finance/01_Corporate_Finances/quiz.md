## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Основная цель корпоративных финансов — максимизация стоимости компании для владельцев при управлении рисками и обеспечении финансовой устойчивости. |
| 2 | B | Финансы фокусируются на планировании будущего и принятии решений, бухгалтерия — на учёте и отчётности по прошлым операциям. |
| 3 | A | Валовая прибыль = Доходы - Прямые расходы = $100,000 - $70,000 = $30,000. |
| 4 | A | Валовая маржа = Валовая прибыль / Доходы × 100% = $60,000 / $200,000 × 100% = 30%. |
| 5 | B | Денежный поток в январе равен $0, так как деньги ещё не получены. Прибыль по учёту будет $50,000, но реальных денег нет. |
| 6 | C | Покупка нового офисного здания относится к инвестиционному денежному потоку, а не операционному. |
| 7 | B | Коэффициент текущей ликвидности = Текущие активы / Текущие обязательства = $150,000 / $100,000 = 1.5. |
| 8 | C | Коэффициент 0.8 меньше 1.0, что означает проблемы с ликвидностью — текущих активов недостаточно для покрытия обязательств. |
| 9 | B | ROA = Чистая прибыль / Средняя стоимость активов × 100% = $80,000 / $400,000 × 100% = 20%. |
| 10 | C | В сервисной IT-компании 60-80% расходов приходится на персонал, так как люди — основной актив. |
| 11 | A | Utilization Rate = Биллабл часы / Доступные часы × 100% = 120 / 160 × 100% = 75%. |
| 12 | C | Utilization Rate 92% находится в диапазоне 85-95%, что означает отличную загрузку, но возможна перегрузка сотрудников. |
| 13 | C | Bench Cost = Количество небиллабл сотрудников × Стоимость сотрудника = 4 × $8,000 = $32,000/месяц. |
| 14 | A | Contribution Margin = Доходы - Прямые расходы = $60,000 - $45,000 = $15,000. |
| 15 | B | Fixed Price модель предполагает фиксированную стоимость проекта независимо от фактически затраченного времени. |
| 16 | C | Ликвидный риск — это риск неспособности выполнить обязательства из-за недостатка денежных средств. |
| 17 | A | Коэффициент финансовой независимости = Собственный капитал / Активы = $300,000 / $600,000 = 0.5 (50%). |
| 18 | C | Коэффициент 25% означает высокую зависимость от заёмных средств (75% активов финансируется за счёт долгов), что создаёт высокий финансовый риск. |
| 19 | C | Увеличение сроков оплаты клиентам ухудшает денежные потоки, так как деньги поступают позже. Правильные действия — сокращать сроки оплаты от клиентов. |
| 20 | C | Бюджет компании включает прогноз доходов, расходов, денежных потоков и планирование персонала (headcount). |
| 21 | C | Days Sales Outstanding (DSO) показывает средний срок оплаты клиентами. |
| 22 | C | Операционная маржа 8% ниже типичного диапазона 15-30% для сервисных IT-компаний, что является признаком проблем с эффективностью. |
| 23 | B | Валовая прибыль = Доходы - Прямые расходы = $150,000 - $100,000 = $50,000. Операционные расходы не входят в расчёт валовой прибыли. |
| 24 | A | Прибыль до налогов = $200,000 - $150,000 = $50,000. Налоги = $50,000 × 20% = $10,000. Чистая прибыль = $50,000 - $10,000 = $40,000. |
| 25 | C | В сервисной IT-компании основной актив — это люди и их экспертиза, а не материальные активы. |
