## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | Сервисный бизнес — это продажа компетенций и времени людей для решения задач заказчика. |
| 2 | B | Time and Materials — основная коммерческая модель в IT-аутсорсинге. |
| 3 | A | Это прямая финансовая зависимость: сколько поработали, столько заработали. |
| 4 | C | В классическом T&M клиент платит за все время, необходимое для достижения цели, принимая риск на себя. |
| 5 | C | T&M позволяет гибко маневрировать в условиях неопределенности без переподписания контракта на каждый чих. |
| 6 | B | FP подразумевает жесткую фиксацию трех параметров (Scope, Time, Cost). |
| 7 | B | Любой перерасход времени при фиксированной цене ложится на плечи вендора, снижая его прибыль. |
| 8 | B | "Расползание рамок" — критическая проблема, когда клиент добавляет задачи, а бюджет остается прежним. |
| 9 | C | Без четкого Scope невозможно адекватно оценить стоимость Fixed Price проекта. |
| 10 | B | Это страховка от неизбежных неточностей при оценке сложных интеллектуальных задач. |
| 11 | C | Retainer обеспечивает "бронирование" ресурсов, создавая стабильный денежный поток. |
| 12 | C | Регулярные платежи (подписка на команду) легче всего прогнозировать в долгосроке. |
| 13 | B | Поскольку цена зафиксирована, каждый сэкономленный час работы — это чистая прибыль компании. |
| 14 | B | Это гибрид, сочетающий почасовую оплату и ограничение максимального бюджета. |
| 15 | B | Это позволяет клиенту контролировать бюджет ("не больше $X"), а вендору не брать на себя все риски плохой спецификации. |
| 16 | B | В FP вендор ВСЕГДА закладывает риски (padding), за которые клиент платит, даже если всё пошло идеально. |
| 17 | B | Фиксированная сумма в месяц позволяет компании легко планировать свои расходы и инвестиции. |
| 18 | B | Бонус за успех мотивирует команду работать на бизнес-результат клиента (например, конверсия или сроки). |
| 19 | B | Сервисный бизнес масштабируется "в лоб": больше заказов -> больше людей -> больше выручки. |
| 20 | B | Клиенту важно знать точную сумму затрат для своего бюджета, и FP это гарантирует. |
| 21 | B | GM = (60 - 35) / 60 = 25 / 60 = 41.6%. |
| 22 | B | Условия Fixed Price не меняются автоматически — компания обязана сдать работу за договорную сумму. |
| 23 | B | Устраняется конфликт по поводу "каждого часа", что позволяет сосредоточиться на качестве и партнерстве. |
| 24 | B | Это механизм мотивации вендора не затягивать проект ради лишних биллабл-часов. |
| 25 | B | Большинство проектов выходят за рамки бюджета из-за неописанных требований ("а сделайте еще это"). |
