## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Бюджет — это статическая цель, прогноз — динамическое обновление. **Пример**: Бюджет на год фиксируется в декабре: выручка $6M, расходы $5M, прибыль $1M. Это план-обязательство, по которому оцениваются KPI. Прогноз обновляется ежемесячно: в марте видим, что выручка отстаёт на 10% → прогноз на год снижается до $5.4M. Бюджет остаётся $6M (цель), но прогноз показывает реальность. Бюджет = "Куда идём", Прогноз = "Где реально будем". |
| 2 | C | Направление задается топ-менеджментом. **Top-down подход**: CEO говорит "Выручка $10M в следующем году". Команда разбивает на кварталы и проекты. Преимущество: стратегическое видение, амбициозные цели. Недостаток: может быть нереалистичным, команда не верит в цифры. Bottom-up: Команды планируют свои проекты, CFO суммирует. Преимущество: реалистично, команда верит. Недостаток: может быть консервативно. Лучший подход — комбинация: топ задаёт направление, команды детализируют. |
| 3 | A | Отсутствие "фильтра" потребностей со стороны стратегии. **Проблема Bottom-up**: Каждая команда просит ресурсы для своих проектов. Без стратегического фильтра получается "список желаний", а не план. Все хотят больше людей, больше бюджета. Нужен фильтр: "Это соответствует стратегии? Это приоритетно? Это окупится?" Без фильтра бюджет раздувается, ресурсы распыляются. Top-down подход решает эту проблему через стратегические приоритеты. |
| 4 | D | IT-бизнес — это прежде всего люди. **Структура расходов**: В IT-компании 60-80% расходов — это зарплаты и налоги на ФОТ. Ошибка в планировании найма — самая дорогая ошибка. Если наняли 10 лишних человек по $5k/месяц = $50k/месяц = $600k/год потерь. Если недонаняли — упущенная выгода от невыполненных проектов. Поэтому Headcount Planning — главный файл года для финансового директора. Каждый человек = $60k-100k/год затрат (зарплата + налоги + overhead). |
| 5 | B | Рекрутинг и адаптация — длительные процессы. **Таймлайн найма**: Поиск кандидата (1-2 месяца) → Интервью и оффер (2 недели) → Оформление (2 недели) → Онбординг (1 месяц) → Первый проект (1 месяц адаптации) = 4-5 месяцев от начала поиска до полной продуктивности. Если планируете выручку на март, нанимать нужно в ноябре-декабре. Это критично для Capacity Planning. Нельзя нанять людей "на завтра" — процесс долгий и дорогой. |
| 6 | D | Стыковка возможностей производства и аппетитов продаж. |
| 7 | D | Люди без работы при сохранении затрат на них. |
| 8 | B | Радикальный способ очистки бюджета от ненужных трат. |
| 9 | A | Инерционное планирование мешает развитию. |
| 10 | A | Гибкий метод, устраняющий эффект "устаревания" плана. |
| 11 | C | Базовый отчет для управленческого контроля. |
| 12 | B | Проблема в цене продажи, а не в количестве работы. |
| 13 | C | Продано меньше времени, чем планировалось. |
| 14 | D | Готовность к любому повороту событий. |
| 15 | B | Гибкий метод управления численностью без резких сокращений. |
| 16 | C | Математическое ожидание выручки. |
| 17 | C | Страховка от мелких ошибок в расчетах. |
| 18 | B | Психология управления и реалистичность обещаний. |
| 19 | D | В кеш-флоу учитываются только реальные движения денег. |
| 20 | B | Критично для международных компаний. |
| 21 | A | Крупные капитальные вложения, создающие активы. |
| 22 | B | Стандартный период финансового цикла. |
| 23 | A | Ответственность должна быть персональной. |
| 24 | A | Основа прибыльности сервисного бизнеса. |
| 25 | D | Бюджет — это инструмент достижения стратегии. |
