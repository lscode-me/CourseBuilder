| 7 | C | Write XOR Execute — память либо записываема, либо исполняема |
| 8 | A | KARL (Kernel Address Randomized Link) — уникальное ядро при каждой загрузке |
| 9 | D | Privilege separation — разделение привилегий между частями программы |
| 10 | B | Нарушение pledge вызывает SIGABRT и завершение процесса |
| 11 | B | unveil(NULL, NULL) блокирует добавление новых путей |
| 12 | B | /var/log/authlog содержит логи аутентификации в OpenBSD |
| 13 | B | mtree проверяет целостность файлов по спецификации |
| 14 | C | ASLR — рандомизация адресного пространства |
| 15 | D | chroot изолирует процесс в ограниченной части файловой системы |
| 16 | B | Ed25519 — современный и безопасный тип ключа |
| 17 | B | securelevel ограничивает возможности даже для root |
| 18 | D | mtree проверяет целостность файлов по спецификации |
