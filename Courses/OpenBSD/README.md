# OpenBSD Course

Курс для тех, кто хочет освоить операционную систему OpenBSD — от установки и базовых команд до продвинутого системного администрирования и настройки безопасности. OpenBSD славится своим фокусом на безопасности, качеством кода и отличной документацией.

---

## 📋 Требования

- **Железо**: x86_64 или arm64 (физическая машина или виртуальная)

- **RAM**: минимум 512 MB (рекомендуется 2 GB+)

- **Диск**: минимум 5 GB (рекомендуется 20 GB+)

- **Сеть**: доступ к интернету для загрузки образа и пакетов

- **Базовые знания**: опыт работы с командной строкой Unix/Linux

## 🚀 Как использовать курс

### 1. Подготовка окружения

**Вариант A: Виртуальная машина (рекомендуется для начала)**

```bash
# Скачайте установочный образ с официального сайта
# https://www.openbsd.org/faq/faq4.html

# Для VirtualBox:
VBoxManage createvm --name "OpenBSD" --ostype OpenBSD_64 --register
VBoxManage modifyvm "OpenBSD" --memory 2048 --cpus 2

# Для QEMU:

qemu-img create -f qcow2 openbsd.qcow2 20G
qemu-system-x86_64 -enable-kvm -m 2048 -cdrom install74.iso -hda openbsd.qcow2
```

**Вариант B: Физический сервер**

Загрузите ISO с https://www.openbsd.org и создайте загрузочный USB.

### 2. Изучение материала

1. Читайте лекции последовательно
2. Выполняйте все примеры на реальной системе
3. Используйте `man` страницы — документация OpenBSD великолепна
4. Выполняйте практические задания в конце каждого модуля

### 3. Практика

После каждого модуля:

- **Practice Ideas** — задачи для закрепления

- **Going Deeper** — продвинутые темы для самостоятельного изучения

## ⚡ Ключевые отличия OpenBSD

| Особенность | OpenBSD | Linux |
|-------------|---------|-------|
| Пакетный менеджер | pkg_add | apt/dnf/pacman |
| Инит-система | rc.d (простая) | systemd/openrc |
| Файрвол | PF (встроен) | iptables/nftables |
| Sudo альтернатива | doas | sudo |
| Документация | man pages | wiki/forums |
| Релизы | 2 раза в год | варьируется |
