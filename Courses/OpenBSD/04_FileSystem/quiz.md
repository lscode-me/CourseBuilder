## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | FFS2 (Fast File System) — стандартная файловая система OpenBSD |
| 2 | B | Раздел 'b' традиционно используется для swap в BSD системах |
| 3 | B | Раздел 'c' представляет весь диск и используется для операций с диском целиком |
| 4 | D | DUID (Disk UID) — уникальный идентификатор диска, не меняется при смене порта |
| 5 | D | nosuid игнорирует setuid/setgid биты, повышая безопасность |
| 6 | C | setuid позволяет выполнять программу от имени владельца файла (напр. passwd от root) |
| 7 | B | sticky bit на каталоге позволяет удалять файлы только их владельцам |
| 8 | D | 666 (права по умолчанию) - 022 (umask) = 644 (rw-r--r--) |
| 9 | B | df (disk free) показывает использование разделов, du — размер каталогов |
| 10 | D | softraid предоставляет программный RAID и шифрование дисков |
| 11 | C | fsck нужно запускать на размонтированной FS, иначе можно повредить данные |
| 12 | B | /etc/fstab содержит настройки автоматического монтирования |
| 13 | B | schg (system change) делает файл неизменяемым, снять может только root в single-user |
| 14 | C | /usr/local — место установки пакетов через pkg_add |
| 15 | C | /usr/local часто требует wxallowed для работы некоторых программ (напр. Firefox) |
| 16 | A | newfs создаёт новую файловую систему FFS на разделе |
| 17 | B | mount_mfs создаёт файловую систему в оперативной памяти |
| 18 | C | disklabel управляет BSD разделами (a-p) внутри диска |
| 19 | C | /tmp монтируется как MFS (memory filesystem) по умолчанию |
| 20 | C | mount -u обновляет опции монтирования без размонтирования |
