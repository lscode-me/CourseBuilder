## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | /etc/master.passwd содержит зашифрованные пароли, /etc/passwd — только * |
| 2 | D | Только члены группы wheel могут использовать doas и su для получения root |
| 3 | A | Флаг -m (make home) создаёт домашний каталог |
| 4 | B | /etc/doas.conf — единственный файл конфигурации doas |
| 5 | A | bcrypt — OpenBSD первой внедрила этот безопасный алгоритм |
| 6 | C | login.conf определяет классы входа с лимитами ресурсов и параметрами |
| 7 | C | Системные пользователи начинаются с _ (например, _sshd, _ntp) |
| 8 | C | persist кеширует аутентификацию на 5 минут для удобства |
| 9 | B | usermod -Z блокирует аккаунт, также можно passwd -l |
| 10 | D | /etc/skel содержит шаблонные файлы (.profile, .kshrc и т.д.) |
| 11 | D | id показывает UID, GID и список групп текущего или указанного пользователя |
| 12 | A | groupadd создаёт новую группу в OpenBSD |
| 13 | B | nopass позволяет выполнять команду без запроса пароля |
| 14 | A | Флаг -r (remove) удаляет домашний каталог и почту пользователя |
| 15 | A | ulimit -a показывает все текущие лимиты оболочки |
| 16 | C | vipw безопасно редактирует /etc/master.passwd с блокировкой |
| 17 | D | chpass позволяет изменять shell, GECOS и другую информацию |
| 18 | C | Системные пользователи начинаются с _ (напр. _sshd) |
| 19 | C | default — класс по умолчанию в login.conf |
| 20 | B | nopass опасен для интерактивных команд с высокими привилегиями |
