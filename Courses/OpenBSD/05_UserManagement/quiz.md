## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | /etc/master.passwd содержит зашифрованные пароли, /etc/passwd — только * |
| 2 | A | Только члены группы wheel могут использовать doas и su для получения root |
| 3 | B | Флаг -m (make home) создаёт домашний каталог |
| 4 | D | /etc/doas.conf — единственный файл конфигурации doas |
| 5 | D | bcrypt — OpenBSD первой внедрила этот безопасный алгоритм |
| 6 | D | login.conf определяет классы входа с лимитами ресурсов и параметрами |
| 7 | D | Системные пользователи начинаются с _ (например, _sshd, _ntp) |
| 8 | B | persist кеширует аутентификацию на 5 минут для удобства |
| 9 | C | usermod -Z блокирует аккаунт, также можно passwd -l |
| 10 | D | /etc/skel содержит шаблонные файлы (.profile, .kshrc и т.д.) |
| 11 | B | id показывает UID, GID и список групп текущего или указанного пользователя |
| 12 | B | groupadd создаёт новую группу в OpenBSD |
| 13 | A | nopass позволяет выполнять команду без запроса пароля |
| 14 | D | Флаг -r (remove) удаляет домашний каталог и почту пользователя |
| 15 | C | ulimit -a показывает все текущие лимиты оболочки |
| 16 | A | vipw безопасно редактирует /etc/master.passwd с блокировкой |
| 17 | A | chpass позволяет изменять shell, GECOS и другую информацию |
| 18 | B | Системные пользователи начинаются с _ (напр. _sshd) |
| 19 | B | default — класс по умолчанию в login.conf |
| 20 | B | nopass опасен для интерактивных команд с высокими привилегиями |
