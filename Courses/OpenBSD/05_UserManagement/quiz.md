## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | /etc/master.passwd содержит зашифрованные пароли, /etc/passwd — только * |
| 2 | A | Только члены группы wheel могут использовать doas и su для получения root |
| 3 | C | Флаг -m (make home) создаёт домашний каталог |
| 4 | B | /etc/doas.conf — единственный файл конфигурации doas |
| 5 | A | bcrypt — OpenBSD первой внедрила этот безопасный алгоритм |
| 6 | C | login.conf определяет классы входа с лимитами ресурсов и параметрами |
| 7 | A | Системные пользователи начинаются с _ (например, _sshd, _ntp) |
| 8 | D | persist кеширует аутентификацию на 5 минут для удобства |
| 9 | A | usermod -Z блокирует аккаунт, также можно passwd -l |
| 10 | A | /etc/skel содержит шаблонные файлы (.profile, .kshrc и т.д.) |
| 11 | A | id показывает UID, GID и список групп текущего или указанного пользователя |
| 12 | B | groupadd создаёт новую группу в OpenBSD |
| 13 | C | nopass позволяет выполнять команду без запроса пароля |
| 14 | A | Флаг -r (remove) удаляет домашний каталог и почту пользователя |
| 15 | B | ulimit -a показывает все текущие лимиты оболочки |
