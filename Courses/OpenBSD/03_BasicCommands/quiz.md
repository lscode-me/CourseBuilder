## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | OpenBSD использует ksh (Korn Shell) как оболочку по умолчанию |
| 2 | B | `cd ~` или просто `cd` без аргументов возвращает в домашний каталог |
| 3 | B | Буква 'd' означает directory (каталог), '-' означает обычный файл |
| 4 | C | rwx=7, r-x=5, r-x=5, итого 755 |
| 5 | B | И `man -k` и `apropos` ищут по ключевым словам в описаниях man-страниц |
| 6 | C | Флаг -i (case insensitive) игнорирует регистр при поиске |
| 7 | C | >> добавляет в конец файла, > перезаписывает файл |
| 8 | B | SIGKILL (9) принудительно завершает процесс, его нельзя перехватить |
| 9 | B | `find /home -type f -name "*.txt"` ищет файлы с расширением .txt |
| 10 | D | `echo $PATH` выводит значение переменной, $ указывает на переменную |
| 11 | A | Секция 5 содержит форматы файлов и конфигурации |
| 12 | B | u+x добавляет (+) право на выполнение (x) для владельца (u=user) |
| 13 | A | wc -l подсчитывает количество строк (lines) |
| 14 | A | Флаг 'g' (global) заменяет все вхождения, без него только первое |
| 15 | D | & в конце команды запускает её в фоновом режиме |
| 16 | C | type показывает тип команды (builtin, alias, external command) |
| 17 | D | ksh имеет встроенную поддержку vi и emacs стилей редактирования |
| 18 | D | jobs показывает фоновые задания текущей shell сессии |
| 19 | B | В ksh команда r или fc -e - повторяет последнюю команду |
| 20 | C | tee копирует stdin в файл и одновременно выводит в stdout |
