## 1. What Is C2 Really?

### 1.1 The CEFR Definition

The Common European Framework describes C2 as:

> "Can understand with ease virtually everything heard or read. Can summarise information from different spoken and written sources, reconstructing arguments and accounts in a coherent presentation. Can express him/herself spontaneously, very fluently and precisely, **differentiating finer shades of meaning** even in more complex situations."

Ключевые слова: **"finer shades of meaning"** — тонкие оттенки смысла.

### 1.2 C2 Grammar: What It Actually Means

На C2 речь идёт не о знании правил — вы их уже знаете. Речь о:

**1. Appropriate Choice (уместный выбор)**
```
"Can I see you tomorrow?"    — OK
"Could I see you tomorrow?"  — more tentative  
"I was wondering if I might see you tomorrow?" — very polite

C1 knows all three. C2 knows WHEN to use which.
```

**2. Natural Collocation (естественная сочетаемость)**
```
C1: "She was very angry."
C2: "She was absolutely furious." / "She was seething."

C1: "He explained it very well."
C2: "He explained it beautifully." / "He laid it out clearly."
```

**3. Stylistic Flexibility (стилистическая гибкость)**
```
Casual:   "So basically, he just kind of went off on one."
Neutral:  "He started complaining loudly."
Formal:   "He proceeded to voice his displeasure at some length."
Academic: "The subject exhibited signs of verbal escalation."

C2 can produce ALL of these appropriately.
```

**4. Pragmatic Competence (прагматическая компетенция)**
```
"Your presentation was interesting."
C1 hears: compliment
C2 hears: polite deflection (it wasn't very good)

"We should do lunch sometime."
C1 hears: invitation
C2 hears: social formula (probably won't happen)
```

### 1.3 The "Last Mile" Problem

The gap from C1 to C2 is paradoxically the **hardest** part of language learning:

```
A1 → A2: Obvious progress, quick wins
A2 → B1: New structures, noticeable improvement
B1 → B2: Major leap, academic English unlocks
B2 → C1: Refinement, fewer errors

C1 → C2: "The last mile"
- Progress feels slow
- Errors are subtle
- Feedback is rare
- Native speakers don't correct you
- You can communicate everything — так зачем стараться?
```

## 2. C1 vs C2: Concrete Differences

### 2.1 Grammar Accuracy

| Feature | C1 | C2 |
|---------|----|----|
| Article errors | Occasional (1-2 per page) | Rare (1 per 5 pages) |
| Preposition errors | Sometimes | Almost never |
| Tense choice | Usually correct | Always appropriate |
| Complex structures | Can use | Uses naturally |
| Collocation | Acceptable | Native-like |

### 2.2 Stylistic Range

**C1 Writing:**
```
The government should take action on climate change. This is important 
because it affects everyone. Many scientists agree that we need to 
reduce emissions. If we don't act now, the situation will get worse.
```
*Correct, clear, but somewhat flat.*

**C2 Writing:**
```
The case for governmental intervention on climate change has never been 
more compelling. With the scientific consensus now beyond dispute, the 
question is no longer whether to act, but how decisively. Inaction, 
as a growing body of evidence suggests, carries risks that far outweigh 
the costs of meaningful policy reform.
```
*More varied structure, better hedging, more sophisticated vocabulary.*

### 2.3 Specific Markers

**C2 speakers typically:**

1. **Use hedging naturally:**
   ```
   "It might arguably be the case that..."
   "There's a sense in which..."
   "One could potentially argue..."
   ```

2. **Employ stylistic inversion:**
   ```
   "Not only did he fail to respond, but he actually made things worse."
   "Rarely have I encountered such a clear case of..."
   "Little did she know that..."
   ```

3. **Use advanced cohesion:**
   ```
   "The former approach... the latter..."
   "The aforementioned study..."
   "This notwithstanding..."
   ```

4. **Manipulate register freely:**
   ```
   Academic → Conversational → Journalistic → Literary
   ```

5. **Understand pragmatic meaning:**
   ```
   "That's one way of looking at it." = I disagree
   "I hear what you're saying." = I disagree
   "With respect..." = I'm about to disagree
   ```

## 3. The Russian C1 Profile

### 3.1 What Russian Speakers Typically Have at C1

**Strengths:**
- Wide vocabulary
- Good reading comprehension
- Understanding of complex grammar
- Academic writing skills
- Strong analytical ability

**Typical remaining issues:**
- Article subtleties (especially zero article)
- Preposition nuances (depend on vs from)
- Hedging and politeness (too direct)
- Collocation "misses" (do a mistake)
- Pragmatic misfires (sounds rude/abrupt)
- Written vs spoken grammar confusion

### 3.2 Fossilized Errors

By C1, some errors have become **fossilized** — automatic and resistant to change:

**Common fossilized patterns for Russian speakers:**

```
1. "I am agree" — still slips out
2. "It depends from" — automatic translation
3. "Feel myself" — reflexive transfer
4. Too much "the" before abstracts — "the life", "the love"
5. Direct requests — "Give me..." instead of "Could I have..."
```

### 3.3 The "Glass Ceiling"

Many Russian speakers hit a glass ceiling at C1 because:

1. **Communication works** — there's no pressure to improve
2. **Errors don't cause problems** — people understand you
3. **Feedback stops** — native speakers don't correct fluent speakers
4. **Russian patterns are automatic** — hard to override
5. **Subtle differences feel unimportant** — "what's the difference?"

## 4. Self-Diagnosis: Where Are You?

### 4.1 Article Subtleties Test

Choose the better option:

**1.** ___ science has made great progress.
- a) The science
- b) Science

**2.** ___ English spoken in Australia is different.
- a) The English
- b) English

**3.** ___ homeless need support.
- a) The homeless
- b) Homeless

**4.** In ___ general, I agree.
- a) the general
- b) general

**5.** ___ economics is a social science.
- a) The economics
- b) Economics

<details>
<summary>Answers</summary>

1. b) Science (generic)
2. a) The English (specified by "spoken in Australia")
3. a) The homeless (adjective as noun = the + adj)
4. b) general (fixed phrase: in general)
5. b) Economics (academic subject, generic)

If you got all 5: You're ready for C2 article subtleties.
If you got 3-4: Review article patterns carefully.
If you got <3: Consider reviewing C1 materials first.
</details>

### 4.2 Hedging and Diplomacy Test

Rate each response: Too Direct / Appropriate / Too Indirect

**Situation:** A colleague asks for feedback on their presentation.

A) "Your presentation had several problems."
B) "There might be a few areas worth looking at again."
C) "Well, I mean, it's not that it was bad or anything, but maybe, possibly, in some ways..."

<details>
<summary>Analysis</summary>

A) Too Direct — sounds harsh in English professional context
B) Appropriate — hedged but clear
C) Too Indirect — loses confidence, sounds unsure

Russian speakers typically produce (A). Native speakers typically produce (B).
</details>

### 4.3 Register Test

Which sentence fits **academic writing**?

A) "Scientists have found out that the drug works."
B) "The efficacy of the compound has been empirically demonstrated."
C) "They discovered the medicine does the job."

<details>
<summary>Answer</summary>

B) is appropriate for academic writing.
A) is neutral but too informal ("found out").
C) is conversational/informal ("does the job").
</details>

### 4.4 Pragmatic Meaning Test

What does the speaker REALLY mean?

**1.** "That's an interesting approach." (said by a boss about your work)
- a) They're impressed
- b) They have doubts
- c) They're neutral

**2.** "I'll bear that in mind." (in response to a suggestion)
- a) They'll definitely do it
- b) They probably won't do it
- c) They need time to decide

**3.** "With the greatest respect..." (beginning of a statement)
- a) They respect you highly
- b) They're about to disagree
- c) They're being sincere

<details>
<summary>Answers</summary>

1. b) They have doubts — "interesting" is often damning with faint praise
2. b) They probably won't — polite dismissal
3. b) They're about to disagree — formulaic hedge before criticism

If you got these wrong, focus on Modules 05 and 10 (Modals and Pragmatics).
</details>

## 5. Course Methodology

### 5.1 The Four Pillars

**1. NOTICE — Замечать**
```
Reading authentic texts and noticing:
- Why did the writer choose this structure?
- How does this differ from what I would write?
- What's the effect of this choice?
```

**2. DISCRIMINATE — Различать**
```
Before producing, learn to HEAR/SEE the difference:
- Which sounds more natural?
- Which is more formal?
- Which is more hedged?
```

**3. ANALYSE — Анализировать**
```
Understand WHY something works:
- Corpus evidence
- Pragmatic principles
- Register requirements
```

**4. PRODUCE — Производить**
```
Finally, practice producing:
- With feedback
- In appropriate contexts
- With conscious attention
```

### 5.2 The Receptive-Productive Gap

At C1+, your **receptive** knowledge (what you understand) is much greater than your **productive** knowledge (what you can produce).

```
What you understand when reading:
- Stylistic inversion
- Complex hedging
- Subtle irony
- Register shifts

What you typically produce:
- Simpler structures
- Less hedging
- More direct style
- Mixed registers
```

**Goal:** Close this gap through deliberate practice.

### 5.3 Working with Corpora

Throughout this course, we use corpus data to show **what native speakers actually do** (not what grammar books say they should do).

**Key corpora:**
- **COCA** (Corpus of Contemporary American English) — 1 billion words
- **BNC** (British National Corpus) — 100 million words
- **BAWE** (British Academic Written English) — student essays

**Example corpus insight:**

```
"Very" + adjective patterns (COCA data):

very important   — 234,567 hits ✓
very crucial     — 789 hits    (crucial is already "very")
very essential   — 432 hits    (essential is absolute)

Native speakers rarely say "very crucial" or "very essential".
Non-native speakers often do.
```

## 6. Key Concepts for This Course

### 6.1 Grammaticality vs Acceptability vs Naturalness

```
GRAMMATICAL = follows the rules
ACCEPTABLE = native speakers use it
NATURAL = what native speakers would spontaneously say

"It is I who am responsible."
- Grammatical: ✓
- Acceptable: ✓ (formal)
- Natural: ✗ (most people say "It's me who's responsible")

"I feel myself tired."
- Grammatical: ? (debatable)
- Acceptable: ✗
- Natural: ✗
```

### 6.2 Marked vs Unmarked Choices

**UNMARKED** = default, neutral, expected
**MARKED** = special, draws attention, has extra meaning

```
"I have never seen such a mess." — unmarked (normal word order)
"Never have I seen such a mess." — marked (inversion = emphasis)

Using marked forms without reason sounds "off".
Using only unmarked forms sounds flat.
```

### 6.3 Prescriptive vs Descriptive Grammar

**PRESCRIPTIVE:** What rules say you should do
**DESCRIPTIVE:** What people actually do

```
Prescriptive: "Whom did you see?"
Descriptive:  "Who did you see?" (what most people say)

This course focuses on DESCRIPTIVE grammar with awareness of prescriptive norms.
```

### 6.4 Register Continuum

```
FROZEN        │ Legal documents, prayers, pledges
              │ "Wherefore art thou Romeo?"
              │
FORMAL        │ Academic papers, business correspondence
              │ "We would like to draw your attention to..."
              │
CONSULTATIVE  │ Professional discussions, lectures
              │ "Let me explain how this works."
              │
CASUAL        │ Conversations with friends
              │ "So basically what happened was..."
              │
INTIMATE      │ Close relationships, private language
              │ "Wanna grab coffee?"
```

C2 means moving **freely** along this continuum.

## 8. Study Recommendations

### 8.1 How to Use This Course

**1. Don't skip modules**
```
Each module builds on previous concepts.
```

**2. Do the quizzes honestly**
```
Check your weak spots. Return to them.
```

**3. Read native texts actively**
```
After each module, find examples in real texts.
Notice how native speakers use the structures.
```

**4. Get feedback**
```
Writing without feedback won't fix errors.
Find a teacher, tutor, or language partner.
```

**5. Be patient**
```
C1 → C2 is slow. Months, not weeks.
But the changes are permanent.
```

### 8.2 Recommended External Practice

**Reading:**
- Quality journalism (The Economist, The Atlantic, The Guardian long reads)
- Academic papers in your field
- Modern literary fiction

**Listening:**
- Podcasts aimed at native speakers (not learner podcasts)
- BBC Radio 4, NPR
- Academic lectures

**Writing:**
- Keep a journal in English
- Write essay responses to articles you read
- Get feedback from native speakers or advanced teachers

**Speaking:**
- Record yourself and analyse
- Work with a conversation partner on specific points
- Practice the specific structures from each module

## 💡 Key Takeaways

- **C2 is about choices, not rules**: You know the rules — now learn when to apply them
- **Native-like ≠ perfect**: It means natural, appropriate, and flexible
- **Russian interference persists**: Some patterns are deeply automatic
- **Receptive > Productive**: You understand more than you produce — close the gap
- **Corpora are your friend**: See what native speakers actually write/say
