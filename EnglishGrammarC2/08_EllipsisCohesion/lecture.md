## 1. What Is Cohesion?

### 1.1 Definition

**Cohesion** = the linguistic ties that connect sentences and create unified text.

Without cohesion:
```
"The researchers conducted a study. A study found significant results. 
Significant results surprised the researchers."
(Repetitive, awkward)
```

With cohesion:
```
"The researchers conducted a study. It found significant results, 
which surprised them."
(Flowing, connected)
```

### 1.2 Types of Cohesive Devices

| Device | Example |
|--------|---------|
| **Reference** | "The book... it..." (pronouns) |
| **Substitution** | "I'll take the blue one." |
| **Ellipsis** | "She can swim and he can [swim] too." |
| **Conjunction** | "however, therefore, moreover" |
| **Lexical cohesion** | synonyms, collocations, repetition |

## 2. Ellipsis

### 2.1 What Is Ellipsis?

**Ellipsis** = omitting words that are understood from context:

```
Full: "She can speak French and he can speak French too."
Ellipsis: "She can speak French and he can too."
(The repeated "speak French" is omitted)
```

### 2.2 Types of Ellipsis

**Nominal ellipsis** (noun omitted):
```
"Which car do you want?" — "I'll take the red [car]."
"These cookies are good, but those [cookies] are better."
```

**Verbal ellipsis** (verb phrase omitted):
```
"Can you swim?" — "Yes, I can [swim]."
"She said she would help, and she did [help]."
"He hasn't finished, but she has [finished]."
```

**Clausal ellipsis** (whole clause omitted):
```
"Are you coming?" — "I hope so." (= I hope I am coming)
"Will it rain?" — "I don't think so." (= I don't think it will rain)
```

### 2.3 Ellipsis in Coordination

When clauses are joined by **and, but, or**, identical elements can be omitted:

```
"She bought bread and [she bought] butter."
"He can sing and [he can] dance."
"I wanted to help but couldn't [help]."
```

### 2.4 Gapping

In comparative structures, the verb is often "gapped":

```
"She plays tennis and he [plays] golf."
"Mary ordered coffee and John [ordered] tea."
```

### 2.5 Sluicing

Reducing a question to just the wh-word:

```
"Someone called." — "Who [called]?"
"I found something." — "What [did you find]?"
```

## 3. Substitution

### 3.1 ONE/ONES

Substitute for **nouns**:

```
"I don't like this shirt. Show me another one."
"The old computers are slow. We need new ones."
"Which book?" — "The one on the table."
```

**Rules:**
- ONE replaces singular countable nouns
- ONES replaces plural countable nouns
- Cannot replace uncountable nouns

```
✓ "I like this car. That one is nice too."
✗ "I bought some rice. Do you have one?" 
✓ "I bought some rice. Do you have any?"
```

### 3.2 DO/DOES/DID

Substitute for **verb phrases**:

```
"She speaks French better than I do."
"He plays guitar, and so does his brother."
"I promised I would help, and I did."
```

### 3.3 SO and NOT

Substitute for **clauses** after certain verbs:

**Verbs + SO/NOT:**
```
think, believe, hope, expect, suppose, be afraid, imagine, guess
```

**Examples:**
```
"Will it rain?" — "I think so." / "I don't think so."
"Is she coming?" — "I hope so." / "I hope not."
"Have they arrived?" — "I believe so." / "I believe not." (formal)
"Did you win?" — "I'm afraid not."
```

**Note:** Some verbs use different patterns:
```
"I don't think so" (more common than "I think not")
"I hope not" (not "I don't hope so")
```

### 3.4 SO with Inversion

**So + auxiliary + subject** = "also":

```
"She's tall." — "So is her brother." (= Her brother is also tall)
"I can swim." — "So can I." (= I can also swim)
"They've been to Paris." — "So have we."
```

**Neither/Nor** for negative:
```
"I can't sing." — "Neither can I." / "Nor can I."
"She hasn't finished." — "Neither has he."
```

## 4. Reference

### 4.1 Pronouns

Pronouns create cohesion by **referring back**:

```
"John arrived late. He had missed the bus."
"The researchers published their findings. They were significant."
```

### 4.2 Demonstratives

**This/these** (close), **that/those** (distant):

```
"I have an idea. This might work: we could..."
"She made several suggestions. These were all rejected."
"He told me a story. That was thirty years ago."
```

### 4.3 The... Noun (Lexical Reference)

Repeating with **THE + synonymous noun**:

```
"A new study was published. The research focused on..."
"The government announced tax cuts. The measures were criticized."
"She gave a speech. The address lasted two hours."
```

### 4.4 Such

**Such** refers back to a description:

```
"The results were surprising. Such findings are rare."
"He showed great courage. Such bravery should be recognized."
```

## 5. Conjunction and Discourse Markers

### 5.1 Adding Information

```
moreover, furthermore, in addition, besides, also
"The policy is ineffective. Moreover, it is expensive."
```

### 5.2 Contrasting

```
however, nevertheless, nonetheless, on the other hand, yet, but
"The data are inconclusive. However, some patterns emerge."
```

### 5.3 Cause/Result

```
therefore, consequently, thus, hence, as a result
"Costs increased. Consequently, prices rose."
```

### 5.4 Exemplifying

```
for example, for instance, such as, namely
"Several factors are involved, for example, age and income."
```

### 5.5 Sequencing

```
firstly, secondly, finally, next, then, subsequently
"First, we collected data. Next, we analyzed it."
```

### 5.6 Summarizing

```
in conclusion, to sum up, overall, in brief
"In conclusion, the evidence supports the hypothesis."
```

## 6. Information Structure

### 6.1 Given Before New

**Given** (known) information typically comes **before** **new** information:

```
Given → New:
"The government [given] announced new policies [new]."
"These policies [given from last sentence] aim to reduce inequality [new]."
```

### 6.2 Theme and Rheme

**Theme** = starting point (often given)
**Rheme** = comment, new information

```
Theme:      Rheme:
"Scientists have discovered a new planet."
"The planet   is similar to Earth."
"This discovery has excited astronomers."
```

### 6.3 End Weight

Put **heavy/long** elements at the **end**:

```
❌ "That he would eventually succeed was obvious to everyone."
✓ "It was obvious to everyone that he would eventually succeed."
```

### 6.4 End Focus

**Important new** information comes at the **end**:

```
"She gave the book to John." (focus: John)
"She gave John the book." (focus: the book)
```

## 7. Creating Textual Flow

### 7.1 Topic Chains

Maintain the **same topic** across sentences:

```
Good flow (consistent topic):
"The economy grew last year. It expanded by 3%, driven by exports. 
This growth is expected to continue."

Poor flow (shifting topics):
"The economy grew last year. Exports drove growth. 
3% was the expansion rate."
```

### 7.2 Linking Sentences

Use **transition** devices at sentence beginnings:

```
"The results were unexpected. However, they support the hypothesis."
"Several factors contribute to this. First, economic conditions..."
"This pattern is common. Such trends typically indicate..."
```

### 7.3 Known-New Bridges

Each sentence should **connect** to the previous:

```
"Researchers conducted a study [new → known].
The study [now known] examined stress levels [new → known].
These levels [now known] were measured weekly [new]."
```

## 8. Russian Speakers' Issues

### 8.1 Over-Repetition

Russian tolerates more repetition. English prefers substitution:

```
❌ "I bought a book. The book is interesting. I will read the book tonight."
✓ "I bought a book. It's interesting, and I'll read it tonight."
```

### 8.2 Missing Ellipsis

```
❌ "She can swim and he can swim too."
✓ "She can swim and he can too."

❌ "I want to go, but I'm not able to go."
✓ "I want to go, but I'm not able to."
```

### 8.3 Pronoun Reference Confusion

Russian allows more distant pronoun reference:

```
❌ "John saw Peter when he was leaving." (Who was leaving?)
✓ "John saw Peter who was leaving." (Clear: Peter)
✓ "John, who was leaving, saw Peter." (Clear: John)
```

### 8.4 Missing Discourse Markers

Russian academic style uses fewer explicit markers:

```
❌ "The results were significant. They support the hypothesis."
✓ "The results were significant. Moreover, they support the hypothesis."
```

## 9. Advanced Patterns

### 9.1 Comparative Ellipsis

```
"She works harder than I [work]."
"He knows more than he lets on [that he knows]."
```

### 9.2 Pseudo-Ellipsis

Some constructions **look like** ellipsis but aren't:

```
"I can if I want to [try]." 
(Not really ellipsis—"to" marks an understood infinitive)

"I told her not to [do it]."
(The infinitive complement is understood)
```

### 9.3 "Same" and "Different"

```
"I'll have the same [thing you're having]."
"She chose a different approach [from the one she used before]."
```

## 10. Practice: Creating Cohesion

### 10.1 Transform with Ellipsis

```
Original: "She can speak French and he can speak French."
Better: "She can speak French and he can too."
         "She can speak French and so can he."

Original: "I wanted to help but I wasn't able to help."
Better: "I wanted to help but wasn't able to."
```

### 10.2 Add Appropriate Substitution

```
Original: "I don't like this shirt. Show me another shirt."
Better: "I don't like this shirt. Show me another one."

Original: "She swims well." "Her brother swims well."
Better: "She swims well." "So does her brother."
```

### 10.3 Create Flow

```
Choppy:
"The study examined climate change. Climate change affects agriculture. 
Agriculture is important for food security."

Flowing:
"The study examined climate change and its effects on agriculture, 
a sector of critical importance for food security."

OR:
"The study examined climate change. This phenomenon affects agriculture 
significantly, making it a matter of food security."
```

---

## 💡 Key Takeaways

- **Ellipsis** omits repeated information: "She can sing and he can too"
- **Substitution** replaces nouns (one/ones) and verbs (do/so)
- **Reference** (pronouns, demonstratives) creates backward links
- **Given-new** structure: known information before new
- **Discourse markers** signal logical relationships
- **Russian speakers**: Avoid over-repetition; use more substitution
