## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | OpenBSD использует ksh (Korn Shell) как оболочку по умолчанию |
| 2 | B | `cd ~` или просто `cd` без аргументов возвращает в домашний каталог |
| 3 | A | Буква 'd' означает directory (каталог), '-' означает обычный файл |
| 4 | B | rwx=7, r-x=5, r-x=5, итого 755 |
| 5 | A | И `man -k` и `apropos` ищут по ключевым словам в описаниях man-страниц |
| 6 | A | Флаг -i (case insensitive) игнорирует регистр при поиске |
| 7 | A | >> добавляет в конец файла, > перезаписывает файл |
| 8 | A | SIGKILL (9) принудительно завершает процесс, его нельзя перехватить |
| 9 | A | `find /home -type f -name "*.txt"` ищет файлы с расширением .txt |
| 10 | B | `echo $PATH` выводит значение переменной, $ указывает на переменную |
| 11 | A | Секция 5 содержит форматы файлов и конфигурации |
| 12 | A | u+x добавляет (+) право на выполнение (x) для владельца (u=user) |
| 13 | A | wc -l подсчитывает количество строк (lines) |
| 14 | D | Флаг 'g' (global) заменяет все вхождения, без него только первое |
| 15 | A | & в конце команды запускает её в фоновом режиме |
