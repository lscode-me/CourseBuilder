## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | pledge() ограничивает набор системных вызовов, которые может использовать процесс |
| 2 | B | unveil() ограничивает, какие пути файловой системы видит процесс |
| 3 | C | inet — категория для IPv4/IPv6 сетевых операций |
| 4 | C | Securelevel 1 — стандартный в multi-user режиме |
| 5 | C | Securelevel можно только повышать, понизить — только через single-user |
| 6 | C | schg (system change) делает файл неизменяемым даже для root |
| 7 | B | Write XOR Execute — память либо записываема, либо исполняема |
| 8 | B | KARL (Kernel Address Randomized Link) — уникальное ядро при каждой загрузке |
| 9 | B | Privilege separation — разделение привилегий между частями программы |
| 10 | B | Нарушение pledge вызывает SIGABRT и завершение процесса |
| 11 | B | unveil(NULL, NULL) блокирует добавление новых путей |
| 12 | B | /var/log/authlog содержит логи аутентификации в OpenBSD |
| 13 | B | mtree проверяет целостность файлов по спецификации |
| 14 | B | ASLR — рандомизация адресного пространства |
| 15 | B | chroot изолирует процесс в ограниченной части файловой системы |
