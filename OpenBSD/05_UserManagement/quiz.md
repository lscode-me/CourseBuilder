## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | C | /etc/master.passwd содержит зашифрованные пароли, /etc/passwd — только * |
| 2 | B | Только члены группы wheel могут использовать doas и su для получения root |
| 3 | C | Флаг -m (make home) создаёт домашний каталог |
| 4 | B | /etc/doas.conf — единственный файл конфигурации doas |
| 5 | C | bcrypt — OpenBSD первой внедрила этот безопасный алгоритм |
| 6 | A | login.conf определяет классы входа с лимитами ресурсов и параметрами |
| 7 | B | Системные пользователи начинаются с _ (например, _sshd, _ntp) |
| 8 | B | persist кеширует аутентификацию на 5 минут для удобства |
| 9 | B | usermod -Z блокирует аккаунт, также можно passwd -l |
| 10 | B | /etc/skel содержит шаблонные файлы (.profile, .kshrc и т.д.) |
| 11 | B | id показывает UID, GID и список групп текущего или указанного пользователя |
| 12 | C | groupadd создаёт новую группу в OpenBSD |
| 13 | C | nopass позволяет выполнять команду без запроса пароля |
| 14 | C | Флаг -r (remove) удаляет домашний каталог и почту пользователя |
| 15 | C | ulimit -a показывает все текущие лимиты оболочки |
