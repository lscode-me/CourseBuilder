## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | D | FFS2 (Fast File System) — стандартная файловая система OpenBSD |
| 2 | D | Раздел 'b' традиционно используется для swap в BSD системах |
| 3 | B | Раздел 'c' представляет весь диск и используется для операций с диском целиком |
| 4 | C | DUID (Disk UID) — уникальный идентификатор диска, не меняется при смене порта |
| 5 | A | nosuid игнорирует setuid/setgid биты, повышая безопасность |
| 6 | A | setuid позволяет выполнять программу от имени владельца файла (напр. passwd от root) |
| 7 | A | sticky bit на каталоге позволяет удалять файлы только их владельцам |
| 8 | D | 666 (права по умолчанию) - 022 (umask) = 644 (rw-r--r--) |
| 9 | B | df (disk free) показывает использование разделов, du — размер каталогов |
| 10 | C | softraid предоставляет программный RAID и шифрование дисков |
| 11 | C | fsck нужно запускать на размонтированной FS, иначе можно повредить данные |
| 12 | A | /etc/fstab содержит настройки автоматического монтирования |
| 13 | D | schg (system change) делает файл неизменяемым, снять может только root в single-user |
| 14 | A | /usr/local — место установки пакетов через pkg_add |
| 15 | D | /usr/local часто требует wxallowed для работы некоторых программ (напр. Firefox) |
