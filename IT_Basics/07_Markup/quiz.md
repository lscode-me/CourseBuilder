## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | A | Язык разметки аннотирует текст тегами для структурирования и форматирования. |
| 2 | B | HTML (HyperText Markup Language) — стандарт для веб-страниц. |
| 3 | C | DOCTYPE указывает браузеру использовать стандартный (standards) режим рендеринга. |
| 4 | D | `<nav>` — семантический тег HTML5 для навигации. |
| 5 | A | XML позволяет создавать произвольные теги, HTML имеет фиксированный набор. |
| 6 | B | XML требует точного совпадения регистра открывающего и закрывающего тегов. |
| 7 | C | `&lt;` — entity для символа `<` в XML и HTML. |
| 8 | D | `##` создаёт `<h2>` (заголовок второго уровня). |
| 9 | A | `**текст**` или `__текст__` создают жирный текст. |
| 10 | B | `[текст](url)` — синтаксис ссылки в Markdown. |
| 11 | C | Три обратных кавычки с указанием языка для подсветки синтаксиса. |
| 12 | D | `|` (вертикальная черта) разделяет ячейки таблицы в Markdown. |
| 13 | A | `id` должен быть уникальным на странице, `class` может повторяться. |
| 14 | B | XML документ должен иметь ровно один корневой элемент. |
| 15 | C | `*`, `-` или `+` начинают маркированный список. |
| 16 | D | `method="GET"` или `method="POST"` указывает HTTP метод. |
| 17 | A | SVG (Scalable Vector Graphics) — XML-based формат векторной графики. |
| 18 | B | `> текст` создаёт blockquote (цитату). |
| 19 | C | Namespaces предотвращают конфликты имён при использовании тегов из разных схем. |
| 20 | D | pandoc — универсальный конвертер документов. |
