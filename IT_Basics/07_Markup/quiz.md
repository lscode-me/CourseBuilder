## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Язык разметки аннотирует текст тегами для структурирования и форматирования. |
| 2 | B | HTML (HyperText Markup Language) — стандарт для веб-страниц. |
| 3 | B | DOCTYPE указывает браузеру использовать стандартный (standards) режим рендеринга. |
| 4 | B | `<nav>` — семантический тег HTML5 для навигации. |
| 5 | B | XML позволяет создавать произвольные теги, HTML имеет фиксированный набор. |
| 6 | C | XML требует точного совпадения регистра открывающего и закрывающего тегов. |
| 7 | B | `&lt;` — entity для символа `<` в XML и HTML. |
| 8 | B | `##` создаёт `<h2>` (заголовок второго уровня). |
| 9 | B | `**текст**` или `__текст__` создают жирный текст. |
| 10 | B | `[текст](url)` — синтаксис ссылки в Markdown. |
| 11 | B | Три обратных кавычки с указанием языка для подсветки синтаксиса. |
| 12 | B | `|` (вертикальная черта) разделяет ячейки таблицы в Markdown. |
| 13 | B | `id` должен быть уникальным на странице, `class` может повторяться. |
| 14 | B | XML документ должен иметь ровно один корневой элемент. |
| 15 | A | `*`, `-` или `+` начинают маркированный список. |
| 16 | B | `method="GET"` или `method="POST"` указывает HTTP метод. |
| 17 | B | SVG (Scalable Vector Graphics) — XML-based формат векторной графики. |
| 18 | B | `> текст` создаёт blockquote (цитату). |
| 19 | B | Namespaces предотвращают конфликты имён при использовании тегов из разных схем. |
| 20 | B | pandoc — универсальный конвертер документов. |
