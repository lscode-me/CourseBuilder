## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | Хэш преобразует вход любого размера в фиксированную строку (fingerprint). |
| 2 | B | MD5 = 128 бит = 32 hex символа. |
| 3 | C | SHA-256 = 256 бит = 64 hex символа. |
| 4 | B | Для MD5 найдены практические коллизии, алгоритм криптографически ненадёжен. |
| 5 | B | `sha256sum` — стандартная команда в Linux. |
| 6 | B | `-c` (check) проверяет файлы по списку хэшей. |
| 7 | B | Хэш — односторонняя функция, восстановить вход невозможно. |
| 8 | B | Изменение одного бита входа меняет ~50% бит хэша. |
| 9 | B | Коллизия — когда разные входы дают одинаковый хэш. |
| 10 | C | Нужно `.encode()` для преобразования str в bytes. |
| 11 | B | Блочное чтение позволяет хэшировать файлы больше RAM. |
| 12 | B | Git использует SHA-1 (переход на SHA-256 планируется). |
| 13 | C | bcrypt/argon2 специально разработаны для паролей (медленные, с солью). |
| 14 | B | На macOS используется `shasum -a 256`. |
| 15 | B | Без `-n` echo добавляет `\n`, изменяя хэш. |
