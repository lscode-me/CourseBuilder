# IT Basics
## Фундаментальные концепции: данные, форматы, кодировки

---

## 📚 О курсе

Этот курс охватывает фундаментальные концепции, которые должен знать каждый IT-специалист. Мы разберём вечные темы, которые являются источником множества проблем и недопонимания: кодировки символов, форматы файлов, структурированные данные и многое другое.

### Целевая аудитория

- Начинающие разработчики
- Системные администраторы
- DevOps инженеры
- Data инженеры
- Все, кто работает с данными и файлами

### Предварительные требования

- Базовое умение работать с компьютером
- Опыт работы в командной строке (желательно)
- Понимание основ программирования (желательно)

## 🛠️ Практические требования

### Рекомендуемое окружение

- Linux, macOS или WSL на Windows
- Терминал с bash или zsh
- Текстовый редактор (VS Code, Vim, etc.)

### Полезные инструменты

```bash
# Работа с кодировками
iconv            # Конвертация кодировок
file             # Определение типа файла
xxd, hexdump     # Hex-просмотр

# Работа с JSON/YAML
jq               # Обработка JSON
yq               # Обработка YAML

# Сжатие и хэши
gzip, bzip2, xz  # Сжатие
tar              # Архивация
md5sum, sha256sum # Контрольные суммы

# Кодирование
base64           # Base64 encode/decode
```

### Установка инструментов

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y jq file xxd coreutils

# macOS
brew install jq coreutils

# yq (YAML процессор)
# https://github.com/mikefarah/yq
```
