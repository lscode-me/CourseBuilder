## Question 5: Когда Cloud Native НЕ нужен?

A) Высоконагруженные системы
B) Простое CRUD приложение маленькой команды
C) Микросервисная архитектура
D) Глобальное распределённое приложение

---

## Answer Key

| # | Answer | Explanation |
|---|--------|-------------|
| 1 | B | CNCF (Cloud Native Computing Foundation) — организация, управляющая cloud native проектами. |
| 2 | B | "Cattle" — серверы заменяемы и эфемерны. Сломался — уничтожь и создай новый. |
| 3 | C | MySQL — не CNCF проект. Kubernetes, Prometheus, Helm — graduated CNCF проекты. |
| 4 | B | "Design for failure" — предполагайте, что всё может сломаться, и проектируйте устойчиво. |
| 5 | B | Для простого CRUD с маленькой командой монолит проще и эффективнее. |
